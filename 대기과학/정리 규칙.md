### 1.4 규칙에 반영한 특징

1. **빈칸이 많고(247개) 모든 정답이 PDF 안에 있다.** 단답형의 1순위 재료다. 강의 노트마다 끝에 빈칸 셀프 테스트를 둔다.
2. **필기의 용어는 PDF와 일치한다.** 그래서 용어는 PDF 표기를 그대로 쓴다. 같은 현상에 두 용어를 쓰는 경우(L4 p11 **침적** / L5 p4 **침착**)는 둘 다 적는다.
3. **뜻은 맞아도 용어가 다르면 틀린다.** 빈칸 채점에서 틀린 7개(열적 운동, 지구 대기, 기온 역전층, 저지대, 기온 인자, 적도, 침착)가 모두 이런 경우였다. 이런 용어는 "헷갈림 주의"에 모은다.
4. **그림이 많다.** 에너지 수지(100단위), 기온의 연직 구조, 구름의 고도, 안정도 그래프가 핵심이다. 그림은 말로 풀지 않고 **결론 한 줄과 숫자 표**로 옮긴다.
5. **숫자가 많고 객관식에 나오기 좋다.** 1013.25 hPa, 6.5 ℃/km, 10 ℃/km, 255 K·288 K, 1367 W/m², 알베도 30 같은 값을 강의마다 표로 모은다.
6. **인과 사슬(A → B → C)로 설명하는 슬라이드가 많다.** 서술형 답안의 뼈대가 되므로 화살표 한 줄로 살린다.

## 3. 공통 규칙

| 항목 | 규칙 |
| --- | --- |
| 출처 태그 | `[L3 p6]` = L3 PDF 6쪽. 필기는 `[필기 9/10]`. 모든 bullet·표에 붙인다. |
| 강조 표시 | 🟩**용어** = 빈칸 정답 · 🔴**구절** = 빨간 글씨 · ☆ = 필기 강조 · `(필기)` = 필기에만 있는 내용 · `(보충)` = 내가 덧붙인 설명 |
| 굵게 | 🟩·🔴가 붙은 곳에만 쓴다. 굵은 글씨만 훑어도 시험 포인트가 보이게 한다. |
| 용어 | PDF 표기를 따른다. 필기와 다르면 `⚠ 필기: … / PDF: …`로 둘 다 적는다. 영어가 병기돼 있으면 그대로 둔다. |
| 띄어쓰기 | PDF에서 추출한 문장은 띄어쓰기가 빠져 있으므로 맞춤법대로 띄운다. 빈칸 정답도 띄어 쓴다 (기온 역전층). |
| 범위 | 수업자료와 필기에 있는 내용만 쓴다. 이해에 꼭 필요한 교재식 설명만 `(보충)`으로 짧게 덧붙인다. |
| 쪽 범위 | `p3–13` (en dash). 맨 물결표 `~`는 쓰지 않는다 (취소선으로 렌더링됨). 필요하면 `\~`. |
| 숫자·단위 | 슬라이드 값과 단위를 그대로 쓴다 (hPa, W/m², ℃/km, μm). |

## 6. 새 PDF가 들어올 때 작업 순서

1. **빈칸 추출:** 흰 글씨 빈칸과, 흰 상자에 가려진 초록 글씨 빈칸을 모두 찾는다. 셀프 테스트용으로 쓸 때는 정답을 먼저 보지 않는다.
2. **색 강조 추출:** 빨간 글씨, 테두리, 밑줄, 슬라이드 질문을 찾는다.
3. **필기 사진 매칭:** 날짜와 내용으로 해당 강의를 찾는다.
4. **강의 노트 작성:** 한눈에 보기 → 본문 → 헷갈림 → 숫자 → 서술형 → 셀프 테스트 순서로 쓴다.
5. `빈칸 정답.md`, `정리/README.md`, `시험 대비.md`를 갱신한다.
