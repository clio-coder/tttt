- ★★★ ☆ **세 가지 바람의 힘의 균형** [p4–11]

| 바람 | 어디서 | 힘의 균형 | 방향 |
| --- | --- | --- | --- |
| 🟩**지균풍** 🔵(Geostrophic wind) | 마찰 없는 상층, 직선 등압선 | 기압경도력 = 전향력 | 등압선과 평행. 북반구에서 저기압을 왼쪽, 고기압을 오른쪽에 두고 붊 |
| 🟩**경도풍** 🔵(gradient wind) | 상층, 곡선 등압선 (고·저기압 주위) | 기압경도력·전향력·원심력 | 곡선 등압선과 평행. 북반구 저기압성 = 🟩**반시계**, 고기압성 = 🟩**시계** |
| 지상풍 | 지표 부근 (마찰층 = 행성경계층) | 기압경도력 = 마찰력 + 전향력 (기압경도력 > 전향력) | 등압선을 가로질러 🟩**고기압** → 🟩**저기압**. 북반구 고기압 🟩**시계방향**으로 불어 나감, 저기압 🟩**반시계방향**으로 불어 들어옴 |

- ★★★ **경도풍 vs 지균풍** (등압선 간격이 같을 때) — 고기압성 흐름: 기압경도력 + 원심력 = 전향력 → 지균풍보다 🟩**강함** / 저기압성 흐름: 기압경도력 = 전향력 + 원심력 → 지균풍보다 🟩**약함** [p7]
- ★★★ ☆ **바람과 연직운동** — 지상 저기압: 수렴, 🟩**상승**기류 → 구름·강수, 상공은 발산 / 지상 고기압: 발산, 🟩**하강**기류 → 상대습도 감소, 맑음, 상공은 수렴 [p12]
- ★★ **정역학 평형** — 🟩**중력**과 🟩**연직 기압경도력**이 평형, 연직 가속도 없음: ∂P/∂z = −ρg → 공기가 우주로 빠져나가지 않는 이유 [p13]
- ★★ **지상풍과 마찰** — 마찰력은 풍향 반대 → 풍속 🟩**감소**. 지표에서 멀어질수록 마찰 효과 🟩**감소** → 고도가 높을수록 풍속 증가 [p10]
- ★★ 🟩**저기압성** 흐름(Cyclonic flow): 북반구 반시계, 남반구 시계 / 🟩**고기압성** 흐름(Anticyclonic flow): 북반구 시계, 남반구 반시계 [p8]
- ★★ 상층일기도는 🟩**등압선** 대신 🟩**등고선**을 사용 [p9] · 지균풍의 풍속은 🟩**기압경도**와 직접 관계 [p5]
- ★ 🔵**바람 탐측(sounding)** — 라디오존데(레윈존데), 드롭존데, 윈드프로파일러 [p15–16]

## 본문

### 상공에서의 직선 바람: 지균풍 [p4–5]
- 지표면의 물체·지형에 의한 마찰력이 작용하지 않는 **상층**에서 분다.
- 기압경도력과 전향력이 균형을 이루며 분다 → 🟩**지균풍** 🔵(Geostrophic wind) (☆ 필기 동그라미, "지균 평형")
- 직선으로 일정한 간격을 이루는 등압선(또는 등고선)에서 발생
- 등압선과 **평행**하게 분다 (필기: 등고선과도 평행).
- (북반구) **저기압을 왼쪽에, 고기압을 오른쪽에** 두고 분다.
- 지균풍의 풍속은 🟩**기압경도**와 직접 관계가 있다 [p5] (필기: 기압경도에 비례 = 등압선 간격에 반비례)
  - 상층의 등압선·등고선은 둑과 같다. 폭이 넓으면 느리게, 좁으면 강하게 흐른다. 흐름이 빨라지면 전향력이 커져 기압경도력과 평형을 이룬다.

### 상층 고·저기압 주위의 곡선 바람: 경도풍 [p6–8]
- 곡선 등압선에서는 **기압경도력, 전향력, 원심력**이 균형을 이루며 분다 → 🟩**경도풍** 🔵(gradient wind) (☆ 필기 동그라미)
- 기압경도력과 전향력의 **차이만큼 원심력**이 작용한다.
- 경도풍은 곡선 등압선에 평행하게 분다.
- 북반구: 저기압성 흐름 → 🟩**반시계** 방향 / 고기압성 흐름 → 🟩**시계** 방향 (☆ 필기 밑줄)
- 실제 대기에서는 바람이 직선이 아니라 곡선 경로를 따라 분다.

**등압선 간격이 같을 때 (= 기압경도력이 같을 때)** [p7]

| 흐름 | 힘의 관계 | 지균풍과 비교 |
| --- | --- | --- |
| 고기압성 흐름 | 기압경도력 + 원심력 = 전향력 | 지균풍보다 🟩**강함** |
| 저기압성 흐름 | 기압경도력 = 전향력 + 원심력 | 지균풍보다 🟩**약함** |

- (보충) 고기압 둘레에서는 원심력이 기압경도력과 같은 바깥쪽으로 작용해 전향력이 더 커야 하므로(= 풍속이 커야 하므로) 더 강하다.

**🔵저기압성 흐름의 반구별 회전 방향** [p8]

| | 북반구 | 남반구 |
| --- | --- | --- |
| 🟩**저기압성** 흐름 (Cyclonic flow) | 반시계 방향 | 시계 방향 |
| 🟩**고기압성** 흐름 (Anticyclonic flow) | 시계 방향 | 반시계 방향 |

### 상층일기도상의 바람 [p9]
- 상층일기도는 🟩**등압선** 대신 🟩**등고선**을 사용한다 → 상층일기도의 등고선은 지상일기도의 등압선과 같은 의미로 해석한다.
- **남북류**(meridional wind)와 **동서류**(zonal wind)

### 지상풍 [p10–11]
- 지상 바람은 지표면 마찰의 영향을 받는다.
- 마찰력이 바람에 미치는 영향
  - 마찰력은 바람이 부는 방향의 반대로 작용 → 풍속 🟩**감소**
  - 지표면에서 멀어질수록 마찰 효과는 🟩**감소**한다 → 고도가 증가하면 풍속 증가
  - 바람이 등압선을 가로질러 🟩**고기압**에서 🟩**저기압**으로 분다.
  - 지상 마찰의 영향을 받는 대기층: **마찰층** 또는 **행성경계층**
- 지표면 부근: 마찰로 풍속 감소 → 전향력↓ → **기압경도력 > 전향력** → **기압경도력 = 마찰력 + 전향력** [p11]
- 북반구 기준 (☆ 필기 물결 밑줄)
  - 고기압: 🟩**시계방향**으로 불어 나감
  - 저기압: 🟩**반시계방향**으로 불어 들어옴
  - 🔵**남반구는 반대**
- 지상풍과 등압선이 이루는 각도: **마찰이 클수록 커진다.**

### 바람과 연직운동 [p12–13]

| | 지상 저기압 중심 | 지상 고기압 중심 |
| --- | --- | --- |
| 지상 흐름 | 나선형으로 공기 **수렴** | 나선형으로 공기 **발산** |
| 연직운동 | 🟩**상승**기류 | 🟩**하강**기류 |
| 날씨 | 구름 및 강수 형성 가능 (☆ 필기 동그라미) | 하강하며 상대습도 감소 → 맑은 하늘 (☆ 필기 동그라미) |
| 상공 | 발산 | 수렴 |

- 기압은 고도가 증가하면 감소한다. **공기는 왜 우주 공간으로 빠져나가지 않는가?** [p13]
  → 연직 방향으로 힘의 균형이 있다: **정역학 평형**(hydrostatic equilibrium)
  - 🟩**중력**과 🟩**연직 기압경도력**이 평형을 이룬 상태
  - 연직 가속도가 없다.
  - 강한 상승·하강 운동이 있으면 정역학 평형이 깨질 수 있다.
  - $\dfrac{\partial P}{\partial z}=-\rho g$

### 바람을 측정하는 기구 [p14–16]
- **풍향계**(wind vane): 화살이 항상 바람을 향해 있어 풍향을 알 수 있다.
- **풍속계**(anemometer): 컵 회전 속도를 기계로 풍속으로 환산
- **풍향풍속계**(aerovane): 풍속과 풍향을 함께 측정
- 건물·나무 같은 국지적 조건의 영향(오류)을 피하도록 건물 지붕 꼭대기 등 **높이** 설치해야 한다.
- 🔵**바람 탐측(sounding)** [p15–16]
  - **라디오존데**(Radiosonde): 풍선에 기기를 달아 띄워 관측. 라디오존데로 바람을 관측하면 **레윈존데**(Rawinsonde) 관측
  - **드롭존데**(Dropsonde): 관측 장비를 낙하산에 달아 항공기에서 떨어뜨려 관측. 자료가 부족한 지역이나 태풍·허리케인 같은 특별한 경우에 사용
  - **윈드프로파일러**: 도플러 레이더로 고해상도 바람 연직 분포를 관측. 약 **16 km** 이상 고도까지 풍속·풍향의 연직 구조 제공

## 헷갈림 주의

- **지균풍** = 기압경도력 = 전향력 (직선, 상층) / **경도풍** = 기압경도력·전향력·원심력 (곡선, 상층) / **지상풍** = 기압경도력 = 마찰력 + 전향력.
- 같은 기압경도에서 **고기압성 경도풍 > 지균풍 > 저기압성 경도풍** (풍속).
- 북반구 저기압 = **반시계**(들어옴), 고기압 = **시계**(나감). **남반구는 반대**.
- 지균풍: 북반구에서 **저기압이 왼쪽**, 고기압이 오른쪽.
- 지상풍이 등압선과 이루는 각도는 **마찰이 클수록 크다**. 지표에서 멀어질수록 마찰 효과 **감소**, 풍속 **증가**.
- 지상 **저기압 = 수렴·상승·구름**, 상공은 **발산** / 지상 **고기압 = 발산·하강·맑음**, 상공은 **수렴**.
- 정역학 평형 = **중력 ↔ 연직 기압경도력**. 수평 바람의 힘(기압경도력 ↔ 전향력)과 헷갈리지 말 것.
- **레윈존데** = 라디오존데로 바람 관측 / **드롭존데** = 항공기에서 낙하산으로 / **윈드프로파일러** = 도플러 레이더, 약 16 km.

## 서술형 대비

<details><summary>Q1. 지균풍이 등압선과 평행하게 부는 이유는? [p4–5]</summary>

마찰이 없는 상층에서는 공기가 기압경도력을 받아 움직이기 시작하면 전향력이 운동 방향의 직각(북반구 오른쪽)으로 작용해 바람을 휘게 한다. 바람이 등압선과 평행해지면 기압경도력(저기압 쪽)과 전향력(고기압 쪽)이 크기가 같고 방향이 반대가 되어 균형을 이룬다. 이 바람이 지균풍이며 북반구에서는 저기압을 왼쪽에 두고 분다. 풍속은 기압경도에 비례한다.
</details>

<details><summary>Q2. 같은 등압선 간격에서 고기압성 흐름이 저기압성 흐름보다 강한 이유는? [p7]</summary>

곡선 운동에는 원심력이 작용한다. 고기압성 흐름에서는 기압경도력과 원심력이 모두 바깥쪽이라 전향력 = 기압경도력 + 원심력이 되어 전향력, 곧 풍속이 지균풍보다 커야 한다. 저기압성 흐름에서는 기압경도력(안쪽) = 전향력 + 원심력이라 전향력이 기압경도력보다 작아 지균풍보다 약하다.
</details>

<details><summary>Q3. 지상풍이 등압선을 가로질러 부는 이유와 북반구 고·저기압의 지상풍 방향은? [p10–11]</summary>

지표 부근에서는 마찰력이 풍속을 줄이고 그에 따라 전향력도 줄어, 기압경도력 = 마찰력 + 전향력이 되어 기압경도력이 전향력보다 크다. 그래서 바람이 등압선을 비스듬히 가로질러 고기압에서 저기압으로 분다. 북반구에서 고기압에서는 시계 방향으로 불어 나가고, 저기압으로는 반시계 방향으로 불어 들어온다. 마찰이 클수록 등압선과의 각도가 커진다.
</details>

<details><summary>Q4. 지상 저기압에서 날씨가 흐리고 고기압에서 맑은 이유는? [p12]</summary>

지상 저기압 중심으로 공기가 나선형으로 수렴하면 쌓인 공기가 상승해(상공은 발산) 단열냉각으로 구름과 강수가 생긴다. 지상 고기압에서는 공기가 발산해 위에서 공기가 내려오고(상공은 수렴), 하강하며 승온해 상대습도가 줄어 맑다.
</details>

<details><summary>Q5. 기압이 위로 갈수록 낮은데 공기가 우주로 빠져나가지 않는 이유는? [p13]</summary>

위쪽(낮은 기압)으로 향하는 연직 기압경도력과 아래로 당기는 중력이 평형을 이루는 정역학 평형 상태이기 때문이다. 연직 가속도가 없으며 ∂P/∂z = −ρg로 나타낸다. 강한 상승·하강 운동이 있으면 깨질 수 있다.
</details>
