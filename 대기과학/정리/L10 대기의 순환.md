## 한눈에 보기 (시험 가능성 순)

범례: ★★★ 빈칸 + 빨강·파랑·필기 강조 겹침, 또는 슬라이드 질문 · ★★ 빈칸 · ★ 빨강·파랑 글씨

- ★★★ ☆ **푄(치눅) 바람** — 산맥을 넘은 뒤 풍하측 사면을 따라 부는 🟩**덥고 건조한** 바람. 풍상측: 상승하며 🟩**단열팽창냉각** → 구름·강수 / 풍하측: 하강하며 🟩**단열압축가열** → 🔴**저지대에 덥고 건조한 바람**. 주 열원 = 단열압축가열 [p14]
- ★★★ **우리나라의 푄** — 🟩**저지 푄 기작**(풍상측 저층에 차고 안정한 공기, 산 정상보다 높은 공기만 넘어옴, 풍상측 🟩**구름 형성** 없음) / 🔵🟩**양간지풍**(봄, 서풍 → 영동 건조·고온 강풍, 산불) · 🔵🟩**높새바람**(동풍 → 영서 건조·고온) [p15–18]
- ★★★ ☆ **해륙풍** — 육지와 바다의 비열 차 → 차등 가열 → 🟩**기압경도력**. 낮 해풍, 밤 육풍. 육풍이 해풍보다 약함(온도차 밤 < 낮). 해풍의 앞면 = 🟩**해풍전선** [p8–9]
- ★★★ ☆ **몬순(계절풍)** — 여름: 대륙이 빠르게 🟩**가열** → 대륙 저기압, 해양에서 🟩**반시계** 방향 습한 바람 / 겨울: 대륙이 빠르게 🟩**냉각** → 대륙 고기압, 🟩**시계** 방향 건조 바람. 🟩**장마** = 동아시아 여름 몬순의 일부 [p10–11]
- ★★★ **산곡풍** — 🟩**골바람**(🟩**낮**, 계곡 → 산정상, 정상부 구름) / 🟩**산바람**(🟩**밤**, 산비탈 냉각 → 하강, 야간 배출풍·중력풍) [p12]
- ★★ **맴돌이** — 🟩**난류** = 맴돌이가 포함된 불규칙한 흐름. 🟩**두루마리 맴돌이**(rotor) = 산맥 풍하측, 산악파 마루 밑 → 항공기 위험. 상층은 🟩**바람시어**로 맴돌이, 청천난류 [p5–6]
- ★★ **열순환** — 남쪽 가열·북쪽 냉각 → 상공에 🟩**수평기압경도력** → 상층 공기 남 → 북, 지상은 남쪽 저기압·북쪽 고기압 [p7]
- ★★ **활강바람** — 눈 덮인 🟩**고원지대**에서 냉각된 찬 공기가 사면을 따라 하강. 🟩**산바람**보다 크고 강함 (50 m/s 이상도) [p13]
- ★★ **산타아나 바람**(캘리포니아 🟩**대형산불 발생**) · 🟩**하부브**(뇌우의 🟩**하강기류** → 먼지 장벽) · 🟩**먼지 회오리** [p19–21]
- ★ **대기운동의 규모** — 미규모 · 중규모 · 종관규모 · 지구(행성) 규모 [p3–4]

## 본문

### 대기운동의 각종 규모 [p3–4]

| 규모 | 수평 규모 | 예 | 지속 시간 |
| --- | --- | --- | --- |
| 미규모 (microscale) | 수 m 이하 | 작은 맴돌이, 먼지 회오리 | 수초–수분 |
| 중규모 (mesoscale) | 수 km–수백 km | 해륙풍, 뇌우, 토네이도, 작은 열대폭풍 (필기: 산곡풍) | 수십 분–하루 |
| 종관규모 (synoptic scale) | 수백 km–수천 km | 중위도 고·저기압, 전선 ("일기도" 규모) | 수일–수주일 |
| 지구(행성) 규모 (planetary scale) | 수천 km 이상 | 행성파 | 일주일 이상 |

- 작은 미규모 운동은 더 큰 중규모 운동의 일부이고, 중규모 운동은 훨씬 큰 종관규모 운동의 일부다. [p4]
- 규모가 커질수록 작은 규모에서 보이던 운동은 더 이상 보이지 않는다. (필기: 규모↑ → 유지 시간↑)

### 맴돌이 [p5–6]
- **맴돌이**: 공기 흐름 속에서 생기는 소용돌이 운동. 규모는 장애물의 크기·모양과 바람의 속도에 좌우
- 🟩**난류**(turbulence): 맴돌이가 포함된 불규칙적이고 거친 바람의 흐름 (필기: 대류성 난류, 산악파 난류)
- **지표 부근 맴돌이**: 건물·나무·산맥 같은 장애물을 지나는 바람 때문에 **풍하측**에 생긴 소용돌이
  - 🟩**두루마리 맴돌이**(rotor): 산맥 풍하측, 산악파의 마루 밑마다 생긴 맴돌이. 격렬한 연직운동을 동반해 **항공기 운행에 위험** (☆ 필기 파란 펜)
- **상층 맴돌이** [p6]
  - 🟩**바람시어**로 인해 강한 혼합과 맴돌이가 생길 수 있다. (☆ 필기 파란 펜)
  - 바람시어(wind shear): 풍속이나 풍향이 급격히 변하는 현상
  - **청천난류**(clear-air turbulence): 맑은 대기에서 생긴 난류. 주로 **상층 제트류 주변**. (필기: 구름·강수 없이 생겨 관측이 어려워 경고·예측이 필요)
  - 바람시어가 강한 층의 맴돌이가 구름 모양으로 나타난 것: Kelvin-Helmholtz billow

### 국지풍계 [p7–21]

**1) 열순환** [p7]
- 따뜻한 공기는 상승하고 찬 공기는 하강하는, 온도 차에 따른 순환
- 처음: 등압면이 모두 지표면과 평행 → 수평 기압경도 없음 → 바람 없음
- ☆ 남쪽 가열, 북쪽 냉각 (필기 물결 밑줄)
  - 북쪽: 밀도 커짐, 등압면 조밀 / 남쪽: 밀도 작아짐, 등압면 간격 넓어짐
- 상공에 🟩**수평기압경도력** 발생 (☆ 필기 밑줄) → 상공의 공기가 남쪽에서 북쪽으로 이동
- → 지상 기압경도 발생: **남쪽 저기압, 북쪽 고기압** (→ L8 p6 공기기둥과 같은 원리)

**2) 해륙풍** [p8–9]
- 열순환의 일종. ☆ 하루 주기 (필기)
- 육지와 바다의 **비열 차이**에 의한 차등 가열이 원인 → 🟩**기압경도력** 발생
- 낮: **해풍**(sea breeze, 바다 → 육지) / 밤: **육풍**(land breeze, 육지 → 바다)
- **오후**에 강도가 가장 큼 → 육지와 수면의 기온 차가 최대
- **육풍은 해풍보다 약함** → 육지와 수면의 온도차: 밤 < 낮 (☆ 필기 "!")
- 🟩**해풍전선**: 해풍의 앞면 [p9]
  - 해풍이 내륙으로 전진 → 상대적으로 차고 밀도 큰 해양 공기와 따뜻한 육지 공기가 만나는 경계
  - 여름철 플로리다 남부: 지면 가열 + 해풍 수렴 → 강한 상승기류 → 적운·뇌우, 대류성 강수

**3) 몬순(계절풍)** [p10–11]: 계절에 따라 풍향이 바뀌는 순환

| | 여름 | 겨울 |
| --- | --- | --- |
| 원인 | 대륙이 해양보다 빠르게 🟩**가열** | 대륙이 해양보다 빠르게 🟩**냉각** |
| 기압 | 대륙 저기압역 / 해양 고기압역 | 대륙 고기압역 / 해양 저기압역 |
| 바람 | 해양 → 대륙, 🟩**반시계** 방향으로 습한 바람 불어 들어옴 (☆ 필기 밑줄) | 대륙 → 해양, 🟩**시계** 방향으로 건조 바람 불어 나감 |
| 대륙 날씨 | 강한 상승기류, 뇌우, 우기 | 건조하고 맑은 하늘 |

- 아시아 남부와 동부에서 가장 강하게 발달. 온난습윤한 여름 & 한랭건조한 겨울 [p11]
- 여름 몬순이 인도 연강수량의 약 75–80%를 공급 (대부분의 비가 여름 몬순 우기 4–10월에)
- **대륙 규모의 해륙풍 순환**으로 이해 (필기: 육지·해양의 비열 차로 계절 단위로 생기는 대륙 규모의 해륙풍)
- "몬순"은 여름 계절풍이 가져오는 우기나 그 비를 부르기도 한다.
- 🟩**장마**: 우리나라에 영향을 주는 동아시아 여름 몬순 시스템의 일부. 여름철 많은 비가 내리는 강수 시기 (☆ 필기 네모)

**4) 산곡풍** [p12]: 산비탈을 따라 부는 바람

| | 🟩**골바람** (valley breeze) | 🟩**산바람** (mountain breeze) |
| --- | --- | --- |
| 때 | 🟩**낮** ("곡풍") | 🟩**밤** ("산풍") |
| 원인 | 산비탈면이 낮에 가열 → 인접 공기의 밀도가 같은 고도 공기보다 낮아짐 | 산비탈면이 밤에 빠르게 냉각 → 인접한 차고 밀도 큰 공기가 비탈을 따라 하강 |
| 방향 | 계곡 → 산 정상 (활승) | 산 → 계곡 |
| 특징 | 정상부에 구름 발달 | 야간 배출풍 또는 중력풍 |

**5) 활강바람** [p13]
- 눈 덮인 🟩**고원지대**에서 냉각된 찬 공기가 산사면을 따라 하강하는 바람 (☆ 필기 밑줄)
- 🟩**산바람**보다 더 큰 규모로 강하게 부는 바람 (☆ 필기 밑줄)
- 지형(협곡, 좁은 수로)에 의해 집중되면 매우 강하게 발달 → 허리케인급(50 m/s 이상)도 가능

**6) 치눅(푄) 바람** [p14–18]
- ☆ **푄**: 공기덩이가 산맥을 넘은 뒤 산맥의 **풍하측** 경사면을 따라 아래로 부는 🟩**덥고 건조한** 바람 (필기 ☆, 파란 펜)
- 풍상측: 공기가 상승하며 🟩**단열팽창냉각** → 구름 형성 / 강수 발생
- 풍하측: 건조 공기가 하강하며 🟩**단열압축가열** → 🔴**저지대에 덥고 건조한 바람** (☆ 필기 물결 밑줄)
- 푄 바람 온기의 **주 열원: 단열압축가열** (→ L6 p25 풍하측이 따뜻한 이유와 같다)
- 이름: 치눅 바람(미국 로키산맥), 푄 바람(유럽 알프스), 높새바람(동해안에서 태백산맥을 넘어 서쪽 사면으로 부는 바람)
- **저지 푄 기작** [p15] (고전적인 푄 기작과 결과는 같다)
  - 풍상측: 저층에 차고 안정한 공기층이 있음
  - 산 정상보다 높은 고도의 따뜻하고 건조한 공기만 산맥을 넘어 하강
  - 풍상측 🟩**구름 형성** 없음 (필기: 풍상측 강수 X, 구름 X ↔ 열역학적 푄 기작은 구름·강수 있음)
- 🔵**높새바람** [p16]: 2011년 5월 24일 사례 — 북동쪽 고기압에서 온 차고 습한 공기가 태백산맥을 넘어 서쪽에 따뜻하고 건조한 공기가 됨 → 산맥 서쪽(영서)의 낮 최고기온이 높게 나타남 (그림 7.13)
- 🔵**양간지풍** [p17–18]: 강원도 양양과 간성 사이에서 부는 국지적 강풍. 봄철 영동지방의 주된 강풍 (서풍류), 🟩**저지 푄 기작**
  - 🟩**양간지풍**: 영동지방에 건조·고온 **강풍** 영향 (필기: 서 → 동, 태백산맥 동쪽 경사가 매우 급함!)
  - 🟩**높새바람**: 영서지방에 건조·고온 바람 영향 (필기: 동 → 서)
  - 산불 발생 위험 증가와 빠른 확산 — 2005년 양양 일대 산불(낙산사 소실)

**7) 산타아나 바람** [p19]
- 미국 캘리포니아 남부를 향해 동쪽이나 북동쪽에서 부는 온난 건조 바람
- 높은 사막 고원에서 침강하는 공기가 산 계곡을 따라 불어 내려옴. 미 서부 대분지 상공에 고기압역이 생기면 잘 발달
- 사막에서 온 건조 공기 + 압축 가열 → 매우 건조한 고온 바람 (상대습도 10% 이하)
- 캘리포니아주 🟩**대형산불 발생**과 관련이 높다.

**8) 사막의 바람** [p20–21]
- 🟩**하부브**: 뇌우의 강한 🟩**하강기류**가 지면에 닿아 퍼지면서 먼지·모래를 들어 올려 만든 거대한 먼지 장벽 / 강한 모래폭풍, 먼지폭풍 (아프리카 수단, 아라비아반도, 미국 남서부 사막) (☆ 필기 파란 펜)
- 🟩**먼지 회오리**: 맑고 더운 날 지상의 먼지나 모래를 끌어올리는 상승·회전하는 공기 기둥 (☆ 필기 파란 펜)
  - 강하게 가열된 지표 부근의 **불안정한 대기**에서 형성
  - 주변 지형 장애물로 굴절된 바람이 상승 공기를 회전시킴 → 시계·반시계 방향 둘 다 가능
  - 직경 수 m, 높이 대부분 100 m 이하, 지속시간 짧음

## 헷갈림 주의

- **미규모 < 중규모 < 종관규모 < 지구 규모**. 해륙풍·뇌우·토네이도 = **중규모**, 고·저기압·전선 = **종관규모**.
- 두루마리 맴돌이(rotor) = **산맥 풍하측**, 산악파 마루 밑 / 청천난류 = **맑은 하늘, 상층 제트류 주변**.
- 열순환: 상공은 **가열된 쪽 → 냉각된 쪽**, 지상은 가열된 쪽이 **저기압**.
- 해풍(낮)이 육풍(밤)보다 **강하다**. 강도는 **오후**에 최대.
- 몬순 여름 = 대륙 **저기압**, 해양 → 대륙 **반시계** / 겨울 = 대륙 **고기압**, 대륙 → 해양 **시계**.
- **골바람 = 낮, 올라감** / **산바람 = 밤, 내려감**. 활강바람은 산바람보다 **크고 강함**(고원지대).
- 푄의 열원은 **단열압축가열**(풍하측). 풍상측은 **단열팽창냉각**.
- **저지 푄 기작** = 풍상측에 **구름 없음** (차고 안정한 저층). 고전적(열역학적) 푄 = 풍상측에 구름·강수.
- **양간지풍 = 서 → 동, 영동, 봄, 강풍, 산불** / **높새바람 = 동 → 서, 영서**.
- 산타아나 = **캘리포니아 산불** / 하부브 = **뇌우의 하강기류**가 만든 먼지 장벽 / 먼지 회오리 = **불안정한 대기의 상승·회전 기둥**, 시계·반시계 둘 다.
- ⚠ 하부브는 필기에 "하부브", PDF도 **하부브**.

## 서술형 대비

<details><summary>Q1. 해륙풍의 원리와, 육풍이 해풍보다 약한 이유는? [p8]</summary>

육지와 바다의 비열 차이로 낮에는 육지가 더 빨리 데워져 육지 위가 상대적 저기압이 되고 바다에서 육지로 해풍이 분다. 밤에는 육지가 더 빨리 식어 육지에서 바다로 육풍이 분다. 밤의 육지·수면 온도차가 낮보다 작아 기압경도력이 약하므로 육풍이 해풍보다 약하다. 해풍은 기온차가 최대인 오후에 가장 강하다.
</details>

<details><summary>Q2. 여름 몬순과 겨울 몬순을 비교하라. [p10–11]</summary>

여름에는 대륙이 해양보다 빨리 가열되어 대륙에 저기압, 해양에 고기압이 생기고, 해양에서 대륙으로 반시계 방향의 습한 바람이 불어 들어와 대륙에서 강한 상승기류·뇌우·우기가 생긴다. 겨울에는 대륙이 빨리 냉각되어 대륙에 고기압이 생기고 대륙에서 해양으로 시계 방향의 건조한 바람이 불어 나가 대륙은 건조하고 맑다. 대륙 규모의 해륙풍 순환이며, 장마는 동아시아 여름 몬순의 일부다.
</details>

<details><summary>Q3. 푄(치눅) 바람이 덥고 건조한 이유는? [p14]</summary>

풍상측에서 공기가 산을 타고 오르며 단열팽창 냉각되어 구름이 생기고 비를 뿌려 수증기를 잃는다(응결 잠열도 방출). 산을 넘은 건조한 공기는 풍하측 사면을 내려가며 단열압축 가열되어(건조단열감률 10 ℃/km) 저지대에 덥고 건조한 바람이 된다. 주 열원은 단열압축 가열이다.
</details>

<details><summary>Q4. 저지 푄 기작은 고전적 푄과 어떻게 다른가? 양간지풍과 높새바람을 비교하라. [p15–17]</summary>

저지 푄 기작에서는 풍상측 저층에 차고 안정한 공기층이 막혀 있어, 산 정상보다 높은 곳의 따뜻하고 건조한 공기만 산을 넘어 내려온다. 그래서 풍상측에 구름·강수가 없다. 양간지풍은 봄철 서풍이 태백산맥을 넘어 영동지방(양양–간성)에 부는 건조·고온 강풍으로 저지 푄 기작이며 산불을 키운다. 높새바람은 동쪽에서 태백산맥을 넘어 영서지방에 부는 건조·고온 바람이다.
</details>

<details><summary>Q5. 골바람과 산바람, 활강바람을 비교하라. [p12–13]</summary>

골바람은 낮에 산비탈면이 가열되어 인접 공기가 같은 고도의 공기보다 가벼워져 계곡에서 산 정상으로 올라가는 바람으로, 정상부에 구름이 생긴다. 산바람은 밤에 산비탈면이 냉각되어 차고 무거운 공기가 비탈을 따라 내려가는 바람(야간 배출풍)이다. 활강바람은 눈 덮인 고원지대에서 냉각된 찬 공기가 사면을 따라 내려가는 바람으로 산바람보다 크고 강하며, 지형에 집중되면 50 m/s 이상이 되기도 한다.
</details>
