# 대기과학

## 학습목표

지구를 둘러싼 대기의 구조와 그 안에서 일어나는 다양한 규모의 기상현상 및 대기운동을 학습한다. 기후변화, 대기오염, 오존층 파괴 등 최근의 대기·지구환경 변화도 다룬다. 자연과학 전공자에게 대기현상 전반의 지식을 소개하여 지구 대기환경 문제를 이해하게 하고, 대기과학 전공에 관심 있는 학생이 대기과학의 전체적인 모습을 파악하도록 한다.
