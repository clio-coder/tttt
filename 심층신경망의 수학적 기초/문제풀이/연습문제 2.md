## 문제 1. Hessian과 smoothness ★★

[근거] Descent Lemma와 ③ [06 §6.2](../중간고사%20정리/06%20최적화.md) · GD 감소 조건 [06 §6.3](../중간고사%20정리/06%20최적화.md) · 로지스틱 Hessian [03 §3.1](../중간고사%20정리/03%20분류.md)

$f\in C^2$라 하자. 수업(9/28)에서는 " $\nabla f$가 $\beta$-Lipschitz ⇒ $-\beta I\preceq\nabla^2f\preceq\beta I$ "를 보였다.

**(a)** 역을 보여라: 모든 $x$에서 $-\beta I\preceq\nabla^2f(x)\preceq\beta I$ 이면 $\nabla f$는 $\beta$-Lipschitz다.
*Hint.* 보조식 $(\ast)$ $\nabla f(y)-\nabla f(x)=\big(\int_0^1\nabla^2f(x+t(y-x))\thinspace dt\big)(y-x)$ 와, 대칭행렬 $A$의 고윳값이 모두 $[-\beta,\beta]$ 안에 있으면 $\lVert Av\rVert\le\beta\lVert v\rVert$ 임을 써도 된다.

**(b)** $y_i\in\lbrace0,1\rbrace$ 로지스틱 손실 $J(w)=-\sum_i[y_i\log\sigma(w^\top x_i)+(1-y_i)\log(1-\sigma(w^\top x_i))]$ 의 Hessian은 $X^\top SX$, $S=\mathrm{diag}(\sigma_i(1-\sigma_i))$ 이다 (03장). $J$가 $\beta=\frac14\lambda_{\max}(X^\top X)$ 로 smooth함을 보이고, GD가 매 스텝 $J$를 줄이는 step size 범위를 써라.

**(c)** 데이터 두 개 $x_1=(1,1)$, $x_2=(1,-1)$ (행)일 때 (b)의 $\beta$와 step 범위를 구하라.

**(d)** 1차원 함수 $f(x)=\log(1+e^{-x})+\log(1+e^{x})$ ( $y=1$인 점과 $y=0$인 점이 하나씩 있는 로지스틱 손실)에 대해
  1. $f'(x)=2\sigma(x)-1$, $f''(x)=2\sigma(x)(1-\sigma(x))$ 를 보이고 $f$가 $\beta=\frac12$로 smooth함을 보여라.
  2. $x_0=2$, $\eta=1/\beta=2$로 GD를 한 스텝 가라. $x_1$, $f(x_0)$, $f(x_1)$을 구하고, GD 한 스텝 부등식이 주는 상계와 비교하라. ( $f'(2)\approx0.7616$ )

## 문제 2. SGD: 2차 모멘트 분해와 분산 가정의 수렴 ★

[근거] SGD lemma와 수렴 [06 §6.4](../중간고사%20정리/06%20최적화.md) · mini-batch [05 §5.1](../중간고사%20정리/05%20학습%20기술.md)

$f=\frac1n\sum_if_i$ 는 $L$-smooth, SGD $x_{t+1}=x_t-\eta g_t$, $\mathbb E_t[g_t]=\nabla f(x_t)$ (불편).

**(a)** $\mathbb E_t\lVert g_t\rVert^2=\lVert\nabla f(x_t)\rVert^2+\mathbb E_t\lVert g_t-\nabla f(x_t)\rVert^2$ 를 보여라. 슬라이드가 $\mathbb E_t\lVert g_t\rVert^2$을 "variance"라 부른 것이 정확하지 않은 이유를 한 문장으로 설명하라.

**(b)** 수업의 가정 ③( $\mathbb E_t\lVert g_t\rVert^2\le G$ ) 대신 **분산 가정** $\mathbb E_t\lVert g_t-\nabla f(x_t)\rVert^2\le\sigma^2$ 을 두자. SGD lemma와 (a)로

$$\mathbb E_t[f(x_{t+1})]\le f(x_t)-\eta\Big(1-\frac{L\eta}2\Big)\lVert\nabla f(x_t)\rVert^2+\frac{L\eta^2\sigma^2}2$$

를 보이고, $\eta\le1/L$ 이면

$$\min_{k}\mathbb E\lVert\nabla f(x_k)\rVert^2\le\frac{2(f(x_0)-f_\ast)}{\eta T}+L\eta\sigma^2$$

임을 보여라 ( $f\ge f_\ast$ , $T$번 반복).

**(c)** (b)의 결론에서 $\sigma^2=0$ (잡음 없는 GD)이면 수렴 속도는? $\sigma^2>0$일 때 $\eta=\min(1/L,\thinspace1/\sqrt T)$로 잡으면?

**(d)** batch 크기 $B$인 mini-batch를 쓰면 분산이 $\sigma^2/B$가 된다 (연습문제 1 문제 8). (b)의 우변의 두 번째 항은 어떻게 바뀌는가? 같은 계산량 $BT=$ 일정으로 비교하면 $B$를 키우는 것이 항상 이득인가? 한두 문장으로 답하라.

## 문제 3. 이차함수에서 momentum ★★

[근거] 조건수 예제 [06 §6.5](../중간고사%20정리/06%20최적화.md) · momentum [06 §6.6](../중간고사%20정리/06%20최적화.md)

수업 예제 $f(x_1,x_2)=\frac12x_1^2+\frac{100}2x_2^2$ 에서 GD는 $\alpha=0.019$일 때 좌표별 배율이 0.981, −0.9였다. 좌표마다 따로 볼 수 있으므로 1차원 $f(x)=\frac\lambda2x^2$ 을 생각한다 ( $\lambda=1$ 또는 100).

**(a)** momentum $x_{t+1}=x_t-\alpha\nabla f(x_t)+\rho(x_t-x_{t-1})$ 을

$$\begin{pmatrix}x_{t+1}\cr x_t\end{pmatrix}=M\begin{pmatrix}x_t\cr x_{t-1}\end{pmatrix}$$

꼴로 쓰고 $M$ ( $2\times2$ )을 구하라.

**(b)** $M$의 고윳값 $z$는 $z^2-(1-\alpha\lambda+\rho)z+\rho=0$ 의 근이다. 두 근이 **복소수**이면 $\lvert z\rvert=\sqrt\rho$ 임을 보여라. 근이 복소수일 조건이 $(1-\sqrt\rho)^2\lt\alpha\lambda\lt(1+\sqrt\rho)^2$ 임을 보여라.
*Hint.* 두 근의 곱 = 상수항. 복소수 근은 켤레다.

**(c)** $\rho=0.81$로 두자. $\lambda=1$과 $\lambda=100$ **둘 다** 복소수 근이 되는 $\alpha$의 범위를 구하고, $\alpha=0.02$가 그 안에 있음을 확인하라. 이때 두 방향 모두 매 스텝 대략 $\sqrt\rho=0.9$배로 줄어든다.

**(d)** 상수 step GD의 가장 좋은 배율은 $\frac{99}{101}\approx0.980$ 이었다 (06 §6.5 보충). 100스텝 뒤 오차가 대략 몇 배로 줄어드는지 GD와 momentum을 비교하라. 06 §6.6의 "부호가 바뀌는 방향은 지워지고 같은 방향은 쌓인다"를 이 결과와 연결하라.

## 문제 6. Batch Normalization ★

[근거] [05 §5.4](../중간고사%20정리/05%20학습%20기술.md)

한 채널의 batch 값 $x_1,\dots,x_N$, $\mu=\frac1N\sum x_i$, $\sigma^2=\frac1N\sum(x_i-\mu)^2$, $\hat x_i=\frac{x_i-\mu}{\sqrt{\sigma^2+\varepsilon}}$, $y_i=\gamma\hat x_i+\beta$

**(a)** $\hat x_1,\dots,\hat x_N$의 평균이 0이고, 분산이 $\frac{\sigma^2}{\sigma^2+\varepsilon}$ (≈ 1)임을 보여라.

**(b)** $\gamma=\sqrt{\sigma^2+\varepsilon}$, $\beta=\mu$ 이면 $y_i=x_i$ (항등함수)임을 보여라. 슬라이드의 " $\gamma=\sigma$, $\beta=\mu$ "와의 차이는?

**(c)** 테스트 때는 $\mu,\sigma^2$이 running 평균으로 고정된다. BN 앞에 FC 층 $z=Wx+b$ 가 있을 때, BN까지 합친 것이 $W'x+b'$ 꼴의 FC 층 하나와 같음을 보이고 $W'$, $b'$을 구하라.

**(d)** 학습 때 BN 앞 층의 가중치와 편향을 모두 $c\gt0$배 하면( $W\to cW$, $b\to cb$ ) BN 출력이 바뀌지 않음을 보여라 ( $\varepsilon=0$으로 근사). 슬라이드의 장점 "scale invariance → 큰 learning rate에서도 덜 발산"과 연결하라.

**(e)** $x=(1,2,3,6)$, $\gamma=2$, $\beta=1$, $\varepsilon\approx0$ 일 때 $\mu$, $\sigma^2$, $\hat x$, $y$를 구하라.

## 문제 8. Equivariance와 invariance ★★

[근거] 정의와 증명 [07 §7.1–7.2](../중간고사%20정리/07%20CNN.md)

1차원 신호 $x[i]$ ( $i\in\mathbb Z$ , 무한히 길다고 하자), 필터 $w[0],\dots,w[K-1]$, 합성곱 $(w\star x)[i]=\sum_{a=0}^{K-1}w[a]\thinspace x[i+a]$, 이동 $(T_px)[i]=x[i-p]$

**(a)** $w\star(T_px)=T_p(w\star x)$ 를 보여라. 위치마다 다른 필터 $w_i$를 쓰는 locally connected layer $(Lx)[i]=\sum_aw_i[a]\thinspace x[i+a]$ 에서는 일반적으로 성립하지 않는 이유는?

**(b)** 길이 $n$인 신호를 **원형**으로 이동( $(T_px)[i]=x[(i-p)\bmod n]$ )한다고 하자. global average pooling $\text{GAP}(z)=\frac1n\sum_iz[i]$ 에 대해 $\text{GAP}(T_pz)=\text{GAP}(z)$ (invariant)임을 보이고, "합성곱(원형) → GAP"가 이동에 invariant함을 결론지어라.

**(c)** 창 2, stride 2인 max pooling $P(x)=(\max(x[0],x[1]),\thinspace\max(x[2],x[3]))$ 을 길이 4 신호에 쓴다. $x=(0,1,0,0)$과 이를 오른쪽으로 한 칸 옮긴 $(0,0,1,0)$, 그리고 $x'=(1,0,0,0)$과 이를 한 칸 옮긴 $(0,1,0,0)$의 출력을 각각 구하라. 한 칸 이동에 대해 stride 2 pooling은 equivariant인가 invariant인가?

**(d)** 길이 4 입력, 필터 $(w_0,w_1,w_2)$, padding 없음, stride 1인 합성곱을 행렬 $Wx$ 로 쓸 때 $W$ ( $2\times4$ )를 써라. FC 층이라면 자유로운 가중치가 몇 개이고 여기서는 몇 개인가? "합성곱 = 지역 연결 + 가중치 공유된 FC"를 이 행렬로 설명하라.
