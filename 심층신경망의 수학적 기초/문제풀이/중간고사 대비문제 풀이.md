## 기출식 답안 쓰는 법

2024 midterm 풀이를 보면 답안은 길지 않다. 대신 다음이 빠짐없이 들어간다.

1. **무엇을 보일지 한 줄로** — "귀납법으로 보인다", "두 목적함수가 상수 차이임을 보인다".
2. **가정을 쓰는 곳에 이름을 붙인다** — "독립이므로", "평균이 0이므로", " $\alpha\ge0$ 이므로". 채점은 여기서 갈린다.
3. **특수한 경우 문제는 값을 정확히** — " $\beta_1=0$, $\beta_2=\beta$ " 처럼 모든 파라미터를 적는다. 나머지는 대입만.
4. **귀납법은 세 줄** — 처음 값, 가정, $k\to k+1$.
5. **"아니다"는 반례 하나** — 가장 단순한 경우를 숫자까지.

## 문제 1. Adam 가족

**(a)** $\beta_1=0$, $\beta_2=\beta$, $\alpha$, $\epsilon$ 은 그대로. $\beta_1=0$ 이면 $m_1=g_t$ 이고, $m_2$ 의 점화식은 $z$ 와 같고 둘 다 0에서 시작하므로 매 스텝 $m_2=z$. 따라서 $x_{t+1}=x_t-\alpha g_t/(\sqrt z+\epsilon)$ ∎

**(b)** $\beta_1=\beta_2=0$, $\epsilon=0$. 그러면 $m_1=g_t$, $m_2=g_t\odot g_t$ 이고 성분마다 $\sqrt{m_2}=\lvert g_t\rvert$ 이므로 $m_1/\sqrt{m_2}=g_t/\lvert g_t\rvert=\mathrm{sign}(g_t)$ ∎

**(c)** $\beta_2=1$ 이면 $m_2\leftarrow m_2+0$ 이라 **$m_2$ 는 계속 0**이다. 그러면 Adam은 $x_{t+1}=x_t-\frac\alpha\epsilon m_1$ ( $\epsilon\gt0$ 필요). 이제 $\beta_1=\rho$ 로 두고 $m_1^{(t)}$ 를 $t$ 번 업데이트한 값이라 하자.

주장: 모든 $t$ 에서 $v_t=-\dfrac\eta{1-\rho}m_1^{(t)}$.
- $t=0$: $v_0=0=m_1^{(0)}$
- 가정이 $t$ 에서 맞으면 $v_{t+1}=\rho v_t-\eta g_t=-\dfrac\eta{1-\rho}\big(\rho m_1^{(t)}+(1-\rho)g_t\big)=-\dfrac\eta{1-\rho}m_1^{(t+1)}$

따라서 $x_{t+1}=x_t+v_{t+1}=x_t-\frac\eta{1-\rho}m_1^{(t+1)}$. Adam과 같아지려면 $\frac\alpha\epsilon=\frac\eta{1-\rho}$:

$$\beta_1=\rho,\qquad\beta_2=1,\qquad\epsilon\gt0\text{ 아무거나},\qquad\alpha=\frac{\eta\epsilon}{1-\rho}\qquad\blacksquare$$

✗ bias correction이 있으면 $\hat m_2=m_2/(1-\beta_2^t)=0/0$ 이라 정의되지 않는다 — 그래서 문제가 "bias correction 없는 Adam"이다 (2022 #1도 같다).

**(d)** RMSProp에서 $\beta_t=1-\frac1t$ 이면 $z_t=\big(1-\frac1t\big)z_{t-1}+\frac1tg_t^2$. 귀납법으로 $z_t=\frac1tA_t$ (기울기 제곱의 **산술평균**):
- $t=1$: $\beta_1=0$ 이라 $z_1=g_1^2=A_1$
- $z_{t-1}=\frac{A_{t-1}}{t-1}$ 이면 $z_t=\frac{t-1}t\cdot\frac{A_{t-1}}{t-1}+\frac{g_t^2}t=\frac{A_t}t$

그러면

$$\alpha_t\frac{g_t}{\sqrt{z_t}+\epsilon_t}=\frac\alpha{\sqrt t}\cdot\frac{g_t}{\sqrt{A_t/t}+\epsilon/\sqrt t}=\frac{\alpha\thinspace g_t}{\sqrt{A_t}+\epsilon}\qquad\blacksquare$$

해석: AdaGrad = "모든 과거를 똑같이 평균하는 RMSProp" + **step $\alpha/\sqrt t$ 감소**. 기울기 크기가 일정해도 $\alpha/\sqrt t$ 때문에 step이 0으로 간다. RMSProp은 $\beta$ 를 고정해 최근 기울기만 보고, 이 $1/\sqrt t$ 가 없다. ( [연습문제 2](연습문제%202.md) 문제 5(c)의 $\alpha/\sqrt t$ 와 같은 이야기)

✔ (c) " $\beta_2=1$ ⇒ $m_2\equiv0$ " 과 귀납법 · ✔ (d) $z_t=A_t/t$

## 문제 2. Softmax와 log-softmax

**(a)** $s(z+c\mathbf 1)_ k=\dfrac{e^{z_k+c}}{\sum_je^{z_j+c}}=\dfrac{e^ce^{z_k}}{e^c\sum_je^{z_j}}=s(z)_ k$ ∎
계산: $M=\max_jz_j=1001$ 을 빼면 $\log\sum_je^{z_j}=M+\log\sum_je^{z_j-M}=1001+\log(e^{-1}+1+e^{-2})\approx1001.4076$. ( $e^{1000}$ 은 배정밀도에서 넘친다)

**(b)** $\mathrm{LSE}(z)=\log\sum_je^{z_j}$ 라 하면 $\ell(z)=z-\mathrm{LSE}(z)\mathbf 1$. 그런데

$$\mathrm{LSE}(\ell(z))=\log\sum_je^{\ell_j(z)}=\log\sum_js_j(z)=\log1=0$$

이므로 $\ell(\ell(z))=\ell(z)-0\cdot\mathbf 1=\ell(z)$ ∎ ((a)로 보면: $\ell(z)$ 는 $z$ 를 상수만큼 옮긴 것이라 softmax 값이 같다.)

**(c)** $s_k=e^{z_k}/S$, $S=\sum_je^{z_j}$, $\partial S/\partial z_m=e^{z_m}$. 몫의 미분:

$$\frac{\partial s_k}{\partial z_m}=\frac{\delta_{km}e^{z_k}S-e^{z_k}e^{z_m}}{S^2}=\delta_{km}s_k-s_ks_m=s_k(\delta_{km}-s_m)\qquad\blacksquare$$

수업(03 §3.2)의 $\partial p_k/\partial w_{mn}=(\delta_{mk}p_k-p_kp_m)x_{in}$ 은 여기에 연쇄법칙 $\partial z_m/\partial w_{mn}=x_n$ 을 붙인 것이다.

**(d)** $\dfrac{\partial L}{\partial z_m}=-\sum_ky_k\dfrac1{s_k}\dfrac{\partial s_k}{\partial z_m}=-\sum_ky_k(\delta_{km}-s_m)=-y_m+s_m\sum_ky_k=s_m-y_m$ ∎
✔ 마지막에 $\sum_ky_k=1$ 을 쓴다 — one-hot일 필요는 없다.

**(e)** (d)에서 $\nabla L=s(z)-y$ 이고 $y$ 는 상수라 $\nabla^2L$ = $s$ 의 Jacobian $=\mathrm{diag}(s)-ss^\top$. 확률이 $s$ 인 확률변수 $K$ 를 잡으면

$$v^\top\big(\mathrm{diag}(s)-ss^\top\big)v=\sum_ks_kv_k^2-\Big(\sum_ks_kv_k\Big)^2=\mathbb E[v_K^2]-\big(\mathbb E[v_K]\big)^2=\text{Var}(v_K)\ge0$$

→ 양의 반정치, $L$ 은 $z$ 에 대해 볼록. $z=Wx$ 는 $W$ 에 대해 선형이라 $W$ 에 대해서도 볼록 (로지스틱 볼록성 03 §3.1의 다중 클래스 판).
모든 $s_k\gt0$ 이므로 분산이 0 ⟺ $v_K$ 가 상수 ⟺ $v\propto\mathbf 1$. 즉 고윳값 0의 고유벡터는 $\mathbf 1$ 하나이고, 이것이 (a)의 **이동 불변 방향**이다: $L(z+c\mathbf 1)=L(z)$ 라 그 방향으로는 평평하다 → 순볼록이 아니고, 로짓의 최소점은 유일하지 않다.

✔ (b) $\sum_js_j=1$ ⇒ LSE가 0 · ✔ (e) 이차형식 = 분산
✗ (c)에서 $k=m$ 과 $k\ne m$ 을 따로 안 나누고 $\delta_{km}$ 을 빠뜨림

## 문제 3. 라벨이 여러 개인 데이터

**(a)** 02 §2.4의 $KL(p\Vert q)=H_p(q)-H(p)$ 를 점마다 쓴다. cross entropy는 **첫째 인자에 대해 선형**이고, 라벨 값별로 묶으면

$$H_{P_i}(q)=-\sum_{k=1}^CP_i(k)\log q_k=-\sum_k\frac{\#\lbrace j:Y_{ij}=k\rbrace}n\log q_k=-\frac1n\sum_{j=1}^n\log q_{Y_{ij}}$$

따라서

$$\frac1N\sum_iKL\big(P_i\Vert q_\theta(X_i)\big)=\underbrace{\frac1{nN}\sum_{i,j}-\log q_\theta(X_i)_ {Y_{ij}}}_ {\text{(CE)}}-\underbrace{\frac1N\sum_iH(P_i)}_ {\theta\text{와 무관}}$$

두 목적함수가 상수 차이라 최소점이 같다 ∎

**(b)** $Y=+1$ 이면 $-\log\sigma(f)=\log(1+e^{-f})$, $Y=-1$ 이면 $-\log\sigma(-f)=\log(1+e^{f})$. 두 경우 모두 $\log(1+e^{-Yf})$ 이므로 (CE)에 넣으면 끝 ∎ ( [연습문제 1](연습문제%201.md) 문제 5(b)의 라벨 하나짜리를 $n$ 개로 늘린 것)

**(c)** $KL\ge0$ 이고 등호 ⟺ $q_i=P_i$ (02 §2.2) → (KL)의 최솟값은 **0**, 최소점 $q_i=P_i$. (CE) = (KL) + 상수이므로 최소점은 같고 최솟값은 $\frac1N\sum_iH(P_i)$.
라벨 $(+1,+1,+1,-1)$ 이면 $P=(\frac14,\frac34)$ ( $-1$, $+1$ 순) → $\sigma(f)=\frac34$ ⟺ $f=\log3\approx1.0986$, 손실 $=H(P)=-\frac34\log\frac34-\frac14\log\frac14\approx0.5623$.

**(d)** 아니다. 라벨이 엇갈리면 cross entropy의 하한은 $\frac1N\sum_iH(P_i)\gt0$ 이다. 0이 아니라 이 값에 가까워지는지를 봐야 한다 (0이 되려면 모델이 라벨 잡음까지 외워야 한다).

✔ cross entropy가 $P$ 에 선형 · ✔ $H(P_i)$ 가 $\theta$ 와 무관
✗ "KL을 줄이면 cross entropy도 0이 된다" — KL이 0이어도 CE는 $H(P)$

## 문제 4. Weight decay와 ℓ2 정규화

$\nabla f_\lambda(x)=\nabla f(x)+\lambda x$.

**(a)** $\rho=0$, $v_0=0$ 이면 두 방법 모두 $v$ 가 직전 값과 무관하다.
- ℓ2: $x_{t+1}=x_t-\alpha\nabla f(x_t)-\alpha\lambda x_t=(1-\alpha\lambda)x_t-\alpha\nabla f(x_t)$
- weight decay: $x_{t+1}=(1-\mu)x_t-\alpha\nabla f(x_t)$

$\mu=\alpha\lambda$ 이면 같다 ∎

**(b)** $f\equiv0$ 에서
- ℓ2: $v_1=-\alpha\lambda x_0$, $x_1=(1-\alpha\lambda)x_0$, $v_2=\rho v_1-\alpha\lambda x_1$, $x_2=x_1+v_2=\big((1-\alpha\lambda)^2-\rho\alpha\lambda\big)x_0$
- weight decay: $v_t\equiv0$ 이라 $x_t=(1-\mu)^tx_0$

$x_0\ne0$ 에서 $x_1$ 이 같으려면 $\mu=\alpha\lambda$ 뿐이다. 그때 $x_2$ 의 차이는 $-\rho\alpha\lambda x_0\ne0$ ( $\rho,\alpha,\lambda\gt0$ ). 어떤 $\mu$ 도 둘을 같게 만들지 못한다 ∎

**(c)**

| $t$ | 1 | 2 | 3 | 5 | 10 | 60 |
| --- | --- | --- | --- | --- | --- | --- |
| ℓ2 | 0.9 | 0.72 | 0.486 | −0.029 | −0.589 | 0.038 |
| weight decay | 0.9 | 0.81 | 0.729 | 0.590 | 0.349 | 0.0018 |

- 처음에는 **ℓ2가 빠르다**: 정규화 기울기 $\lambda x$ 가 velocity에 들어가 momentum으로 **쌓이기** 때문이다 (계속 같은 방향이면 $\frac1{1-\rho}=10$ 배까지).
- 길게 보면 ℓ2 쪽은 이차함수 $\frac\lambda2x^2$ 위의 momentum이다. 특성방정식 $z^2-(1+\rho-\alpha\lambda)z+\rho=z^2-1.8z+0.9=0$ 의 근은 $0.9\pm0.3i$ (복소수) → $\lvert z\rvert=\sqrt{0.9}\approx0.949$ 로 **0을 지나치며 진동**하고, weight decay의 배율 0.9보다 느리다 (60스텝 뒤 0.038 vs 0.0018).

✔ 반례는 $f\equiv0$ 하나로 충분 · ✔ $x_1$ 로 $\mu$ 를 고정한 뒤 $x_2$ 에서 모순
(보충) Adam에서도 같은 차이가 있어서 weight decay를 업데이트 밖으로 뺀 것이 AdamW다.

## 문제 5. 이동평균의 편향·분산

**(a)** $k=0$: $\mathbb E[m_0]=0=(1-\beta^0)\mu$. $\mathbb E[m_{k-1}]=(1-\beta^{k-1})\mu$ 이면 기댓값의 선형성으로

$$\mathbb E[m_k]=\beta(1-\beta^{k-1})\mu+(1-\beta)\mu=(1-\beta^k)\mu\qquad\blacksquare$$

**(b)** $m_{k-1}$ 은 $g_1,\dots,g_{k-1}$ 만의 함수이고 $g_k$ 는 그것들과 독립이다 → $m_{k-1}$ 과 $g_k$ 는 **독립** → 공분산 0 →

$$\text{Var}(m_k)=\beta^2\text{Var}(m_{k-1})+(1-\beta)^2\sigma^2$$

$k=0$: $\text{Var}(m_0)=0=\sigma^2\frac{1-\beta}{1+\beta}(1-\beta^0)$. 가정을 넣으면 ( $(1-\beta)^2=\frac{1-\beta}{1+\beta}(1-\beta^2)$ 를 쓴다)

$$\text{Var}(m_k)=\sigma^2\frac{1-\beta}{1+\beta}\Big(\beta^2-\beta^{2k}+1-\beta^2\Big)=\sigma^2\frac{1-\beta}{1+\beta}(1-\beta^{2k})\qquad\blacksquare$$

✗ " $\text{Var}(X+Y)=\text{Var}X+\text{Var}Y$ " 를 근거(독립) 없이 쓰기 — 채점 포인트가 바로 여기다.

**(c)** $\beta^k\to0$ 이므로 $\mathbb E[m_k]\to\mu$, $\text{Var}(m_k)\to\sigma^2\frac{1-\beta}{1+\beta}$. $\beta=0.9$ 이면 $\frac{0.1}{1.9}=\frac1{19}$ → 독립 표본 **19개의 평균**과 같은 분산. 일반적으로 이동평균은 "표본 $\frac{1+\beta}{1-\beta}$ 개 평균" 정도로 잡음을 줄인다. 분산이 0으로 가지 않는 이유: 오래된 표본을 지수적으로 잊으므로 표본 수가 무한히 늘지 않는다.

**(d)** $1-\beta^k$ 는 상수라 $\mathbb E[\hat m_k]=\mu$, $\text{Var}(\hat m_k)=\text{Var}(m_k)/(1-\beta^k)^2$. $1-\beta^{2k}=(1-\beta^k)(1+\beta^k)$ 이므로

$$\text{Var}(\hat m_k)=\sigma^2\frac{1-\beta}{1+\beta}\cdot\frac{(1-\beta^k)(1+\beta^k)}{(1-\beta^k)^2}=\sigma^2\frac{1-\beta}{1+\beta}\cdot\frac{1+\beta^k}{1-\beta^k}\qquad\blacksquare$$

$k=1$: $\frac{1-\beta}{1+\beta}\cdot\frac{1+\beta}{1-\beta}=1$ → $\sigma^2$ ( $\hat m_1=g_1$ 이니 당연). $\beta^k$ 가 줄면 $\frac{1+\beta^k}{1-\beta^k}$ 도 줄므로 **감소**하고, 극한은 (c)와 같다.

**(e)**

| $k$ | $\mathbb E[m_k]$ | $\text{Var}(m_k)$ | $\text{Var}(\hat m_k)$ |
| --- | --- | --- | --- |
| 1 | 0.15 | 0.04 | 4.0 |
| 10 | 0.977 | 0.185 | 0.436 |
| 50 | 1.492 | 0.2105 | 0.2127 |
| ∞ | 1.5 | 0.2105 | 0.2105 |

보정 전: 처음 평균이 $\mu=1.5$ 의 10%뿐(편향)이지만 분산은 작다 — 0 쪽으로 눌려 있어서다. 보정 후: 평균은 처음부터 1.5지만 $k=1$ 분산이 $\sigma^2=4$ (표본 하나). bias correction은 **편향을 없애는 대신 처음 몇 스텝의 잡음을 그대로 드러낸다**. (보충) Adam이 처음에 큰 step을 내는 위험이 여기서 나오고, warmup이 그 대책 중 하나다 (05 §5.3).

✔ 귀납법 세 줄 · ✔ 독립의 근거 · ✔ $1-\beta^{2k}=(1-\beta^k)(1+\beta^k)$

## 문제 6. CNN 구조의 성질

**(a)** 항등: $w[c,c',a,b]=1$ ( $c=c'$, $a=b=0$ ), 나머지 0, $b=0$. 그러면 $Y[c,i,j]=X[c,i,j]$.
오른쪽 한 칸 이동: $w[c,c',a,b]=1$ ( $c=c'$, $a=0$, $b=-1$ ), 나머지 0, $b=0$. 그러면 $Y[c,i,j]=X[c,\thinspace i,\thinspace j-1]$ 이고 첫 열은 padding이라 0 ✔
→ 3×3 합성곱은 이동·항등을 정확히 표현한다 (ResNet의 skip이 "항등을 배우기 쉽게" 하려는 것과 대비해 볼 것, 07 §7.3).

**(b)** 한 창의 값을 $x_1,\dots,x_4$ 라 하자. $\mathrm{ReLU}(u)=\max(0,u)$ 이므로

$$\max_k\mathrm{ReLU}(x_k)=\max_k\max(0,x_k)=\max(0,x_1,\dots,x_4)=\mathrm{ReLU}\big(\max_kx_k\big)$$

창마다, 채널마다 성립하므로 $\mathrm{MP}\circ\mathrm{ReLU}=\mathrm{ReLU}\circ\mathrm{MP}$ ∎ (일반화: **증가함수**는 max와 순서를 바꿀 수 있다)
- conv→MP→ReLU = conv→ReLU→MP: 위 등식을 conv 출력에 적용
- conv→ReLU→MP→ReLU: $\mathrm{MP}(\mathrm{ReLU}(Y))\ge0$ 이고 음이 아닌 값에서 ReLU는 항등이라 마지막 ReLU는 아무것도 안 한다
- 계산량: **conv→MP→ReLU**. ReLU를 $\frac14$ 개의 값에만 적용한다 (MP 비용은 같다).
- average pooling 반례: 창 $(2,-2,0,0)$ → 평균 후 ReLU $=\mathrm{ReLU}(0)=0$, ReLU 후 평균 $=\frac{2+0+0+0}4=0.5$

**(c)** 각 층 $\phi$ 가 $\phi(\alpha u)=\alpha\phi(u)$ ( $\alpha\ge0$ )를 만족함을 보이면, 합성 $F=\phi_K\circ\dots\circ\phi_1$ 은 층 수에 대한 귀납법으로

$$F(\alpha X)=\phi_K(\dots\phi_1(\alpha X))=\phi_K(\dots\alpha\phi_1(X))=\dots=\alpha F(X)$$

- bias 없는 합성곱, GAP, bias 없는 FC: **선형**이라 모든 $\alpha$ 에서 성립
- ReLU: $\max(0,\alpha u)=\alpha\max(0,u)$ — $\alpha\ge0$ 이라 $\max$ 안의 0과 $\alpha u$ 의 대소가 그대로
- max pooling: $\max_k\alpha x_k=\alpha\max_kx_k$ — 역시 $\alpha\ge0$ 이 필요 ∎

깨지는 경우: $\alpha=-1$, $u=1$ 이면 $\mathrm{ReLU}(-1)=0\ne-1=-\mathrm{ReLU}(1)$. bias가 있으면 $w\star(\alpha X)+b\ne\alpha(w\star X+b)$ ( $b\ne0$, $\alpha\ne1$ ).
밝기 2배: 로짓이 2배가 되고 양수배는 순서를 안 바꾸므로 **$\arg\max$ 는 같다**. 단 softmax 확률은 더 뾰족해진다 ( $s(2z)\ne s(z)$ ).

**(d)** circular padding에서는 모든 첨자가 mod $m$ 이라 **경계가 없다**. 07 §7.1의 계산을 그대로 하면

$$(w\star T_{p,q}X)[c,i,j]=\sum_{c',a,b}w[c,c',a,b]\thinspace X[c',\thinspace i+a-p,\thinspace j+b-q]=(w\star X)[c,\thinspace i-p,\thinspace j-q]$$

모든 $(i,j)$ 에서 맞으므로 합성곱은 $T_{p,q}$ 와 교환한다. bias $b_c$ 는 모든 위치에 같은 값이고 ReLU는 원소별이라 역시 교환한다 → 합성곱–ReLU를 쌓은 $H$ 는 $H(T_{p,q}X)=T_{p,q}H(X)$ (equivariant).
GAP는 채널마다 **모든 위치의 평균**이고 $T_{p,q}$ 는 위치를 일대일로 섞을 뿐이라 $\mathrm{GAP}(T_{p,q}Z)=\mathrm{GAP}(Z)$. 그 뒤 FC를 붙여도 그대로 → $G(T_{p,q}X)=G(X)$ ∎

- zero padding: 경계 근처에서 "밀려 들어오는 값"이 원형(반대편 값)이 아니라 0이라 equivariance가 경계 근처에서만 깨진다. GAP는 $m^2$ 개를 평균하므로 차이는 경계 부분의 비율만큼 작다 → **근사적** 불변. (보충) bias가 0이고 물체 주변에 0인 여백이 충분하면(층 수 + 이동 거리 이상) 정확히 같다 — 2022 #7이 묻던 "정확 vs 근사"가 이것이다.
- stride 2 max pooling: 홀수 이동에서는 창의 경계가 바뀌어 equivariance가 깨진다 ( [연습문제 2](연습문제%202.md) 문제 8의 반례). 짝수 이동 $(p,q)$ 이면 MP 출력이 $(p/2,\thinspace q/2)$ 만큼 원형 이동하므로 불변이 유지된다.

✔ (b) $\max(0,\cdot)$ 로 둘 다 $\max(0,x_1,\dots,x_4)$ · ✔ (c) 층별 성질 + 합성 · ✔ (d) equivariance + GAP의 위치 무관성

## 문제 7. 합성곱 층의 초기화 모멘트

출력 하나는 $Y=b_c+\sum_{(c',a,b)\in\mathcal V}w_{c'ab}X_{c'ab}$ 꼴이다 ( $\mathcal V$ = 그 픽셀에서 padding이 아닌 입력 위치, 첨자는 줄여 씀).

**(a)** $w$, $X$ 독립이고 $\mathbb E[w]=0$, $\mathbb E[b_c]=0$ → $\mathbb E[Y]=0+\sum\mathbb E[w]\thinspace\mathbb E[X]=0$ ∎

**(b)** 제곱을 펼치면

$$\mathbb E[Y^2]=\mathbb E[b_c^2]+2\sum\mathbb E[b_c]\thinspace\mathbb E[wX]+\sum_{u,u'\in\mathcal V}\mathbb E[w_uw_{u'}]\thinspace\mathbb E[X_uX_{u'}]$$

- 둘째 항: $\mathbb E[b_c]=0$
- 셋째 항: $u\ne u'$ 이면 $\mathbb E[w_uw_{u'}]=\mathbb E[w_u]\mathbb E[w_{u'}]=0$ (독립, 평균 0) → 교차항 0
- 남는 것: $\sigma_b^2+\lvert\mathcal V\rvert\sigma_w^2V$

내부 $\lvert\mathcal V\rvert=9C_{in}$ → $9C_{in}\sigma_w^2V+\sigma_b^2$ ∎. 테두리(꼭짓점 제외)는 한 줄이 padding이라 $6C_{in}\sigma_w^2V+\sigma_b^2$, 꼭짓점은 $4C_{in}\sigma_w^2V+\sigma_b^2$.
(시뮬레이션 $C_{in}=2$, $\sigma_w=0.4$, $\sigma_b=0.3$, $V=\frac12$: 이론 1.53 / 1.05 / 0.73, 실험 1.537 / 1.044 / 0.722)
이 계산은 $X$ 성분끼리의 독립을 **쓰지 않는다** ( $\mathbb E[X_u^2]=V$ 만 씀) — 그래서 다음 층에도 그대로 쓸 수 있다.

**(c)** $Y[c,i,j]\thinspace Y[c',i,j]$ 를 펼친 모든 항에 $b_c$, $b_{c'}$, $w[c,\cdot]$, $w[c',\cdot]$ 중 하나가 **혼자** 들어간다 ( $c\ne c'$ 이라 서로 다른 독립 변수). 그 변수의 평균이 0이라 모든 항이 0 → 무상관 ∎

**(d)** 같은 채널이면 **같은 가중치와 bias를 쓴다** (가중치 공유). 펼치면

$$\mathbb E\big[Y[c,i,j]\thinspace Y[c,i',j']\big]=\mathbb E[b_c^2]+\sum_{c',a,b}\mathbb E\big[w[c,c',a,b]^2\big]\thinspace\mathbb E\big[X[c',i+a,j+b]\thinspace X[c',i'+a,j'+b]\big]$$

(서로 다른 가중치의 곱은 (b)처럼 0.) $(i,j)\ne(i',j')$ 라 두 $X$ 는 다른 위치 → 독립 → $\mathbb E[XX']=m_X^2$. 둘 다 내부라 $9C_{in}$ 개 모두 유효:

$$=\sigma_b^2+9C_{in}\sigma_w^2m_X^2\qquad\blacksquare$$

- 두 픽셀이 겹치는 입력을 보는지와 **무관**하다 — 상관은 겹침이 아니라 **같은 $w$** 에서 나온다.
- FC에서는 출력마다 다른(독립) 가중치라 이 항이 0이다 (2022 #6의 "무상관").
- 무상관이 되려면 $m_X=0$ (0 중심 입력, 예: tanh 뒤)이고 $\sigma_b=0$ 이어야 한다. ReLU 뒤는 $m_X\gt0$. 예: $X=\mathrm{ReLU}(Z)$, $Z\sim N(0,1)$ 이면 $m_X^2/V=\frac{1/2\pi}{1/2}=\frac1\pi$ → $\sigma_b=0$ 일 때 상관계수 $\frac1\pi\approx0.32$.
- (시뮬레이션: 이웃 픽셀 이론 0.548, 실험 0.553)

**(e)** $(w,b)\mapsto(-w,-b)$ 는 $(X,w,b)$ 의 결합분포를 바꾸지 않는다 ( $w,b$ 는 0 대칭 정규분포이고 $X$ 와 독립). 이 변환에서 $Y\mapsto-Y$ 이므로 $Y$ 와 $-Y$ 는 분포가 같다 → **0에 대해 대칭**.
대칭이면 $\mathbb E[Y^2\thinspace\mathbb 1_ {Y\gt0}]=\mathbb E[Y^2\thinspace\mathbb 1_ {Y\lt0}]$ 이라

$$\mathbb E\big[\mathrm{ReLU}(Y)^2\big]=\frac12\mathbb E[Y^2]=\frac12\cdot9C_{in}\sigma_w^2V$$

이것이 $V$ 가 되려면 $\sigma_w^2=\dfrac2{9C_{in}}$. 수업의 He $\sigma^2=2/D_{in}$ 에서 **$D_{in}=9C_{in}=K^2C_{in}$** (출력 하나가 보는 입력 수, fan-in)이다.

✔ 교차항 0의 근거 (독립 + 평균 0) · ✔ 경계 픽셀 개수 · ✔ (e) 대칭 → 절반
✗ (d)에서 "다른 위치니까 독립"이라 하고 끝내기 — 같은 $w$ 를 공유하므로 독립이 아니다

## 문제 8. 0 초기화와 대칭성

잔차를 $r_i=f_\theta(x_i)-y_i$ 라 하면 역전파(04 §4.3)로

$$\frac{\partial\mathcal L}{\partial A_L}=\frac1N\sum_ir_ih_{L-1,i}^\top,\qquad\frac{\partial\mathcal L}{\partial b_L}=\frac1N\sum_ir_i,\qquad\delta_{L-1,i}=\big(A_L^\top r_i\big)\odot\tanh'(\cdot)$$

그리고 $\ell\lt L$ 의 기울기는 모두 $\delta_{\ell,i}$ 를 곱한 꼴이다 ( $\partial/\partial A_\ell=\frac1N\sum_i\delta_{\ell,i}h_{\ell-1,i}^\top$, $\partial/\partial b_\ell=\frac1N\sum_i\delta_{\ell,i}$, $\delta_{\ell-1}=(A_\ell^\top\delta_\ell)\odot\tanh'$ ).

**(a)** 귀납 가정: $t$ 에서 $A_1,\dots,A_L$, $b_1,\dots,b_{L-1}$ 이 모두 0.
1. 순전파: $h_\ell=\tanh(0)=0$ ( $\ell=1,\dots,L-1$ ) → $f_\theta(x)=b_L$
2. $\partial\mathcal L/\partial A_L=\frac1N\sum_ir_ih_{L-1,i}^\top=0$ ( $h_{L-1}=0$ )
3. $\delta_{L-1}=(A_L^\top r)\odot\tanh'=0$ ( $A_L=0$ ) → 역전파로 모든 $\delta_\ell=0$ → $A_\ell$, $b_\ell$ ( $\ell\lt L$ )의 기울기 0
4. 업데이트 후에도 0. $t=0$ 은 가정이므로 모든 $t$ 에서 성립 ∎

**(b)** $f=b_L$ 이라 $\partial\mathcal L/\partial b_L=\frac1N\sum_i(b_L-y_i)=b_L-\bar y$ →

$$b_L^{t+1}=b_L^t-\eta(b_L^t-\bar y)\quad\Rightarrow\quad b_L^t-\bar y=(1-\eta)^t(0-\bar y)$$

$0\lt\eta\lt2$ ⟺ $\lvert1-\eta\rvert\lt1$ → $b_L\to\bar y$. 학습된 망은 입력을 무시하는 **상수함수 $f\equiv\bar y$** (제곱오차를 최소로 하는 상수 = 평균).

**(c)** sigmoid는 $\sigma(0)=\frac12\ne0$ 이라 처음 은닉값이 $h=\frac12\mathbf 1\ne0$ → 첫 스텝에서 $r_i=-y_i$ 라 $\partial\mathcal L/\partial a=\frac1N\sum_ir_ih_i=-\frac{\bar y}2\mathbf 1\ne0$ ( $\bar y\ne0$ 이면) → $a$ 가 0에서 벗어나고, 그다음 스텝부터 $\partial\mathcal L/\partial w_k=\frac1N\sum_ir_ia_k\sigma'(u_{k,i})x_i\ne0$ 이라 $W$ 가 움직인다. (tanh는 $h=0$ 이라 이 고리가 처음부터 끊겼다.)
대칭: $t$ 에서 $w_k$, $c_k$, $a_k$ 가 $k$ 에 무관하다고 하자. 그러면 은닉 입력 $u_{k,i}=w_k^\top x_i+c_k$ 와 $h_{k,i}$ 도 $k$ 에 무관하고

$$\frac{\partial\mathcal L}{\partial a_k}=\frac1N\sum_ir_ih_{k,i},\qquad\frac{\partial\mathcal L}{\partial w_k}=\frac1N\sum_ir_ia_k\sigma'(u_{k,i})x_i,\qquad\frac{\partial\mathcal L}{\partial c_k}=\frac1N\sum_ir_ia_k\sigma'(u_{k,i})$$

가 모두 $k$ 에 무관하다 → 업데이트 후에도 같다. $t=0$ 은 모두 0이라 성립 ∎
따라서 $f(x)=\big(\sum_ka_k\big)\sigma(w_1^\top x+c_1)+d$ — 은닉 노드가 $H$ 개여도 **1개짜리**와 같다. (시뮬레이션: 50스텝 뒤 $W\ne0$ 이지만 행이 모두 같음)

**(d)** 같은 값으로 시작한 노드는 같은 기울기를 받아 영원히 같다(대칭) — 이 대칭을 깨려면 크기가 적절한(Xavier/He) **무작위** 초기화가 필요하다.

✔ (a) 순전파 $h=0$ 과 역전파 $A_L=0$ 두 곳에서 끊긴다는 것 · ✔ (c) 귀납 가정 "행이 모두 같다"
✗ (a)에서 $b_L$ 도 0으로 남는다고 쓰기 — 마지막 bias만은 $h$ 를 곱하지 않아 움직인다
