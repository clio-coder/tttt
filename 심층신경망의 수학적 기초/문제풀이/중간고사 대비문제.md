**기출이 반복하는 증명 패턴 6가지**
1. **특수한 경우 고르기** — "A는 B의 특수한 경우": B의 파라미터를 정하고 두 업데이트 식이 같아짐을 보인다.
2. **점화식 + 귀납법** — 이동평균, GD 반복. 처음 값을 확인하고 $k\to k+1$.
3. **목적함수 동치** — 두 목적함수가 "양수배 + 상수" 차이면 최소점이 같다. KL = cross entropy − 엔트로피(상수).
4. **층별로 보이고 합성** — 동차성·equivariance·교환 법칙을 층마다 보이면 합성에도 성립한다.
5. **독립 + 평균 0으로 교차항 지우기** — 초기화 문제는 Xavier/He 증명의 반복이다.
6. **반례 하나로 "아니다"** — 동치가 아님은 가장 단순한 경우( $f\equiv0$, 1차원) 하나로 충분하다.

## 문제 1. Adam 가족 (10점)

[근거] Momentum [06 §6.6](../중간고사%20정리/06%20최적화.md) · AdaGrad, RMSProp, Adam [06 §6.7–6.8](../중간고사%20정리/06%20최적화.md)

모든 연산은 원소별이고, $g_t=\nabla f(x_t)$ 라 하자. 수업의 **bias correction 없는 Adam** ("Adam (almost)")은 $m_1=m_2=0$ 에서 시작해

$$m_1\leftarrow\beta_1m_1+(1-\beta_1)g_t,\qquad m_2\leftarrow\beta_2m_2+(1-\beta_2)\thinspace g_t\odot g_t,\qquad x_{t+1}=x_t-\alpha\frac{m_1}{\sqrt{m_2}+\epsilon}$$

이다 ( $0\le\beta_1,\beta_2\le1$, $\epsilon\ge0$ ). 아래 방법이 이 Adam의 특수한 경우임을 보여라. 즉 $(\alpha,\beta_1,\beta_2,\epsilon)$ 을 구체적으로 정하고 두 반복이 같은 $x_t$ 를 냄을 보여라.

**(a)** RMSProp: $z\leftarrow\beta z+(1-\beta)\thinspace g_t\odot g_t$, $x_{t+1}=x_t-\alpha\dfrac{g_t}{\sqrt z+\epsilon}$ ( $z=0$ 에서 시작)

**(b)** signSGD: $x_{t+1}=x_t-\alpha\thinspace\mathrm{sign}(g_t)$ (모든 성분이 0이 아니라고 가정)

**(c)** 수업의 momentum: $v_{t+1}=\rho v_t-\eta g_t$, $x_{t+1}=x_t+v_{t+1}$ ( $v_0=0$, $0\le\rho\lt1$, $\eta\gt0$ )
*Hint.* $\beta_2=1$ 로 두면 $m_2$ 가 어떻게 되는가? $v_t$ 와 $m_1$ 이 비례함을 귀납법으로 보여라.

**(d)** AdaGrad ( $A_t=A_{t-1}+g_t\odot g_t$, $x_{t+1}=x_t-\alpha\dfrac{g_t}{\sqrt{A_t}+\epsilon}$ )는 상수 파라미터로는 특수한 경우가 되지 않는다. 대신 **시간에 따라 바뀌는** $\beta_t=1-\frac1t$, $\alpha_t=\alpha/\sqrt t$, $\epsilon_t=\epsilon/\sqrt t$ 를 쓴 RMSProp과 같음을 보여라 ( $t=1,2,\dots$ ). 이 결과로 "AdaGrad의 step이 사라진다"를 한 문장으로 설명하라.

## 문제 2. Softmax와 log-softmax (10점)

[근거] Softmax 모델과 기울기 [03 §3.2](../중간고사%20정리/03%20분류.md) · 볼록성 [03 §3.1](../중간고사%20정리/03%20분류.md)

$z\in\mathbb R^C$ 에 대해 $s(z)_ k=\dfrac{e^{z_k}}{\sum_je^{z_j}}$ (softmax), $\ell(z)=\log s(z)$ (log-softmax, 원소별 log), $\mathbf 1=(1,\dots,1)$.

**(a)** 모든 $c\in\mathbb R$ 에서 $s(z+c\mathbf 1)=s(z)$ 임을 보여라. 이것을 이용해 $z=(1000,\thinspace1001,\thinspace999)$ 의 $\log\sum_je^{z_j}$ 를 넘침(overflow) 없이 계산하는 방법을 쓰고 값을 구하라.

**(b)** $\ell(\ell(z))=\ell(z)$ 임을 보여라.

**(c)** $\dfrac{\partial s_k}{\partial z_m}=s_k(\delta_{km}-s_m)$ 임을 보여라. 즉 Jacobian은 $\mathrm{diag}(s)-ss^\top$.

**(d)** $y\in\mathbb R^C$ 가 $y_k\ge0$, $\sum_ky_k=1$ (one-hot이 아니어도 됨)일 때 $L(z)=-\sum_ky_k\log s_k(z)$ 의 기울기가 $\nabla L=s-y$ 임을 보여라.

**(e)** $\nabla^2L=\mathrm{diag}(s)-ss^\top$ 이 양의 반정치임을 보여라. ( $v^\top(\cdot)v$ 를 어떤 확률변수의 분산으로 읽어라.) 그런데 양의 정치는 아니다 — 고윳값 0의 고유벡터를 찾고, 그것이 (a)와 어떻게 연결되는지 말하라.

## 문제 3. 라벨이 여러 개인 데이터 (10점)

[근거] Cross entropy = $H$ + KL [02 §2.4](../중간고사%20정리/02%20정보이론.md) · 로지스틱·softmax 손실 [03 §3.1–3.2](../중간고사%20정리/03%20분류.md)

데이터 $X_1,\dots,X_N$ 마다 라벨을 $n$ 명이 따로 달아 $Y_{i1},\dots,Y_{in}\in\lbrace1,\dots,C\rbrace$ 를 얻었다 (사람마다 다를 수 있다). 모델의 예측 분포는 $q_\theta(X)=s(f_\theta(X))\in\mathbb R^C$ (softmax)이다. 점 $i$ 의 **라벨 경험분포**를 $P_i(k)=\frac1n\#\lbrace j:Y_{ij}=k\rbrace$ 라 하자.

**(a)** 다음 두 최소화 문제의 최소점이 같음을 보여라.

$$\text{(KL)}\quad\min_\theta\frac1N\sum_{i=1}^NKL\big(P_i\Vert q_\theta(X_i)\big)\qquad\qquad\text{(CE)}\quad\min_\theta\frac1{nN}\sum_{i=1}^N\sum_{j=1}^n-\log q_\theta(X_i)_ {Y_{ij}}$$

즉 라벨이 여러 개면 $(X_i,Y_{ij})$ 를 **각각 다른 데이터 점처럼** 넣고 평소의 cross entropy로 학습하면 된다.

**(b)** $C=2$, 라벨을 $\pm1$ 로 쓰고 $q_\theta(X)=\big(\sigma(-f_\theta(X)),\thinspace\sigma(f_\theta(X))\big)$ (각각 $-1$, $+1$ 의 확률, $f_\theta$ 는 실수값)라 하자. (CE)가

$$\frac1{nN}\sum_{i=1}^N\sum_{j=1}^n\log\big(1+e^{-Y_{ij}f_\theta(X_i)}\big)$$

와 같음을 보여라.

**(c)** 모델이 점마다 아무 분포나 낼 수 있다고 하자. (KL)과 (CE)의 최솟값을 각각 구하라. 한 점의 라벨이 $(+1,+1,+1,-1)$ 이면 (b)에서 그 점의 손실을 최소로 하는 $f$ 값과 그때의 손실값은? (수치로)

**(d)** (c)로 보아, 라벨이 엇갈리는 데이터에서 "train cross entropy가 0으로 가지 않는다"는 것이 학습 실패를 뜻하는가?

## 문제 4. Momentum에서 weight decay와 ℓ2 정규화 (10점)

[근거] Momentum [06 §6.6](../중간고사%20정리/06%20최적화.md) · Ridge (ℓ2 정규화) [01 §1.7](../중간고사%20정리/01%20회귀와%20추정.md)

$\lambda\gt0$ 이라 하고 두 방법을 비교한다 ( $v_0=0$ ).

- **ℓ2 정규화**: $f_\lambda(x)=f(x)+\frac\lambda2\lVert x\rVert^2$ 에 수업의 momentum을 쓴다: $v_{t+1}=\rho v_t-\alpha\nabla f_\lambda(x_t)$, $x_{t+1}=x_t+v_{t+1}$
- **weight decay** (정의): $v_{t+1}=\rho v_t-\alpha\nabla f(x_t)$, $x_{t+1}=(1-\mu)x_t+v_{t+1}$ ( $0\lt\mu\lt1$ )

**(a)** $\rho=0$ (SGD)이면 $\mu=\alpha\lambda$ 로 두 방법이 같음을 보여라.

**(b)** $\rho\gt0$ 이면 어떤 $\mu$ 를 골라도 두 방법이 같지 않음을 보여라. *Hint.* $f\equiv0$ 에서 $x_1$, $x_2$ 를 계산하라.

**(c)** $\alpha=0.1$, $\lambda=1$, $\rho=0.9$, $x_0=1$, $f\equiv0$, $\mu=\alpha\lambda$ 일 때 두 방법의 $x_1,x_2,x_3$ 을 구하라. 처음에는 어느 쪽이 빨리 줄어드는가? 그 이유를 한 문장으로 쓰고, ℓ2 쪽의 $x_t$ 가 길게 보면 어떻게 움직이는지 [연습문제 2](연습문제%202.md) 문제 3(b)의 결과(복소수 근이면 $\lvert z\rvert=\sqrt\rho$ )로 설명하라.

## 문제 5. 이동평균의 편향·분산과 bias correction (15점)

[근거] Adam과 bias correction [06 §6.8](../중간고사%20정리/06%20최적화.md)

$g_1,g_2,\dots$ 가 i.i.d. 실수 확률변수이고 $\mathbb E[g_k]=\mu$, $\text{Var}(g_k)=\sigma^2$ 이다. $0\lt\beta\lt1$ 에 대해

$$m_0=0,\qquad m_k=\beta m_{k-1}+(1-\beta)g_k\quad(k\ge1)$$

**(a)** $\mathbb E[m_k]=(1-\beta^k)\mu$ 를 귀납법으로 보여라.

**(b)** $\text{Var}(m_k)=\sigma^2\dfrac{1-\beta}{1+\beta}(1-\beta^{2k})$ 를 귀납법으로 보여라. 귀납 단계에서 $\text{Var}(m_k)=\beta^2\text{Var}(m_{k-1})+(1-\beta)^2\sigma^2$ 가 성립하는 근거를 분명히 써라.

**(c)** $k\to\infty$ 일 때 $\mathbb E[m_k]$, $\text{Var}(m_k)$ 의 극한을 구하라. $\beta=0.9$ 이면 극한 분산은 $\sigma^2$ 의 몇 분의 1인가? 이것을 "독립 표본 몇 개의 평균과 같은 분산인가"로 해석하라.

**(d)** bias correction $\hat m_k=m_k/(1-\beta^k)$ 에 대해 $\mathbb E[\hat m_k]=\mu$ 이고

$$\text{Var}(\hat m_k)=\sigma^2\frac{1-\beta}{1+\beta}\cdot\frac{1+\beta^k}{1-\beta^k}$$

임을 보여라. $k=1$ 일 때 값은? $k$ 에 대해 증가하는가 감소하는가?

**(e)** $\mu=1.5$, $\sigma=2$, $\beta=0.9$ 일 때 $k=1,10,50$ 에서 $\mathbb E[m_k]$, $\text{Var}(m_k)$, $\text{Var}(\hat m_k)$ 를 구하라. bias correction이 **평균은 고치지만 처음 몇 스텝의 분산은 키운다**는 것을 숫자로 확인하라.

## 문제 6. CNN 구조의 성질 (15점)

[근거] Equivariance [07 §7.1](../중간고사%20정리/07%20CNN.md) · 합성곱 층, pooling, GAP [07 §7.2](../중간고사%20정리/07%20CNN.md)

입력 $X\in\mathbb R^{C_{in}\times m\times m}$, 3×3 합성곱(stride 1, zero padding 1)은 $a,b\in\lbrace-1,0,1\rbrace$ 로 첨자를 붙여

$$Y[c,i,j]=b_c+\sum_{c'=1}^{C_{in}}\sum_{a,b}w[c,c',a,b]\thinspace X[c',\thinspace i+a,\thinspace j+b]\qquad(\text{범위 밖의 }X\text{는 }0)$$

이다. max pooling은 2×2 창, stride 2이고 $m$ 은 짝수라 하자.

**(a)** $C_{in}=C_{out}=C$ 일 때 $Y=X$ (항등 사상)가 되는 $w$, $b$ 를 구하라. 또 $Y[c,i,j]=X[c,\thinspace i,\thinspace j-1]$ (오른쪽으로 한 칸 이동, 빈 열은 0)이 되는 $w$, $b$ 를 구하라.

**(b)** max pooling을 $\mathrm{MP}$ 라 할 때 $\mathrm{MP}(\mathrm{ReLU}(X))=\mathrm{ReLU}(\mathrm{MP}(X))$ 임을 보여라. 이로부터 conv→MP→ReLU, conv→ReLU→MP, conv→ReLU→MP→ReLU 가 모두 같은 함수임을 보이고, 계산량이 가장 적은 순서를 골라라. average pooling이면 교환 법칙이 깨짐을 반례로 보여라.

**(c)** 모든 bias가 0인 CNN (합성곱, ReLU, max pooling, global average pooling, FC의 합성)을 $F$ 라 하자. 모든 $\alpha\ge0$ 에서 $F(\alpha X)=\alpha F(X)$ 임을 보여라. $\alpha\lt0$ 이거나 bias가 있으면 왜 깨지는가? 이미지 밝기를 2배로 하면 분류 결과( $\arg\max$ )는?

**(d)** **circular padding** (범위 밖 첨자를 $m$ 으로 나눈 나머지로 읽는다)을 쓰는 합성곱–ReLU 층을 여러 번 쌓고 global average pooling과 FC를 붙인 망을 $G$ 라 하자. 원형 이동 $(T_{p,q}X)[c,i,j]=X[c,\thinspace i-p,\thinspace j-q]$ (첨자는 mod $m$ )에 대해 $G(T_{p,q}X)=G(X)$ 임을 보여라. zero padding이면 왜 근사적으로만 성립하는가? 중간에 stride 2 max pooling을 넣으면?

## 문제 7. 합성곱 층의 초기화 모멘트 (15점)

[근거] Xavier·He 유도 [05 §5.2](../중간고사%20정리/05%20학습%20기술.md) · 합성곱 층 [07 §7.2](../중간고사%20정리/07%20CNN.md)

문제 6의 3×3 합성곱(zero padding 1)에서 다음을 가정한다.
- 입력 $X$ 의 성분은 서로 독립이고 같은 분포, $\mathbb E[X]=m_X$, $\mathbb E[X^2]=V$ (예: 앞 층 ReLU의 출력)
- $w[c,c',a,b]$ 는 i.i.d. $N(0,\sigma_w^2)$, $b_c$ 는 i.i.d. $N(0,\sigma_b^2)$, 그리고 $X$, $w$, $b$ 는 서로 독립

**(a)** 모든 $c,i,j$ 에서 $\mathbb E\big[Y[c,i,j]\big]=0$ 임을 보여라.

## 문제 8. 0 초기화와 대칭성 (15점)

[근거] 역전파 [04 §4.3](../중간고사%20정리/04%20신경망과%20역전파.md) · 초기화 [05 §5.2](../중간고사%20정리/05%20학습%20기술.md)

$L$ 층 ( $L\ge2$ ) MLP $f_\theta(x)=A_Lh_{L-1}+b_L$, $h_0=x$, $h_\ell=\tanh(A_\ell h_{\ell-1}+b_\ell)$ ( $\ell=1,\dots,L-1$ , 출력은 실수 하나)를 손실

$$\mathcal L(\theta)=\frac1{2N}\sum_{i=1}^N\big(f_\theta(x_i)-y_i\big)^2$$

에 대해 GD $\theta^{t+1}=\theta^t-\eta\nabla\mathcal L(\theta^t)$ 로 학습한다. 모든 파라미터를 0으로 초기화한다.

**(a)** 모든 $t$ 에서 $A_1,\dots,A_L$, $b_1,\dots,b_{L-1}$ 이 0으로 남음을 귀납법으로 보여라.

**(b)** $b_L$ 의 업데이트를 $\bar y=\frac1N\sum_iy_i$ 로 써라. $0\lt\eta\lt2$ 이면 $b_L\to\bar y$ 임을 보여라. 결국 학습된 망은 어떤 함수인가?

**(c)** 은닉층이 하나이고 활성화가 sigmoid인 $f(x)=a^\top\sigma(Wx+c)+d$ ( $W$ 의 행 $w_1,\dots,w_H$ )를 0으로 초기화하면 (a)와 달리 $W$ 가 움직인다. 왜인가? 그래도 모든 $t$ 에서 $w_1=\dots=w_H$, $c_1=\dots=c_H$, $a_1=\dots=a_H$ 임을 귀납법으로 보이고, 이 망이 사실상 은닉 노드 몇 개짜리인지 말하라.

**(d)** (a)–(c)로 보아 수업의 초기화(Xavier, He)가 **분산**뿐 아니라 **무작위성** 자체가 필요한 이유를 한 문장으로 써라.
