# 심층신경망의 수학적 기초 (심수기)

> ‘심수기’는 이 과목의 줄임말이다.

- [정리 규칙](./정리%20규칙.md) — 필기 PDF 기준 수업정리 방식, 회차별 범위, 증명 정리 틀

## 학습목표

머신러닝 알고리즘의 작동 원리를 이해하고, 분석을 바탕으로 더 나은 학습 방법을 설계하는 능력을 기른다. 이론과 실습을 균형 있게 다루어 기계학습을 이해하고 활용하는 역량을 키운다.
