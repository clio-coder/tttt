## 한눈에

- **엔트로피**는 정보량 $-\log p(x)$의 평균 = 불확실성의 크기.
- **KL divergence**는 두 분포의 차이. 항상 0 이상이고 같을 때만 0 (Jensen). 하지만 **대칭이 아니라 거리가 아니다**.
- **상호정보량**은 $Y$를 알면 $X$의 불확실성이 얼마나 줄어드는가. 독립일 때 0.
- **Cross entropy = 엔트로피 + KL**. 정답 분포가 고정이면 cross entropy를 줄이는 것 = KL을 줄이는 것 = MLE. 그래서 분류의 손실함수가 cross entropy다 (03장).

| 양 | 정의 | 핵심 성질 |
| --- | --- | --- |
| 엔트로피 | $H(X)=-\mathbb E[\log p(X)]$ | $\ge0$ |
| 조건부 엔트로피 | $H(Y\mid X)=-\mathbb E_{X,Y}[\log p(Y\mid X)]$ | |
| 결합 엔트로피 | $H(X,Y)=-\mathbb E_{X,Y}[\log p(X,Y)]$ | $=H(X)+H(Y\mid X)$ |
| KL divergence | $KL(p\Vert q)=\mathbb E_p\big[\log\frac pq\big]$ | $\ge0$, 등호 ⟺ $p=q$ |
| 상호정보량 | $I(X;Y)=KL\big(p(x,y)\Vert p(x)p(y)\big)$ | $=H(Y)-H(Y\mid X)$ |
| Cross entropy | $H_p(q)=-\mathbb E_p[\log q(X)]$ | $=H(p)+KL(p\Vert q)\ge H(p)$ |

## 2.1 정보량과 엔트로피

**정보량** $X=x$를 관찰했을 때의 정보량 $h(x)$가 만족해야 할 두 조건
1. $p(x)$가 작을수록(드문 일일수록) $h(x)$가 크다
2. $X,Y$가 독립이면 $h(x,y)=h(x)+h(y)$ — $-\log p(x)-\log p(y)=-\log p(x)p(y)$

→ $h(x)=-\log p(x)$

**엔트로피** 정보량의 기댓값

$$H(X)=-\mathbb E[\log p(X)]=-\sum_xp(x)\log p(x)$$

- $p(x)\in[0,1]$이라 $H(X)\ge0$. 어떤 $x$에서 $p(x)=1$이면(확실하면) $H(X)=0$.

**정리 (결합 엔트로피)** $H(X,Y)=H(X)+H(Y\mid X)$

**증명** $p(x,y)=p(y\mid x)\thinspace p(x)$ 이므로

$$H(X,Y)=-\mathbb E_{X,Y}[\log p(Y\mid X)]-\mathbb E_{X,Y}[\log p(X)]=H(Y\mid X)+H(X)$$

마지막 항: $\log p(X)$는 $Y$와 무관하므로 $\mathbb E_{X,Y}[\log p(X)]=\mathbb E_X[\log p(X)]$ ∎

## 2.2 KL divergence

**정의**

$$KL(p\Vert q)=\sum_xp(x)\log\frac{p(x)}{q(x)}$$

관례 ( $a,b\gt0$ ): $0\log\frac00=0$, $0\log\frac0a=0$, $b\log\frac b0=\infty$

**KL은 거리가 아니다** — 대칭이 아니고 삼각부등식도 성립하지 않는다. 베르누이 $p(1)=r$, $q(1)=s$:

$$KL(p\Vert q)=(1-r)\log\frac{1-r}{1-s}+r\log\frac rs\ \ne\ KL(q\Vert p)=(1-s)\log\frac{1-s}{1-r}+s\log\frac sr$$

**🔴 정리 (KL ≥ 0)** $KL(p\Vert q)\ge0$, 등호 ⟺ 모든 $x$에서 $p(x)=q(x)$

**증명 아이디어** $\log\frac pq=-\log\frac qp$ 로 뒤집고, 볼록함수 $-\log$에 Jensen 부등식을 쓴다.

**증명**
1. $E=\lbrace x:p(x)\gt0\rbrace$ ( $p$의 support )로 두면
   $$KL(p\Vert q)=\sum_{x\in E}p(x)\Big[-\log\frac{q(x)}{p(x)}\Big]$$
2. Jensen ( $-\log$는 볼록, 확률변수 $q(X)/p(X)$, 기댓값은 $p$에 대해):
   $$\ge-\log\Big(\sum_{x\in E}p(x)\frac{q(x)}{p(x)}\Big)=-\log\sum_{x\in E}q(x)\ge0\qquad(\because\textstyle\sum_{x\in E}q(x)\le1)$$
3. 등호 조건: Jensen의 등호는 $q(x)/p(x)=c$ (상수)일 때. 그러면 $1=\sum_xq(x)=c\sum_xp(x)=c$ → $p=q$ ∎

> **Jensen 부등식** $\varphi$가 볼록이면 $\mathbb E[\varphi(X)]\ge\varphi(\mathbb E[X])$

## 2.3 상호정보량

**정의** $I(X;Y)=KL\big(p(x,y)\Vert p(x)p(y)\big)$ — 결합분포가 "독립인 척한 분포"에서 얼마나 먼가

**정리** $I(X;Y)=H(Y)-H(Y\mid X)=H(X)-H(X\mid Y)$

**증명** $p(x,y)=p(y\mid x)p(x)$를 대입하면

$$I(X;Y)=\sum_{x,y}p(x,y)\log\frac{p(y\mid x)\thinspace p(x)}{p(x)\thinspace p(y)}=\mathbb E_{X,Y}[\log p(Y\mid X)]-\mathbb E[\log p(Y)]=-H(Y\mid X)+H(Y)$$

$p(x,y)=p(x\mid y)p(y)$를 쓰면 같은 방법으로 $H(X)-H(X\mid Y)$ ∎

- 뜻: $Y$를 알려 주면 $X$의 불확실성이 그만큼 준다.
- 벤 다이어그램: $H(X,Y)=H(X\mid Y)+I(X;Y)+H(Y\mid X)$
- (보충) $p(x)p(y)$도 확률분포이므로 KL ≥ 0에서 $I\ge0$, 등호 ⟺ 독립. 따라서 $H(Y\mid X)\le H(Y)$ ("조건을 주면 엔트로피는 줄거나 같다").

## 2.4 Cross entropy

**정의** $H_p(q)=-\mathbb E_p[\log q(X)]$ — 분포 $p$를 기준으로 본 $q$의 cross entropy

**정리** $KL(p\Vert q)=H_p(q)-H(p)\ge0$, 따라서 $H_p(q)\ge H(p)$ (등호 ⟺ $q=p$)

**증명**

$$KL(p\Vert q)=\sum_xp(x)\log\frac{p(x)}{q(x)}=-\sum_xp(x)\log q(x)+\sum_xp(x)\log p(x)=H_p(q)-H(p)\qquad\blacksquare$$

**왜 중요한가**
- 정답 분포 $p$가 고정이면 $H(p)$는 상수 → **$q$에 대해 cross entropy 최소화 = KL 최소화**
- (보충) 라벨의 경험분포 $\hat p$에 대해 $\frac1N\log\mathcal L(\theta)=-H_{\hat p}(\theta)$ → **MLE = cross entropy 최소화**. 로지스틱 회귀의 손실(binary cross entropy)과 softmax 손실이 이것이다 (03장).

## 2.5 📝 PS1 P1 — Jensen–Shannon divergence

$m=\frac12(p+q)$, $D_{JS}(p\Vert q)=\frac12KL(p\Vert m)+\frac12KL(q\Vert m)$ 일 때 세 성질을 보인다.

**0단계 (먼저 쓴다)** $m$은 확률분포다: $m(x)\ge0$, $\sum_xm(x)=\frac12(1+1)=1$. 그래야 KL ≥ 0 정리를 쓸 수 있다.

| 성질 | 증명 |
| --- | --- |
| (i) $D_{JS}\ge0$ | 두 항 모두 KL ≥ 0 |
| (ii) $D_{JS}=0\iff p=q$ | (⇐) $p=q$면 $m=p$라 두 KL이 0. (⇒) 0 이상인 두 항의 합이 0이면 둘 다 0 → KL 등호 조건으로 $p=m$, $q=m$ → $p=q$ |
| (iii) 대칭 | $m=\frac12(p+q)$가 $p,q$의 순서와 무관 → 두 항이 자리만 바뀐다 |

- (보충) $p(x)\gt0$이면 $m(x)\ge\frac12p(x)\gt0$ 이라 $D_{JS}$는 **항상 유한**하다. $KL(p\Vert q)$는 무한대가 될 수 있다.
- (보충) $D_{JS}=H(m)-\frac12\big(H(p)+H(q)\big)$, $D_{JS}\le\log2$ (등호 ⟺ 두 분포의 support가 겹치지 않음)

🧮 $p=\text{Bern}(1/2)$, $q=\text{Bern}(0)$: $KL(p\Vert q)=\infty$, $KL(q\Vert p)=\log2$, $D_{JS}=\frac34\log\frac43\approx0.216$

## 자주 틀리는 것

- ⚠️ KL ≥ 0을 새 대상에 쓸 때 **두 인자가 확률분포인지** 확인하지 않는다 (JS의 $m$, 상호정보량의 $p(x)p(y){}$).
- ⚠️ "⟺" 증명에서 한 방향만 쓴다 — (⇐)는 대입 한 줄이지만 반드시 쓴다.
- ⚠️ KL을 거리처럼 대칭으로 쓴다.
- ⚠️ Jensen의 방향: 볼록 $\varphi$에서 $\mathbb E[\varphi(X)]\ge\varphi(\mathbb E X)$. $\log$는 오목이라 반대 방향이다.
