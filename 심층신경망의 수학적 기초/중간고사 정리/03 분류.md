## 한눈에

- **로지스틱 회귀**: log-odds를 선형으로 둔다 → $p=\sigma(w^\top x)$. 학습은 MLE = **binary cross entropy** 최소화. 손실이 **볼록**이라 GD가 전역 최소로 간다.
- **Softmax**: 클래스가 $C$개일 때의 확장. 손실은 cross entropy, 기울기는 또 **(정답 − 예측) × 입력**.
- **SVM**: 맞게 나누는 초평면 중 **마진이 최대**인 것. → $\min\frac12\lVert w\rVert^2$ s.t. $y_i(w^\top x_i+b)\ge1$ → 라그랑주 쌍대로 푼다.

| | 로지스틱 | Softmax | SVM |
| --- | --- | --- | --- |
| 라벨 | $y\in\lbrace0,1\rbrace$ | one-hot $y\in\lbrace0,1\rbrace^C$ | $y\in\lbrace-1,+1\rbrace$ |
| 예측 | $\sigma(w^\top x)$ | $\frac{e^{w_k^\top x}}{\sum_je^{w_j^\top x}}$ | $\text{sign}(w^\top x+b)$ |
| 손실 | $-\sum[y\log p+(1-y)\log(1-p)]$ | $-\sum_i\sum_ky_{ik}\log p_k$ | $\frac12\lVert w\rVert^2$ + 제약 |
| 기울기 | $\sum_i(\sigma(w^\top x_i)-y_i)x_i$ | $-\sum_i(y_{im}-p_m)x_{in}$ | (쌍대로 푼다) |

## 3.1 로지스틱 회귀

**Odds와 logit**
- $p$의 odds $o=\dfrac p{1-p}$. **logit** $\log\dfrac p{1-p}=:z$ 는 $[0,1]$을 실수 전체로 보낸다.
- 역함수가 **sigmoid** $\sigma(z)=\dfrac1{1+e^{-z}}$, 미분은 $\sigma'(z)=\sigma(z)(1-\sigma(z))$

**모델** log-odds가 입력의 선형함수라고 둔다: $\log\frac p{1-p}=w^\top x$ ( $x=(1,x_1,\dots,x_n)$ 로 절편 포함 ) → $p=P(y=1\mid x,w)=\sigma(w^\top x)$

**MLE → binary cross entropy** $p_i=\sigma(w^\top x_i)$

$$\mathcal L=\prod_ip_i^{y_i}(1-p_i)^{1-y_i}\quad\Rightarrow\quad w^\ast=\arg\min_w\Big\lbrace-\sum_i\big[y_i\log p_i+(1-y_i)\log(1-p_i)\big]\Big\rbrace$$

괄호 안이 **cross-entropy loss**다 (9/7 베르누이 가능도와 같은 꼴, 확률만 $x_i$마다 다르다).

**전개와 기울기** $1-p_i=\frac{e^{-w^\top x_i}}{1+e^{-w^\top x_i}}$ 를 넣으면

$$-\log\mathcal L=\sum_i\log(1+e^{-w^\top x_i})+\sum_i(1-y_i)w^\top x_i,\qquad\nabla_w(-\log\mathcal L)=\sum_i\big(\sigma(w^\top x_i)-y_i\big)x_i$$

닫힌 해가 없으므로 GD: $w\leftarrow w-\alpha\sum_i(\sigma(w^\top x_i)-y_i)x_i$

**2차원 결정경계** 로지스틱 함수는 매끄럽게 증가하고 값이 $[0,1]$이라 **소속 확률**을 준다. 2차원 이진분류의 목표는 결정경계를 찾는 것이다. 슬라이드 예: 등고선 $p=0.666$ 너머의 점들은 소속 확률이 0.666보다 커서 1로 분류된다. 결정경계 $p=\frac12$ 는 $w^\top x=0$ (초평면)이다.

### 🔴 로지스틱 손실은 볼록이다

**정리** $J(w)=-\sum_i[y_i\log p_i+(1-y_i)\log(1-p_i)]$ 의 Hessian은 양의 준정부호다 → $J$는 볼록

**증명 아이디어** Hessian이 $X^\top SX$ ( $S$는 음이 아닌 대각행렬) 꼴이라, 이차형식이 "음이 아닌 가중치 × 제곱"의 합이 된다.

**증명**
1. $l_i(w)=-[y_i\log p_i+(1-y_i)\log(1-p_i)]$, $z_i=w^\top x_i$ 로 두면 $\nabla_wl_i=(\sigma(z_i)-y_i)\thinspace x_i$ (∵ 연쇄법칙, $\sigma'=\sigma(1-\sigma)$ )
2. 한 번 더 미분: $\nabla_w^2l_i=\sigma'(z_i)\thinspace x_ix_i^\top=\sigma(z_i)(1-\sigma(z_i))\thinspace x_ix_i^\top$
3. 합치면 $\nabla_w^2J=\sum_i\sigma(z_i)(1-\sigma(z_i))\thinspace x_ix_i^\top=X^\top SX$, $S=\mathrm{diag}(s_1,\dots,s_N)$, $s_i=\sigma(z_i)(1-\sigma(z_i))\ge0$
4. 임의의 $v$에 대해 $v^\top X^\top SXv=\sum_is_i(x_i^\top v)^2\ge0$ → PSD → 볼록 ∎

볼록이면 극소점이 곧 전역 최소점이라 GD로 최적해에 갈 수 있다. 신경망 손실은 볼록이 아니다.

<details><summary>1단계 자세히 (보충)</summary>

$\dfrac{dl_i}{dz_i}=-y_i\dfrac{\sigma'}{\sigma}+(1-y_i)\dfrac{\sigma'}{1-\sigma}=-y_i(1-\sigma)+(1-y_i)\sigma=\sigma(z_i)-y_i$, 그리고 $\nabla_wz_i=x_i$.
</details>

## 3.2 Softmax 다중분류

$$p_k=P(y=k\mid x,W)=\frac{e^{w_k^\top x}}{\sum_{j=1}^Ce^{w_j^\top x}},\qquad J(W)=-\sum_{i=1}^N\sum_{k=1}^Cy_{ik}\log p_k\quad(\text{cross entropy})$$

**기울기** $\dfrac{\partial p_k}{\partial w_{mn}}=(\delta_{mk}p_k-p_kp_m)\thinspace x_{in}$ 이므로

$$\frac{\partial J}{\partial w_{mn}}=-\sum_{i=1}^N\big(y_{im}-p_m(x_i)\big)\thinspace x_{in}\qquad\text{("error × input")}$$

(마지막 단계에서 one-hot이라 $\sum_ky_{ik}=1$ 을 쓴다.)

🧮 **iris 예제** ( $C=3$ ) $x=(5.1,\thinspace3.5,\thinspace1.4,\thinspace0.2)$, $w_1=(0.1,0.2,0.3,0.4)$, $w_2=(-0.3,0.1,0.5,0.2)$, $w_3=(0.2,-0.4,0.1,0.3)$
- $z=(w_1^\top x,\thinspace w_2^\top x,\thinspace w_3^\top x)=(1.71,\thinspace-0.44,\thinspace-0.18)$
- $p\approx(0.78,\thinspace0.09,\thinspace0.12)$ → **클래스 1**. 정답이 one-hot $(1,0,0)$이면 가능도 기여는 $p_1\approx0.79$

## 3.3 SVM

### 초평면과 마진
- 초평면 $w^\top x+b=0$. $w$는 **법선 방향**이다 (평면 위 어떤 점을 $w$ 방향으로 사영해도 길이가 같다).
- 분류: $\hat y=\text{sign}(w^\top x+b)$. 전부 맞게 분류 ⟺ 모든 $i$에서 $y_i(w^\top x_i+b)\ge0$
- 맞는 초평면 중 **마진**(초평면과 가장 가까운 점 사이 거리)이 최대인 것을 고른다.
- 양쪽의 가장 가까운 점을 지나는 평행한 평면 $H_\pm:w^\top x+b=\pm1$ → 모든 점이 $y_i(w^\top x_i+b)\ge1$. 등호인 점이 **support vector**.

### 🔴 점과 초평면 사이 거리

**정리** $x$와 $H=\lbrace x:w^\top x+b=0\rbrace$ 사이 거리는 $\dfrac{\lvert w^\top x+b\rvert}{\lVert w\rVert}$

**증명**
1. $x$에서 $H$에 내린 발을 $x_p=x-d$ 라 하면 $x_p\in H$: $w^\top(x-d)+b=0$
2. $d$는 법선 방향 → $d=\alpha w$ ( $\alpha\ne0$ )
3. $w^\top(x-\alpha w)+b=0$ 을 풀면 $\alpha=\dfrac{w^\top x+b}{w^\top w}$
4. $\lVert d\rVert=\lvert\alpha\rvert\thinspace\lVert w\rVert=\dfrac{\lvert w^\top x+b\rvert}{w^\top w}\lVert w\rVert=\dfrac{\lvert w^\top x+b\rvert}{\lVert w\rVert}$ ∎

데이터 $\mathcal D$에 대한 마진: $r(w,b)=\min_{x\in\mathcal D}\dfrac{\lvert w^\top x+b\rvert}{\lVert w\rVert}$

### 🔴 마진 최대화 → 이차 계획 문제

**정리** 마진 최대화 ⟺ $\displaystyle\min_{w,b}\frac12\lVert w\rVert^2$ s.t. $y_i(w^\top x_i+b)\ge1$ ( $\forall i$ )

**증명 아이디어** $(w,b)$를 양수배해도 초평면과 마진이 그대로라서 $\min\lvert w^\top x+b\rvert=1$ 로 고정할 수 있다.

**증명**
1. **scale invariance**: $r(cw,cb)=r(w,b)$ ( $c\gt0$ )
2. 풀 문제: $\max_{w,b}\frac1{\lVert w\rVert}\min_{x\in\mathcal D}\lvert w^\top x+b\rvert$ s.t. $y_i(w^\top x_i+b)\ge0$
3. 1에 의해 $\min_x\lvert w^\top x+b\rvert=1$ 로 둔다 → $\max\frac1{\lVert w\rVert}$ ⟺ $\min w^\top w$
4. "모두 맞게 분류" + "가장 가까운 점이 1" ⟺ $y_i(w^\top x_i+b)\ge1$ ∎

(보충) 4단계의 ⟸: 제약 $\ge1$만 두면 $\min\lvert\cdot\rvert$이 1보다 클 수도 있지만, 그러면 $(w,b)$를 줄여 $w^\top w$를 더 작게 만들 수 있으므로 최적해에서는 1이 된다.

### 🔴 Penalty term으로 제약 없애기

$$\min_{w,b}\frac12w^\top w+\sum_i\max_{\alpha_i\ge0}\alpha_i\big(1-y_i(w^\top x_i+b)\big),\qquad\max_{\alpha_i\ge0}\alpha_ic_i=\begin{cases}0&c_i\le0\ (\text{제약 만족})\cr\infty&c_i\gt0\ (\text{제약 위반})\end{cases}$$

괄호가 0 이하면 최대화하는 $\alpha_i=0$ → 0. 양수면 $\alpha_i\to\infty$ → 제약을 어기는 $(w,b)$는 목적함수가 무한대가 되어 저절로 빠진다.

### 쌍대 문제 (슬라이드 · 📝 PS1 P3·P4 출제)

- $\min_{w,b}\max_{\alpha\ge0}L\ \ge\ \max_{\alpha\ge0}\min_{w,b}L$, $L(w,b,\alpha)=\frac12w^\top w+\sum_i\alpha_i(1-y_i(x_i^\top w+b))$ ( $\alpha_i$ = Lagrange multiplier )
- $\nabla_wL=0$ → $w=\sum_i\alpha_iy_ix_i$, $\partial L/\partial b=0$ → $\sum_i\alpha_iy_i=0$
- 대입하면 쌍대 문제:

$$\max_\alpha\ \sum_i\alpha_i-\frac12\sum_i\sum_j\alpha_i\alpha_jy_iy_j\thinspace x_i^\top x_j\qquad\text{s.t. }\alpha_i\ge0,\ \sum_i\alpha_iy_i=0$$

- $b$: support vector( $\alpha_s\gt0$ )에서 $y_s(x_s^\top w+b)=1$ → 양변에 $y_s$를 곱하고 $y_s^2=1$ → $b=y_s-x_s^\top w$
- (보충) 쌍대에는 데이터가 내적 $x_i^\top x_j$로만 나온다 → 커널로 바꿀 수 있다 (01장 1.8).

### 📝 PS1 P3 — 점 2개짜리 SVM을 끝까지

$x_1=(0,0)$, $y_1=-1$ / $x_2=(2,2)$, $y_2=+1$

**풀이 순서 6단계** ① 라그랑주 함수 ② $\nabla_w=0$, $\partial_b=0$ ③ 대입해 쌍대 함수 ④ 제약 아래 최대화 ⑤ $w$, $b$ 복원 ⑥ 검산

1. $L=\frac12\lVert w\rVert^2+\alpha_1(1+b)+\alpha_2(1-2w_1-2w_2-b)$
2. $w=\alpha_2(2,2)$, 그리고 $\alpha_1=\alpha_2$
3. $x_1^\top x_1=x_1^\top x_2=0$, $x_2^\top x_2=8$ → $g(\alpha)=\alpha_1+\alpha_2-4\alpha_2^2$
4. $\alpha_1=\alpha_2=\alpha$ → $2\alpha-4\alpha^2$ 최대 → $\alpha=\frac14$
5. $w=(\frac12,\frac12)$, $b=y_2-x_2^\top w=1-2=-1$
6. 검산: 두 점 모두 $y_i(w^\top x_i+b)=1$ (둘 다 support vector). primal $\frac12\lVert w\rVert^2=\frac14$ = 쌍대 최댓값 $\frac14$

**답** 초평면 $x_{(1)}+x_{(2)}=2$ (두 점의 수직이등분선), 마진 $\dfrac1{\lVert w\rVert}=\sqrt2$

### 📝 PS1 P4 — max–min 부등식

**정리** $\max_x\min_yf(x,y)\le\min_y\max_xf(x,y)$

**증명**
1. 임의의 $x',y'$를 고정하면 $\min_yf(x',y)\le f(x',y')\le\max_xf(x,y')$
2. 왼쪽 끝은 $x'$만, 오른쪽 끝은 $y'$만의 함수다. 모든 $x'$에서 성립하므로 왼쪽에 $\max_{x'}$
3. 이제 왼쪽은 상수이고 모든 $y'$에서 성립하므로 오른쪽에 $\min_{y'}$ ∎

**반례** (등호 불성립)
- $X=Y=\lbrace0,1\rbrace$, $f(x,y)=1$ ( $x=y$ ), $0$ ( $x\ne y$ ): max–min = 0, min–max = 1
- $X=Y=[0,1]$, $f=(x-y)^2$: max–min = 0, min–max = $\frac14$ ( $y=\frac12$ )

(보충) **안장점** $(x^\ast,y^\ast)$ ( $f(x,y^\ast)\le f(x^\ast,y^\ast)\le f(x^\ast,y)$ )이 있으면 등호가 성립한다. SVM 쌍대의 "equality holds in certain conditions"가 이 경우다.

## 자주 틀리는 것

- ⚠️ 라벨 규약: 로지스틱은 $\lbrace0,1\rbrace$, SVM은 $\lbrace-1,+1\rbrace$.
- ⚠️ SVM 쌍대에서 $\partial L/\partial b=0$ 조건( $\sum\alpha_iy_i=0$ )을 빠뜨리면 $\alpha$를 정할 수 없다.
- ⚠️ 마진 정의: 수업은 "초평면과 가장 가까운 점 사이 거리" $=1/\lVert w\rVert$. $H_+$와 $H_-$ 사이 폭 $2/\lVert w\rVert$ 로 쓰는 책도 있으니 답안에 정의를 한 줄 적는다.
- ⚠️ 거리의 분모는 $\lVert w\rVert=\sqrt{w^\top w}$ ( $w^\top w$ 아님 — 판서에 한 번 잘못 적힘).
- ⚠️ max–min 증명에서 max와 min을 한꺼번에 취한다 → 한쪽씩, 순서대로.
