## 한눈에

- **신경망 = 선형함수 + 비선형 활성화의 반복.** 활성화를 빼면 행렬 곱 하나 = 선형 모델로 돌아간다.
- **층을 쌓는 이유**: 은닉층은 입력을 **선형분리 가능한 공간으로 보내는 비선형 임베딩**이다. 커널(01장)처럼 공간을 바꾸되, 그 사상을 **학습한다**.
- **역전파 = 연쇄법칙을 계산 그래프 위에서 체계적으로**: 노드마다 **downstream = upstream × local**.
- **활성화 함수**: sigmoid(포화, 0 중심 아님) → tanh(0 중심, 포화) → ReLU(포화 없음, 음수 쪽 기울기 0).

## 4.1 신경망의 구조

- **분류**: 입력을 둘 이상의 클래스 중 하나로 보내는 함수 $f:\mathcal X\to\mathcal Y$ (예: $\mathcal X=\mathbb R^2$, $\mathcal Y=\lbrace C_1,C_2,C_3\rbrace$ ). 결정 규칙은 입력공간을 **decision region**으로 나누고, 그 경계가 **decision boundary**다.
- **end-to-end 학습**: 예전에는 색(RGB 양자화)·텍스처(filter bank) 같은 특징을 사람이 설계했다 (이동·크기·회전·가림에 불변인가가 문제). 딥러닝은 **특징과 분류기를 함께 학습**한다.

| 모델 | 식 |
| --- | --- |
| 선형 | $f(x)=Wx$ |
| 2층 신경망 | $f(x)=W_2\max(0,W_1x)$ |
| 3층 신경망 | $f(x)=W_3\max(0,W_2\max(0,W_1x))$ |
| 분류기 | $f(x)=\text{softmax}(W_2\max(0,W_1x))$ |

- **활성화 함수를 빼면?** $W_3W_2W_1x=(W_3W_2W_1)x$ — 행렬 하나짜리 선형 모델과 같다. 비선형성이 있어야 층을 쌓는 의미가 있다.
- 🧮 **파라미터 수** (CIFAR10, 입력 $32\times32\times3=3072$, 은닉 100, 출력 10): $3072\times100+100\times10=$ **308,200** (편향 제외) — 작은 데이터에서는 외워 버려(rote learning) 과적합한다.
- **MLP** (fully connected network): $y_1=\sigma(W_1x+b_1)$, …, $y_{L-1}=\sigma(W_{L-1}y_{L-2}+b_{L-1})$, $y_L=W_Ly_{L-1}+b_L$. $\sigma$는 **원소별**로 적용한다.
- **softmax** $\sigma(\vec z)_ i=\dfrac{e^{z_i}}{\sum_je^{z_j}}$ 는 실수 벡터를 확률분포로 바꾼다. 예: $(-1,3)$ → $(0.018,\thinspace0.982)$

**층을 쌓는 이유**
- 실제 데이터는 대부분 **선형분리가 안 된다** → 비선형성이 필요하다: 퍼셉트론 $\hat y=g(w^\top x+b)$
- **은닉층 = 입력의 비선형 임베딩**: 원 안(빨강)·밖(파랑)으로 나뉜 2차원 점도 3차원으로 올리면 평면 하나로 나뉜다.
- 층이 깊을수록 **추상화된 특징의 계층**을 배운다 (edges → facial landmarks → global face).
- 예: 손글씨 숫자(MNIST)는 28×28 흑백 이미지를 **784차원 벡터**(픽셀값 0–1)로 펴서 넣고, 은닉층을 거쳐 출력 10개(숫자 0–9)를 낸다 (forward propagation).

## 4.2 활성화 함수

| 함수 | $g(z)$ | $g'(z)$ | 장점 | 단점 |
| --- | --- | --- | --- | --- |
| Sigmoid | $\frac1{1+e^{-z}}$ | $g(1-g)$ | 값이 $[0,1]$ | **포화**된 뉴런에서 기울기 0 · **0 중심이 아님** (항상 양수) |
| tanh | $\frac{e^z-e^{-z}}{e^z+e^{-z}}$ | $1-g^2$ | $[-1,1]$, **0 중심** | 포화 시 기울기 0 |
| ReLU | $\max(0,z)$ | 1 ( $z\gt0$ ), 0 (그 외) | **포화 없음**, 계산 쉬움 | 0 중심 아님, **음수 입력에서 기울기 0** |
| Leaky ReLU | $\max(0.01z,z)$ | | 음수 쪽 작은 기울기 | |
| ELU | $z$ ( $z\gt0$ ), $\alpha(e^z-1)$ | | | |
| Maxout | $\max(w_1^\top x+b_1,\thinspace w_2^\top x+b_2)$ | | (9/16 슬라이드에만) | |

(Leaky ReLU의 음수 쪽 기울기는 9/16 슬라이드 0.1, 9/21 슬라이드 0.01 — 작은 기울기를 준다는 점만 기억)

- **0 중심이 아니면 왜 문제인가**: $\frac{\partial\mathcal L}{\partial W}=\frac{\partial\mathcal L}{\partial h}\thinspace z^\top$ 에서 입력 $z$가 전부 양수면, 한 뉴런의 가중치 기울기가 **모두 같은 부호** → 가중치가 전부 양수 또는 전부 음수 방향으로만 움직인다.
- **포화**: sigmoid·tanh는 입력 크기가 크면 $g'\approx0$ → 기울기가 사라진다 (05장 초기화, 07장 AlexNet이 ReLU를 쓴 이유).

## 4.3 역전파

**왜 필요한가**: $L=\frac1N\sum_iL_i+\lambda R(W_1)+\lambda R(W_2)$ 같은 손실의 $\partial L/\partial W_1$, $\partial L/\partial W_2$를 손으로 구할 수는 없다 → 연쇄법칙을 기계적으로.

**규칙** 노드 $f$가 입력 $x,y$를 받아 $z$를 내보낼 때

$$\underbrace{\frac{\partial L}{\partial x}}_ {\text{downstream}}=\underbrace{\frac{\partial L}{\partial z}}_ {\text{upstream}}\cdot\underbrace{\frac{\partial z}{\partial x}}_ {\text{local}}$$

local gradient는 노드 안에서만 계산되고, upstream은 출력 쪽에서 흘러 들어온다.

### 🧮 예제 1: f(x, y, z) = (x + y)z

입력 $(x,y,z)=(-2,5,-4)$

- Forward: $q=x+y=3$, $f=qz=-12$
- Local: $\partial q/\partial x=\partial q/\partial y=1$, $\partial f/\partial q=z$, $\partial f/\partial z=q$
- Backward:

| 변수 | 계산 | 값 |
| --- | --- | --- |
| $\partial f/\partial z$ | $q$ | 3 |
| $\partial f/\partial q$ | $z$ | −4 |
| $\partial f/\partial x$, $\partial f/\partial y$ | $\frac{\partial f}{\partial q}\cdot1$ | −4, −4 |

### 🧮 예제 2: sigmoid 뉴런

$f=\dfrac1{1+e^{-(w_0x_0+w_1x_1+w_2)}}$, $w=(w_0,w_1,w_2)=(2,-3,-3)$, $x=(x_0,x_1)=(-1,-2)$

- Forward: $w_0x_0=-2$, $w_1x_1=6$, 합 $4$, $+w_2$ → 1 → $\times(-1)$ → −1 → exp → 0.37 → $+1$ → 1.37 → $1/x$ → **0.73**
- sigmoid 게이트로 한 번에: $\sigma'=\sigma(1-\sigma)=(1-0.73)(0.73)\approx$ **0.2**
- 덧셈 노드는 0.2를 그대로 나눠 준다: $\partial f/\partial w_2=0.2$
- 곱셈 노드는 상대 입력을 곱한다: $\partial f/\partial w_0=0.2\cdot x_0=-0.2$, $\partial f/\partial x_0=0.2\cdot w_0=0.4$, $\partial f/\partial w_1=0.2\cdot x_1=-0.4$, $\partial f/\partial x_1=0.2\cdot w_1=-0.6$
- 계산 그래프는 유일하지 않다. **local gradient가 쉽게 표현되는 쪽**을 고른다.

### Gradient 흐름의 패턴

| 게이트 | 별명 | 하는 일 |
| --- | --- | --- |
| add | **distributor** | upstream을 두 입력에 그대로 나눠 준다 |
| mul | **swap multiplier** | 각 입력에 upstream × **다른 쪽 입력** |
| copy | **adder** | 갈라진 가지의 기울기를 더한다 |
| max | **router** | 최댓값이었던 입력에만 upstream을 보낸다 |

### 다변수 미분과 벡터 역전파

| 경우 | 미분 | 크기 |
| --- | --- | --- |
| 스칼라 → 스칼라 | 보통 미분 | $\mathbb R$ |
| 벡터 → 스칼라 | **gradient** | $\mathbb R^N$ |
| 벡터 → 벡터 | **Jacobian** | $\mathbb R^{N\times M}$ |

🧮 **ReLU 벡터 역전파** $x=(1,-2,3,-1)$, $y=\max(0,x)=(1,0,3,0)$, upstream $\partial L/\partial y=(4,-1,5,9)$
- $y_i$는 $x_i$에만 의존 → Jacobian은 대각 $\mathrm{diag}(1,0,1,0)$
- $\partial L/\partial x=(1,0,1,0)\odot(4,-1,5,9)=$ **(4, 0, 5, 0)**
- Jacobian은 **희소**하다 → 행렬을 만들지 말고 **원소별 곱**으로 계산한다:
  $\big(\frac{\partial L}{\partial x}\big)_ i=\big(\frac{\partial L}{\partial y}\big)_ i$ ( $x_i\gt0$ ), 아니면 0

## 자주 틀리는 것

- ⚠️ 곱셈 노드에서 upstream × **자기 자신** 입력을 곱한다 → **상대 입력**이다 (swap).
- ⚠️ 덧셈 노드에서 기울기를 반으로 나눈다 → 나누지 않고 **그대로** 둘 다에게 준다.
- ⚠️ copy(분기)된 변수의 기울기는 가지마다 온 것을 **더한다**.
- ⚠️ sigmoid의 $g'$ 최댓값은 $\frac14$ ( $z=0$ ) — 층이 쌓이면 기울기가 계속 줄어든다.
