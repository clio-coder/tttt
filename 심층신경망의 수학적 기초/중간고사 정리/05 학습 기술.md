## 한눈에

- **SGD·mini-batch**: 기울기의 **기댓값은 full gradient와 같고(불편)**, 차이는 **분산**뿐이다. 실전은 mini-batch.
- **초기화**: 층을 지나도 신호의 크기(분산·2차 모멘트)가 유지되게 고른다. tanh → **Xavier** $\sigma^2=1/D_{in}$, ReLU → **He** $\sigma^2=2/D_{in}$.
- **Learning rate**: 처음엔 크게, 나중엔 작게(decay). 처음 몇천 step은 0에서 키운다(warmup).
- **Batch Norm**: 층마다 채널별로 평균 0·분산 1로 맞춘 뒤 $\gamma,\beta$로 다시 조정. 효과의 이유는 ICS 감소가 아니라 **매끄러운 손실 지형**이라는 설명이 유력하다.

## 5.1 Full batch · SGD · Mini-batch

| 방법 | 기울기 | 장점 | 단점 |
| --- | --- | --- | --- |
| Full batch | $\nabla f=\frac1N\sum_{i=1}^N\nabla f_i$ | **정확한** 기울기 | 데이터가 크면 한 스텝이 매우 느림 |
| SGD | $\nabla f_i$, $i\sim\text{Unif}\lbrace1,\dots,N\rbrace$ | 한 스텝이 **매우 빠름** | **분산이 큼**, 경로가 흔들림 |
| Mini-batch | $\frac1{\lvert\mathcal K\rvert}\sum_{k\in\mathcal K}\nabla f_k$ | full보다 빠르고 SGD보다 안정 | batch size를 정해야 함 |

- **세 방법 모두 기댓값이 같다**: $\mathbb E[\nabla f_i]=\sum_i\frac1N\nabla f_i=\nabla f$ — 불편추정
- (보충) batch 크기 $B$ (복원추출)이면 $\mathbb E\lVert g-\nabla f\rVert^2=s^2/B$ — 분산이 $1/B$로 준다. 교차항은 독립·평균 0이라 사라진다.
- **Mini-batch SGD 루프**: ① batch 뽑기 ② forward로 loss ③ backprop으로 기울기 ④ 업데이트
- 01장 GD의 단점("매 스텝 데이터 전체")에 대한 답이다. 수렴 분석은 06장.

## 5.2 가중치 초기화

**실험** (6층, 은닉 4096, tanh, `W = c * randn(Din, Dout)`)

| 초기화 | 층별 활성값 | 결과 |
| --- | --- | --- |
| 너무 작게 ( $c=0.01$ ) | std 0.49 → 0.29 → … → 0.05 | 위층 활성값 ≈ 0 → $\frac{\partial\mathcal L}{\partial W}=\frac{\partial\mathcal L}{\partial h}z^\top\approx0$ → **학습 안 됨** |
| 너무 크게 ( $c=0.05$ ) | 모든 층 std ≈ 0.85, 값이 ±1에 몰림 | tanh 포화 → $\sigma'=1-\tanh^2\approx0$ → **학습 안 됨** |
| Xavier ( $1/\sqrt{D_{in}}$ ) | std 0.63 → 0.49 → … → 0.30 | 모든 층에서 적당한 크기 |

### 🔴 Xavier 초기화

**설정** $y=\sum_{i=1}^{D_{in}}w_ix_i$. $w_i$ i.i.d., $w$와 $x$ 독립, $\mathbb E[w_i]=0$, $\text{Var}(w_i)=\sigma^2$, $\mathbb E[x_i]=0$, $\text{Var}(x_i)=V$
**결론** $\text{Var}(y)=D_{in}\sigma^2V$ → 분산을 유지하려면( $\text{Var}(y)=V$ )

$$\sigma^2=\frac1{D_{in}}\qquad(\text{std }=1/\sqrt{D_{in}})$$

**증명**
1. $\mathbb E[y]=\sum\mathbb E[w_i]\mathbb E[x_i]=0$ (∵ 독립, $\mathbb E[w_i]=0$ ) → $\text{Var}(y)=\mathbb E[y^2]$
2. $\mathbb E[y^2]=\sum_i\mathbb E[w_i^2]\mathbb E[x_i^2]+\sum_{i\ne k}\mathbb E[w_iw_k]\thinspace\mathbb E[x_ix_k]$
3. $i\ne k$면 $\mathbb E[w_iw_k]=\mathbb E[w_i]\mathbb E[w_k]=0$ → **교차항 0**
4. $\mathbb E[w_i^2]=\sigma^2$, $\mathbb E[x_i^2]=V$ → $\text{Var}(y)=D_{in}\sigma^2V$
5. $D_{in}\sigma^2V=V$ → $\sigma^2=1/D_{in}$ ∎

⚠️ 4단계에서 $\mathbb E[x_i^2]=\text{Var}(x_i)$ 는 **$\mathbb E[x_i]=0$일 때만** 맞다. ReLU 출력은 항상 0 이상이라 이 가정이 깨진다 → He.

### 🔴 He (Kaiming) 초기화

**설정** $z=\sum_iw_ix_i$, $\text{Var}(z)=D_{in}\sigma^2V=:q$, $h=\max(0,z)$, $z\sim N(0,q)$로 가정
**결론** $\mathbb E[h^2]=\frac12D_{in}\sigma^2V$ → 2차 모멘트를 유지하려면

$$\sigma^2=\frac2{D_{in}}\qquad(\text{std }=\sqrt{2/D_{in}})$$

**증명 아이디어** ReLU는 0에 대칭인 분포의 **절반을 0으로 만든다** → 2차 모멘트가 절반 → 분산을 2배로.

**증명**
1. Xavier와 같이 $\text{Var}(z)=D_{in}\sigma^2V=q$
2. $\mathbb E[h]=\int_0^\infty z\thinspace\varphi_q(z)\thinspace dz=\sqrt{q/(2\pi)}$ — **D.I.Y.** ( $\varphi_q$ = $N(0,q)$ 의 밀도, $z\lt0$이면 $h=0$ 이라 적분이 0부터)
3. $\mathbb E[h^2]=\int_0^\infty z^2\varphi_q(z)\thinspace dz=\frac12q$ — **D.I.Y.**
4. 신호 전파에서는 **2차 모멘트** $V=\mathbb E[x^2]$를 따라간다: ReLU 전 $\mathbb E[z^2]=D_{in}\sigma^2V$, 후 $\mathbb E[h^2]=\frac12D_{in}\sigma^2V$
5. $\frac12D_{in}\sigma^2V=V$ → $\sigma^2=2/D_{in}$ ∎

<details><summary>D.I.Y. 풀이: E[h] = √(q/2π)</summary>

$u=z^2/(2q)$로 치환하면 $z\thinspace dz=q\thinspace du$ 이므로

$$\mathbb E[h]=\frac1{\sqrt{2\pi q}}\int_0^\infty e^{-u}\thinspace q\thinspace du=\frac{q}{\sqrt{2\pi q}}=\sqrt{\frac q{2\pi}}$$
</details>

<details><summary>D.I.Y. 풀이: E[h²] = q/2</summary>

$z^2\varphi_q(z)$는 짝함수라 $\int_0^\infty z^2\varphi_q=\frac12\int_{-\infty}^\infty z^2\varphi_q=\frac12\mathbb E[z^2]=\frac12q$
</details>

| | Xavier | He |
| --- | --- | --- |
| 활성화 | tanh (0 중심 대칭) | ReLU |
| 유지하는 양 | 분산 $\text{Var}(y)=V$ | 2차 모멘트 $\mathbb E[h^2]=V$ |
| 결과 | $\sigma^2=1/D_{in}$ | $\sigma^2=2/D_{in}$ |
| 코드 | `randn(Din, Dout) / np.sqrt(Din)` | `randn(Din, Dout) * np.sqrt(2/Din)` |

- Xavier를 ReLU에 쓰면 활성값이 층마다 0으로 무너진다 (mean 0.39 → 0.07). (보충) 이론적으로 층마다 $\mathbb E[h^2]$가 **정확히 절반**이 된다: $q=V$ → $\mathbb E[h^2]=V/2$.
- He를 쓰면 모든 층이 mean ≈ 0.56, std ≈ 0.82로 유지된다. (보충) $q=2$이면 $\mathbb E[h]=1/\sqrt\pi\approx0.564$, $\text{std}(h)=\sqrt{(\pi-1)/\pi}\approx0.826$ — 슬라이드 숫자와 맞는다.

## 5.3 Learning rate

- SGD, Momentum, AdaGrad, RMSProp, Adam 모두 **learning rate가 하이퍼파라미터**다.
- 손실 곡선: (a) 발산 · (b) 천천히 꾸준히 · (c) 빨리 떨어졌다가 정체 · (d) 빨리 떨어지고 계속 낮아짐. LR 오름차순은 (b) < (d) < (c) < (a), 최선은 (d). 둘의 장점을 합치려면 → **처음엔 크게, 나중엔 작게**

| LR decay | 식 |
| --- | --- |
| Step | 정해진 epoch마다 줄임 (ResNet: 30, 60, 90 epoch에 ×0.1) |
| Cosine | $\alpha_t=\frac12\alpha_0\big(1+\cos(t\pi/T)\big)$ |
| Linear | $\alpha_t=\alpha_0(1-t/T)$ |
| Inverse sqrt | $\alpha_t=\alpha_0/\sqrt t$ |

- **Linear warmup**: 초기 LR이 크면 loss가 폭발할 수 있다 → 처음 약 5000 iteration 동안 0에서 선형으로 올린다.
- 왜 줄여야 하는지는 06장의 SGD 수렴식에서 수학적으로 나온다.

## 5.4 Batch Normalization

**학습 시** 입력 $x$: $N\times D$ ( $N$ = batch size, $D$ = 특성 수), **열(채널)마다** 정규화

$$\mu_j=\frac1N\sum_{i=1}^Nx_{i,j},\qquad\sigma_j^2=\frac1N\sum_{i=1}^N(x_{i,j}-\mu_j)^2,\qquad\hat x_{i,j}=\frac{x_{i,j}-\mu_j}{\sqrt{\sigma_j^2+\varepsilon}},\qquad y_{i,j}=\gamma_j\hat x_{i,j}+\beta_j$$

- $\gamma,\beta$는 **학습하는** scale·shift. $\gamma=\sigma$, $\beta=\mu$로 학습되면 **항등함수**가 된다 → 표현력을 잃지 않는다.
- $\varepsilon$ (예: $10^{-5}$ )은 0으로 나누기 방지.

**테스트 시** batch가 작거나 $N=1$일 수 있다 → 학습 중에 모은 **running average**를 쓴다.
- 학습 중: $\mu^{run}\leftarrow m\thinspace\mu^{run}+(1-m)\mu_{batch}$ (분산도 같은 식)
- 테스트: $\mu,\sigma^2,\gamma,\beta$가 모두 상수 → BN은 **채널별 affine 변환** $y=a_jx+b_j$, $a_j=\frac{\gamma_j}{\sqrt{\sigma_j^2+\varepsilon}}$, $b_j=\beta_j-a_j\mu_j$ → 앞의 FC·conv 층에 **합칠(fuse) 수 있다** (추가 비용 0)

**위치와 장점**
- 보통 **FC·Conv 뒤, 비선형 함수 앞**: FC → BN → tanh → …
- 깊은 망을 훨씬 쉽게 학습 · gradient flow 개선 · **더 큰 LR 허용** · **초기화에 덜 민감** · 학습 중 정규화 효과 · 테스트 비용 0
- BN을 쓰면 **batch size**가 중요한 하이퍼파라미터가 된다. ResNet 학습에는 BN이 필요하다. 이론적 근거는 약하다.

**이론적 근거**

| | 내용 |
| --- | --- |
| 원래 가설 (Ioffe & Szegedy 2015) | BN이 internal covariate shift(ICS)를 줄여서 학습이 좋아진다 |
| 실험 (Santurkar et al. 2018) | 재 보면 **BN은 ICS를 줄이지 않는다**. 그런데도 학습은 좋아진다 |
| 다른 설명 | BN이 **손실 지형을 매끄럽게** 한다 → 최적화가 쉬워진다 |

**정의 (판서)**
- **Covariate shift**: $P_{train}(X)\ne P_{test}(X)$ 인데 $P_{train}(Y\mid X)=P_{test}(Y\mid X)$ — 입력 분포만 바뀌고 입력–출력 관계는 그대로
- **Internal covariate shift**: 학습 중 파라미터가 바뀌어 같은 데이터라도 은닉층 입력의 분포가 스텝마다 바뀌는 것: $P_t(h^{(\ell-1)})\ne P_{t+1}(h^{(\ell-1)})$
- (보충) "매끄러운 지형" = 작은 smoothness 상수 $\beta$ → 06장의 $\eta\lt2/\beta$ 가 넓어진다 → BN이 큰 LR을 허용하는 이유

## 자주 틀리는 것

- ⚠️ SGD가 "틀린 기울기"를 쓴다고 생각한다 → **기댓값은 정확하다(불편)**. 문제는 분산.
- ⚠️ Xavier 증명에서 교차항이 0인 근거를 빼먹는다 → $w$끼리 독립 + 평균 0.
- ⚠️ He에서 "분산"을 유지한다고 쓴다 → ReLU 뒤는 평균이 0이 아니라 **2차 모멘트**를 유지한다.
- ⚠️ BN은 행(샘플)이 아니라 **열(채널)마다** 평균을 낸다.
- ⚠️ BN의 $\beta$(shift)와 smoothness 상수 $\beta$, 회귀계수 $\beta$는 다른 것이다.
