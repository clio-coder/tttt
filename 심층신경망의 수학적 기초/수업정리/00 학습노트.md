## 1. 공통 틀: 모델 → 손실 → 최적화

이 과목의 모델은 모두 **"모델을 정하고, 손실을 정하고, 최소화한다"**는 같은 틀이다. 손실이 어디서 오는지가 [2]–[3]의 주제다.

| 모델 | 예측 | 손실 | 손실의 출처 | 푸는 법 | 기울기 꼴 |
| --- | --- | --- | --- | --- | --- |
| 선형회귀 | $x^\top\beta$ | $\lVert y-X\beta\rVert^2$ | 가우시안 오차 MLE | 정규방정식 / GD | $-2\sum_i(y_i-\hat y_i)x_i$ |
| Ridge | $x^\top\beta$ | $\frac12\lVert y-X\beta\rVert^2+\frac\lambda2\lVert\beta\rVert^2$ | MAP (가우시안 prior) | $(\lambda I+X^\top X)^{-1}X^\top y$ | |
| Kernel ridge | $\phi(x)^\top\beta=K(x,X)\alpha$ | ridge와 같음 | | $\alpha^\ast=(K+\lambda I)^{-1}y$ | |
| 로지스틱 | $\sigma(w^\top x)$ | binary cross entropy | 베르누이 MLE | GD (볼록) | $\sum_i(\sigma(w^\top x_i)-y_i)x_i$ |
| Softmax | $\text{softmax}(Wx)$ | cross entropy | 범주형 MLE | GD | $-\sum_i(y_{im}-p_m)x_{in}$ |
| SVM | $\text{sign}(w^\top x+b)$ | $\frac12\lVert w\rVert^2$ s.t. $y_i(w^\top x_i+b)\ge1$ | 기하 (최대 마진) | QP / 쌍대 | |
| 신경망 | $\text{softmax}(W_2\max(0,W_1x))$ | cross entropy (+ 정규화) | | mini-batch SGD + 역전파 (비볼록) | 역전파로 계산 |

> **"(예측 − 정답) × 입력"** — 선형회귀, 로지스틱, softmax의 기울기가 모두 이 꼴이다 (softmax 슬라이드: "error times the input value"). 역전파의 "upstream × local"도 같은 구조를 층마다 반복하는 것이다.

## 2. 단계별 흐름

### [1] 선형회귀 — 모델·손실·최적화의 원형 · [09.02](09.02%20수업정리.md)

- **질문:** 데이터를 가장 잘 설명하는 직선은?
- **답:** 잔차 제곱합(SSE)을 최소화한다. $f(\beta)=\lVert y-X\beta\rVert^2$
  - 한 번에: 🔴 $\nabla f=-2X^\top y+2X^\top X\beta=0$ → $\boxed{\hat\beta=(X^\top X)^{-1}X^\top y}$
  - 반복해서: $\beta\leftarrow\beta-\alpha\nabla f(\beta)$ (GD). 단점: **매 스텝 전체 데이터**를 훑는다.
- **도구:** $\nabla_\beta(\beta^\top m)=m$, $\nabla_\beta(\beta^\top A\beta)=(A+A^\top)\beta$ — 이후 계속 쓴다.
- **다음 질문:** 왜 하필 **제곱** 오차인가? → [2]에서 확률로 보면 [4]에서 답이 나온다. GD의 단점 → [7] SGD.

### [2] 확률로 보기 — MLE, 베이즈, MAP · [09.02 §5](09.02%20수업정리.md) · [09.07](09.07%20수업정리.md)

- **질문:** 모수 $\theta$를 데이터로 어떻게 추정하나? 사전 지식은 어떻게 넣나?
- **답:**
  - **MLE** $\hat\theta=\arg\max_\theta\log p(\mathcal D\mid\theta)$ — i.i.d.라 곱 → 로그 → 합. 🔴 베르누이면 $\hat\theta=\frac1n\sum x_i$
  - **베이즈** $p(\theta\mid\mathcal D)\propto p(\mathcal D\mid\theta)\,p(\theta)$ — posterior ∝ likelihood × prior, 분모는 evidence
  - 🔴 **MAP** $\hat\theta=\arg\min_\theta[\underbrace{-\log p(x\mid\theta)}_{\text{data fitting loss}}\underbrace{-\log p(\theta)}_{\text{regularization}}]$ — prior $N(0,\tau^2I)$ → $\frac{1}{2\tau^2}\lVert\theta\rVert^2$ (**L2 정규화**)
  - 🔴 베르누이 + 균등 prior → posterior **Beta$(S+1,\,n-S+1)$** (prior와 posterior가 같은 Beta족)
- **예제로 감 잡기:** 기침→감기 30.8% (prior가 낮으면 posterior도 낮다) · 동전 7/10: MLE 0.7, MAP 0.667 (prior가 0.5 쪽으로 당김) · Amazon 판매자: 리뷰 2개짜리 100%보다 100개짜리 90%가 낫다 (확률 0.71)
- **다음 질문:** 손실을 "분포 사이의 차이"로 볼 수 있나? → [3]

### [3] 정보이론 — 손실함수의 언어 · [09.07 §8–9](09.07%20수업정리.md) · [09.09 §1–2](09.09%20수업정리.md)

- **질문:** 불확실성과 두 분포의 차이를 어떻게 재나?
- **답:**

| 양 | 정의 | 성질 |
| --- | --- | --- |
| 정보량 | $h(x)=-\log p(x)$ | 드물수록 큼, 독립이면 더해짐 |
| 엔트로피 | $H(X)=-\mathbb E[\log p(X)]$ | $\ge0$ |
| 결합·조건부 | $H(X,Y)=H(X)+H(Y\mid X)$ | 🟠 로그의 곱 → 합 |
| KL | $KL(p\Vert q)=\mathbb E_p[\log\frac pq]$ | 🔴 $\ge0$, 등호 ⇔ $p=q$ (Jensen). 비대칭 |
| 상호정보량 | $I(X;Y)=KL(p(x,y)\Vert p(x)p(y))$ | $=H(Y)-H(Y\mid X)$ |
| Cross entropy | $H_p(q)=-\mathbb E_p[\log q]$ | $=H(p)+KL(p\Vert q)\ge H(p)$ |

- **핵심 연결:** 데이터 분포 $p$가 고정이면 $H(p)$는 상수 → **cross entropy 최소화 = KL 최소화**. 그리고 [5]에서 보듯 **cross entropy 최소화 = MLE**다.
- **다음:** 회귀로 돌아가 [1]의 "왜 제곱오차?"에 답한다.

### [4] 회귀 완성 — 제곱오차의 정체, 과적합, 정규화, 커널 · [09.09](09.09%20수업정리.md)

- **질문 1:** 왜 제곱오차인가? → 오차가 $N(0,\sigma^2)$이면 로그가능도 $=\text{const}-\frac{1}{2\sigma^2}\sum(y_i-\hat y_i)^2$ → **LSE = MLE**
- **질문 2:** 모델이 너무 복잡하면? → 다항회귀(특성 $1,x,\dots,x^M$인 선형회귀)에서 $M=9$면 train 오차는 0에 가깝지만 test 오차가 커진다(**과적합**). 큰 계수에 벌점: $J=\frac12f(\beta)+\frac\lambda2\lVert\beta\rVert^2$
  - 🟠 **ridge 해** $\hat\beta=(\lambda I+X^\top X)^{-1}X^\top y$ ($\lambda>0$이면 항상 가역)
  - [2]와 합치면: 가우시안 오차 + 가우시안 prior의 **MAP = ridge**, $\lambda=\sigma^2/\tau^2$ (보충)
- **질문 3:** 관계가 비선형이면? → 특성공간으로 보낸다 $x\mapsto\phi(x)$. 🔴 **kernel ridge**:
  $$\beta^\ast=\phi(X)\big(\lambda I+\phi(X)^\top\phi(X)\big)^{-1}y,\qquad f^\ast(x)=K(x,X)\,\alpha^\ast,\quad\alpha^\ast=(K+\lambda I)^{-1}y$$
  $\phi$는 내적으로만 나타나므로 커널 $K(x,z)=\phi(x)^\top\phi(z)$만 있으면 된다. 역행렬 크기가 특성 차원에서 **샘플 수**로 바뀐다.
- **다음 질문:** 출력이 범주라면? → [5]. 그리고 "공간을 바꾼다"는 발상은 [6]에서 **학습되는** $\phi$로 다시 나온다.

### [5] 분류 — 로지스틱, softmax, SVM · [09.14](09.14%20수업정리.md)

- **질문 1:** $y\in\{0,1\}$이면? → **log-odds를 선형으로** 둔다: $\log\frac{p}{1-p}=w^\top x$ → $p=\sigma(w^\top x)$
  - 학습은 MLE. 가능도는 [2]의 베르누이와 같은 꼴 → $-\log\mathcal L$ = **binary cross entropy** ([3]과 연결)
  - 기울기 $\sum_i(\sigma(w^\top x_i)-y_i)x_i$, 닫힌 해가 없어서 GD
  - 🔴 **볼록성:** $\nabla^2J=X^\top SX$, $S=\text{diag}(\sigma_i(1-\sigma_i))\succeq0$ → 극소 = 전역 최소
- **질문 2:** 클래스가 $C$개면? → **softmax** $p_k=e^{w_k^\top x}/\sum_je^{w_j^\top x}$, 정답은 one-hot, 손실은 cross entropy. 기울기는 또 "(정답 − 예측) × 입력"
- **질문 3:** 맞게 나누는 초평면이 여러 개면 어느 것? → **마진이 최대인 것 (SVM)**
  - 🔴 거리 $\frac{|w^\top x+b|}{\lVert w\rVert}$ → 🔴 scale invariance로 $\min|w^\top x+b|=1$ 고정 → $\min\frac12\lVert w\rVert^2$ s.t. $y_i(w^\top x_i+b)\ge1$
  - 🔴 penalty $\max_{\alpha_i\ge0}\alpha_i(1-y_i(\cdot))$로 제약을 없애고, 라그랑주 쌍대로 푼다. 쌍대에는 데이터가 $x_i^\top x_j$ 내적으로만 나온다 → 커널 적용 가능
- **다음 질문:** 선형 경계로 안 되는 데이터는? 커널처럼 공간을 바꾸되, 그 공간을 **데이터에서 배울** 수는 없나? → [6]

### [6] 신경망 — 학습되는 특성공간 + 역전파 · [09.16](09.16%20수업정리.md) · [09.21 §1–3](09.21%20수업정리.md)

- **질문 1:** 비선형 경계를 어떻게 학습하나?
  - 신경망 = 선형함수 + 비선형 활성화의 반복: $f(x)=W_2\max(0,W_1x)$
  - 활성화를 빼면 $W_3W_2W_1x$ = 행렬 하나 → **선형 모델**로 돌아간다
  - **은닉층 = 입력의 비선형 임베딩**: 데이터를 선형분리 가능한 공간으로 옮긴다 ([4] 커널과 같은 발상, $\phi$를 학습)
  - 마지막 층은 softmax + cross entropy — [5]와 같다
- **질문 2:** 파라미터 수백만 개의 기울기를 어떻게 구하나? → **역전파 = 연쇄법칙의 체계적 적용**
  - 노드마다 **downstream = upstream × local**
  - 게이트 패턴: add = 그대로 나눠줌, mul = 상대 입력을 곱함, copy = 더함, max = 최댓값 쪽으로만
  - 🟠 벡터: ReLU의 Jacobian은 대각 → 행렬을 만들지 말고 원소별 곱
- **다음 질문:** 손실이 볼록도 아니고 파라미터도 많다. 잘 학습되게 하려면? → [7]

### [7] 학습 기술 — 빠르게, 안정적으로 · [09.21 §4–6](09.21%20수업정리.md) · [09.23 §1–3](09.23%20수업정리.md)

| 문제 | 해결 | 핵심 |
| --- | --- | --- |
| 한 스텝이 너무 느림 ([1]의 단점) | **SGD / mini-batch** | $\mathbb E[\nabla f_i]=\nabla f$ (불편), 차이는 **분산**. 실전은 mini-batch |
| 기울기가 사라짐 | 활성화 선택 | sigmoid: 포화 + zero-centered 아님 → tanh: zero-centered, 포화 → ReLU: 포화 없음, 음수 쪽 0 |
| 초기값이 작으면 활성값 → 0, 크면 포화 | **초기화** | 🔴 Xavier $\text{Var}(y)=D_{in}\sigma^2V$ → $\sigma^2=1/D_{in}$ · 🔴★ He (ReLU가 절반을 0으로) → $\sigma^2=2/D_{in}$ |
| LR이 크면 발산, 작으면 느림 | **LR 스케줄** | step·cosine·linear·inverse sqrt decay, linear warmup |
| 층마다 활성값 분포가 흔들림 | **Batch Norm** | $\hat x=\frac{x-\mu}{\sqrt{\sigma^2+\varepsilon}}$, $y=\gamma\hat x+\beta$. 테스트엔 running 평균 → affine → fuse. 효과의 이유는 ICS 감소가 아니라 **매끄러운 손실 지형** |

- **공통 원리:** 신호의 크기(분산·2차 모멘트)를 **층마다 유지**한다. 초기화는 시작할 때 한 번, BN은 학습 내내 한다.
- **다음 질문:** GD가 정말 함수값을 줄이나? LR은 얼마까지 키워도 되나? → [8]

### [8] 최적화 이론 — GD가 내려가는 이유 · [09.23 §4–6](09.23%20수업정리.md) · 9/28 계속

- **직관:** 1차 Taylor $f(x+\eta v)\approx f(x)+\eta\langle\nabla f,v\rangle$ → 가장 빨리 줄이는 단위 방향은 $v=-\nabla f/\lVert\nabla f\rVert$ → GD
- 🔴★ **Descent Lemma:** $\nabla f$가 $\beta$-Lipschitz이면
  $$f(y)\le f(x)+\langle\nabla f(x),y-x\rangle+\frac\beta2\lVert y-x\rVert^2$$
  "$f$는 1차 근사 + 포물선 위로 올라가지 못한다." (③ Hessian 상계는 9/28)
- 🟠 **GD 한 스텝:** $f(x_{t+1})\le f(x_t)-(\eta-\frac{\beta\eta^2}{2})\lVert\nabla f(x_t)\rVert^2$ → **$\eta<2/\beta$면 감소**, $\eta=1/\beta$일 때 가장 많이 준다 (보충)
- **돌아보면:** [7]의 LR 곡선 (a)가 발산한 이유 = $\eta$가 $2/\beta$보다 컸다. BN이 큰 LR을 허용하는 이유 = 지형이 매끄러워져 $\beta$가 작아졌다.

## 3. 연결 고리 — 반복해서 나오는 아이디어

| 아이디어 | 처음 나온 곳 | 다시 나오는 곳 |
| --- | --- | --- |
| **가능도 최대화 = 손실 최소화** | 베르누이 MLE (9/7) | 가우시안 → 제곱오차 (9/9), 베르누이 → binary CE, 범주형 → CE (9/14) |
| **prior = 정규화** | MAP의 $-\log p(\theta)$ (9/7) | ridge $=$ 가우시안 prior, $\lambda=\sigma^2/\tau^2$ (9/9). (보충) LASSO = 라플라스 prior |
| **cross entropy = H + KL** | 9/9 | 분류 손실 (9/14), 신경망 출력층 (9/16) |
| **(예측 − 정답) × 입력** | 선형회귀 GD (9/2) | 로지스틱·softmax 기울기 (9/14), 역전파의 upstream × local (9/21) |
| **연쇄법칙** | 로지스틱 기울기 $dl/dz\cdot dz/dw$ (9/14) | 역전파 (9/21), Descent Lemma의 $g'(t),g''(t)$ (9/23) |
| **이차형식 $v^\top Av$** | $\nabla(\beta^\top A\beta)$ (9/2) | Hessian PSD → 볼록 (9/14), $\nabla^2f\preceq\beta I$ (9/23) |
| **독립 → 곱으로 분리, 교차항 0** | 독립 사건 (9/2), i.i.d. 가능도 (9/7) | Xavier·He의 분산 계산 (9/21, 9/23) |
| **공간 바꾸기** | kernel trick $\phi$ (9/9) | SVM 쌍대의 내적 (9/14), 은닉층 = 학습되는 임베딩 (9/16) |
