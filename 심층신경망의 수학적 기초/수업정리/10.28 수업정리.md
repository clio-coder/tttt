## 1. 왜 RNN인가 [W9W p2–3]

**순서가 있거나 길이가 바뀌는(sequence / variable-length) 데이터를 처리·생성**하려고 쓴다.

| 유형 | 입력 → 출력 | 응용 (슬라이드) |
| --- | --- | --- |
| one to one | 1 → 1 | 보통의 NN / FFN |
| one to many | 1 → 여러 개 | Img2Vid, **Img2Cap** (이미지 캡셔닝) |
| many to one | 여러 개 → 1 | 동영상 분류, 행동 인식 |
| many to many (입력 다 읽고 출력) | 여러 개 → 여러 개 | **번역 (ENG → KOR)**, Video to caption |
| many to many (매 시점 출력) | 여러 개 → 여러 개 | 동영상 분할·편집·스타일 변환 |

판서: many-to-one 입력 아래 $t=1,2,3$ , 번역형 many-to-many는 입력 $t=1,2,3$ , 출력 $t=4,5,6$ .

## 2. RNN의 구조 [W9W p4–9]

**Key idea:** RNN은 시퀀스를 처리하면서 갱신되는 **내부 상태(internal state)** $h_t$ 를 가진다.

$$h_t=f(h_{t-1},x_t),\qquad y_t=g(h_t)\qquad(\text{판서 p5})$$

**Vanilla RNN** (슬라이드 p6, $t\ge1$ )

$$h_t=\sigma(Uh_{t-1}+Wx_t+b),\qquad\hat y_t=W^{out}h_t,\qquad h_0=0$$

- 판서 전개: $t=1$ 이면 $h_1=\sigma(Wx_1+b)$ ( $h_0=0$ 이라 $Uh_0$ 이 사라짐) → $\hat y_1=W^{out}h_1$ . $t=2$ 이면 $h_2=\sigma(Uh_1+Wx_2+b)$ → $\hat y_2=W^{out}h_2$
- **"the same function and the same set of parameters are used at every time step"** (박스) — 시점마다 다른 가중치가 아니라 **같은 $U,W,b,W^{out}$ 를 공유**한다. CNN이 위치마다 같은 필터를 쓰는 것(가중치 공유)의 시간판이다.
- p7의 일반형: $h_t=f_W(h_{t-1},x_t)$ (new state = 함수(old state, 입력)), $y_t=f_{W_{hy}}(h_t)$

**Backprop through time (BPTT)** (p8): 시퀀스 전체를 forward해서 loss를 구하고, 시퀀스 전체를 backward해서 기울기를 구한다. 모든 시점의 출력 loss가 합쳐진다.

**Truncated BPTT** (p9): hidden state는 계속 앞으로 넘기되, 역전파는 **최근 몇 스텝만** 한다 (긴 시퀀스에서 계산량을 줄임).

## 3. 📋🔴 2-step RNN의 BPTT 손계산 [W9W p10–13] — "Quiz 2 11/04"

### 3.1 설정 (판서 표기)

$$h_t=\tanh(Wh_{t-1}+Ux_t+b),\qquad Y_t=Vh_t+c,\qquad\theta=(W,U,V,b,c)$$

- 입력 $(X_1,\dots,X_T)$ , 출력 $(Y_1,\dots,Y_T)$ , 목표 $(Z_1,\dots,Z_T)$ , 손실 $L=\sum_tL_t$ .
- 각 시점의 계산과 시간을 거치는 계산이 합성되어 있어서 MLP보다 복잡하다 → **간단히 2스텝, 모든 변수는 1차원 실수**로 본다.

**Forward**

| $t=1$ | $t=2$ |
| --- | --- |
| $a_1=Wh_0+UX_1+b$ | $a_2=Wh_1+UX_2+b$ |
| $h_1=\tanh a_1$ | $h_2=\tanh a_2$ |
| $Y_1=Vh_1+c$ | $Y_2=Vh_2+c$ |

$$L=L_1+L_2=\frac12(Y_1-Z_1)^2+\frac12(Y_2-Z_2)^2,\qquad\text{구할 것: }\nabla_\theta L=\Big(\frac{\partial L}{\partial W},\frac{\partial L}{\partial V},\frac{\partial L}{\partial U},\frac{\partial L}{\partial b},\frac{\partial L}{\partial c}\Big)$$

### 3.2 재료: 국소 미분 (판서 p11–12)

$\frac d{da}\tanh a=\mathrm{sech}^2a=1-\tanh^2a$ 를 쓰면

| 미분 | 값 | 비고 |
| --- | --- | --- |
| $\partial h_1/\partial W$ | $(1-h_1^2)h_0$ | $\partial a_1/\partial W=h_0$ |
| $\partial h_2/\partial W$ | $(1-h_2^2)h_1$ | **$h_1$ 을 고정한 직접 미분** |
| $\partial h_1/\partial U$ , $\partial h_2/\partial U$ | $(1-h_1^2)X_1$ , $(1-h_2^2)X_2$ | 직접 미분 |
| $\partial h_1/\partial b$ , $\partial h_2/\partial b$ | $1-h_1^2$ , $1-h_2^2$ | 직접 미분 |
| $\partial L_1/\partial h_1$ | $(Y_1-Z_1)V$ | $L_1$ 은 $Y_1$ 을 통해서만 $h_1$ 에 의존 |
| $\partial L_2/\partial h_2$ | $(Y_2-Z_2)V$ | |
| **$\partial h_2/\partial h_1$** | **$(1-h_2^2)W$** | 시간을 건너는 고리 |

⚠️ 표의 $\partial h_2/\partial W$ 등은 $h_1$ 을 상수로 본 **직접(explicit) 미분**이다. $h_1$ 도 $W$ 에 의존하므로, 그 경로는 아래에서 $\frac{\partial h_2}{\partial h_1}\frac{\partial h_1}{\partial W}$ 항으로 **따로 더한다**.

### 3.3 출력층 파라미터: V, c (시간 경로 없음)

$L_t$ 는 $Y_t$ 를 통해서만 $V$ , $c$ 에 의존한다.

$$\frac{\partial L}{\partial V}=\frac{\partial L_1}{\partial Y_1}\frac{\partial Y_1}{\partial V}+\frac{\partial L_2}{\partial Y_2}\frac{\partial Y_2}{\partial V}=(Y_1-Z_1)h_1+(Y_2-Z_2)h_2=\sum_t(Y_t-Z_t)h_t$$

★ (D.I.Y.) $\partial Y_t/\partial c=1$ 이므로

$$\frac{\partial L}{\partial c}=\sum_t(Y_t-Z_t)=(Y_1-Z_1)+(Y_2-Z_2)$$

✏️ 판서는 $\partial L/\partial V$ 의 좌변을 $\partial L_t/\partial V$ 로 박스 쳤지만 우변이 $L_1+L_2$ 의 합이라 $\partial L/\partial V$ 다.

### 3.4 순환 파라미터: W (시간 경로 있음)

$L_2$ 는 $W$ 에 **두 경로**로 의존한다: $h_2$ 에 직접( $a_2=Wh_1+\cdots$ ), 그리고 $h_1$ 을 거쳐( $h_1$ 도 $W$ 의 함수).

$$\frac{\partial L}{\partial W}=\underbrace{\frac{\partial L_1}{\partial h_1}\frac{\partial h_1}{\partial W}}_ {L_1}+\underbrace{\frac{\partial L_2}{\partial h_2}\frac{\partial h_2}{\partial W}}_ {L_2\text{, 직접}}+\underbrace{\frac{\partial L_2}{\partial h_2}\frac{\partial h_2}{\partial h_1}\frac{\partial h_1}{\partial W}}_ {L_2\text{, 시간을 거슬러}}$$

$$=(Y_1-Z_1)V(1-h_1^2)h_0+(Y_2-Z_2)V(1-h_2^2)h_1+(Y_2-Z_2)V(1-h_2^2)\thinspace W(1-h_1^2)h_0$$

- ✏️ 판서 p13은 셋째 항을 $(1-h_0^2)$ 로 적었다. $\frac{\partial h_2}{\partial h_1}=(1-h_2^2)W$ (p12) 이므로 **$(1-h_2^2)$** 가 맞다 (수치 미분으로 확인).
- $h_0=0$ 이면 첫째·셋째 항이 0이라 $(Y_2-Z_2)V(1-h_2^2)h_1$ 만 남는다.

### 3.5 ★ D.I.Y.: U와 b

$U$ , $b$ 도 $W$ 와 똑같이 **직접 경로 + 시간 경로**가 있다. $\frac{\partial h_1}{\partial W}$ 자리에 $\frac{\partial h_1}{\partial U}$ 또는 $\frac{\partial h_1}{\partial b}$ 를 넣으면 된다.

$$\frac{\partial L}{\partial U}=(Y_1-Z_1)V(1-h_1^2)X_1+(Y_2-Z_2)V(1-h_2^2)\Big[X_2+W(1-h_1^2)X_1\Big]$$

$$\frac{\partial L}{\partial b}=(Y_1-Z_1)V(1-h_1^2)+(Y_2-Z_2)V(1-h_2^2)\Big[1+W(1-h_1^2)\Big]$$

- 대괄호 안: 첫째 = $h_2$ 에 직접, 둘째 = $\frac{\partial h_2}{\partial h_1}$ 의 $W$ 와 $h_1$ 의 국소 미분을 곱한 시간 경로.
- 판서의 $\partial L/\partial U$ 첫 항 $(Y_1-Z_1)V(1-h_1^2)X_1$ 과 일치한다.

**검산** $W=0.7$, $U=-0.4$, $V=1.3$, $b=0.2$, $c=-0.1$, $X=(0.5,-1.2)$, $Z=(0.3,0.8)$, $h_0=0.6$ 에서 위 다섯 식과 수치 미분이 소수 8자리까지 같다 ( $\partial L/\partial W\approx0.1052$ ; 판서대로 $(1-h_0^2)$ 를 쓰면 0.1111로 틀린다).

**정리: RNN 역전파의 규칙**
1. 출력층 파라미터( $V,c$ ): 시점별로 구해서 **더한다** (가중치 공유라서).
2. 순환·입력 파라미터( $W,U,b$ ): 시점 $t$ 의 loss는 **$t$ 이전 모든 시점**의 그 파라미터를 거친다 → $\frac{\partial h_t}{\partial h_{t-1}}$ 을 곱해 가며 과거로 내려간다.

### 3.6 Multi-cell 일반화 (판서 p13, 슬라이드 p14)

$$h_0=0,\qquad h_\ell=q_{\tilde\theta}(h_{\ell-1},u_\ell)\ \ (\ell=1,\dots,L),\qquad q_{\tilde\theta}:\mathbb R^n\times\mathbb R^m\to\mathbb R^n,\qquad q(h,u)=\phi(Wh+Uu+c)$$

$$f_\theta(X)=Ah_L+b,\qquad\theta=(A,b,\tilde\theta)$$

(⚠️ 여기서는 $b$ 가 출력 bias, $c$ 가 hidden bias로 2-step 예와 반대다. 입력은 $\tau(X)=(u_1,\dots,u_L)$ , $A\in\mathbb R^{1\times n}$ .)

## 4. 🟠 일반 RNN의 역전파: Jacobian의 긴 곱 [W9W p14–18]

**출력 쪽** (p14)

$$\frac{\partial\mathcal L(f_\theta(X),Y)}{\partial\theta}=\frac{\partial\mathcal L}{\partial f}\cdot\frac{\partial f_\theta(X)}{\partial\theta},\qquad\frac{\partial f_\theta}{\partial A}=h_L,\quad\frac{\partial f_\theta}{\partial b}=1,\quad\frac{\partial f_\theta}{\partial\tilde\theta}=A\frac{\partial h_L}{\partial\tilde\theta}$$

**순환 파라미터** (p15 판서로 채움, p16)

$$\frac{\partial\mathcal L}{\partial\tilde\theta}=\sum_{\ell=1}^L\frac{\partial\mathcal L}{\partial h_\ell}\frac{\partial q_{\tilde\theta}}{\partial\tilde\theta}(h_{\ell-1},u_\ell)$$

같은 $\tilde\theta$ 가 모든 cell에 쓰이므로 $\ell=1,\dots,L$ 의 기여를 **더한다** (§3.4–3.5의 일반형).

**문제의 곱** (빨강·파랑 박스)

$$\frac{\partial\mathcal L}{\partial h_\ell}=\frac{\partial\mathcal L}{\partial h_L}\frac{\partial h_L}{\partial h_{L-1}}\frac{\partial h_{L-1}}{\partial h_{L-2}}\cdots\frac{\partial h_{\ell+1}}{\partial h_\ell}$$

- 시퀀스 길이가 수백·수천이 흔하다 (판서 " $L\approx100,1000$ "). → **RNN은 매우 깊은 망**이다.
- 많은 수를 곱하면 불안정하다:
  - 대부분 $\gt1$ → $\infty$ : **exploding gradient** (gradient clipping으로 고칠 수 있다)
  - 대부분 $\lt1$ → 0: **vanishing gradient** (**더 큰 문제**)
  - 모두 1에 가까울 때만 적당한 크기
- 10/7의 깊은 CNN에서 본 gradient vanishing(층별 Jacobian의 곱)과 같은 구조. 여기서는 **같은 $W$ 가 반복해서 곱해진다** ( $\frac{\partial h_{k+1}}{\partial h_k}=\mathrm{diag}(1-h_{k+1}^2)W$ ).

**Exploding과 gradient clipping** (p17)
- exploding = 출력이 어떤 방향의 작은 파라미터 변화에 매우 민감하다. 쓸 수 없으면 구조를 바꿔야 하지만, **방향은 괜찮다면** 크기만 잘라 쓴다.
- 임계값 $v$ (스칼라)로 ✏️

$$g\leftarrow\min\Big(1,\frac v{\lVert g\rVert}\Big)g=\begin{cases}g&\lVert g\rVert\le v\cr\dfrac v{\lVert g\rVert}g&\text{otherwise}\end{cases}$$

- ✏️ 슬라이드는 $\max(1,v/\lVert g\rVert)$ 로 적었지만, 그러면 $\lVert g\rVert\le v$ 일 때 $v/\lVert g\rVert\ge1$ 이라 기울기를 오히려 키운다. 오른쪽 case 식과 맞으려면 **$\min$** 이다.
- 판서 " $v=\infty$ ?": $v\to\infty$ 이면 항상 $g$ 그대로 = clipping 없음.
- 효과: **방향은 그대로, 크기만 $v$ 로 제한**. 그림: clipping이 없으면 손실 지형의 절벽에서 한 스텝이 멀리 튕겨 나가고, 있으면 스텝이 작게 유지된다.

**Vanishing** (p18): $\partial\mathcal L/\partial h_L$ 은 작지 않아도 $\partial\mathcal L/\partial h_\ell$ 은 작을 수 있다. 그러면 $h_\ell$ 의 변화가 $\mathcal L$ 에 영향을 주지 않고, $\frac{\partial\mathcal L}{\partial u_\ell}=\frac{\partial\mathcal L}{\partial h_\ell}\frac{\partial h_\ell}{\partial u_\ell}$ 도 작다 → **RNN이 시점 $\ell$ 의 입력 $u_\ell$ 을 시점 $L$ 까지 기억하지 못한다** (먼 미래의 기울기 신호가 사라져서 무엇을 보존해야 할지 배우지 못한다).

## 5. 🔴 LSTM [W9W p19–27]

### 5.1 식 (슬라이드 p20, p23)

$$\begin{pmatrix}i\cr f\cr o\cr g\end{pmatrix}=\begin{pmatrix}\sigma\cr\sigma\cr\sigma\cr\tanh\end{pmatrix}W\begin{pmatrix}h_{t-1}\cr x_t\end{pmatrix},\qquad c_t=f\odot c_{t-1}+i\odot g,\qquad h_t=o\odot\tanh(c_t)$$

- vanilla RNN은 $h_t=\tanh\big(W[h_{t-1};x_t]\big)$ ( $[h_{t-1};x_t]$ = 두 벡터를 세로로 쌓은 것) 하나뿐.
- 차원 (p23, 밑줄): $x_t$ , $h_{t-1}$ 이 각각 $h$ 차원이면 $W$ 는 **$4h\times2h$** , 결과 $4h$ 를 넷으로 나눠 $i,f,o$ (sigmoid), $g$ (tanh). (보충) 입력이 $d$ 차원이면 $W\in\mathbb R^{4h\times(h+d)}$ .

### 5.2 판서 정의 (p21–22)

- RNN: $h_t=\tanh(W_hh_{t-1}+W_xx_t+b)$
- LSTM: $h_t$ = hidden state, **$C_t$ = cell state (long memory)**

| 게이트 | 식 | 판서 설명 | 슬라이드 (p23) |
| --- | --- | --- | --- |
| input $i_t$ | $\sigma(W_ix_t+U_ih_{t-1}+b_i)$ | 새 정보 $g_t$ 를 cell에 얼마나 쓸까 | whether to write to cell |
| forget $f_t$ | $\sigma(W_fx_t+U_fh_{t-1}+b_f)$ | ✏️ 이전 cell $C_{t-1}$ 의 정보를 얼마나 가져갈까 | whether to erase cell |
| output $o_t$ | $\sigma(W_ox_t+U_oh_{t-1}+b_o)$ | cell을 얼마나 $h_t$ 에 쓸까 | how much to reveal cell |
| $g_t$ | $\tanh(W_gx_t+U_gh_{t-1}+b_g)$ | 현재 입력에서 새로 쓸 내용 | "gate gate", how much to write |

$$C_t=f_t\odot C_{t-1}+i_t\odot g_t\quad(\text{파란 박스}),\qquad h_t=o_t\odot\tanh(C_t),\qquad\odot=\text{원소별 곱}$$

- ✏️ 판서의 forget gate 설명은 " $C_t$ 의 Info."지만 식에서 $f_t$ 가 곱해지는 것은 $C_{t-1}$ 이다.
- sigmoid 게이트는 값이 $(0,1)$ 이라 "얼마나 통과시킬지"의 비율, $g_t$ 는 tanh라 $(-1,1)$ 의 내용.
- p25 (colah 그림)의 $\tilde C_t$ = $g_t$ , $\ast$ = $\odot$ .

### 5.3 🔴 왜 vanishing이 줄어드나 (판서 p26, 슬라이드 p27)

**Rmk** cell state 경로로 미분하면 (게이트 값을 고정한 직접 경로)

$$\frac{\partial C_t}{\partial C_{t-1}}=\mathrm{diag}(f_t),\qquad f_t\approx1\quad(\text{동그라미·이중 밑줄})$$

| | 한 스텝 뒤로 갈 때 곱해지는 것 |
| --- | --- |
| RNN | $\frac{\partial h_t}{\partial h_{t-1}}=(1-h_t^2)W_h$ — **같은 행렬 $W_h$ 를 반복해서 곱함** + tanh 미분 |
| LSTM (cell 경로) | $\mathrm{diag}(f_t)$ — **행렬 곱 없이 forget gate 값만 원소별로 곱함** |

- $f_t\approx1$ 이면 기울기가 cell state를 따라 거의 그대로 과거로 간다: **"Uninterrupted gradient flow!"** ( $c_3\to c_0$ 빨간 화살표)
- 예: $f=1$, $i=0$ 이면 그 cell의 정보가 **무한히 보존**된다. vanilla RNN은 정보를 보존하는 $W$ 를 배우기가 훨씬 어렵다.
- 단 LSTM이 vanishing/exploding이 **없다고 보장하지는 않는다.** 먼 거리의 의존성을 배우는 더 쉬운 길을 줄 뿐이다.
- (보충) ResNet의 $x+F(x)$ 가 기울기를 identity 경로로 보내는 것과 같은 생각이다 (10/7).

## 6. RNN의 응용 [W9W2 p2–13]

(판서 p2 스케치: SIRD 전염병 ODE 모형의 감염지수 $\alpha(t)$ 를 LSTM으로 추정하는 응용 예. 설명 문장은 없다.)

### 6.1 언어 모델 (p3–10)

- 문장 = 이산 기호(토큰)의 시퀀스 → **one-hot 인코딩** $x_t\in\mathbb R^n$ ( $n$ = 어휘 수). 예: A = [00001000], Man = [01000000], … (대소문자 구분 없이 A와 a는 같은 토큰)
- **문장 생성 = 다음 토큰 예측** (박스)

| 층 | 식 | 차원 |
| --- | --- | --- |
| one-hot | $x_t$ | $\mathbb R^n$ |
| continuous word embedding | $z_t=W_ex_t+b_e$ | $W_e\in\mathbb R^{d\times n}$ , $z_t\in\mathbb R^d$ |
| RNN | $h_t=\mathrm{LSTM}(z_t,h_{t-1},c_{t-1};\theta)$ | $h_t\in\mathbb R^d$ |
| classification layer | $\hat x_{t+1}=W_dh_t+b_d$ | $W_d\in\mathbb R^{n\times d}$ , $\hat x_{t+1}\in\mathbb R^n$ (단어별 점수) |

- **학습** (p8): 입력 <SOS>, A, Man, …, bat → 출력 A, Man, …, bat, <EOS>. 손실 $\sum_{t=1}^T\mathcal L(\hat x_t,x_t)$ = **cross entropy (단어 단위 분류)** — 03장 softmax 분류를 시점마다 하는 것. 학습 때 입력은 **정답 토큰**이다.
- **추론** (p9–10): 시점마다 출력 점수에서 단어 하나를 뽑아 **다음 입력으로 넣는다** (빨간 화살표). <EOS>가 나오면 멈춘다.
  - **greedy**: 점수가 최대인 단어 ( $\arg\max$ , 결정적)
  - **probabilistic**: 점수(확률)에 따라 샘플링 (확률적)
- ✏️ 슬라이드 p7의 <EOS> one-hot이 [00001000]으로 A와 같게 적혀 있다 (복사 실수, 별도 인덱스여야 함).

### 6.2 기계 번역 (p11)

encoder RNN이 원문(He loved to eat)을 읽어 **context vector $s$** 를 만들고, decoder RNN이 $s$ 에서 시작해 번역문(Er liebte zu essen)을 한 단어씩 생성한다. decoder 입력은 NULL, Er, liebte, … — 출력이 한 칸 밀려 다음 입력이 된다 (many-to-many, 입력을 다 읽고 출력).

### 6.3 이미지 캡셔닝 정의 (p13)

이미지 $x$ 를 문장 $y$ 로 묘사한다 (one-to-many).

$$f_\theta\big(y\mid g_\phi(x)\big)$$

1. 이미지의 시각 패턴 인식 → **CNN** $g_\phi$
2. 이미지에 조건부로 문장 생성 → **RNN** $f_\theta$

(✏️ 슬라이드의 안쪽 기호가 깨져 있어 판서로 $f_\theta(y\mid g_\phi(x))$ 로 고쳐 썼다.) 구체적인 모델은 11/2 수업 → [11.02](11.02%20수업정리.md).
