## 1. 🔴 Linearization of Transformer (linear attention) [W10W p1–4 · 필기본 p19]

### 1.1 Recap: attention을 행렬로 [p1]

입력 $X=[x_1,\dots,x_N]^\top\in\mathbb R^{N\times D_x}$ .

- **step 1** Project $X$ into $Q,K,V$ : $Q=XW_Q^\top$, $K=XW_K^\top$, $V=XW_V^\top$ . $W_Q,W_K\in\mathbb R^{D\times D_x}$, $W_V\in\mathbb R^{D_v\times D_x}$ (learnable). $Q=[q_1,\dots,q_N]^\top$ , $K$, $V$ 도 같은 식.
- **step 2** Output seq. $\hat V=[\hat v_1,\dots,\hat v_N]^\top$ where

$$\hat v_i=\sum_{j=1}^N\text{softmax}\Big(\frac{q_i^\top k_j}{\sqrt D}\Big)v_j\iff\hat V=\underbrace{\text{softmax}\Big(\frac{QK^\top}{\sqrt D}\Big)}_ {A}V=AV$$

- 판서는 softmax 부분 위에 괄호를 긋고 **"AV"** 에 여러 겹 동그라미. 11/2의 $\text{softmax}(QK^\top/\sqrt{d_k})V$ 와 같은 식인데, 여기서는 가중치 행렬을 $W^\top$ 로 곱하는 표기다.

### 1.2 병목 [p2]

| 무엇 | 비용 | 판서 |
| --- | --- | --- |
| $A\in\mathbb R^{N\times N}$ 저장 | $O(N^2)$ | memory |
| $AV$ 계산 | $O(N^2)$ ( $D_v$ 고정) | time |

→ **"Want to relax this"** (밑줄). 토큰 수 $N$ 이 두 배가 되면 메모리·시간이 네 배다 (보충: 긴 문서, 고해상도 이미지에서 문제).

판서 오른쪽의 동그라미 메모 **"KIMI"** 는 이 아이디어를 쓰는 모델 이름을 적은 것으로 보인다 [추정].

### 1.3 softmax를 "유사도 가중평균"으로 다시 쓰기 [p2–3]

Note that (빨강 박스) $\hat v_i=\sum_j\text{softmax}(\cdot)v_j$ can be written as

$$\hat v_i=\frac{\sum_{j=1}^N\mathrm{sim}(q_i,k_j)\thinspace v_j}{\sum_{j=1}^N\mathrm{sim}(q_i,k_j)},\qquad\mathrm{sim}(q,k):=\exp\Big(\frac{q^\top k}{\sqrt D}\Big)\qquad(\text{초록 형광})$$

∵ (판서 "b/c") $s_{ij}=\frac{q_i^\top k_j}{\sqrt D}$ 로 두면 $\alpha_{ij}=\text{softmax}_ j(s_{ij})=\frac{\exp(s_{ij})}{\sum_{l=1}^N\exp(s_{il})}$ 이므로

$$\hat v_i=\sum_{j=1}^N\alpha_{ij}v_j=\frac{\sum_{j=1}^N\exp(s_{ij})\thinspace v_j}{\sum_{l=1}^N\exp(s_{il})}$$

이고 $\exp(s_{ij})=\mathrm{sim}(q_i,k_j)$ 다. (✏️ 판서 p2 마지막 줄은 분수 뒤의 $v_j$ 가 빠졌고, p3 첫 줄에서 $v_j$ 를 넣어 다시 썼다.)

- 뜻: attention 출력은 value들을 **query–key 유사도로 가중평균**한 것이다. softmax는 그 유사도를 $\exp$ 로 고른 특수한 경우일 뿐이다.

### 1.4 Key idea: 유사도를 kernel로 바꾼다 [p3]

**Key idea** $\mathrm{sim}(q_i,k_j)$ 를 feature map의 내적으로 쓸 수 있는 kernel로 바꾼다 (이중 세로선 강조).

$$\kappa(q_i,k_j)=\phi(q_i)^\top\phi(k_j),\qquad\phi:\mathbb R^D\to\mathbb R^r$$

그러면 (파랑 동그라미 "≈", 파랑 타원)

$$\hat v_i\approx\frac{\sum_j\kappa(q_i,k_j)\thinspace v_j}{\sum_j\kappa(q_i,k_j)}\quad\Longrightarrow\quad\tilde v_i^\top=\frac{\phi(q_i)^\top\sum_{j=1}^N\phi(k_j)v_j^\top}{\phi(q_i)^\top\sum_{j=1}^N\phi(k_j)}$$

- 핵심은 **$\phi(q_i)$ 가 $j$ 와 무관해서 합 밖으로 나온다**는 것이다. 남은 합 $\sum_j\phi(k_j)v_j^\top$, $\sum_j\phi(k_j)$ 는 $i$ 와 무관하므로 **한 번만 계산해서 모든 $i$ 에 재사용**한다.
- (보충) 행렬로 쓰면 결합법칙이다: $\big(\phi(Q)\phi(K)^\top\big)V=\phi(Q)\big(\phi(K)^\top V\big)$ . 왼쪽은 $N\times N$ 행렬을 만들고, 오른쪽은 $r\times D_v$ 행렬만 만든다. 판서 메모 " $\hat V=AV\approx(ab^\top)V$ "가 이 직관 (A를 낮은 rank의 곱으로 보면 곱하는 순서를 바꿀 수 있다).
- (보충) 9/9 kernel trick과 방향이 반대다. 9/9는 $\phi$ 를 직접 계산하지 않으려고 내적을 kernel로 바꿨고, 여기서는 kernel(softmax)을 **유한 차원 $\phi$ 의 내적으로** 바꿔서 계산 순서를 바꾼다.

### 1.5 $\phi$ 의 예와 $O(N)$ [p4]

**예** (빨강 타원) 성분별로

$$\phi(x)_ l=\mathrm{ELU}(x_l)+1=\begin{cases}x_l+1&x_l\ge0\cr e^{x_l}&x_l\lt0\end{cases}$$

✏️ 판서는 " $\phi(x)=\mathrm{ELU}(x)$ "라고 썼지만 적힌 구간식은 $\mathrm{ELU}(x)+1$ 이다 ( $\mathrm{ELU}(x)=x$ ( $x\ge0$ ), $e^x-1$ ( $x\lt0$ )). (보충) $+1$ 은 $\phi\gt0$ 으로 만들어 분모 $\phi(q_i)^\top z$ 가 양수가 되게 한다 (softmax의 $\exp$ 가 양수인 것과 같은 역할).

**Set** (파랑 동그라미)

$$S=\sum_{j=1}^N\phi(k_j)v_j^\top\in\mathbb R^{r\times d_v},\qquad z=\sum_{j=1}^N\phi(k_j)\in\mathbb R^r\qquad\Longrightarrow\qquad\tilde v_i=\frac{S^\top\phi(q_i)}{\phi(q_i)^\top z}$$

| 계산 | 비용 (파랑 필기) |
| --- | --- |
| $S$ | $O(Nrd_v)$ |
| $z$ | $O(Nr)$ |
| 모든 $i$ 의 $S^\top\phi(q_i)$, $\phi(q_i)^\top z$ | $O(Nrd_v+Nr)$ |
| **합계** | **$O(N)$** (파랑 박스) — $r,d_v$ 고정 |

- (보충) 숫자로: $N=4096$, $r=d_v=64$ 이면 softmax attention의 $AV$ 는 $N^2d_v\approx1.07\times10^9$ 번 곱, linear attention의 $S$ 는 $Nrd_v\approx1.68\times10^7$ 번 곱 (64배 적다). $N$ 이 커질수록 차이가 커진다.
- (요약) "트랜스포머의 $O(n^2)$ 을 선형 연산으로 $O(n)$ 으로 줄이는 것이 효율 면에서 중요하다. 관련 문제를 직접 찾아보며 기본 아이디어를 이해할 것." (요약의 기법 이름은 받아쓰기가 깨져 있어 옮기지 않았다.)

## 2. 🔴 Layer Normalization: 어느 축으로 정규화하나 [W10W p5–6]

**슬라이드 그림 + 판서 정의** (빨강, 슬라이드 p5)

| 방법 | 평균·분산을 구하는 묶음 (판서) | 그림 (축 N, C, H·W) |
| --- | --- | --- |
| ① **BN** (CNN) | **같은 채널**에 있는, 배치의 모든 샘플·공간 위치 | 채널 하나를 N·H·W 방향으로 |
| ② **LN in CNNs** | **이미지 한 장**의 모든 채널과 공간 위치 | 샘플 하나의 C·H·W 전체 |
| ③ **LN in Transformer** | **토큰 하나**의 모든 특징 성분 | 토큰 하나의 C 방향 한 줄 |

- (요약) CNN의 LN과 Transformer의 LN은 이름이 같지만 정규화하는 축이 다르므로 계산할 때 어느 것인지 분명히 해야 한다.
- BN은 9/23 [09.23 §3](09.23%20수업정리.md)에서 배운 것 (배치 축). ViT 블록의 Norm은 ③이다.

**🔴 판서 수치 예** (p6) CNN, $B=2$, $C=2$ (빨강 밑줄), $H=1$, $W=2$ . 각 이미지의 윗줄 = 채널 1, 아랫줄 = 채널 2 (빨강 "CH1", "CH2")

$$X^{(1)}=\begin{pmatrix}1&3\cr5&7\end{pmatrix},\qquad X^{(2)}=\begin{pmatrix}9&11\cr13&15\end{pmatrix}$$

| 방법 | 묶음 | 평균 | 분산 | 첫 값 1의 정규화 |
| --- | --- | --- | --- | --- |
| (i) BN | 채널 1 = $\lbrace1,3,9,11\rbrace$ / 채널 2 = $\lbrace5,7,13,15\rbrace$ | $\mu_1=6$ / $\mu_2=10$ | $\sigma_1^2=17$ / $\sigma_2^2=17$ | $\frac{1-6}{\sqrt{17}}\approx-1.21$ |
| (ii) LN (CNN) | 이미지 1 = $\lbrace1,3,5,7\rbrace$ / 이미지 2 = $\lbrace9,11,13,15\rbrace$ | $\mu^{(1)}=4$ / $\mu^{(2)}=12$ | $5$ / $5$ | $\frac{1-4}{\sqrt5}\approx-1.34$ |
| (iii) LN (TF) | 토큰 1 = $(1,5)$ / 토큰 2 = $(3,7)$ | $3$ / (보충) $5$ | $4$ / (보충) $4$ | 토큰 1 → $(-1,1)$ |

- (iii)은 위치(가로 칸) 하나를 토큰으로 보고, 그 토큰의 채널 값들(특징 성분)을 묶는다: 토큰 1 = (채널 1, 채널 2) = $(1,5)$ . (판서의 토큰 1 아래 숫자는 6처럼도 보이지만 $\mu=3,\sigma^2=4$ 와 맞는 값은 5다.)
- 분산은 $\frac1n\sum(x-\mu)^2$ (모분산): 채널 1은 $\frac{25+9+9+25}4=17$ , 이미지 1은 $\frac{9+1+1+9}4=5$ .
- 판서에는 $\epsilon$ 과 학습 파라미터 $\gamma,\beta$ 가 없다. (보충) 실제 층은 정규화 뒤 $\gamma\hat x+\beta$ (9/23 BN과 같은 형태).

## 3. Transformer의 성능과 scaling law [W10W p7]

- 원래 Transformer는 기계번역용이었지만 **대규모 데이터에서 놀랍게 잘 scale**되었고, 대규모 모델의 혁신 대부분이 Transformer 구조를 쓴다. (그림: Eliza(1967)부터 GPT-4(2023)까지 LLM 연대표)
- 🟡 판서 **"Scaling law"** (박스) + 손그림: 가로축 param, 세로축 손실(추정) — 파라미터가 늘면 손실이 점점 완만하게 주는 곡선.
- (요약) 파라미터를 올바른 방식으로 늘리면 오차가 **음의 지수승(멱법칙) 형태**로 준다는 것이 실험으로 확인되었고, 기업들은 자기 scaling law를 공개하지 않는다. LLM의 핵심 요소는 ① Transformer 구조 ② 대규모 학습 데이터 ③ 강화학습 ④ fine-tuning.

## 4. 🟠 Vision Transformer (ViT) [W10W p8–15]

**문제:** 이미지는 시퀀스가 아니다 → 토큰 시퀀스로 바꿔서 Transformer에 넣는다. (Dosovitskiy et al., "An Image is Worth 16x16 Words", ICLR 2021)

| 단계 | 슬라이드 (밑줄·동그라미) | 쪽 |
| --- | --- | --- |
| 1 | An image is **tokenized into non-overlapping patches** | p9 |
| 2 | 패치를 **continuous embedding**으로: 1) flattened patch를 linear projection 2) ConvNet feature 사용 (**hybrid**) | p10 |
| 3 | **Positional encoding**을 임베딩에 더한다 (learnable, 또는 고정된 2D 주기함수) | p11 |
| 4 | 맨 앞에 **global token** (0\*, extra learnable [class] embedding): 토큰 임베딩들을 **분류용 고정 차원 벡터**로 모으는 보조(auxiliary) 토큰 | p12 |
| 5 | Transformer가 토큰들을 처리하고, **global token에 classifier head (MLP Head)** 를 붙여 클래스를 예측 | p13 |

**식** (p15, 식 왼쪽에 큰 괄호, "MLP"에 물결 밑줄)

$$\mathbf z_0=[\mathbf x_{class};\thinspace\mathbf x_p^1\mathbf E;\thinspace\mathbf x_p^2\mathbf E;\cdots;\thinspace\mathbf x_p^N\mathbf E]+\mathbf E_{pos},\qquad\mathbf E\in\mathbb R^{(P^2\cdot C)\times D},\ \mathbf E_{pos}\in\mathbb R^{(N+1)\times D}\qquad(1)$$

$$\mathbf z'_ \ell=\mathrm{MSA}(\mathrm{LN}(\mathbf z_{\ell-1}))+\mathbf z_{\ell-1},\qquad\mathbf z_\ell=\mathrm{MLP}(\mathrm{LN}(\mathbf z'_ \ell))+\mathbf z'_ \ell,\qquad\ell=1,\dots,L\qquad(2),(3)$$

$$\mathbf y=\mathrm{LN}(\mathbf z_L^0)\qquad(4)$$

- BERT의 [class] token처럼 $\mathbf z_0^0=\mathbf x_{class}$ 를 넣고, 마지막 층에서 그 자리의 상태 $\mathbf z_L^0$ 가 이미지 전체의 표현 $\mathbf y$ 다.
- **LN은 모든 블록 앞**에 (Pre-LN), **residual connection은 모든 블록 뒤**에 (10/7 ResNet의 $x+F(x)$ ). MLP는 **2층 + GELU**.
- 여기서 $N$ = 패치 수, $P$ = 패치 한 변, $C$ = 채널, $D$ = 임베딩 차원 (§1의 $D$ 와 다르다).
- (보충) 크기 계산 예: $224\times224\times3$ 이미지, $P=16$ → 패치 $N=(224/16)^2=196$ 개, 패치 하나를 펴면 $P^2C=768$ 차원, $\mathbf E$ 는 $768\times D$ , $\mathbf z_0$ 는 $197\times D$ (global token 포함).
- (요약) 인코더는 Layer Norm → Multi-Head Attention → Layer Norm → MLP를 반복하고, 출력의 CLS 토큰에 MLP head와 softmax를 써서 분류한다.

## 5. 🟡 GELU [W10W p16]

$$\mathrm{GELU}(x)=x\cdot\Phi(x),\qquad\Phi=\text{표준정규분포의 CDF}$$

- tanh 근사: $\mathrm{GELU}(x)\approx0.5x\big(1+\tanh(\sqrt{2/\pi}(x+0.044715x^3))\big)$ (PyTorch `approximate='tanh'`)
- 판서: 가우시안 종 모양 곡선, $\Phi(x)$ 에 동그라미, 그래프에서 **0 근처의 음수로 살짝 내려가는 부분**에 동그라미.
- (보충) 읽는 법: 입력 $x$ 를 "통과시킬 확률" $\Phi(x)$ 로 곱한다. $x$ 가 크면 $\Phi\approx1$ (ReLU처럼 그대로), 아주 작으면 $\Phi\approx0$ (0), 0 근처에서는 매끄럽게 이어지고 최솟값은 약 $-0.17$ ( $x\approx-0.75$ ). ReLU와 달리 모든 곳에서 미분 가능하다.
- (요약) 경험적으로 성능이 좋아 Transformer에서 널리 쓴다.

## 6. 🟡 ViT vs CNN, 실험 결과 [W10W p17–18]

| | CNN | ViT |
| --- | --- | --- |
| Locality of features | localized | **global (non-local)** |
| Translation equivariance | O | X? |

- **Fine-tuning, 더 높은 해상도?** prediction head를 바꿔 다시 학습하고, 사전학습한 positional encoding을 **2D interpolation**한다 (해상도가 커지면 패치 수가 늘어서).
- 판서: 3×3 패치 격자를 한 칸 옮겨 그린 그림 — (보충) 이미지가 패치 크기의 배수가 아닌 만큼 이동하면 패치 내용이 바뀌고, 위치 임베딩도 위치마다 다르므로 ViT는 이동에 equivariant하지 않다. 11/2의 **inductive bias**: CNN은 translation invariance를 구조로 가정하고, ViT는 가정이 적다 ([11.02 §3](11.02%20수업정리.md)).
- **실험** (p18, 제목 밑줄): 작은 데이터(ImageNet)로 사전학습하면 BiT ResNet이 낫고, 큰 데이터(JFT-300M)에서는 ViT가 앞선다. ViT도 큰 모델이 데이터가 많을수록 작은 모델을 앞선다. (보충) 가정이 적은 모델은 그만큼 데이터가 많이 필요하다.
- (요약) CNN은 sliding window로 국소 정보를 모으고 ViT는 전역 attention을 한다. 패치로 자르면 인접 픽셀 정보가 끊긴다는 의문이 있지만 전역 연산이 보완한다. 고해상도·super-resolution 작업에서 강하다.
