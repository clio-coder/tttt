## 짚은 포인트 (시험 가능성 순)

범례: 📋 시험 언급 · 🔴 노트 페이지 증명·유도 · 🟠 슬라이드 위 유도·박스 · 🟡 밑줄·동그라미 · ⚪ 필기 없음

- 🔴★ **MLE = KL 최소화** — $\arg\max_\theta\sum_i\log P_\theta(x_i)$ → (대수의 법칙) $\arg\min_\theta\mathbb E_{P_{data}}[-\log P_\theta]=\arg\min H(P_{data},P_\theta)$ , 그리고 $H(P_{data},P_\theta)=KL(P_{data}\Vert P_\theta)+H(P_{data})$ 에서 $H(P_{data})$ 는 $\theta$ 와 무관 → $\arg\min KL$ . 등호 위 " $(?)$ "로 던지고 증명했다 [W11M2 p22–24]
- 🟡 **unsupervised 표현 학습의 목적 = maximum likelihood estimation** (빨강 밑줄) [p21]
- 🟡 supervised 표현 학습 목적식 $\arg\min\sum\mathcal L(p_\psi(q_\phi(x)),y)$ — 인코더 $q_\phi$ , 예측기 $p_\psi$ 둘 다 NN (판서) [p19]
- ⚪ generative modeling = $p_{model}\approx p_{data}$ 학습 + 샘플링, explicit vs implicit, 네 가지 모델 [p4–6]
- ⚪ PixelRNN·PixelCNN: 순차 생성이라 느림 (32×32 이미지 하나에 forward 1024번) [p9–12]
- ⚪ compact representation: $x\in\mathbb R^d$ → $z\in\mathbb R^m$ , $d\gg m$ , latent variable은 관측할 수 없고 데이터에서 **추론(inferred)** 해야 한다 [p17–18]

## 1. ⚪ 생성 모델이란 [W11M2 p2–6]

| | Supervised Learning | Unsupervised Learning |
| --- | --- | --- |
| Data | $(x,y)$ — $y$ 는 label | $x$ 만 (label 없음) |
| Goal | $x\to y$ 를 잇는 함수 학습 | 데이터에 숨은 구조 학습 |
| 예 | 분류, 회귀, object detection, segmentation, image captioning | clustering, 차원 축소 (PCA), density estimation |

**Generative Modeling** — 학습 데이터가 주어지면 **같은 분포에서 새 샘플을 생성**한다.
1. $p_{data}(x)$ 를 근사하는 $p_{model}(x)$ 를 배운다.
2. $p_{model}(x)$ 에서 새 $x$ 를 샘플링한다.

density estimation으로 보면
- **Explicit**: $p_{model}(x)$ 를 명시적으로 정의하고 푼다.
- **Implicit**: $p_{model}(x)$ 를 정의하지 않고, 거기서 샘플링할 수 있는 모델을 배운다.

**네 가지 생성 모델** (슬라이드 7)

| 모델 | 한 줄 | 구조 |
| --- | --- | --- |
| GAN | adversarial training | $z\to G(z)\to x'$ , discriminator $D$ 가 $x$ / $x'$ 를 0/1로 구별 |
| VAE | variational lower bound 최대화 | $x\to$ encoder $q_\phi(z\mid x)\to z\to$ decoder $p_\theta(x\mid z)\to x'$ |
| Flow | 분포의 가역 변환 | $x\to f(x)=z\to f^{-1}(z)\to x'$ |
| Diffusion | 가우시안 잡음을 점점 더하고 되돌림 | $x_0\to x_1\to\cdots\to z$ (역방향 점선) |

- 범례: 빨강 = 잠재 변수(단순하고 다루기 쉬운 분포), 초록·파랑 = 복잡한 분포의 데이터.
- (보충) 강의계획서의 11–12주 "Flow models, VAE", 13–14주 "Diffusion Models"에 해당한다.

## 2. ⚪ Autoregressive model [W11M2 p7–12]

- **RNN**: $p(x_i\mid x_1,\dots,x_{i-1})$ — 앞의 것을 보고 다음 것을 예측 (10/28 언어모델과 같은 구조).
- **PixelRNN** (van der Oord et al. 2016): 이미지 픽셀을 **모서리부터** 하나씩 생성, 앞 픽셀들에 대한 의존성을 RNN(LSTM)으로. 단점: **순차 생성이라 학습·추론이 느리다**.
- **PixelCNN**: 의존성을 context 영역 위의 CNN (**masked convolution**)으로. 학습 때는 context 값을 학습 이미지에서 다 알므로 합성곱을 병렬로 → PixelRNN보다 빠르다. 하지만 **생성은 여전히 느리다**: 32×32 이미지 하나에 forward 1024번.
- 장점: likelihood $p(x)$ 를 **명시적으로 계산**할 수 있다, 최적화가 쉽다, 샘플이 좋다. 단점: 순차 생성 → 느리다.

## 3. ⚪ 데이터 생성 과정 다시 보기 [W11M2 p14–18]

- 데이터를 고정 차원 벡터로 본다: $x\in\mathbb R^d$ . 이미지는 $d$ = 가로 × 세로 × 3, 문장은 $d$ = (문장 길이) × (단어 수).
- Q: 데이터 공간의 모든 점이 유효한 데이터인가? 무작위 점을 뽑으면 유효할까? → A: **거의 항상 아니다** (잡음 이미지, 무의미한 문자열).
- 유효한 데이터는 데이터 공간의 **작은 일부**다 → 훨씬 **compact한 표현**이 있을 수 있다:

$$\text{Data }x\in\mathbb R^d\ \Longrightarrow\ \text{Compact representation }z\in\mathbb R^m,\qquad d\gg m$$

- **Observable variable**: 데이터에서 직접 관측한다. **Latent variable**: 숨어 있어 관측할 수 없고, 데이터에서 **추론해야(inferred)** 한다.

## 4. 🟡 표현은 어떻게 배우나 [W11M2 p19–21]

**Supervised learning of representation** — $(x,y)$ 쌍이 주어지면 $x$ 와 $y$ 를 잇는 파라미터를 배운다.

$$\arg\min_{\psi,\phi}\sum_{(x,y)\in D}\mathcal L\big(p_\psi(q_\phi(x)),\thinspace y\big)\qquad(x\overset{q_\phi}{\longrightarrow}z\overset{p_\psi}{\longrightarrow}y)$$

- $p_\psi(q_\phi(x))$ = $x$ 에 대한 모델의 예측, $y$ = 알려진 정답. 손실은 둘을 비교한다.
- ✏️ 슬라이드 식은 $p_\varphi(g_\phi(x))$ 인데 그림은 $q_\phi(x)$, $p_\psi(z)$ — 판서로 식을 그림 기호 $P_\psi$, $q_\phi$ 로 고치고, 그림의 $q_\phi$, $p_\psi$ 옆에 각각 동그라미 친 **"NN"** (둘 다 신경망).

**Unsupervised learning of representation** — $x$ 만 주어지면 확률분포 $p(x)$ 를 모델링한다. 그림 $x\overset{q_\phi}{\longrightarrow}z\overset{p_\psi}{\longrightarrow}x$ (자기 자신을 다시 만든다 → 11/11 autoencoder).

**Learning objective (maximum likelihood estimation)** (빨강 밑줄, 대괄호)

$$\arg\max_\theta\sum_{x\in D}\log p_\theta(x)\qquad(\text{관측한 데이터 }x\text{의 추정 확률을 최대화})$$

✏️ 슬라이드 식은 $\sum p_\theta(x)$ ( $\log$ 없음). 판서 p22는 $\prod P_\theta(x_i)$ → $\sum\log P_\theta(x_i)$ 로 썼다.

## 5. 🔴 MLE = cross entropy 최소화 = KL 최소화 [W11M2 p22–24 판서]

**목표** (빨강 밑줄) $P_\theta(x)\approx P_{data}(x)$

$$\theta^\ast=\arg\max_\theta\prod_{i=1}^nP_\theta(x_i)\ \ (x_i\sim\text{data})=\arg\max_\theta\sum_{i=1}^n\log P_\theta(x_i)\ \overset{(?)}{=}\ \arg\min_\theta KL(P_{data}\Vert P_\theta)$$

(빨강: $\theta^\ast$ 동그라미, 우변 박스, $\arg\min_\theta$ 동그라미, KL 밑줄, 체크) — " $(?)$ "는 지금부터 증명할 등호라는 표시.

**Recall** (동그라미, 9/7–9/9의 정의)

$$\text{①}\ \ KL(P_{data}\Vert P_\theta)=\mathbb E_{x\sim P_{data}}\Big[\log\frac{P_{data}(x)}{P_\theta(x)}\Big]=\int P_{data}(x)\log\frac{P_{data}(x)}{P_\theta(x)}dx$$

$$\text{②}\ \ H(P_{data},P_\theta)=\mathbb E_{x\sim P_{data}}[-\log P_\theta(x)]=-\int P_{data}(x)\log P_\theta(x)\thinspace dx\qquad(\text{cross entropy})$$

$$\text{③}\ \ H(P_{data})=\mathbb E_{x\sim P_{data}}[-\log P_{data}(x)]=-\int P_{data}(x)\log P_{data}(x)\thinspace dx\qquad(\text{entropy})$$

**가정** $x_1,\dots,x_n$ 은 $P_{data}$ 에서 i.i.d.

**결론** $\arg\max_\theta\sum_i\log P_\theta(x_i)\iff\arg\min_\theta KL(P_{data}\Vert P_\theta)$

**핵심 아이디어** 표본평균을 기댓값으로 바꾸면 MLE는 cross entropy 최소화이고, cross entropy = KL + (θ와 무관한 엔트로피)다.

**증명 (판서 순서)**
1. MLE의 목적함수는 로그가능도의 합 $\ell(\theta)=\sum_{i=1}^n\log P_\theta(x_i)$ (최대화). $n$ 으로 나눠도 같다: ✏️ $\theta_{MLE}=\arg\max_\theta\frac1n\sum_{i=1}^n\log P_\theta(x_i)$ [p23]
2. $n\to\infty$ 이면 **대수의 법칙** (∵ $x_i$ i.i.d. $\sim P_{data}$ ) [p23, 빨강 박스]

$$\lim_{n\to\infty}\frac1n\sum_{i=1}^n\log P_\theta(x_i)=\mathbb E_{x\sim P_{data}}[\log P_\theta(x)]$$

3. ⇔ MLE는 $\arg\min_\theta\mathbb E_{x\sim P_{data}}[-\log P_\theta(x)]=\arg\min_\theta H(P_{data},P_\theta)$ (빨강 박스) [p23]
4. 한편 ①을 로그로 나누면 [p23–24]

$$KL(P_{data}\Vert P_\theta)=\mathbb E[\log P_{data}(x)-\log P_\theta(x)]=\mathbb E_{x\sim P_{data}}[-\log P_\theta(x)]-\mathbb E_{x\sim P_{data}}[-\log P_{data}(x)]=H(P_{data},P_\theta)-H(P_{data})$$

5. $\Rightarrow\ H(P_{data},P_\theta)=KL(P_{data}\Vert P_\theta)+H(P_{data})$ (빨강: $KL$ 박스, $H(P_{data})$ 큰 동그라미) [p24]
6. $H(P_{data})$ 는 데이터 분포만의 양이라 **$\theta$ 와 무관** (보충: 판서는 빨강 동그라미만 쳤다) → $\theta_{MLE}\iff\arg\min_\theta H(P_{data},P_\theta)\iff\arg\min_\theta KL(P_{data}\Vert P_\theta)$ ∎ [p24]

**보조 사실**
- 5의 식은 9/9에서 배운 " $\text{cross entropy}=H+KL$ " ( $H_p(q)=H(p)+KL$ ) 그대로다 → [09.09 §2](09.09%20수업정리.md). 분류에서 cross entropy를 손실로 쓰는 것도 같은 이유 (9/14).
- (보충) KL ≥ 0 이고 $P_\theta=P_{data}$ 일 때만 0 (9/7) → 모델이 충분히 표현력이 있으면 MLE의 최적점은 $P_\theta=P_{data}$ .
- (보충) 방향이 $KL(P_{data}\Vert P_\theta)$ 인 이유: 기댓값을 **데이터 분포**로 잡아야 학습 데이터의 표본평균으로 계산할 수 있다 (2단계).
