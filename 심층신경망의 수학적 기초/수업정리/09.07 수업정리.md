## 1. 확률변수와 분포 🟡 [W1W p20–21, W2M p2–6]

| 개념 | 정의 |
| --- | --- |
| 확률변수 $X$ | 표본공간 $\Omega$에서 $\mathbb R$로 가는 함수. 예: 동전 3번 중 앞면 수, $\omega=(H,H,T)$면 $X(\omega)=2$ |
| 분포함수(cdf) | $F(x)=P\{X\le x\}$, $X\sim F$ |
| tail distribution | $G(x)=1-F(x)=P\{X>x\}$ |
| 이산 · pmf | $p(x_i)=P\{X=x_i\}$, $F(x)=\sum_{x_i\le x}p(x_i)$ |
| 연속 · pdf | $P\{X\le x\}=\int_{-\infty}^xf(t)\,dt$를 만족하는 $f\ge0$ |
| 모수(parameter) | 분포를 결정하는 값. 베르누이 $P\{X=1\}=p$에서 $p$ (판서: 앞으로는 $\theta$) |

## 2. 가능도와 MLE 🟠 [W2M p7 → 노트 p8]

- $X_1,\dots,X_n$ **i.i.d.**, 모수 $\theta$, pmf(pdf) $p(x\mid\theta)$일 때 가능도는

$$\mathcal L(x_1,\dots,x_n\mid\theta)=p(x_1\mid\theta)\,p(x_2\mid\theta)\cdots p(x_n\mid\theta)$$

- **MLE:** 가능도를 최대화하는 $\theta$. 가능도를 **$\theta$의 함수로 본다.** 계산할 때는 보통 $\log\mathcal L$을 쓴다 (곱 → 합).
- 판서 [p8]: 같은 식을 다르게 읽는다.
  - $p(x\mid\theta)$: $\theta$ 고정, **$x$의 함수** (확률)
  - $L(\theta;x)=p(x\mid\theta)$: 관찰된 $x$ 고정, **$\theta$의 함수** (가능도)
  - 예: $P(X=1\mid\theta)=\theta$. $\theta=\tfrac12$로 고정하면 확률 $\tfrac12$이고, $x=1$을 관찰했다고 고정하면 $L(\theta;x=1)=\theta$라는 함수가 된다.

## 3. 베르누이 MLE  🔴  [W2M p9–10 → 노트 p11]

**가정** $X_i$ i.i.d. 베르누이, $P\{X_1=1\mid\theta\}=\theta$, $P\{X_1=0\mid\theta\}=1-\theta$
**결론** $\hat\theta_{MLE}=\dfrac1n\sum_{i=1}^nx_i$ (표본평균)

**핵심 아이디어** 한 줄로 쓴 pmf $\theta^{x}(1-\theta)^{1-x}$를 곱하고 로그를 취해 미분한다.

**증명 (판서 순서)**
1. 가능도 [p9]: $P\{X_1=x_1,\dots,X_n=x_n\mid\theta\}=\prod_iP\{X_i=x_i\mid\theta\}=\prod_i\theta^{x_i}(1-\theta)^{1-x_i}=\theta^{\sum x_i}(1-\theta)^{n-\sum x_i}$ (∵ 독립)
2. $S=\sum_ix_i$로 두면 $L(\theta)=\theta^S(1-\theta)^{n-S}$ [p11]
3. 로그: $\ell(\theta)=S\log\theta+(n-S)\log(1-\theta)$
4. 미분: $\ell'(\theta)=\dfrac S\theta-\dfrac{n-S}{1-\theta}$, $0<\theta<1$
5. $\ell'(\theta)=0$ → $\dfrac S\theta=\dfrac{n-S}{1-\theta}$ → $S=n\theta$ → $\hat\theta_{MLE}=\dfrac Sn=\dfrac1n\sum x_i$ ∎

## 4. 베이즈 모델과 기침·감기 예제  🔴  [W2M p12 → 노트 p13–14]

두 확률변수 $X,Y$에 대해 처음에 주어지는 것:
- data generating distribution: $X\mid Y\sim p(x\mid y)$
- prior: $Y\sim p(y)$

$X=x$를 관찰한 뒤 $Y$의 **posterior** $p(y\mid x)$를 구한다.

$$p(y\mid x)=\frac{p(x,y)}{p(x)}=\frac{p(x\mid y)\,p(y)}{\int p(x,y)\,dy}\qquad\Rightarrow\qquad p(y\mid x)\propto p(x\mid y)\,p(y)$$

판서의 이름표: $p(y\mid x)$ posterior · $p(x\mid y)$ likelihood · $p(y)$ prior · 분모 evidence.

**예제** [p13–14] $X$ = 기침(1 yes / 0 no), $Y$ = 감기(1 yes / 0 no)
- prior: $P(Y=1)=0.1$, $P(Y=0)=0.9$
- likelihood: $P(X=1\mid Y=1)=0.8$, $P(X=1\mid Y=0)=0.2$ ("감기면 기침할 확률")
- 질문: $P(Y=1\mid X=1)$ ("기침하면 감기일 확률")
- evidence (전확률): $P(X=1)=0.8\cdot0.1+0.2\cdot0.9=0.26$
- 답: $P(Y=1\mid X=1)=\dfrac{0.8\cdot0.1}{0.26}\approx0.308$ → **30.8%**

> 감기면 80%가 기침하지만, 기침한다고 감기일 확률은 31%뿐이다. prior(10%)가 낮기 때문이다.

## 5. 베이즈 관점의 네 가지 이름 🟡 [W2M p15–17]

베이즈 모델에서는 모수 $\theta$도 **확률변수**로 본다: $\theta\sim p(\theta)$.

$$p(\theta\mid x)=\frac{p(x,\theta)}{p(x)}=\frac{p(x\mid\theta)p(\theta)}{p(x)}=\frac{p(x\mid\theta)p(\theta)}{\int p(x,\theta)\,d\theta}$$

| 이름 | 식 | 뜻 |
| --- | --- | --- |
| prior | $P(\theta)$ | 데이터를 보기 전 $\theta$에 대한 믿음 |
| posterior | $P(\theta\mid\mathcal D)$ | 데이터로 다듬은 믿음 |
| likelihood | $P(\mathcal D\mid\theta)$ | $\theta$로 데이터를 생성했을 때 $\mathcal D$가 나올 확률 |
| evidence | $P(\mathcal D)$ | 가능한 모든 $\theta$를 고려했을 때 $\mathcal D$가 나올 확률 |

## 6. MAP (Maximum A Posteriori)  🔴  [W2M p18–19 → 노트 p20]

**정의** $\theta_{MAP}=\arg\max_\theta\log p(\theta\mid X)$
- $p(\theta\mid X)=p(\theta,X)/p(X)$이고 $p(X)$는 $\theta$와 무관 → $\theta_{MAP}=\arg\max_\theta\log p(\theta,X)=\arg\max_\theta\log p(X\mid\theta)p(\theta)$
- 비교: $\theta_{MLE}=\arg\max_\theta\log p(X\mid\theta)$. **MAP는 prior 정보를 쓸 수 있고 MLE는 못 쓴다.**

**핵심 유도 (판서 p20)**

$$\hat\theta_{MAP}\in\arg\max_\theta\{\underbrace{\log p(x\mid\theta)}_{\text{likelihood}}+\underbrace{\log p(\theta)}_{\text{prior}}\}\;=\;\arg\min_\theta\{\underbrace{-\log p(x\mid\theta)}_{\text{data fitting loss}}\;\underbrace{-\log p(\theta)}_{\text{regularization}}\}$$

- prior가 $\theta\sim N(0,\tau^2I)$이면 $-\log p(\theta)=\dfrac{1}{2\tau^2}\lVert\theta\rVert_2^2+\text{const}$ → **L2 정규화 항**이 된다.
- (보충) 여기에 가우시안 오차 회귀의 $-\log$ 가능도(= 제곱오차, 9/9 §3)를 합치면 정확히 **ridge 회귀**다: $\lambda=\sigma^2/\tau^2$. → [09.09 수업정리](09.09%20수업정리.md) §5

## 7. 베이즈 모델 예: 베르누이 + 균등 prior  🔴  [W2M p21–22 → 노트 p23–24, p25]

**설정** $X_i$ i.i.d. 베르누이($\theta$), prior $p(\theta)=1$ ($0\le\theta\le1$, 균등분포 = Beta(1,1))
**결론** $\theta\mid\mathcal D\sim\text{Beta}(S+1,\;n-S+1)$, $S=\sum x_i$

**유도 (판서 순서)**
1. 가능도: $p(x_1,\dots,x_n\mid\theta)=\theta^S(1-\theta)^{F}$, $F=n-S$ [p21, p23]
2. 사후분포: $p(\theta\mid\mathcal D)\propto\theta^S(1-\theta)^{n-S}=:q(\theta)$ (prior가 1이므로) [p22–23]
3. 정규화 상수 $Z=\int_0^1\theta^S(1-\theta)^{n-S}d\theta$ [p23]
4. 베타함수 $B(a,b):=\int_0^1t^{a-1}(1-t)^{b-1}dt=\dfrac{\Gamma(a)\Gamma(b)}{\Gamma(a+b)}$ 에서 $a-1=S$, $b-1=n-S$ [p23–24]
5. $Z=B(S+1,n-S+1)=\dfrac{\Gamma(S+1)\Gamma(n-S+1)}{\Gamma(n+2)}$
6. $p(\theta\mid\mathcal D)=\dfrac{\Gamma(n+2)}{\Gamma(S+1)\Gamma(n-S+1)}\theta^S(1-\theta)^{n-S}$ → $\text{Beta}(S+1,n-S+1)$ ∎ [p24–25]

- 참고: $\text{Beta}(a,b)$ 밀도 $=\dfrac{\Gamma(a+b)}{\Gamma(a)\Gamma(b)}\theta^{a-1}(1-\theta)^{b-1}$. $a=b=1$이면 균등분포.
- **prior와 posterior가 둘 다 Beta 분포다** (보충: 이런 prior를 conjugate prior라고 한다). prior가 Beta($a,b$)면 posterior는 Beta($a+S$, $b+n-S$).

### 7.1 동전 예제: MLE vs MAP 🔴 [노트 p26]
- 10번 던져 앞면 7, 뒷면 3. $P(\mathcal D\mid\theta)=\theta^7(1-\theta)^3$
- ① MLE: 최대점 $\hat\theta_{MLE}=0.7$
- ② MAP: "공정한 동전"이라는 믿음을 prior $\theta\sim\text{Beta}(2,2)$로 둔다.
  $P(\theta\mid\mathcal D)\propto\theta^7(1-\theta)^3\cdot\theta^{2-1}(1-\theta)^{2-1}=\theta^8(1-\theta)^4$ → $\theta_{MAP}=\tfrac{8}{12}\approx0.667$
- prior가 추정값을 0.5 쪽으로 끌어당긴다. (보충: $\theta^a(1-\theta)^b$의 최대점은 $a/(a+b)$)

### 7.2 Amazon 판매자 예제 🔴 [W2M p27 → 노트 p28] (Murphy, *Machine Learning*)
- 판매자 1: 긍정 90 / 부정 10. 판매자 2: 긍정 2 / 부정 0. 누구에게 살까?
- $\theta_1,\theta_2$ = 두 판매자의 신뢰도, prior $\theta_i\sim\text{Beta}(1,1)$ (균등)
- 사후분포: $\theta_1\mid\mathcal D_1\sim\text{Beta}(91,11)$, $\theta_2\mid\mathcal D_2\sim\text{Beta}(3,1)$
- $P(\theta_1>\theta_2\mid\mathcal D_1,\mathcal D_2)=\int_0^1\!\!\int_0^1\mathbb I\{\theta_1>\theta_2\}\,\text{Beta}(\theta_1\mid91,11)\,\text{Beta}(\theta_2\mid3,1)\,d\theta_1d\theta_2\approx0.71$ (수치적분) → **판매자 1**
- (보충) MLE로 보면 판매자 2가 $2/2=1.0$으로 더 높지만, 데이터 2개짜리의 불확실성을 사후분포가 반영한다. 참고로 $\theta_2$의 cdf가 $t^3$이라 이 확률은 $E[\theta_1^3]=\frac{91\cdot92\cdot93}{102\cdot103\cdot104}\approx0.713$으로 정확히 계산된다.

## 8. 엔트로피 🟡🟠 [W2M p29–31]

**정보량** 이산 확률변수 $X$에서 $X=x$를 관찰한 정보량 $h(x)$가 만족해야 할 것 [p29]
- $p(x)$가 작으면 $h(x)$가 커야 한다 → $p(x)$에 대해 **단조감소**
- $X,Y$가 독립이면 $h(x,y)=h(x)+h(y)$ → 판서: $-\log p_X(x)-\log p_Y(y)=-\log(p_X(x)p_Y(y))=-\log p_{X,Y}(x,y)$
- 두 조건을 만족하는 것: $h(x)=-\log p(x)$

**엔트로피 (Definition 1)** 정보량의 기댓값

$$H(X)=-\mathbb E[\log p(X)]=\mathbb E\Big[\log\frac{1}{p(X)}\Big]=-\sum_xp_X(x)\log p_X(x)$$

- $H(X)\ge0$ ($p(x)\in[0,1]$이므로), 어떤 $x$에서 $p(x)=1$이면 $H(X)=0$ [p30]

**조건부 엔트로피 (Definition 2)** $H(Y\mid X)=-\mathbb E_{X,Y}[\log p(Y\mid X)]=-\sum_{x,y}p(x,y)\log p(y\mid x)$ [p30]

**결합 엔트로피 🟠** $H(X,Y)=-\mathbb E_{X,Y}[\log p(X,Y)]=H(X)+H(Y\mid X)$ [p31 판서]

$$\begin{aligned}H(X,Y)&=-\mathbb E_{X,Y}[\log p(Y\mid X)p(X)]\\&=-\mathbb E_{X,Y}[\log p(Y\mid X)]-\mathbb E_{X,Y}[\log p(X)]\\&=H(Y\mid X)+H(X)\end{aligned}$$

마지막 줄의 근거(빨간 판서): $\mathbb E_{X,Y}[\log p(X)]=\mathbb E_X[\log p(X)]$ — $Y$와 무관한 함수라서.

## 9. KL divergence [W2M p32–35]

**정의 (Definition 3)** 🟡

$$KL(p\Vert q)=\mathbb E_{p(X)}\Big[\log\frac{p(X)}{q(X)}\Big]=\sum_xp(x)\log\frac{p(x)}{q(x)}$$

- 관례 ($a,b>0$): $0\log\frac00=0$, $0\log\frac0a=0$, $b\log\frac b0=\infty$. 연속분포도 같은 방식으로 정의한다.
- 표기: $D_{KL}(p\Vert q)=KL(p\Vert q)$

**KL은 진짜 거리가 아니다** 🟠 [p33] — 대칭이 아니고 삼각부등식도 성립하지 않는다.
예: 베르누이 $p(1)=r$, $q(1)=s$ ($r\ne s$)

$$KL(p\Vert q)=(1-r)\log\frac{1-r}{1-s}+r\log\frac rs,\qquad KL(q\Vert p)=(1-s)\log\frac{1-s}{1-r}+s\log\frac sr$$

### Theorem 1: KL ≥ 0  🔴  [W2M p34 → 노트 p35]

**결론** $KL(p\Vert q)\ge0$, 그리고 $KL(p\Vert q)=0\iff p(x)=q(x)$ for all $x$

**핵심 아이디어** $\log\frac pq=-\log\frac qp$로 뒤집고, 볼록함수 $-\log$에 Jensen을 쓴다.

**증명 (판서 순서)**
1. $E=\{x\mid p(x)>0\}$ (p의 support)로 두면 [p34]
   $$KL(p\Vert q)=\sum_{x\in E}p(x)\log\frac{p(x)}{q(x)}=\sum_{x\in E}p(x)\Big[-\log\frac{q(x)}{p(x)}\Big]$$
2. Jensen 부등식 ($-\log$는 볼록):
   $$\ge-\log\Big(\sum_{x\in E}p(x)\frac{q(x)}{p(x)}\Big)=-\log\Big(\sum_{x\in E}q(x)\Big)\ge0$$
   마지막 부등호는 $\sum_{x\in E}q(x)\le1$이므로.
3. 등호 조건 [p35]: Jensen의 등호는 $\dfrac{q(x)}{p(x)}=c$ (상수)일 때. 그러면 $1=\sum_xq(x)=c\sum_xp(x)=c$ → $q(x)=p(x)$ for all $x$ ∎

**Jensen 부등식** (판서 c.f.) $\phi$가 볼록이면 $\mathbb E[\phi(X)]\ge\phi(\mathbb E[X])$.

(보충) 2단계에서 확률변수는 $q(X)/p(X)$, 기댓값은 $p$에 대한 것이다. 등호가 되려면 마지막 부등호도 등호여야 하므로 $\sum_{x\in E}q(x)=1$ (q가 E 밖에 질량이 없음)도 필요하다. 판서의 "$\sum_xq(x)=1$" 줄이 이 조건을 쓴 것이다.
