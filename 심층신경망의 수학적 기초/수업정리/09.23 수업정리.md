## 1. He (Kaiming) 초기화  🔴  [W4W1 p1 → 노트 p2–3]

**설정** $z=\sum_{i=1}^{D_{in}}w_ix_i$, $\mathbb E[w_i]=0$, $\text{Var}(w_i)=\sigma^2$, $\mathbb E[x_i]=0$, $\text{Var}(x_i)=V$. $w_i$와 $x_i$는 독립이고 서로 간에도 독립. $h=\phi(z)=\max(0,z)$ (ReLU)
**결론** $\mathbb E[h^2]=\frac12D_{in}\sigma^2V$ → 층 사이 2차 모멘트를 보존하려면 $\sigma^2=\dfrac{2}{D_{in}}$, $\sigma=\sqrt{2/D_{in}}$

**핵심 아이디어** ReLU는 0에 대칭인 분포의 **절반을 0으로 만든다** → 2차 모멘트가 절반이 된다 → 분산을 2배로 키워 보상한다.

**증명 (판서 순서)**
1. $\text{Var}(z)=\sum_{i=1}^{D_{in}}\text{Var}(w_ix_i)$ (∵ 독립) [p2]
2. $\text{Var}(x_iw_i)=\mathbb E[(w_ix_i)^2]-(\mathbb E[w_ix_i])^2$, 그리고 $\mathbb E[w_ix_i]=\mathbb E[w_i]\mathbb E[x_i]=0$
3. 앞(Xavier)과 같이 $\mathbb E[(w_ix_i)^2]=\mathbb E[w_i^2]\mathbb E[x_i^2]=\text{Var}(w_i)\text{Var}(x_i)=\sigma^2V$
4. 따라서 $\text{Var}(z)=D_{in}\sigma^2V=:q$
5. $h=\max(0,z)$로 두고 **$z\sim N(0,q)$를 가정**한다.
6. $\mathbb E[h]=\displaystyle\int_0^\infty z\frac{1}{\sqrt{2\pi q}}e^{-z^2/2q}\thinspace dz=\frac{\sqrt q}{\sqrt{2\pi}}$ — **D.I.Y.**
7. $\mathbb E[h^2]=\displaystyle\int_0^\infty z^2\frac{1}{\sqrt{2\pi q}}e^{-z^2/2q}\thinspace dz=\frac12q$ — **D.I.Y.**
8. $\mathbb E[h^2]=\frac12\mathbb E[z^2]=\frac12D_{in}\sigma^2V$ [p3]
9. 신호 전파에서는 **2차 모멘트** $V=\mathbb E[x_i^2]$를 추적한다. ReLU 전 $\mathbb E[z^2]=D_{in}\sigma^2V$, ReLU 후 $\mathbb E[h^2]=\frac12D_{in}\sigma^2V$
10. 층 사이 2차 모멘트 보존: $\mathbb E[h^2]=\mathbb E[x^2]=V$ → $\frac12D_{in}\sigma^2V=V$ → $\frac12D_{in}\sigma^2=1$ → $\boxed{\sigma^2=\dfrac2{D_{in}}}$ ∎

**D.I.Y. 풀이 (보충)**
<details><summary>6. E[h] = √q / √(2π)</summary>

$u=z^2/(2q)$로 치환하면 $du=(z/q)\thinspace dz$, 즉 $z\thinspace dz=q\thinspace du$.

$$\mathbb E[h]=\frac{1}{\sqrt{2\pi q}}\int_0^\infty e^{-u}\thinspace q\thinspace du=\frac{q}{\sqrt{2\pi q}}=\frac{\sqrt q}{\sqrt{2\pi}}$$
</details>
<details><summary>7. E[h²] = q/2</summary>

피적분함수 $z^2\varphi_q(z)$는 짝함수($\varphi_q$ = $N(0,q)$ 밀도)이므로

$$\mathbb E[h^2]=\int_0^\infty z^2\varphi_q(z)\thinspace dz=\frac12\int_{-\infty}^\infty z^2\varphi_q(z)\thinspace dz=\frac12\mathbb E[z^2]=\frac12q$$

(마지막은 $\mathbb E[z]=0$이라 $\mathbb E[z^2]=\text{Var}(z)=q$)
</details>

**Xavier와 비교**

| | Xavier (9/21) | He (9/23) |
| --- | --- | --- |
| 활성화 | tanh (0 중심 대칭) | ReLU |
| 보존하는 양 | $\text{Var}(y)=V$ | $\mathbb E[h^2]=V$ (2차 모멘트) |
| 결과 | $\sigma^2=1/D_{in}$ | $\sigma^2=2/D_{in}$ |
| 코드 | `randn(Din, Dout) / np.sqrt(Din)` | `randn(Din, Dout) * np.sqrt(2/Din)` |

## 2. Learning rate 🟡 [W4W1 p4–10]

- SGD, SGD+Momentum, Adagrad, RMSProp, Adam은 모두 **learning rate**가 하이퍼파라미터다. [p6]
- 손실 곡선 4개 (a)–(d): (a) 발산, (b) 천천히 꾸준히 감소, (c) 빨리 떨어졌다가 정체, (d) 빨리 떨어지고 계속 낮아짐
  - "LR 오름차순으로 정렬하라" → (보충) **(b) < (d) < (c) < (a)** (cs231n 원 그림: b = low, d = good, c = high, a = very high)
  - "어느 것이 최선?" → (d). "둘의 장점을 합칠 수 있나?" → 처음엔 크게, 나중엔 작게 = **LR decay**
  - 판서: 큰 LR은 그릇 안에서 튕기고, 작은 LR은 천천히 내려감.
- **LR decay** [p7–9]

| 방식 | 식 |
| --- | --- |
| Step | 정해진 epoch마다 줄임. 예: ResNet은 30, 60, 90 epoch에 ×0.1 (그때마다 training loss가 뚝 떨어짐) |
| Cosine | $\alpha_t=\frac12\alpha_0\big(1+\cos(t\pi/T)\big)$ |
| Linear | $\alpha_t=\alpha_0(1-t/T)$ |
| Inverse sqrt | $\alpha_t=\alpha_0/\sqrt t$ |

  $\alpha_0$ = 초기 LR, $\alpha_t$ = epoch $t$의 LR, $T$ = 전체 epoch 수
- **Linear warmup** [p10]: 초기 LR이 크면 loss가 폭발할 수 있다 → 처음 약 5000 iteration 동안 LR을 0에서 선형으로 올린다 (Goyal et al. 2017).

## 3. Batch Normalization [W4W1 p11–25]

### 3.1 아이디어와 학습 시 식 🟠 [p12–14]
- "You want **zero-mean unit-variance** activations? **Just make them so.**" $\hat x^{(k)}=\dfrac{x^{(k)}-\mathbb E[x^{(k)}]}{\sqrt{\text{Var}[x^{(k)}]}}$
- 입력 $x$: $N\times D$ ($N$ = batch size, $D$ = 특성 차원, MNIST면 $D=28\cdot28=784$). **열(채널)마다** 정규화한다.

$$\mu_j=\frac1N\sum_{i=1}^Nx_{i,j},\qquad\sigma_j^2=\frac1N\sum_{i=1}^N(x_{i,j}-\mu_j)^2\qquad(\text{shape }D)$$

$$\hat x_{i,j}=\frac{x_{i,j}-\mu_j}{\sqrt{\sigma_j^2+\varepsilon}},\qquad y_{i,j}=\gamma_j\hat x_{i,j}+\beta_j\qquad(\text{shape }N\times D)$$

- 판서: $\varepsilon=10^{-5}$ (0으로 나누기 방지)
- **학습 가능한 scale·shift** $\gamma,\beta$ (shape $D$). **$\gamma=\sigma$, $\beta=\mu$로 학습되면 항등함수를 복원**한다 → 정규화가 표현력을 잃게 하지 않는다.

### 3.2 테스트 시 🟠 [p15–17]
- 추론 때는 batch가 작거나 $N=1$일 수도 있다 → 학습 중에 쌓은 **running estimate**를 쓴다.
- 학습 중 업데이트 (momentum $m$): $\mu^{run}\leftarrow m\thinspace\mu^{run}+(1-m)\mu_{batch}$, $(\sigma^2)^{run}\leftarrow m(\sigma^2)^{run}+(1-m)\sigma^2_{batch}$
- 테스트: $\hat x_{i,j}=\dfrac{x_{i,j}-\mu_j^{run}}{\sqrt{(\sigma_j^2)^{run}+\varepsilon}}$, $y_{i,j}=\gamma_j\hat x_{i,j}+\beta_j$
- 테스트 때 BN은 **선형 연산**이 된다 → 앞의 FC·conv 층과 합칠(fuse) 수 있다.

### 3.3 위치와 장점 🟡 [p18–20]
- 보통 **FC·Conv 층 뒤, 비선형 함수 앞**: FC → BN → tanh → FC → BN → tanh → …
- 장점:
  1. 깊은 신경망을 **훨씬** 쉽게 학습
  2. gradient flow 개선
  3. **더 큰 LR** 허용, 빠른 수렴 — scale invariance + 안정된 기울기 → 큰 LR에서도 발산 위험이 적다
  4. **초기화에 덜 민감** — Xavier/He가 조금 틀려도 BN이 다시 중심을 잡고 크기를 맞춘다
  5. 학습 중 regularization 효과
  6. **테스트 시 추가 비용 0** — $\mu,\sigma^2,\gamma,\beta,\varepsilon$이 상수라 채널별 affine 변환이 된다:
     $y_{i,j}=a_jx_{i,j}+b_j$, $a_j=\dfrac{\gamma_j}{\sqrt{\sigma_j^2+\varepsilon}}$, $b_j=\beta_j-\dfrac{\gamma_j\mu_j}{\sqrt{\sigma_j^2+\varepsilon}}$ → FC면 $W'=\text{diag}(a)W$로 앞 층에 흡수

### 3.4 정리 🟡 [p21]
- BN은 층마다 정규화를 (어느 정도) 강제한다. 아주 깊은 신경망을 학습하는 데 **필수 도구**다. 하지만 **이론적 근거는 약하다**.
- BN은 표현력을 바꾸지 않는다: $\beta,\gamma$를 학습하므로 각 층 출력은 어떤 평균·분산도 가질 수 있다. 다만 평균·분산을 **명시적인 학습 파라미터로 두면 학습이 쉬워진다**.
- BN을 쓰면 **batch size**가 더 중요한 하이퍼파라미터가 된다. **ResNet 학습에는 BN이 필요하다** (판서: CNN).

### 3.5 이론적 근거와 covariate shift  🔴  [p22 → 노트 p23, p25]

**슬라이드 [p22]**

| 단계 | 내용 |
| --- | --- |
| 원래 가설 (Ioffe & Szegedy, 2015) | BN이 **Internal Covariate Shift(ICS)**를 줄여서 학습이 좋아진다. ICS = 학습 중 은닉 활성값의 평균·분산이 이동하는 것. BN ⇒ reduced ICS ⇒ improved training |
| 실험 결과 (Santurkar et al., 2018) | 실제로 재 보면 **BN은 ICS를 줄이지 않는다**. 그런데도 학습 성능은 꾸준히 좋아진다. BN ⇏ reduced ICS, but BN ⇒ improved training |
| 다른 설명 | BN이 **손실 지형(loss landscape)을 매끄럽게** 한다 → 최적화가 쉬워진다. BN ⇒ smoother loss landscape ⇒ improved training |

**노트 [p23, p25]**
① **Covariate shift** — 지도학습에서 $P(X,Y)=P(Y\mid X)P(X)$. covariate shift는
$$P_{train}(X)\ne P_{test}(X)\quad\text{while}\quad P_{train}(Y\mid X)=P_{test}(Y\mid X)$$
인 상황: **입력 분포는 바뀌지만 입력–출력 관계는 그대로**다.

② **Internal covariate shift (ICS)** — $\ell$번째 층 $z^{(\ell)}=W^{(\ell)}h^{(\ell-1)}+b^{(\ell)}$, $h^{(\ell)}=f(z^{(\ell)})$. 학습 중에는 파라미터가 계속 바뀌므로 **같은 학습 데이터라도** $h^{(\ell-1)}$의 분포가 최적화 스텝마다 바뀔 수 있다:
$$P_t(h^{(\ell-1)})\ne P_{t+1}(h^{(\ell-1)})$$
→ 다음 층 입장에서는 입력 분포가 계속 변하는 covariate shift와 같다.

"**BN can solve I.C.S. (?)**" — 판서의 물음표는 위 슬라이드의 원래 가설을 가리킨다. 답은 Santurkar 결과: **ICS를 줄여서가 아니라 지형을 매끄럽게 해서** 도움이 된다.

(보충) "매끄러운 지형"은 §4–6의 **β-smooth**와 같은 말이다. $\beta$가 작을수록 Descent Lemma가 허용하는 step($\eta<2/\beta$)이 커진다 → BN이 큰 LR을 허용한다는 장점과 연결된다.

## 4. GD와 1차 Taylor 전개 🟠 [W4W2 p1–4]

- 문제: $\min_{x\in\mathbb R^d}f(x)$, $f:\mathbb R^d\to\mathbb R$ = 목적함수
- GD: 초기점 $x_0$에서 $x_{t+1}=x_t-\eta\nabla f(x_t)$, $t=0,1,2,\dots$, $\eta>0$ = learning rate(step size)
- **왜 이 방향인가** [p3–4]:
  1. $x_t$ 근처 1차 Taylor 근사: $f(x_{t+1})\approx f(x_t)+\langle\nabla f(x_t),x_{t+1}-x_t\rangle$
  2. $x_{t+1}=x_t+\eta v$ ($\lVert v\rVert=1$ 단위 방향, $\eta>0$ 작음)로 두면 $f(x_{t+1})\approx f(x_t)+\eta\langle\nabla f(x_t),v\rangle$
  3. 목표 (판서): $f(x_{t+1})\le f(x_t)$, 가능한 한 작게 → $\langle\nabla f(x_t),v\rangle$를 **최대한 음수로**
  4. 내적은 $v$가 기울기의 **정반대 방향**일 때 최소: $v=-\dfrac{\nabla f(x_t)}{\lVert\nabla f(x_t)\rVert}$ (보충: Cauchy–Schwarz $\langle\nabla f,v\rangle\ge-\lVert\nabla f\rVert\lVert v\rVert$, 등호는 $v\propto-\nabla f$)
  5. 대입: $x_{t+1}=x_t-\eta\dfrac{\nabla f(x_t)}{\lVert\nabla f(x_t)\rVert}$. 정규화 항을 LR에 흡수($\eta'=\eta/\lVert\nabla f(x_t)\rVert$)하면 **표준 GD** $x_{t+1}=x_t-\eta\nabla f(x_t)$
- 이것은 직관이고, 다음은 Taylor 정리로 엄밀하게 분석한다 → Descent Lemma

## 5. Descent Lemma (Lemma 3.1)  🔴  [W4W2 p5 → 노트 p6–9] · 이어짐: 9/28

**가정** $f:\mathbb R^d\to\mathbb R$ 연속미분가능, **$\nabla f$가 $\beta$-Lipschitz** ($f$는 **$\beta$-smooth**):
$$\lVert\nabla f(x)-\nabla f(y)\rVert\le\beta\lVert x-y\rVert\quad\forall x,y\in\mathbb R^d$$
(판서 증명은 Hessian을 쓰므로 $f\in C^2$를 가정 — 슬라이드에 $C^2$ 동그라미)

**결론**
$$f(y)\le f(x)+\langle\nabla f(x),\thinspace y-x\rangle+\frac\beta2\lVert y-x\rVert^2$$

**핵심 아이디어** 두 점을 잇는 선분 위로 제한한 1변수 함수 $g$에 **적분 잉여항 Taylor**를 쓰고, 잉여항의 Hessian을 $\beta$로 누른다. → " $f$는 1차 근사 + 포물선 위로는 못 올라간다"

**증명 (판서 순서)**
1. 보조함수 $g(t)=f(x+t(y-x))$, $t\in\mathbb R$ [p5]
2. 연쇄법칙 [p6]:
   $$g'(t)=\langle\nabla f(x+t(y-x)),\thinspace y-x\rangle,\qquad g''(t)=(y-x)^\top\nabla^2f(x+t(y-x))(y-x)\quad\cdots①$$
3. 적분 잉여항 Taylor:
   $$g(1)=g(0)+g'(0)+\int_0^1(1-s)\thinspace g''(s)\thinspace ds\quad\cdots②$$
4. $g(0)=f(x)$, $g(1)=f(x+y-x)=f(y)$, $g'(0)=\langle\nabla f(x),y-x\rangle$를 대입하면
   $$f(y)=f(x)+\langle\nabla f(x),y-x\rangle+\int_0^1(1-s)(y-x)^\top\nabla^2f(x+s(y-x))(y-x)\thinspace ds\quad(\ast)$$
5. $\beta$-smoothness의 정의로부터 $\forall v$, $v^\top\nabla^2f\thinspace v\le\beta\lVert v\rVert^2$ $\cdots③$ → $v=y-x$를 넣으면 [p7]
   $$\int_0^1(1-s)(y-x)^\top\nabla^2f(\cdot)(y-x)\thinspace ds\le\int_0^1(1-s)\beta\lVert y-x\rVert^2ds=\beta\lVert y-x\rVert^2\int_0^1(1-s)\thinspace ds=\frac\beta2\lVert y-x\rVert^2$$
6. $(\ast)$는 $f(y)\le f(x)+\langle\nabla f(x),y-x\rangle+\frac\beta2\lVert y-x\rVert^2$가 된다 ∎

**보조 사실**

**① $g''(t)$의 유도** [p7–8] — 판서 " $g''(t)=\cdots$ ??" 에 스스로 답함. $f:\mathbb R^n\to\mathbb R$, $f\in C^2$.
- $p:=y-x\in\mathbb R^{n\times1}$ (열벡터), $z(t)=x+tp$, $t\in[0,1]$ → $z'(t)=p$
- $g(t)=f(z(t))$ → $g'(t)=Df(z(t))\thinspace z'(t)$. 여기서 $Df(z)=\nabla f(z)^\top\in\mathbb R^{1\times n}$ (**행벡터**)
- $g'(t)=\underbrace{\nabla f(z(t))^\top}_ {1\times n}\underbrace{z'(t)}_ {n\times1}=\nabla f(z(t))^\top p=p^\top\nabla f(z(t))$ ($1\times1$)
- $g''(t)=p^\top\dfrac{d}{dt}\nabla f(z(t))$. $\nabla f:\mathbb R^n\to\mathbb R^n$의 미분 $D(\nabla f(z))=\nabla^2f(z)$ (Hessian)이므로
  $\dfrac{d}{dt}\nabla f(z(t))=\underbrace{\nabla^2f(z(t))}_ {n\times n}\underbrace{z'(t)}_ {n\times1}=\nabla^2f(z(t))\thinspace p$
- $\Rightarrow g''(t)=\underbrace{p^\top}_ {1\times n}\nabla^2f(z(t))\underbrace{p}_ {n\times1}=(y-x)^\top\nabla^2f(z(t))(y-x)\in\mathbb R^{1\times1}$

**② 적분 잉여항 Taylor** [p8] — 판서: " $g(1)=g(0)+\int_0^1g'(s)ds$, 그리고 $\int_0^1g'(s)ds=g'(0)\cdot1+\int_0^1(1-s)g''(s)ds$ by I.B.P. ($u=1-s$, $v'=g''(s){}$)" — **D.I.Y.**
<details><summary>직접 풀이 (보충)</summary>

$u=1-s$, $v'=g''(s)$ ($u'=-1$, $v=g'(s){}$)로 부분적분:

$$\int_0^1(1-s)g''(s)\thinspace ds=\Big[(1-s)g'(s)\Big]_ 0^1-\int_0^1(-1)g'(s)\thinspace ds=-g'(0)+\int_0^1g'(s)\thinspace ds=-g'(0)+g(1)-g(0)$$

정리하면 $g(1)=g(0)+g'(0)+\int_0^1(1-s)g''(s)\thinspace ds$. (마지막 등호는 미적분의 기본정리)
</details>

**③ $\beta$-smooth ⇒ Hessian 상계** [p8–9] — 판서:
$$\lVert\nabla f(x)-\nabla f(y)\rVert\le\beta\lVert x-y\rVert\ \Rightarrow\ -\beta I\preceq\nabla^2f(x)\preceq\beta I,\quad\forall x\in\mathbb R^d,\ f\in C^2$$
note: $\forall v$, $v^\top\nabla^2f(x)v\le\beta\lVert v\rVert^2\iff\nabla^2f(x)\preceq\beta I$. "We want $v^\top\nabla^2f(x)v\le\beta\lVert v\rVert^2$ — **Next class**"
<details><summary>미리 보는 증명 (보충 — 9/28 판서와 비교할 것)</summary>

방향미분으로 Hessian을 쓰면 $\nabla^2f(x)v=\lim_{t\to0}\dfrac{\nabla f(x+tv)-\nabla f(x)}{t}$. Lipschitz 조건에서 $\lVert\nabla f(x+tv)-\nabla f(x)\rVert\le\beta t\lVert v\rVert$ ($t>0$)이므로 $\lVert\nabla^2f(x)v\rVert\le\beta\lVert v\rVert$.
Cauchy–Schwarz로 $v^\top\nabla^2f(x)v\le\lVert v\rVert\thinspace\lVert\nabla^2f(x)v\rVert\le\beta\lVert v\rVert^2$.
</details>

## 6. Descent Lemma를 GD 한 스텝에 적용 🟠 [W4W2 p10]

$y=x_{t+1}=x_t-\eta\nabla f(x_t)$를 넣으면

$$\begin{aligned}f(x_{t+1})&\le f(x_t)+\langle\nabla f(x_t),\thinspace-\eta\nabla f(x_t)\rangle+\frac\beta2\lVert-\eta\nabla f(x_t)\rVert^2\cr&=f(x_t)-\eta\lVert\nabla f(x_t)\rVert^2+\frac{\beta\eta^2}{2}\lVert\nabla f(x_t)\rVert^2\cr&=f(x_t)-\Big(\eta-\frac{\beta\eta^2}{2}\Big)\lVert\nabla f(x_t)\rVert^2\end{aligned}$$

- 함수값이 줄려면 $\eta-\frac{\beta\eta^2}{2}>0$ ⇔ **$\eta<\dfrac2\beta$**. 판서: $f(x_{t+1})\le f(x_t)$
- 결론: **step size가 충분히 작으면, 매끄러운(smooth) 함수에서 GD는 목적함수를 반드시 줄인다.**
- (보충) 감소량 $\eta-\frac{\beta\eta^2}{2}$는 $\eta=1/\beta$에서 최대 → $f(x_{t+1})\le f(x_t)-\frac{1}{2\beta}\lVert\nabla f(x_t)\rVert^2$
