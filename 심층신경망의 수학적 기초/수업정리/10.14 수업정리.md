## 짚은 포인트 (시험 가능성 순)

범례: 📋 시험 언급 · 🔴 필기본 증명·유도 · 🟡 강조 · ⚪ 서술만 · (요약) AI 요약에만 있는 내용

- 📋 (요약) **손실 함수 설계 (hinge loss와 주의점)는 기말고사 출제 예정** (요약 p2, p9) — 0-1 손실이 학습에 부적합한 이유, hinge loss의 효과, **hinge 기준 최선 모델 ≠ 실제 리스크 기준 최선 모델**인 예
- 🔴 **오차 분해** — $R(\hat f)-R(f_\ast)$ = approximation error + estimation error, estimation error $=[R(\hat f)-\hat R(\hat f)]+\varepsilon_{opt}+[\inf\hat R-\inf R]\le2\sup_{f\in\mathcal F_\delta}\lvert R(f)-\hat R(f)\rvert+\varepsilon_{opt}$ [p1]
- 🔴 **Chebyshev로 일반화 오차 제어** — $f$ 고정 → $\mathrm{Var}(\hat R-R)=\sigma^2/n$ → $P(\lvert\hat R-R\rvert\ge c\sigma/\sqrt n)\le1/c^2$ → $O_p(1/\sqrt n)$ [p2]
- 🔴 **차원의 저주** — Lipschitz 보간 $\hat f$ 의 오차 $\le2\beta\lVert x-x_\ast\rVert$ ( $x_\ast$ = 가장 가까운 학습 샘플), $\mathbb E\lVert x-x_\ast\rVert^2\approx n^{-2/d}$ → $n\ge\varepsilon^{-d/2}$ [p2]
- 🔴 **hinge 반례** — $P(x_1)=0.99$, $P(x_2)=0.01$ (outlier), $g_A\equiv0.1$ vs $g_B=(1,-0.1)$ : hinge는 $g_B$ , 0-1은 $g_A$ 를 고른다 [p3]
- 🟡 **approximation error의 성질** (박스) — $\hat f$ 와 무관, modeling bias를 반영, $\delta\to\infty$ 이면 $\mathcal F_\delta\to\mathcal F$ 라 0으로, 음이 아님 [p1]
- ⚪ **PAC**: 임의의 $\varepsilon,\delta$ 에 대해 $n$ 이 충분히 크면 $P(\lvert\hat R(\hat f)-R(\hat f)\rvert\le\varepsilon)\ge1-\delta$ [p2]
- ⚪ (요약) 세 오차는 서로 다른 연구 분야다. LLM처럼 모델이 충분히 크면 근사 오차보다 최적화·일반화 오차 연구가 활발하다.

## 2. 🔴 오차 분해 (Error Decomposition) [필기본 p1]

### 2.1 그림과 기호

그림: 시작점 **initial**에서 구불구불한 경로로 **learned model** $\hat f$ 에 도착 → 점선 ③ → **Best on training set** → 점선 ② → **Best model** → 화살표 ① → **Target** $f_\ast=\arg\min R(f)$ .

| 기호 | 뜻 |
| --- | --- |
| $R(f)=\mathbb E[\ell(f(X),Y)]$ | risk (분포 전체의 평균 손실, 정말 줄이고 싶은 것) |
| $\hat R(f)=\frac1n\sum_{i=1}^n\ell(f(X_i),Y_i)$ | empirical risk (학습 샘플의 평균 손실, 실제로 계산하는 것) |
| $\mathcal F$ | function class (모든 함수) |
| $\mathcal F_\delta$ | hypothesis class (모델이 표현할 수 있는 함수들, 복잡도 $\delta$ — 예: MLP의 노드 수) |
| $f_\ast$ | target, $R$ 의 최소점 |
| $\hat f$ | learned model (실제 학습으로 얻은 함수) |

| 그림의 구간 | 오차 |
| --- | --- |
| ① best model → target | approximation error |
| ② best on training set → best model | (estimation error 중) 샘플이 유한해서 생기는 부분 |
| ③ learned model → best on training set | (estimation error 중) 최적화가 덜 되어 생기는 부분 |

### 2.2 approximation error와 estimation error

We want to minimize

$$R(\hat f)-R(f_\ast)=R(\hat f)-\inf_{f\in\mathcal F}R(f)=\underbrace{\Big(\inf_{f\in\mathcal F_\delta}R(f)-\inf_{f\in\mathcal F}R(f)\Big)}_ {\text{① Approximation error}}+\underbrace{\Big(R(\hat f)-\inf_{f\in\mathcal F_\delta}R(f)\Big)}_ {\text{②+③ Estimation error}}$$

| | Approximation error ① | Estimation error ②+③ |
| --- | --- | --- |
| 무엇에 의존 | **$\hat f$ 와 무관** (independent of $\hat f$ ) | **$\hat f$ 에 의존** → 학습 데이터에 따라 달라지는 **확률변수** |
| 뜻 | **modeling bias**를 반영 (가설 공간이 target을 얼마나 표현하나) | |
| 변화 | $\delta\to\infty$ 이면 $\mathcal F_\delta\to\mathcal F$ 를 기대 → 0으로 | 샘플 수 $n\nearrow\infty$ 이면 ② ↓ / $\delta\uparrow$ 이면 ②+③ ↑ |
| 부호 | **non-negative** ( $\mathcal F_\delta\subseteq\mathcal F$ ) | |

- 필기본은 ①의 성질 세 줄을 박스로 따로 강조했다.
- 복잡도 $\delta$ 를 키우면 ①은 줄고 ②+③은 커진다 (과적합). (보충) 01장 다항회귀 $M=9$ 가 이 그림의 예다. (요약) 최적화 오차가 반드시 준다고는 할 수 없다.
- (요약) 노드 수를 $m$ 개로 제한하는 것은 Taylor 전개를 유한 차수에서 자르는 것과 같고, 잘린 꼬리가 근사 오차다. 노드를 무한히 늘리면 근사 오차가 0으로 → 정확한 진술이 10/21의 UAT, 속도가 Barron 정리.

### 2.3 Estimation error 자세히 보기

**결론**

$$R(\hat f)-\inf_{f\in\mathcal F_\delta}R(f)\ \le\ \underbrace{2\sup_{f\in\mathcal F_\delta}\lvert R(f)-\hat R(f)\rvert}_ {\varepsilon_{gen}=\text{generalization error}}+\varepsilon_{opt}\qquad(\varepsilon_{gen}\to0\text{ as }n\to\infty)$$

**핵심 아이디어** $\hat R$ 을 더하고 빼서 세 덩어리로 나누고, $R$ 과 $\hat R$ 의 차이는 전부 sup로 누른다.

**증명 (필기본 순서)**

$$R(\hat f)-\inf_{\mathcal F_\delta}R=\underbrace{R(\hat f)-\hat R(\hat f)}_ {(\text{a})}+\underbrace{\hat R(\hat f)-\inf_{f\in\mathcal F_\delta}\hat R(f)}_ {\text{optimization error }\varepsilon_{opt}}+\underbrace{\inf_{f\in\mathcal F_\delta}\hat R(f)-\inf_{f\in\mathcal F_\delta}R(f)}_ {(\text{b})}$$

1. (a): $\hat f\in\mathcal F_\delta$ 이므로 $\le\sup_{f\in\mathcal F_\delta}\lvert R(f)-\hat R(f)\rvert$
2. (b) $\le\sup_{f\in\mathcal F_\delta}\lvert\hat R(f)-R(f)\rvert$ (필기본 물결 밑줄)
   - (보충) 이유: 모든 $f\in\mathcal F_\delta$ 에서 $\inf\hat R\le\hat R(f)\le R(f)+\sup\lvert\hat R-R\rvert$ . 오른쪽에서 $f$ 에 대해 inf를 취하면 $\inf\hat R\le\inf R+\sup\lvert\hat R-R\rvert$ .
3. 합치면 $\le2\sup\lvert R-\hat R\rvert+\varepsilon_{opt}$ ∎

**전체**: $R(\hat f)-R(f_\ast)\le\varepsilon_{app}+2\sup_{f\in\mathcal F_\delta}\lvert R(f)-\hat R(f)\rvert+\varepsilon_{opt}$

| 오차 | 무엇에 의존하나 | 이어지는 곳 |
| --- | --- | --- |
| 근사 $\varepsilon_{app}$ | 가설 공간만 (학습과 무관) | 10/21 UAT, 10/21–10/26 Barron |
| 일반화 $\varepsilon_{gen}$ | 샘플 수 $n$ , 분포 | §3 Chebyshev, 10/26 Rademacher |
| 최적화 $\varepsilon_{opt}$ | 샘플과 $\mathcal F_\delta$ 가 정해지면 분포와 무관 (요약) | 06장 GD·SGD 수렴 |

## 3. 🔴 일반화 오차의 확률적 제어 [필기본 p2]

**Generalized error.** For $f\in\mathcal F_\delta$ (함수 하나를 고정)

$$\hat R(f)-R(f)=\frac1n\sum_{i=1}^n\big(\underbrace{\ell(f(X_i),Y_i)-\mathbb E[\ell(f(X),Y)]}_ {=Z_i}\big)$$

1. $(X_i,Y_i)$ 가 i.i.d.이면 $Z_i$ 도 i.i.d.이고 $\mathbb E\big[\frac1n\sum Z_i\big]=0$
2. $\mathrm{Var}(Z_i)=\sigma^2\lt\infty$ 이면 (∵ 독립) $\mathrm{Var}(\hat R-R)=\frac1n\sigma^2$ — 05장 mini-batch 분산 $1/B$ 와 같은 계산
3. **cf) Chebyshev** 평균 0인 확률변수 $W$ 에 대해 $P(\lvert W\rvert\ge t)\le\frac1{t^2}\mathrm{Var}(W)$ . $W\leftarrow\hat R-R$ , $t\leftarrow\frac{c\sigma}{\sqrt n}$ 를 넣으면

$$P\Big(\lvert\hat R-R\rvert\ge\frac{c\thinspace\sigma}{\sqrt n}\Big)\le\frac1{c^2}\qquad\Longrightarrow\qquad\hat R-R=O_p\Big(\frac1{\sqrt n}\Big)$$

- 읽는 법: $c=10$ 이면 "99% 확률로 오차 $\lt10\sigma/\sqrt n$ ". $n$ 이 커지면 이 폭이 $1/\sqrt n$ 으로 좁아진다.
- (보충) $\varepsilon$ 으로 쓰면 $P(\lvert\hat R(f)-R(f)\rvert\ge\varepsilon)\le\frac{\sigma^2}{n\varepsilon^2}$ . "99% 확률로 오차 0.1 이내" ( $\delta=0.01$, $\varepsilon=0.1$ ), $\sigma=1$ 이면 $n\ge\frac{\sigma^2}{\delta\varepsilon^2}=10{,}000$ .
- 필기본은 이어서 $\mathbb E_{\text{training}}\big(\hat R(\hat f)-R(\hat f)\big)\le\varepsilon$ 을 적었다 (학습 데이터에 대한 기댓값으로 보는 방식).

**한계: 고정된 $f$ 에만 성립** (요약 p5) — 학습된 $\hat f$ 는 샘플을 보고 고른 함수라 샘플과 독립이 아니다. 그래서 $\mathcal F_\delta$ 전체의 sup( $\varepsilon_{gen}$ )를 제어해야 한다 → 10/26 Rademacher complexity.

**PAC (probably approximately correct)**

$$\forall\delta\gt0,\ \forall\varepsilon\gt0,\ \exists N:\quad P_{\text{training}}\big(\lvert\hat R(\hat f)-R(\hat f)\rvert\le\varepsilon\big)\ge1-\delta\quad\text{for }n\gt N$$

- "Approximately Correct" = 오차 $\le\varepsilon$ , "Probably" = 확률 $1-\delta$ 이상.
- (요약) 원하는 $(\varepsilon,\delta)$ 에 필요한 샘플 수 $n$ 을 계산해 데이터 구축 비용을 추정한다. 반대로 $n$ 이 고정이면 가능한 $\varepsilon$ 을 역산한다.

## 4. 예시 ①: 선형 함수 [필기본 p2]

$f_\ast(x)=\langle x,\theta_\ast\rangle$ ( $x\in\mathbb R^d$ ) 이면 미지수가 $d$ 개라 **$n\ge d$ 개면 최적의 $\hat f$ 를 찾는다**. 차원이 커져도 필요한 샘플이 $d$ 정도로만 는다 → 가설 공간이 작으면(선형) 일반화가 쉽다.

## 5. 🔴 예시 ②: Lipschitz 함수와 차원의 저주 [필기본 p2]

**설정** $\mathcal F=\lbrace f:\mathbb R^d\to\mathbb R\mid\text{bounded Lipschitz}\rbrace$ , target의 Lipschitz 상수 $\le\beta$ .

$$\hat f:=\arg\min\lbrace\mathrm{Lip}(f):f(X_i)=Y_i\rbrace\qquad(\text{학습 샘플을 지나는 함수 중 Lipschitz 상수가 가장 작은 것})$$

목표: $R(\hat f)=\mathbb E\lvert\hat f(x)-f(x)\rvert^2\le\varepsilon$ .

**오차 상계** 그림: 공 안의 점 $x$ 와 학습 샘플 $x_1,x_2=x_\ast,x_3,x_4$ — $x_\ast$ = $x$ 에서 **가장 가까운 학습 샘플**.

$$\lvert\hat f(x)-f(x)\rvert\le\lvert\hat f(x)-\hat f(x_\ast)\rvert+\underbrace{\lvert\hat f(x_\ast)-f(x_\ast)\rvert}_ {=0}+\lvert f(x_\ast)-f(x)\rvert\le\underbrace{\mathrm{Lip}(\hat f)}_ {\le\beta}\lVert x-x_\ast\rVert+\underbrace{\mathrm{Lip}(f)}_ {\le\beta}\lVert x-x_\ast\rVert\le2\beta\lVert x-x_\ast\rVert$$

- 가운데 항이 0인 이유: $\hat f$ 는 학습 샘플을 지난다 ( $\hat f(X_i)=Y_i=f(X_i)$ ).
- (보충) $\mathrm{Lip}(\hat f)\le\beta$ 인 이유: target $f$ 자체가 학습 샘플을 지나는 함수이므로, 그중 최소인 $\hat f$ 의 Lipschitz 상수는 $\mathrm{Lip}(f)\le\beta$ 이하.
- ✏️ 필기본은 첫 항을 $\lvert f(x)-\hat f(x_\ast)\rvert$ 로 적었다 (다음 줄 $\mathrm{Lip}(\hat f)$ 와 맞으려면 $\hat f(x)$ ).
- 따라서 (보충) $R(\hat f)\le4\beta^2\thinspace\mathbb E\lVert x-x_\ast\rVert^2$ — 오차는 **가장 가까운 샘플까지의 거리**로 정해진다.

**필요한 샘플 수**

$$\mathbb E\lVert x-x_\ast\rVert^2\approx n^{-2/d}\ \Longrightarrow\ \varepsilon\approx n^{-2/d}\ \Longrightarrow\ n\ge\varepsilon^{-d/2}\qquad\textbf{curse of dimensions}$$

- (보충) 직관: 반지름 $r$ 인 공의 부피는 $r^d$ 에 비례한다. $n$ 개의 점이 공간을 덮으려면 $n\cdot r^d\approx1$ → $r\approx n^{-1/d}$ → 거리 제곱 $\approx n^{-2/d}$ .

| 입력 차원 $d$ | $\varepsilon=0.1$ 에 필요한 $n$ |
| --- | --- |
| 2 | $10^1$ |
| 10 | $10^5$ |
| 784 (MNIST 28×28) | $10^{392}$ |

- 차원이 조금만 늘어도 필요한 데이터가 **지수적으로** 는다. (요약) LLM의 멀티모달 입력은 차원이 더 커서 수조 개의 샘플로도 이론상 부족하다.
- 10/21–10/26의 **Barron 정리**와 대비: Barron class처럼 더 매끄러운 함수로 좁히면 근사 오차가 $c/N$ 으로 **차원과 무관하게** 준다. 모든 Lipschitz 함수처럼 함수 공간을 넓게 잡으면 차원의 저주를 피할 수 없다.

## 6. 🔴 손실 함수 설계: 0-1 risk와 hinge risk [필기본 p2–3] — 📋 (요약) 기말 출제 예정

**이진 분류 설정** $x\in\mathbb R^d$ , $Y\in\lbrace-1,1\rbrace$ , 손실 $\ell(f(X),Y)=\mathbb 1_{\lbrace f(X)\ne Y\rbrace}$ → risk $=\mathbb E[\mathbb 1_{\lbrace f(X)\ne Y\rbrace}]$ (오분류 확률).

실수값 함수 $g:\mathcal X\to\mathbb R$ 를 배우고 $f_g=\mathrm{sign}(g(x))$ 로 분류한다.

$$R_{0\text{-}1}(g)=\mathbb E\big[\mathbb 1_{\lbrace Yg(X)\le0\rbrace}\big],\qquad R^{\text{hinge}}(g)=\mathbb E\big[\max\lbrace1-Yg(X),\thinspace0\rbrace\big]$$

- 0-1: $g(x)\gt0,Y=1$ 또는 $g(x)\lt0,Y=-1$ 이면 0 (맞음), $Yg(X)\le0$ 이면 1 — **$g(x)=0$ 도 틀린 것으로 센다** (요약: 0 근처에서 부호가 불안정한 예측을 맞았다고 치지 않으려고).
- (요약) **0-1 손실은 학습에 못 쓴다**: 불연속이고 거의 모든 곳에서 기울기가 0 → GD가 방향을 얻지 못한다.
- 필기본은 0-1 risk 앞에 " $R\le$ "를 붙였다 [판독: 기호가 불분명]. (보충) $g=0$ 을 틀린 것으로 세므로 $\mathrm{sign}$ 분류기의 오분류율은 $R_{0\text{-}1}(g)$ 이하다.

**Hinge loss** 마진 $u=Yg(X)$ 로 두면 $\max(1-u,0)$

| $u=Yg(X)$ | 0-1 손실 | hinge | 뜻 |
| --- | --- | --- | --- |
| $u\le0$ (틀림) | 1 | $1-u\ge1$ | **크게 틀릴수록 더 큰 벌점** |
| $0\lt u\lt1$ (아슬아슬하게 맞음) | 0 | $1-u\gt0$ | 맞았어도 **더 확실히 맞추라고** 벌점 |
| $u\ge1$ (확실히 맞음) | 0 | 0 | 벌점 없음 |

- (보충) 연속이고 볼록이며 항상 0-1 손실 이상이다 ( $\max(1-u,0)\ge\mathbb 1_{\lbrace u\le0\rbrace}$ → $R_{0\text{-}1}\le R^{\text{hinge}}$ ). 09.14 SVM penalty의 $1-y_i(w^\top x_i+b)$ 와 같은 꼴이다.

### 🔴 반례: hinge loss를 그대로 최소화하면 되는가? → 아니다! [필기본 p3]

$\mathcal X=\lbrace x_1,x_2\rbrace$ , 레이블은 둘 다 $Y=1$ , $P(X=x_1)=0.99$ , $P(X=x_2)=0.01$ ( $x_2$ = outlier)

| 모델 | $g(x_1)$ | $g(x_2)$ | $R^{\text{hinge}}$ | $R_{0\text{-}1}$ |
| --- | --- | --- | --- | --- |
| $g_A$ | 0.1 | 0.1 | ✏️ $0.99\cdot0.9+0.01\cdot0.9=0.9$ | **0** |
| $g_B$ | 1 | −0.1 | ✏️ $0.99\cdot0+0.01\cdot1.1=0.011$ | 0.01 |

- hinge 기준으로는 $R^{\text{hinge}}(g_B)\lt R^{\text{hinge}}(g_A)$ → **$g_B$ 를 고른다**: 흔한 점 $x_1$ 을 확실히 맞추는 쪽에 큰 보상을 준다.
- 실제 목표(0-1 risk) 기준으로는 **$g_A$ 가 낫다** ( $0\lt0.01$ ): $g_A$ 는 둘 다 맞히고 $g_B$ 는 outlier를 틀린다.
- ✏️ 필기본의 값은 $R^{\text{hinge}}(g_B)=0.01$ , $R^{\text{hinge}}(g_A)=0.099$ 다. 적힌 $g$ 값으로 계산하면 각각 0.011, 0.9다 ( $0.099=0.99\times0.1$ 로 $1-g$ 대신 $g$ 를 곱한 것으로 보인다). 대소 관계와 결론은 같다.
- **결론**: 대리 손실(hinge)로 리스크를 최소화한 모델이 실제 리스크를 최소화한다는 보장이 없다. (요약) 이를 보장하려면 가설 공간·분포에 대한 **추가 가정**이 필요하고, 손실 함수는 문제에 맞춰 신중하게 설계해야 한다.
