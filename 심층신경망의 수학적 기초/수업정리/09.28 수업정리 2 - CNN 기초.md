## 1. FC 층의 한계와 CNN의 동기 [p2–6]

**Fully connected layer** [p2]

| | 내용 |
| --- | --- |
| 장점 | 단순하다. 이론상 매우 일반적이다 (충분히 큰 MLP는 이론상 어떤 함수든 배울 수 있다). |
| 단점 | **학습할 파라미터가 너무 많다.** shift equivariance/invariance를 담지 못해 **inductive bias가 나쁘다.** |

- 이미지는 차원이 매우 크고(픽셀 수백만 개), 모양·위치 등 변형이 많다. 모든 픽셀을 입력으로 쓰는 FC 신경망은 파라미터가 많고 **공간 구조를 쓰지 않아서** 학습이 어렵다. [p3]
- FC에서는 이미지(픽셀 값의 행렬)를 **한 줄로 펴서(flatten)** 넣으므로 공간 정보를 쓸 수 없다. [p4]
- 질문: 이미지의 **공간 구조**를 신경망 학습에 어떻게 쓸까?
- **Shift equivariance/invariance** [p5]: 비전의 많은 과제는 이동(shift, translation)에 대해 equivariant/invariant하다. 대략, 물체를 옮겨도 **의미는 그대로이고 위치만 바뀐다** (고양이를 옮겨도 여전히 고양이).
- **Locally connected layer** [p6]: 픽셀 값들은 서로 의존하고 거기에 공간 구조가 들어 있다. 그래서 은닉층의 각 뉴런을 **입력의 작은 패치에만** 연결한다.

## 2. 2D 합성곱 = 창을 옮겨 가며 가중 평균 [p7–13]

- 예 (Moving average in 2D): 10×10 이미지(값 0 또는 90)에 3×3 평균 필터를 한 칸씩 옮기며 적용한다. 창 안에 90이 하나면 $90/9=10$, 셋이면 30, 아홉이면 90.
- 출력의 첫 줄은 0, 10, 20, 30, 30, 30, 20, 10 — 경계가 **흐려진다**. 출력 크기는 $10-3+1=8$ 이라 8×8.
- 슬라이드 질문: 필터가 3×3이 아니라 5×5라면? (보충) 더 넓게 평균하므로 더 흐려지고, 출력은 $10-5+1=6$ 이라 6×6으로 줄어든다.
- 합성곱 층은 이 **평균 필터의 가중치를 학습**하는 것이다 (§5 슬라이드: "These values are the weights to be optimized during the gradient descent update").

## 3. 합성곱 층 [p14–20, p35–38]

CNN의 층 종류 [p14]: **Convolutional layer**, Pooling layer, Fully-connected layer

- 입력: 32×32×3 이미지 (height × width × depth). 한 줄로 펴지 않고 **공간 구조를 유지**한다. [p15]
- 필터: 5×5×3. **필터는 항상 입력의 깊이 전체를 덮는다** (입력 채널이 3이면 필터 깊이도 3). [p17]
- Convolve: 필터를 이미지 위에서 **공간적으로 밀면서 내적**을 계산한다. [p16]
- 한 위치의 출력은 **숫자 하나**: 필터와 이미지의 5×5×3 조각 사이의 내적 + bias, 즉 $w^\top x+b$ ( $5\cdot5\cdot3=75$차원 내적). [p18]
- 모든 위치에서 계산한 결과가 **activation map** (= feature) 한 장: 28×28×1. [p19–20]
- **파라미터 수** [p17]: $5\times5\times3+1=76$ (+1은 bias). FC 층이면 $3072\times\text{dim}_ {\text{out}}$ 개가 필요하다.
- **필터가 여러 개면** [p35–36]: 필터마다 activation map이 한 장씩 나온다. 5×5 필터 6개면 28×28×6의 "새 이미지"가 된다. 파라미터는 $6\times(75+1)=456$.
- **ConvNet** [p37–38]: 합성곱 층을 활성화 함수와 번갈아 쌓은 것.
  32×32×3 → CONV, ReLU (5×5×3 필터 6개) → 28×28×6 → CONV, ReLU (5×5×**6** 필터 10개) → 24×24×10 → …
  - 둘째 층의 필터 깊이는 앞 층의 출력 채널 수(6)와 같다. (보충) 둘째 층 파라미터는 $10\times(5\cdot5\cdot6+1)=1510$.

## 4. 출력 크기 계산 [p21–34, p39–42]

**세 가지 연산** [p39]

| 연산 | 뜻 |
| --- | --- |
| Naive convolution | 필터를 그대로 민다 → 출력이 작아진다 |
| Padding | feature의 경계에 값(보통 0)을 덧붙인다 |
| Stride | 필터를 $S$칸씩 건너뛰며 적용한다 |

**공식** [p31, p33, p40] 입력 $N\times N\times C$, kernel 크기 $K$ (= $F$ ), stride $S$, padding $P$, 필터 $D$개이면 출력은 $N'\times N'\times C'$:

$$N'=\frac{N-K+2P}{S}+1,\qquad C'=D$$

- p33은 나누어떨어지지 않을 때를 포함해 $\Big\lfloor\dfrac{N+2P-F}{S}\Big\rfloor+1$ 로 적었다.
- **Same padding** (크기 유지) [p33–34]: $S=1$이고 $F$가 홀수일 때 $P=\dfrac{F-1}2$ 로 두면 출력 크기 = $N$. $F=3$ → 1, $F=5$ → 2, $F=7$ → 3. 실제로 stride 1, $F\times F$ 필터, zero padding $(F-1)/2$ 조합을 흔히 쓴다.

**슬라이드 예제**

| 입력 | 설정 | 계산 | 출력 | 쪽 |
| --- | --- | --- | --- | --- |
| 7×7 | $F=3$, $S=1$ | $(7-3)/1+1=5$ | 5×5 | p21–25, p31 |
| 7×7 | $F=3$, $S=2$ | $(7-3)/2+1=3$ | 3×3 | p26–28, p31 |
| 7×7 | $F=3$, $S=3$ | $(7-3)/3+1=2.33$ | **맞지 않는다** | p29–31 |
| 7×7 | $F=3$, $S=1$, $P=1$ | $(7-3+2)/1+1=7$ | 7×7 (크기 유지) | p32–34 |
| 32×32×3 | 5×5 필터 6개, $S=1$ | $(32-5)/1+1=28$ | 28×28×6 | p36 |
| 52×52×128 | $K=3$, $S=1$, $P=1$, $D=256$ | $(52-3+2)/1+1=52$ | 52×52×256 | p41 |
| 52×52×128 | $K=4$, $S=2$, $P=1$, $D=256$ | $(52-4+2)/2+1=26$ | 26×26×256 | p42 |

## 5. 합성곱 수치 예제 [p43–50]

**예제 1** [p43–46] 필터 하나(3×3), stride 1.

$$\text{Image}=\begin{pmatrix}2&4&9&1&4\cr2&1&4&4&6\cr1&1&2&9&2\cr7&3&5&1&3\cr2&3&4&8&5\end{pmatrix},\qquad\text{Filter}=\begin{pmatrix}1&2&3\cr-4&7&4\cr2&-5&1\end{pmatrix}$$

- 왼쪽 위 창: $2\cdot1+4\cdot2+9\cdot3+2\cdot(-4)+1\cdot7+4\cdot4+1\cdot2+1\cdot(-5)+2\cdot1=51$
- 한 칸 오른쪽: $4\cdot1+9\cdot2+1\cdot3+1\cdot(-4)+4\cdot7+4\cdot4+1\cdot2+2\cdot(-5)+9\cdot1=66$
- 오른쪽 아래 창: $2\cdot1+9\cdot2+2\cdot3+5\cdot(-4)+1\cdot7+3\cdot4+4\cdot2+8\cdot(-5)+5\cdot1=-2$

padding 없이: $(5-3)/1+1=3$ 이라 3×3 feature. zero padding 1을 주면 5×5 feature (첫 값 $0+0+0+0+2\cdot7+4\cdot4+0+2\cdot(-5)+1\cdot1=21$ ).

$$\text{no padding: }\begin{pmatrix}51&66&20\cr31&49&101\cr15&53&-2\end{pmatrix}\qquad\text{zero padding: }\begin{pmatrix}21&59&37&-19&2\cr30&51&66&20&43\cr-14&31&49&101&-19\cr59&15&53&-2&21\cr49&57&64&76&10\end{pmatrix}$$

- zero padding 결과의 가운데 3×3이 padding 없는 결과와 같다.
- 슬라이드 메모: 필터의 값들은 **gradient descent로 최적화할 가중치**(filter coefficients)다.
- (보충) 필터를 뒤집지 않고 그대로 곱한다. 수학의 convolution은 필터를 뒤집어 곱하지만, 딥러닝에서는 이 계산(cross-correlation)을 convolution이라 부른다.

**예제 2** [p47–50] 필터 두 개(3×3), stride 1, padding 없음. 4×4 입력 → 필터마다 2×2 feature.

$$\text{Input}=\begin{pmatrix}1&0&3&1\cr0&-1&2&0\cr2&0&4&2\cr0&3&0&1\end{pmatrix},\qquad\text{Filter 1}=\begin{pmatrix}1&1&0\cr0&1&-1\cr0&0&0\end{pmatrix},\qquad\text{Filter 2}=\begin{pmatrix}-1&1&0\cr0&-1&0\cr-1&1&0\end{pmatrix}$$

$$\text{Feature 1}=\begin{pmatrix}-2&5\cr-5&3\end{pmatrix},\qquad\text{Feature 2}=\begin{pmatrix}-2&5\cr2&-4\end{pmatrix}$$

- 창을 오른쪽으로 한 칸(Right shift by 1), 아래로 한 칸 옮길 때마다 feature의 다음 칸이 채워진다.
- 검산 (Feature 1 왼쪽 위): $1\cdot1+0\cdot1+(-1)\cdot1+2\cdot(-1)=-2$
- ✏️ Feature 2의 오른쪽 아래 값: 슬라이드는 −5지만 직접 계산하면 **−4**다. 오른쪽 아래 창의 행은 (−1, 2, 0), (0, 4, 2), (3, 0, 1)이고, Filter 2와 원소별로 곱해 더하면 $(-1)(-1)+1\cdot2+(-1)\cdot4+(-1)\cdot3+1\cdot0=-4$.

## 6. Feature 계층과 1×1 conv [p51–53]

- **Feature 계층** [p51–52] (Zeiler and Fergus 2013): low-level features → mid-level → high-level → **linearly separable classifier**. 층이 깊어질수록 추상적인 특징을 본다 (VGG-16의 Conv1_1, Conv3_2, Conv5_3 시각화). 전체 구조는 CONV–ReLU–CONV–ReLU–POOL을 반복하고 마지막에 FC로 클래스 점수를 낸다.
  - 9/16 "은닉층 = 선형분리 가능한 공간으로의 임베딩", "특징의 계층"과 같은 이야기다 → [09.16 수업정리](09.16%20수업정리.md)
- **1×1 convolution** [p53]: 56×56×64에 1×1 필터 32개 → 56×56×32. 필터 하나는 1×1×64이고 **64차원 내적**을 한다. "1×1 convolution layers make perfect sense."
- 슬라이드 질문 "Is it the same as FC Layer?" → (보충) 각 픽셀에서 보면 64차원 벡터를 32차원으로 보내는 FC와 같은 계산이다. 다만 **모든 픽셀이 같은 가중치를 쓰고** 픽셀끼리는 섞이지 않는다. 전체를 한 줄로 편 FC와는 다르다. 10/7 슬라이드는 이것을 "pixel-wise embedding from $C$ to $K$ dimension"이라 부른다 → [10.07 수업정리](10.07%20수업정리.md)

## 7. Pooling 층 [p54–59]

- 역할 [p55]: 표현을 **더 작고 다루기 쉽게** 만든다(downsampling). **activation map마다 따로** 적용한다. 예: 224×224×64 → pool → 112×112×64 (채널 수는 그대로).
- (보충) pooling에는 **학습할 파라미터가 없다.** 출력 크기는 §4 공식에 창 크기와 stride를 넣으면 된다: 2×2 창, stride 2면 $(224-2)/2+1=112$.

**예제** [p56–58] 4×4 입력, 2×2 창 (stride 2)

$$\begin{pmatrix}5&10&6&7\cr4&0&4&3\cr2&4&3&4\cr0&8&1&6\end{pmatrix}\ \longrightarrow\ \text{average: }\begin{pmatrix}4.75&5\cr3.5&3.5\end{pmatrix},\qquad\text{max: }\begin{pmatrix}10&7\cr8&6\end{pmatrix}$$

- **Global average pooling** [p59]: 채널마다 **전체 평균 하나**만 남긴다. 6×6×3 feature → 숫자 3개.

## 8. FC 층과 비교 [p60–65]

- **FC 층** [p60–61]: 32×32×3 이미지를 3072×1로 편다. $Wx$의 $W$는 10×3072. 출력 하나는 $W$의 **한 행과 입력 전체**의 내적(3072차원 내적)이다.
- **합성곱 층** [p63–65]

| | Fully-connected layer | Convolution layer |
| --- | --- | --- |
| 연결 | 모든 노드가 다음 층의 모든 노드와 연결 | 각 노드가 **지역적으로만** 연결 (이웃의 크기 = kernel 크기) |
| 가중치 | 연결마다 따로 | **모든 공간 위치가 같은 가중치를 공유** |

- (보충) 숫자로 보면: 32×32×3 입력에서 28×28×6 출력(4704개 값)을 만들 때 합성곱은 456개, 같은 크기의 FC는 $3072\times4704\approx1.4\times10^7$개의 가중치가 필요하다. 합성곱 층은 **대부분의 가중치를 0으로 두고(지역 연결) 남은 가중치를 묶은(공유) FC 층**이다.
- CNN의 역사 [p62]: LeNet-5 (LeCun, Bottou, Bengio, Haffner 1998, "Gradient-based learning applied to document recognition")

## 9. Filtering 관점과 equivariance [p66–70]

- **Filtering** [p66–68]: 필터로 **모든 이미지 위치에서 가중 평균**을 계산해 저장한다 (원소별 곱 후 평균). 필터와 닮은 무늬가 있는 곳에서 값이 크다(High).
- 숫자 9를 왼쪽·가운데·오른쪽으로 옮기면 반응 지도의 밝은 부분도 **같이 옮겨 간다**. 슬라이드: "Filtering is translation invariant — a filter can handle objects in any locations."

**정의** [p69–70] 변환들의 모임 $G$의 모든 $g$에 대해

$$\text{equivariant: }f(g\cdot x)=g\cdot f(x)\qquad\qquad\text{invariant: }f(g\cdot x)=f(x)$$

- $f$가 **convolution**, $g$가 **translation**이면 equivariant다: "옮기고 나서 합성곱" = "합성곱하고 나서 옮기기" (슬라이드 그림의 가환 도식).
- (보충) p68의 "translation invariant"는 **필터의 가중치가 위치와 무관하다**(어느 위치의 물체든 같은 필터로 잡는다)는 뜻이다. 출력 지도는 물체를 따라 움직이므로 p69–70의 정의로는 **equivariant**다. 출력이 아예 안 바뀌는 invariant는 분류 결과("여전히 고양이")에 해당하고, pooling과 global average pooling이 그쪽을 돕는다.

**(보충) 합성곱이 이동에 equivariant임을 보이기** — 경계는 무시한다.
- 합성곱: $(w\star x)[i,j]=\sum_{a,b}w[a,b]\thinspace x[i+a,\thinspace j+b]$
- 이동: $(T_{p,q}x)[i,j]=x[i-p,\thinspace j-q]$
- 계산:
  $$(w\star T_{p,q}x)[i,j]=\sum_{a,b}w[a,b]\thinspace x[i+a-p,\thinspace j+b-q]=(w\star x)[i-p,\thinspace j-q]=\big(T_{p,q}(w\star x)\big)[i,j]$$
- 핵심은 **모든 위치 $(i,j)$가 같은 $w$를 쓴다**는 것(가중치 공유)이다. 위치마다 가중치가 다른 locally connected layer나 FC 층에서는 둘째 등호가 성립하지 않는다.
- ReLU는 원소별 함수라 이동과 순서를 바꿔도 같다. 그래서 CONV–ReLU를 쌓아도 equivariant다.
