## 짚은 포인트 (시험 가능성 순)

범례: 📋 시험 언급 · 🔴 노트 페이지 증명·유도 · 🟠 슬라이드 위 유도·박스 · 🟡 밑줄·동그라미 · 🔲 슬라이드 빈칸

- 🔴★ **scaled dot-product attention과 $\sqrt{d_k}$ 의 이유** — $q,k$ 의 성분이 i.i.d. $N(0,1)$ 이면 $\text{Var}[q^\top k]=d_k$ (빨간 이중 동그라미) → 차원이 크면 softmax가 한 곳에 몰림 → $\sqrt{d_k}$ 로 나눠 분산 1 [p29–31, p33]
- 🔴 **Q, K, V의 shape과 뜻** ( $A=QK^\top\in\mathbb R^{n\times n}$ , $A_{ij}$ = $i$ 번째가 $j$ 번째를 얼마나 주목하나) [p29, p31 — 빨간 표시가 가장 많은 슬라이드]
- 🟠 **cross vs self attention** — "Q from decoder, K,V from X" / "self-attention: Q,K,V from X" [p35–36]
- 🟠 **self-attention은 permutation equivariant**, single-query attention은 permutation invariant → **positional encoding이 필요한 이유** ("man bites dog / dog bites man") [p32, p36–37]
- 🔴 **positional encoding 수치 예** ( $d=4$ , $\omega_1=1$ , $\omega_2=0.01$ , $p(0)$, $p(1)$, $p(2)$ , $x_{dog}+p(t)$ , 이진수 직관) [p38–39]
- 🔴 **masked self-attention** — query 위치 $j$ 는 $0,\dots,j$ 만 참조, 나머지 $-\infty$ → softmax 후 0 [p40–41]
- 🟡 **attention 캡셔닝의 shape**: $X\in\mathbb R^{14\times14\times512}$ , $X_{ij}\in\mathbb R^{512}$ , $\alpha^t\in\mathbb R^{14\times14}$ , $f_{att}$ = MLP [p12, p16–19]
- 🔴 **캡셔닝 학습의 cross entropy 손계산** $\mathcal L_3=-\log0.8\approx0.223$ [p6–7]
- 🔲 **inductive bias 빈칸**: "RNN exploits 1D chain data structure and **first-order Markov assumption**" (그림에서 가려진 부분, 텍스트 레이어로 확인) [p26]
- 🟡 SENet: "여기서는 attention 합이 1이 아니어도 된다" [p22]

## 1. Naive image captioning [W10M p2–9]

$$f_\theta\big(y\mid g_\phi(x)\big)\qquad g_\phi=\text{ImageNet으로 미리 학습한 CNN},\quad f_\theta=\text{LSTM}$$

- 입력 이미지 224×224×3 → CNN(VGG16 등)의 **FC층 feature vector** (✏️ p2는 1×1×4096, p3 이후는 1×1×2048로 적혀 있다. VGG16 FC는 4096, 2048은 ResNet 계열)
- → Linear(판서 "MLP") → **이미지 feature를 첫 단어처럼** LSTM에 넣는다 → 이후는 10/28 언어모델과 같다: Softmax로 단어 예측, 예측 단어를 $W_{emb}$ 로 다음 입력에 → <eos>에서 정지
- **학습** (p5): (이미지, 문장) 쌍으로 $\sum_{t=1}^T\mathcal L(\hat y_t,y_t)$ , **cross entropy (문장 생성과 같음)**

**🔴 판서 예 (p6–7)** 어휘 5개 {man, plays, guitar, <EOS>, <SOS>}, 정답 문장 "man plays guitar"

| 시점 | 입력 | 정답 | 정답 one-hot $y_t$ |
| --- | --- | --- | --- |
| 1 | <SOS> | man | $(1,0,0,0,0)$ |
| 2 | man | plays | $(0,1,0,0,0)$ |
| 3 | plays | guitar | $(0,0,1,0,0)$ |
| 4 | guitar | <EOS> | $(0,0,0,1,0)$ |

- $y_i$ = 정답 one-hot, $\hat y_i$ = 모델이 예측한 단어들의 확률분포. 3번째 시점에서 $\hat y_3=(0.05,\thinspace0.1,\thinspace0.8,\thinspace0.04,\thinspace0.01)$ 이면

$$\mathcal L_3=-\sum_{k=1}^5y_{3,k}\log\hat y_{3,k}=-\big[0\cdot\log0.05+0\cdot\log0.1+1\cdot\log0.8+\cdots\big]=-\log0.8\approx0.223$$

- one-hot이라 **정답 단어의 확률에 $-\log$ 를 취한 것만 남는다** (03장 softmax 손실과 같다). 전체 손실 $\mathcal L=\sum_{t=1}^4\mathcal L_t$ 를 최소화한다. (✏️ 판서의 합 박스는 칸이 5개지만 $t=1..4$ 의 4항이다.)

**Practical issue** (p8): RNN이 충분히 강하면 **이미지를 보지 않고 앞 단어들만으로** 그럴듯한 문장을 만든다 (앞 단어가 다음 단어에 더 직접적이라). → 이미지 조건을 강화해야 한다.

**Shortcut** (p9): 이미지 feature를 **매 시점** LSTM에 넣는다. 장점: 의존 거리가 1. 단점: 여전히 이미지를 무시할 수 있다.

## 2. Attention 기반 이미지 캡셔닝 [W10M p10–19]

**아이디어:** 단어를 만들 때마다 이미지의 **관련 있는 부분을 "응시(gaze)"** 한다. attention이 없으면 = 모든 위치에 같은 가중치(uniform attention).

**공간 feature를 쓴다** (p11): FC 벡터 대신 **conv5 층 feature map** $X$ (14×14×512) — 위치마다 512차원 벡터 $x_{ij}$ .

**Attention** (p12): feature map과 같은 공간 크기의 양수 행렬

$$\alpha^{(t)}\in\mathbb R^{W\times H}\ (W=\text{Width},\ H=\text{Height}),\qquad\sum_{i,j}\alpha^{(t)}_ {i,j}=1,\qquad z^{(t)}=\sum_{i,j}\alpha^{(t)}_ {i,j}x_{i,j}\in\mathbb R^C$$

- 단어마다 attention $\alpha^{(1)},\dots,\alpha^{(N)}$ 를 새로 계산하고 (각 14×14), 그것으로 이미지 feature를 **가중평균**해 요약한다 ( $C=512$ ).

**계산 방법** (p15–19)

$$e^{(t)}=f_{att}(x,h_{t-1}),\qquad\alpha^{(t)}=\frac{\exp(e^{(t)})}{\sum_{i,j}\exp(e^{(t)}_ {i,j})},\qquad z^{(t)}=\sum_{i,j}\alpha^{(t)}_ {i,j}x_{i,j}$$

- $f_{att}$ = **MLP** (판서). 이미지 feature와 직전 hidden state $h_{t-1}$ 을 보고 위치마다 점수 $e_{ij}$ → 14×14 위치 전체에 softmax → 합 1
- 판서의 shape 정리: $X\in\mathbb R^{14\times14\times512}$ , $X_{ij}\in\mathbb R^{512}$ , $\alpha^t\in\mathbb R^{14\times14}$
- **Modified LSTM**: $h^{(t)}=\text{LSTM}(h_{t-1},\thinspace W_{emb}y_t,\thinspace z^{(t)})$ — 요약한 이미지 정보 $z^{(t)}$ 를 매 시점 입력으로
- 출력: ✏️ $\hat y_{t+1}=\text{softmax}\big(W^o(W_{emb}y_t+W^hh_t+W^zz_t)\big)$ (슬라이드는 " $=\exp(\cdot)$ "로 정규화가 빠져 있다. 원 논문은 $\propto$ )

## 3. Attention의 종류와 inductive bias [W10M p20–27]

**Spatial attention** (p21, Show-Attend-and-Tell): **soft** = 넓게 퍼진 가중치(위 식, 미분 가능), **hard** = 한 위치만 선택.

**Channel attention: SENet** (p22): Global pooling → 채널별 가중치 찾기 (FC → ReLU → FC → **sigmoid**) → 원래 feature에 채널별로 곱하기. 가중치는 sigmoid라 각각 $(0,1)$ 이고 **합이 1일 필요가 없다** (판서 메모). 공간 attention은 softmax라 합 1.

**지금까지의 모델** (p23)

| 모델 | 구성 |
| --- | --- |
| MLP | linear layer + 비선형 함수 |
| CNN | convolution + pooling + 비선형 + MLP |
| RNN | 순환 갱신용 MLP + gating 함수 |
| Attention / Transformer | **dot-product attention + MLP** |

**Inductive bias** (p25–26) — 정의: 학습자가 **보지 못한 입력의 출력을 예측하려고 쓰는 가정들의 집합**
- 많은 구조가 특정 inductive bias에 기댄다. 대부분 데이터의 **locality(국소성)와 invariance(불변성)**.
  - 예 1: convolution은 **2D 격자 구조와 translation invariance**를 쓴다 (07장)
  - 예 2: RNN은 **1D 사슬 구조와 🔲 first-order Markov assumption** ( $h_t$ 가 직전 $h_{t-1}$ 과 $x_t$ 에만 의존) 을 쓴다
- 이런 가정은 효율적인 모델을 만드는 데 유용하지만, **다른 데이터 종류(modality)로는 일반화되지 않는 경우가 많다.** (판서 그림: 이미지를 펴서 MLP에 넣으면 2D 구조가 사라진다 ✗)
- p27: 여러 데이터·과제를 **하나의 모델**로 → 판서 "Foundation model", "AGI", "TF" (Transformer). 가정이 적은 attention이 그 후보다.
- 필기본 p16: **"multimodal이란? 하나의 모델로 여러 개의 task 처리"** — Image, Audio, Language → A single, unified model → Objects, Motion, Semantics, Depth.

## 4. 🔴 Scaled dot-product attention [W10M p28–31]

$$\text{Attention}(Q,K,V)=\text{softmax}\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)V$$

**판서 (p29–30)**
- 입력 $x\in\mathbb R^{n\times d}$ ( $n$ 개 토큰, 각 $d$ 차원), projection 행렬 $W_q,W_k\in\mathbb R^{d\times d_k}$ , $W_v\in\mathbb R^{d\times d_v}$ (✏️ 판서는 셋 다 $d\times d_k$ 로 묶었다. 보통 $d_v=d_k$ )

| | 식 | shape | 뜻 (판서) |
| --- | --- | --- | --- |
| query | $Q=xW_q$ | $n\times d_k$ | 질문 |
| key | $K=xW_k$ | $n\times d_k$ | 정보의 인덱스 |
| value | $V=xW_v$ | $n\times d_v$ | 실제 정보 |

1. $A=QK^\top\in\mathbb R^{n\times n}$ — $A_{ij}=q_i^\top k_j$ : **$i$ 번째가 $j$ 번째 정보를 얼마나 주목하나**
2. scaled: $A'=\dfrac{QK^\top}{\sqrt{d_k}}$
3. $\alpha_{ij}=\text{softmax}(A')$ — **행마다** ( $j$ 방향으로) 정규화해서 $\sum_j\alpha_{ij}=1$
4. $\text{output}_ i=\sum_j\alpha_{ij}V_j$ — value들의 가중평균

**🔴 왜 $\sqrt{d_k}$ 로 나누나** (판서 p29–30, 슬라이드 p33)
- $q,k\in\mathbb R^{d_k}$ 의 성분이 모두 독립이고 $N(0,1)$ 이라 하자. $z=q^\top k=\sum_{m=1}^{d_k}q_mk_m$ .
- $\mathbb E[q_mk_m]=\mathbb E[q_m]\mathbb E[k_m]=0$ → $\mathbb E[z]=0$
- $\text{Var}(q_mk_m)=\mathbb E[q_m^2k_m^2]=\mathbb E[q_m^2]\mathbb E[k_m^2]=1$ , 항들이 독립이라

$$\text{Var}[z]=\sum_{m=1}^{d_k}\text{Var}(q_mk_m)=d_k$$

- 차원이 클수록 점수(logit)의 분산이 커진다 → 큰 logit 하나가 softmax를 **한 곳으로 몰리게(peak)** 해서 나머지에 거의 0을 준다 (분포의 엔트로피가 낮아짐) → 기울기도 거의 0
- $\sqrt{d_k}$ 로 나누면 $\text{Var}[z/\sqrt{d_k}]=d_k/d_k=1$ — **차원과 무관하게 분산 1**
- (검산: $d_k=4,64,512$ 로 시뮬레이션하면 $\text{Var}[q^\top k]\approx d_k$ , 나눈 뒤 $\approx1$ )
- (보충) 05장 Xavier 초기화의 " $\text{Var}(y)=D_{in}\sigma^2V$ → $\sigma^2=1/D_{in}$ "과 같은 계산이다.

**슬라이드 p31** $\text{Attn}(xW_q,xW_k,xW_v)=\text{softmax}\big(\frac{xW_q(xW_k)^\top}{\sqrt d}\big)xW_v$ — 출력은 입력의 **문맥적(contextual) 인코딩**이고, **receptive field가 입력 전체**다 (CNN은 커널 크기만큼만 봄). (✏️ $\sqrt d$ 는 정의상 $\sqrt{d_k}$ , "contexture"는 contextual)

## 5. General attention layer: 단계별로 넓히기 [W10M p32–36]

| 단계 | 입력 | 점수 (alignment) | 출력 | 성질 |
| --- | --- | --- | --- | --- |
| single query (p32) | $x$ ( $N\times D$ ), query $h$ ( $D$ ) | $e_i=f_{att}(h,x_i)$ | $c=\sum_ia_ix_i$ ( $D$ ) | **key = value** = $x$ , **permutation invariant** |
| scaled dot (p33) | 같음 | $e_i=h\cdot x_i/\sqrt D$ | 같음 | $\sqrt D$ = 큰 벡터의 영향 줄이기 |
| multiple query (p34) | $x$ , queries $q$ ( $M\times D$ ) | $q_j\cdot x_i/\sqrt D$ | $y_j=\sum_ia_{i,j}x_i$ ( $M\times D$ ) | query마다 출력 하나 |
| **cross** (p35) | $x$ , queries ( $M\times D_k$ ) | $q_j\cdot k_i/\sqrt{D_k}$ , $k=xW_k$ | $y_j=\sum_ia_{i,j}v_i$ , $v=xW_v$ | key와 value를 FC로 분리 |
| **self** (p36) | $x$ 만 | $q=xW_q$ , $k=xW_k$ , $v=xW_v$ | $y$ ( $N\times D_v$ ) | **permutation equivariant** |

- 판서 (p34): $E=\dfrac{QK^\top}{\sqrt D}$ , $A=\text{softmax}(E)$ , $Y=AX$ (행 = query, 행마다 softmax)
- 판서 (p35): **cross attention → Q from decoder, K·V from X** / **self-attention: Q, K, V from X**
- 필기본 p17의 번역 예 (한국어 → 영어): decoder의 입력으로 **지금까지 번역된 문장**을 넣어 Q를 만들고, K·V는 **한국어 원문 전체**에서 나온다.
- 판서 (p36)의 예 "Image captioning — Query: 문장 생성 쪽 상태 feature / key, value: image feature" — Q와 K·V의 출처가 다르므로 사실은 **cross-attention**의 예다 (§2의 $f_{att}(x,h_{t-1})$ 이 그 원형).
- ✏️ 슬라이드 p34의 출력 shape "D"는 $M\times D$ , p35–36·p40의 분모 $\sqrt D$ 는 key 차원 $\sqrt{D_k}$ .

**🟠 permutation equivariance** (p36, 판서 "[P][A]", " $X_1X_2X_0$ ")

입력 순서를 순열 행렬 $P$ 로 섞으면 $Q,K,V$ 가 모두 $PQ,PK,PV$ 가 되고, 행마다 softmax는 행·열 순서 바꾸기와 교환하며 $P^\top P=I$ 이므로

$$\text{softmax}\Big(\frac{PQK^\top P^\top}{\sqrt{d_k}}\Big)PV=P\thinspace\text{softmax}\Big(\frac{QK^\top}{\sqrt{d_k}}\Big)P^\top PV=P\cdot\text{Attn}(Q,K,V)$$

즉 $f(PX)=Pf(X)$ : **입력을 섞으면 출력도 똑같이 섞일 뿐** (07장 CNN의 이동 equivariance와 같은 꼴). single query는 출력 $c$ 하나가 순서와 무관 → invariant. (검산: 무작위 행렬로 확인)

## 6. 🔴 Positional encoding [W10M p37–39]

**왜 필요한가** (판서 p37): self-attention은 permutation equivariant라 **단어 순서를 모른다.** "man bites dog"와 "dog bites man"은 같은 단어(one-hot man = $(1,0,0)$, dog = $(0,1,0)$ )로 이루어져 있어 위치 정보 없이는 구별되지 않는다.

**방법**: 위치 $j$ 를 $d$ 차원 벡터 $p_j=pos(j)$ 로 바꿔 입력에 붙인다.
- ✏️ 슬라이드는 "Concatenate"라고 했지만 판서(p38)와 원 Transformer는 **더한다**: $z_j=x_j+p_j$ (입력 + 위치 벡터)
- pos(·)의 선택: ① lookup table을 학습 ( $T\times d$ 개 파라미터) ② 정해진 함수 (sinusoidal)

$$p(t)=\begin{bmatrix}\sin(\omega_1t)\cr\cos(\omega_1t)\cr\vdots\cr\sin(\omega_{d/2}t)\cr\cos(\omega_{d/2}t)\end{bmatrix}\in\mathbb R^d,\qquad\omega_k=\frac1{10000^{2k/d}}$$

$t$ = 문장 안의 위치 번호. (✏️ 첨자는 $k=0,1,\dots,d/2-1$ 로 세야 판서 예의 $\omega_1=1$ 과 맞는다. 슬라이드처럼 $\omega_1$ 부터 $k=1$ 로 세면 한 칸 어긋난다.)

**🔴 판서 수치 예** $d=4$ , 주파수 $1$ 과 $0.01$ ( $10000^{-2/4}=0.01$ ):

$$p(t)=\big(\sin t,\ \cos t,\ \sin0.01t,\ \cos0.01t\big)$$

| $t$ | $p(t)$ |
| --- | --- |
| 0 | $(0,\ 1,\ 0,\ 1)$ |
| 1 | $(0.841,\ 0.540,\ 0.01,\ 1.00)$ |
| 2 | $(0.909,\ -0.416,\ 0.02,\ 1.00)$ |

- $x_{dog}=(1,0,2,0)$ 이면 $x_{dog}+p(0)=(1,1,2,1)$ , $x_{dog}+p(2)\approx(1.9,-0.4,2.02,1.00)$ — **같은 단어라도 위치에 따라 다른 벡터**가 된다.
- (✏️ 판서는 $\cos0.01$, $\cos0.02$ 를 0.99로 적었지만 각각 0.99995, 0.9998 ≈ 1.00)
- 필기본 p18: $x_{dog}+p(2)$ 의 앞 두 성분(1.9, −0.4)에 파랑 "크게 변함", 뒤 두 성분(2.02, 0.99)에 "거의 변화X". 위치 벡터를 더하면 "겹치는 vector가 안 생기게 해준다" [추정].
- **직관 (이진수)**: 0 = 0000, 1 = 0001, 2 = 0010, 3 = 0011, … — 낮은 자리는 빨리, 높은 자리는 천천히 바뀐다. $p(t)$ 도 앞 성분( $\omega=1$ , 고주파)은 위치마다 크게 바뀌고 뒤 성분( $\omega=0.01$ , 저주파)은 천천히 바뀐다. 여러 주파수를 섞어 **위치마다 다른 연속적인 코드**를 만든다.

## 7. 🔴 Masked self-attention [W10M p40–41]

**문제** (판서 p41): 문장 생성을 학습할 때 입력과 목표가 한 칸씩 밀려 있다.

| position | input | target |
| --- | --- | --- |
| 0 | <SOS> | man |
| 1 | man | plays |
| 2 | plays | guitar |
| 3 | guitar | <EOS> |

position 1에서 plays를 예측해야 하는데, self-attention이 position 2의 입력 plays를 참조하면 **정답을 미리 보는 것**이다.

**해결**: query 위치 $j$ 에서는 **$0,\dots,j$ 까지만 참조**한다 (판서 관례: $i$ = key 위치)

$$e_{ij}=\begin{cases}\dfrac{q_j^\top k_i}{\sqrt{d_k}}&i\le j\cr-\infty&i\gt j\end{cases}\qquad\Longrightarrow\qquad E=\begin{bmatrix}e_{00}&e_{01}&e_{02}\cr-\infty&e_{11}&e_{12}\cr-\infty&-\infty&e_{22}\end{bmatrix}$$

- $e^{-\infty}=0$ 이라 softmax 뒤 그 가중치가 **정확히 0** — 미래 단어는 출력에 전혀 섞이지 않는다.
- 판서 $E$ 는 행 = key $i$ , 열 = query $j$ 라 **대각 아래**가 $-\infty$ 다. 행 = query인 $QK^\top$ 로 쓰면 **대각 위**가 $-\infty$ 다 (같은 것의 전치).

## 8. Multi-head attention과 Transformer encoder [W10M p42–43]

- **Multi-head** (p42): $Q,K,V$ 를 각각 다른 Linear로 $h$ 번 투영해 scaled dot-product attention을 $h$ 개 병렬로 하고 → **Concat** → Linear. 서로 다른 head가 서로 다른 관계를 본다.
- **Transformer encoder** (p43, Vaswani et al. 2017 "Attention Is All You Need"): 입력 토큰 $x\in\mathbb R^{n\times d}$ → input embedding ⊕ **positional encoding** → [**multi-head attention → Add & Norm → feed forward → Add & Norm**] × $N$ . 각 sublayer에 residual 연결 (ResNet의 $x+F(x)$ , 10/7). 강의는 여기까지.
