## 1. 상호정보량 (Mutual Information) 🟠 [W2W p2–4]

**정의 (Definition 4)** $I(X;Y)=KL\big(p(x,y)\,\Vert\,p(x)p(y)\big)=\mathbb E_{p(x,y)}\Big[\log\dfrac{p(X,Y)}{p(X)p(Y)}\Big]$

**유도 $I(X;Y)=H(Y)-H(Y\mid X)$** [p3 판서]

$$\begin{aligned}I(X;Y)&=\sum_{x,y}p(x,y)\log\frac{p(x,y)}{p(x)p(y)}=\sum_{x,y}p(x,y)\log\frac{p(y\mid x)\,p(x)}{p(x)\,p(y)}\qquad(\because p(x,y)=p(y\mid x)p(x))\\&=\mathbb E_{X,Y}[\log p(Y\mid X)-\log p(Y)]=-H(Y\mid X)+H(Y)\end{aligned}$$

같은 방법으로 $I(X;Y)=H(X)-H(X\mid Y)$.

- 뜻: $Y$ 값을 알려줬을 때 $X$의 불확실성이 줄어드는 양 (반대도 같음).
- 벤 다이어그램 [p4]: $H(X)=H(X\mid Y)+I(X;Y)$, $H(Y)=H(Y\mid X)+I(X;Y)$, $H(X,Y)=H(X\mid Y)+I(X;Y)+H(Y\mid X)$

## 2. Cross entropy와 KL 🟠 [W2W p5]

**정의** $H_p(q)=-\mathbb E_p[\log q(X)]$ — 분포 $p$에 대한 $q$의 cross entropy

**KL과의 관계** (판서, $E$ = p의 support)

$$KL(p\Vert q)=\sum_{x\in E}p(x)\log\frac{p(x)}{q(x)}=-\sum_{x\in E}p(x)\log q(x)-\sum_{x\in E}p(x)\log\frac{1}{p(x)}=H_p(q)-H(p)\ge0$$

$$\Rightarrow\quad H_p(q)\ge H(p)\quad(\text{등호}\iff q=p)$$

- (보충) $p$가 데이터 분포처럼 **고정**이면 $H(p)$는 상수다. 그래서 **$q$에 대해 cross entropy를 최소화하는 것 = KL을 최소화하는 것**이다. 분류에서 cross entropy 손실을 쓰는 이유이고, 9/14 로지스틱 회귀의 음의 로그가능도가 바로 이 형태다 → [09.14 수업정리](09.14%20수업정리.md) §3

## 3. 회귀의 확률적 접근: MLE = LSE 🟠 [W2W p6–9]

**모델** $Y=\beta_0+\sum_{j=1}^k\beta_jx_j+\epsilon$, $\epsilon\sim N(0,\sigma^2)$ (분산 $\sigma^2$ 모름) [p7]

**가능도** $h_i(\beta)=\beta_0+\sum_j\beta_jx_{ij}$로 두면 [p8]

$$p(y_1,\dots,y_n\mid x_1,\dots,x_n,\beta)=\prod_{i=1}^n\frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(y_i-h_i(\beta))^2}{2\sigma^2}}$$

**로그가능도** [p9]

$$\log p(\cdots)=-n\log(\sqrt{2\pi}\sigma)-\sum_{i=1}^n\frac{(y_i-h_i(\beta))^2}{2\sigma^2}$$

- 첫 항은 $\beta$와 무관 → 로그가능도 최대화 ⇔ $\sum_i(y_i-h_i(\beta))^2$ 최소화 = 9/2의 $f(\beta)$
- **결론: 오차가 가우시안이면 최소제곱추정량(LSE) = 최대가능도추정량(MLE)**

## 4. 과적합과 정규화 🟡🟠 [W2W p10–19]

### 4.1 다항회귀는 선형회귀다 🟠 [p10 → 노트 p11, p12]
- 데이터 $\{(x_i,y_i)\}$에 차수 $M$ 다항식 $y=\beta_0+\beta_1x+\cdots+\beta_Mx^M$을 맞춘다.
- 설계행렬 $X\in\mathbb R^{n\times(M+1)}$의 $i$행 $=(1,x_i,x_i^2,\dots,x_i^M)$ → $f(\beta)=\lVert y-X\beta\rVert^2$. **특성이 $\{1,x,\dots,x^M\}$인 선형회귀**일 뿐이다 (판서: "It's linear regression").

### 4.2 과적합 🟡 [p12–14]
- $M=1,3,5,9$ 중 training MSE($=\frac1nf(\beta)$)는 $M=9$에서 최소 → **과적합**.
- 새 데이터에서 잘 맞는 것(**일반화**)이 중요하다. 별도 validation set의 $E_{RMS}=\sqrt{f(\beta)/n}$로 잰다. $M\ge5$부터 train과 test 곡선의 차이가 커진다.

### 4.3 정규화 🟡 [p15–18]
- 큰 계수에 벌점을 준다:

$$J[f]=\frac12f(\beta)+\frac\lambda2\lVert\beta\rVert^2$$

- $M=9$에 적용: $\lambda\to0$ ($\ln\lambda\to-\infty$)이면 계수가 수만 단위로 커지며 과적합. 정규화를 하면 train·test 오차가 비슷한 추세를 보인다.
- **데이터가 많으면** 복잡한 모델(큰 $M$)도 잘 맞는다 ($n=10$ vs $n=100$, $M=9$, $\lambda=0$). 경험칙: **파라미터 하나당 데이터 10개**.

### 4.4 다른 정규화 🟡 [p19]

$$J[f]=\frac12f(\beta)+\frac\lambda2\sum_{j=0}^M|\beta_j|^q$$

- $q=1$: **LASSO** (Least Absolute Shrinkage and Selection Operator)
- $q=2$: **Ridge** (parameter shrinkage regression)
- 슬라이드 그림: $q=0.5,1,2,4$의 등고선 모양 (마름모 = $q=1$, 원 = $q=2$)

## 5. Ridge 회귀 분석  🟠  [W2W p20]

$$J[f]=\frac12(y-X\beta)^\top(y-X\beta)+\frac\lambda2\beta^\top\beta$$

$$\nabla_\beta J=X^\top X\beta-X^\top y+\lambda\beta=0\quad\Rightarrow\quad\hat\beta=(\lambda I+X^\top X)^{-1}X^\top y$$

- 기울기 계산은 9/2 정규방정식과 같다. $\frac12$ 때문에 2가 사라지고, $\frac\lambda2\beta^\top\beta$의 기울기 $\lambda\beta$가 더해진다 → [09.02 수업정리](09.02%20수업정리.md) §2
- (보충) $\lambda>0$이면 $\lambda I+X^\top X$는 항상 가역이다 (양정치). $X^\top X$가 특이해도 해가 있다.
- (보충) **MAP로 보면**: 오차 $N(0,\sigma^2)$ + prior $\beta\sim N(0,\tau^2I)$의 MAP가 ridge이고 $\lambda=\sigma^2/\tau^2$ → [09.07 수업정리](09.07%20수업정리.md) §6

## 6. 커널 트릭과 Kernel ridge 회귀 [W2W p21–34]

### 6.1 아이디어 🟡 [p21–22]
- 원래 공간에서 직선으로 못 나누는 데이터도, 더 높은 차원의 특성공간으로 보내면($x\to\phi(x)$) 선형으로 나뉜다 → **kernel trick**.
- 선형 ridge는 $f(x)=x^\top\beta$, 이제는 $f(x)=\phi(x)^\top\beta$.

$$J[f]=\frac12(y-\phi(X)^\top\beta)^\top(y-\phi(X)^\top\beta)+\frac\lambda2\beta^\top\beta,\qquad\phi(X)=[\phi(x_1)\cdots\phi(x_n)]$$

### 6.2 해 구하기 ①: push-through 항등식  🔴  [p23 → 노트 p24, p25]

1. 전개하고 기울기를 0으로 두면 [p23]
   $$\nabla_\beta J=-\phi(X)y+\phi(X)\phi(X)^\top\beta+\lambda\beta=0\;\Rightarrow\;\beta^\ast=(\lambda I+\phi(X)\phi(X)^\top)^{-1}\phi(X)y$$
   여기서 역행렬은 **특성공간 차원**($D\times D$)이다. $D$가 매우 크면 계산할 수 없다.
2. 항등식 [노트 p24]: 양변을 전개하면 둘 다 $\lambda\phi(X)+\phi(X)\phi(X)^\top\phi(X)$이므로
   $$(\lambda I+\phi(X)\phi(X)^\top)\,\phi(X)=\phi(X)\,(\lambda I+\phi(X)^\top\phi(X))$$
3. 왼쪽에 $(\lambda I+\phi\phi^\top)^{-1}$, 오른쪽에 $(\lambda I+\phi^\top\phi)^{-1}$을 곱하면
   $$(\lambda I+\phi(X)\phi(X)^\top)^{-1}\phi(X)=\phi(X)(\lambda I+\phi(X)^\top\phi(X))^{-1}$$
4. 따라서 [p25]
   $$\beta^\ast=\phi(X)(\lambda I+\phi(X)^\top\phi(X))^{-1}y,\qquad f^\ast(x)=\phi(x)^\top\beta^\ast=\underbrace{\phi(x)^\top\phi(X)}_{K(x,X)}\big(\lambda I+\underbrace{\phi(X)^\top\phi(X)}_{K(X,X)}\big)^{-1}y$$
   이제 역행렬은 **샘플 수 크기**($n\times n$)이고, $\phi$는 내적으로만 나타난다.

### 6.3 커널의 정의 🟡 [p26–28]
- **커널**: 두 벡터를 받아 특성공간 상의 내적을 돌려주는 함수 $K(x_i,x_j)=\phi(x_i)^\top\phi(x_j)$
- 내적만 필요하므로 **새 공간의 차원은 중요하지 않다** (무한 차원이어도 된다).
- $K(x,X)=[K(x,x_1)\cdots K(x,x_n)]=\phi(x)^\top\phi(X)$ ($1\times n$), $K(X,X)=(K(x_i,x_j))$ ($n\times n$)
- 최적 함수:
  $$f^\ast(x)=K(x,X)\,\alpha^\ast,\qquad\alpha^\ast=(\lambda I+K(X,X))^{-1}y,\qquad\beta^\ast=\phi(X)\alpha^\ast$$

### 6.4 해 구하기 ②: $\beta=\phi(X)\alpha$ 대입  🔴  [p29 → 노트 p30]
위 결과를 보고 처음부터 $\beta=\phi(X)\alpha$라고 두고 $\alpha$에 대해 푼다. $K=\phi(X)^\top\phi(X)$ (대칭).

1. 대입 [p29]:
   $$J=\frac12\big(y^\top y-y^\top K\alpha-\alpha^\top Ky+\alpha^\top K^2\alpha\big)+\frac\lambda2\alpha^\top K\alpha=\frac12\big(y^\top y-2y^\top K\alpha+\alpha^\top K^2\alpha\big)+\frac\lambda2\alpha^\top K\alpha$$
2. 기울기 [p30]: $\nabla_\alpha J=-Ky+K^2\alpha+\lambda K\alpha=0$
3. 묶으면 $K\big((K+\lambda I)\alpha-y\big)=0$ → $\boxed{\alpha^\ast=(K+\lambda I)^{-1}y}$ — ①의 결과와 같다 ∎

(보충) 3단계는 $(K+\lambda I)\alpha=y$이면 충분하다는 뜻이다. $K$가 가역이면 이것이 유일한 해다.

### 6.5 커널 예제 [p31–34]
- **Ex 1. 선형 커널** $K(x,z)=x^\top z=\sum_ix_iz_i$
- **Ex 2. 다항 커널** 🟠 $x,z\in\mathbb R^2$:
  $$K(x,z)=(x^\top z)^2=(x_1z_1+x_2z_2)^2=x_1^2z_1^2+x_2^2z_2^2+2x_1z_1x_2z_2=\big\langle(x_1^2,x_2^2,\sqrt2x_1x_2),\,(z_1^2,z_2^2,\sqrt2z_1z_2)\big\rangle$$
  → 2차원에서 3차원으로 가는 사상 $\phi(x)=(x_1^2,x_2^2,\sqrt2x_1x_2)$. 계산은 2차원에서 한다.
- **Ex 3. 가우시안 커널** $K(x,z)=e^{-\lVert x-z\rVert^2/2\sigma^2}$ ⚪
- **Ex 4. 정규화 커널** $K_2(x,z)=K_1(x,z)K_1(x,x)^{-1/2}K_1(z,z)^{-1/2}$ ⚪
- 커널은 **유사도(similarity)**를 잰다.

### 6.6 수치 예제  🔴  [노트 p32–33]
- 데이터: $x_1=(1,1)^\top,\ y_1=3$ / $x_2=(2,0)^\top,\ y_2=2$, 커널 $K(x,z)=(x^\top z)^2$, $\lambda=1$
- Gram 행렬: $K(x_1,x_1)=(1+1)^2=4$, $K(x_1,x_2)=(2+0)^2=4$, $K(x_2,x_2)=(4+0)^2=16$
  $$K=\begin{pmatrix}4&4\\4&16\end{pmatrix},\qquad\lambda I+K=\begin{pmatrix}5&4\\4&17\end{pmatrix}\ (\det=69)$$
- $\alpha^\ast=(\lambda I+K)^{-1}y=\dfrac1{69}\begin{pmatrix}17&-4\\-4&5\end{pmatrix}\begin{pmatrix}3\\2\end{pmatrix}=\dfrac1{69}\begin{pmatrix}43\\-2\end{pmatrix}$
- 테스트 벡터 $x_t=(1,0)^\top$: $K(x_t,X)=[(1\cdot1+0\cdot1)^2,\ (1\cdot2+0\cdot0)^2]=[1,\ 4]$
- $f^\ast(x_t)=[1,\ 4]\cdot\dfrac1{69}(43,-2)^\top=\dfrac{35}{69}\approx0.507$

## 판서·슬라이드 확인
- ⚠ 노트 p24의 근거 줄은 "$A\phi=\phi A\Rightarrow\phi^{-1}A^{-1}=A^{-1}\phi^{-1}\Rightarrow A^{-1}\phi=\phi A^{-1}$"로 적혀 있다. 판서는 양쪽 행렬을 모두 $A$로 썼고, $\phi(X)$는 정사각행렬이 아니라 $\phi^{-1}$이 없다. 위 §6.2 3단계처럼 **두 행렬을 구분해서**($A=\lambda I+\phi\phi^\top$, $B=\lambda I+\phi^\top\phi$) $A\phi=\phi B\Rightarrow\phi B^{-1}=A^{-1}\phi$로 쓰는 것이 맞다.
- p16의 과적합 표 값(예: $\ln\lambda=-36.8$에서 계수가 $10^5$ 단위)은 외울 필요 없다. "$\lambda\to0$이면 계수가 폭발한다"만 기억하면 된다.
