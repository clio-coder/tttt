## 짚은 포인트 (시험 가능성 순)

범례: 📋 교수님 시험 언급 · 🔴 노트 페이지 증명 · 🟠 슬라이드 위 유도·박스 · 🟡 밑줄·동그라미 · ⚪ 필기 없음

- 🔴 **Xavier 초기화 유도** — $y=\sum w_ix_i$에서 $\text{Var}(y)=D_{in}\sigma^2V$ → 분산을 유지하려면 $\sigma^2=1/D_{in}$ [W4M2 p23–24]
- 🟠 **역전파 = 연쇄법칙**: downstream gradient = upstream gradient × local gradient [W4M1 p18–21]
- 🟠 **벡터 역전파**: ReLU의 Jacobian은 대각(희소) → 행렬을 만들지 않고 **원소별 곱** $(1,0,1,0)\odot(4,-1,5,9)=(4,0,5,0)$ [W4M1 p39–40]
- 🟠 **SGD는 불편추정**: $\mathbb E[\nabla f_i]=\nabla f$. 빠르지만 분산이 크다 → mini-batch로 분산을 줄인다 [W4M2 p3–5]
- 🟠 GD 정지 조건 $k\ge N$ 또는 $\lVert\theta^{k+1}-\theta^k\rVert<\epsilon$, 판서 "epoch" [W4M1 p4]
- 🟡 계산 그래프 예제: $f=(x+y)z$ at $(-2,5,-4)$ → $\partial f/\partial x=\partial f/\partial y=-4$, $\partial f/\partial z=3$ [W4M1 p7–17] · sigmoid 뉴런 예제 [p22–36]
- 🟡 초기화가 너무 작으면 활성값 → 0, 너무 크면 포화(saturation) → 둘 다 **no learning** [W4M2 p16–21]
- 🟡 Xavier는 zero-centered 활성화를 가정 → ReLU에서는 붕괴 → **He: std $=\sqrt{2/D_{in}}$** (유도는 9/23) [W4M2 p25–26]
- 🟡 활성화 함수 장단점: sigmoid(포화, not zero-centered), tanh(zero-centered, 포화), ReLU(포화 없음, 음수 쪽 기울기 0) [W4M2 p8–15]
- 🟡 gate 패턴 (add = distributor, mul = swap multiplier, copy = adder, max = router) [W4M1 p37]

## 1. MLP (Multilayer perceptron) ⚪ [W4M1 p1–2]

fully connected neural network라고도 한다.

$$y_1=\sigma(W_1x+b_1),\quad y_2=\sigma(W_2y_1+b_2),\ \dots,\ y_{L-1}=\sigma(W_{L-1}y_{L-2}+b_{L-1}),\quad y_L=W_Ly_{L-1}+b_L$$

- $x\in\mathbb R^{n_0}$, $W_\ell\in\mathbb R^{n_\ell\times n_{\ell-1}}$, $b_\ell\in\mathbb R^{n_\ell}$, $n_L=1$. $\sigma$(활성화)는 **원소별**로 적용.
- CIFAR10 예: 입력 $32\times32\times3=3072$ → 은닉 1536 → 768 → 384 → 출력. 활성화 ReLU.

## 2. 경사하강법 🟠 [W4M1 p3–4]

1. (랜덤) 초기화 $\theta^0$
2. 작은 step으로 업데이트 $\theta^{k+1}\leftarrow\theta^k-\alpha\nabla\mathcal L(\theta^k)$
3. 정지 조건 $k\ge N$ 또는 $\lVert\theta^{k+1}-\theta^k\rVert<\epsilon$을 만족할 때까지 반복

- 판서: 반복 횟수 $k$를 **epoch**로 표시하고, epoch에 따라 손실이 흔들리며 줄어드는 곡선을 그림. 볼록한 그릇과 굴곡 있는 곡선을 비교.
- 손실 곡면 그림: 시작점에 따라 다른 극소점에 도착할 수 있다 (빨간 화살표 두 개).

## 3. 역전파 (Backpropagation)

### 3.1 동기 ⚪ [W4M1 p5–6]
- Werbos(1974), Rumelhart·Hinton·Williams(1986).
- 목적함수(loss + regularization)의 기울기를 **손으로** 구해야 하나? 예:
  $s=W_2\max(0,W_1x)$, $L_i=\sum_{j\ne y_i}\max(0,s_j-s_{y_i}+1)$ (SVM loss), $R(W)=\sum_kW_k^2$, $L=\frac1N\sum_iL_i+\lambda R(W_1)+\lambda R(W_2)$
  → $\partial L/\partial W_1$, $\partial L/\partial W_2$만 구하면 학습할 수 있다. 이것을 기계적으로 하는 방법이 역전파다.

### 3.2 예제 1: $f(x,y,z)=(x+y)z$ 🟡 [W4M1 p7–17]
- 입력 $(x,y,z)=(-2,5,-4)$. 중간변수 $q=x+y$.
- **Forward**: $q=3$, $f=qz=-12$
- **Local gradient**: $\partial q/\partial x=\partial q/\partial y=1$, $\partial f/\partial q=z$, $\partial f/\partial z=q$
- **Backward** (출력에서 거꾸로):

| 변수 | 계산 | 값 |
| --- | --- | --- |
| $\partial f/\partial f$ | 시작 | 1 |
| $\partial f/\partial z$ | $q$ | 3 |
| $\partial f/\partial q$ | $z$ | −4 |
| $\partial f/\partial y$ | $\frac{\partial f}{\partial q}\cdot\frac{\partial q}{\partial y}=(-4)(1)$ | −4 |
| $\partial f/\partial x$ | $\frac{\partial f}{\partial q}\cdot\frac{\partial q}{\partial x}=(-4)(1)$ | −4 |

### 3.3 Upstream gradient와 local gradient 🟠 [W4M1 p18–21]
노드 $f$가 입력 $x,y$를 받아 $z$를 내보낼 때
- **local gradient**: $\dfrac{\partial z}{\partial x},\ \dfrac{\partial z}{\partial y}$ — 노드 안에서만 계산 가능
- **upstream gradient**: $\dfrac{\partial L}{\partial z}$ — 출력 쪽에서 흘러 들어옴
- **downstream gradient** = upstream × local:

$$\frac{\partial L}{\partial x}=\frac{\partial L}{\partial z}\frac{\partial z}{\partial x},\qquad\frac{\partial L}{\partial y}=\frac{\partial L}{\partial z}\frac{\partial z}{\partial y}$$

### 3.4 예제 2: sigmoid 뉴런 🟡 [W4M1 p22–36]
$f(w,x)=\dfrac{1}{1+e^{-(w_0x_0+w_1x_1+w_2)}}$, $w_0=2$, $x_0=-1$, $w_1=-3$, $x_1=-2$, $w_2=-3$

- **Forward**: $w_0x_0=-2$, $w_1x_1=6$ → 합 4 → $+w_2$ = 1 → $\times(-1)$ = −1 → exp = 0.37 → $+1$ = 1.37 → $1/x$ = **0.73**
- 쓰는 local 미분: $(e^x)'=e^x$, $(ax)'=a$, $(1/x)'=-1/x^2$, $(c+x)'=1$
- **Backward**: $1/x$: $-1/1.37^2\approx-0.53$ → $+1$: −0.53 → exp: $e^{-1}(-0.53)\approx-0.20$ → $\times(-1)$: 0.20 → 덧셈 노드는 0.20을 그대로 나눠줌
  - $w_2$: 0.20 · $w_0$: $0.2\times x_0=-0.2$ · $x_0$: $0.2\times w_0=0.4$ · $w_1$: $0.2\times x_1=-0.4$ · $x_1$: $0.2\times w_1=-0.6$
- **sigmoid 게이트로 묶기** [p36]: $\dfrac{d\sigma}{dx}=\dfrac{e^{-x}}{(1+e^{-x})^2}=(1-\sigma(x))\sigma(x)$ → $[1.00]\times(1-0.73)(0.73)\approx0.2$로 한 번에 계산.
  "계산 그래프 표현은 유일하지 않다. **local gradient가 쉽게 표현되는 쪽**을 고르라."
- 9/21 W4M2 p2 판서: 이 예제의 결과로 $\nabla f=(\partial f/\partial w_0,\partial f/\partial w_1,\partial f/\partial w_2)=(-0.2,-0.4,0.2)$ → GD 한 스텝에 쓴다.

### 3.5 gradient 흐름의 패턴 🟡 [W4M1 p37]

| 게이트 | 별명 | 하는 일 |
| --- | --- | --- |
| add | gradient **distributor** | upstream을 두 입력에 그대로 나눠줌 |
| mul | **swap multiplier** | 각 입력에 upstream × **다른 쪽 입력** (예: 입력 2, 3, upstream 5 → 15, 10) |
| copy | gradient **adder** | 갈라진 두 가지의 기울기를 더함 (4 + 2 = 6) |
| max | gradient **router** | 최댓값이었던 입력에만 upstream을 보냄, 나머지는 0 |

### 3.6 다변수 입력·출력의 1차 미분 🟡 [W4M1 p38]

| 경우 | 미분 | 크기 | 뜻 |
| --- | --- | --- | --- |
| 스칼라 → 스칼라 | 보통 미분 | $\mathbb R$ | $x$가 조금 변하면 $y$는 얼마나? |
| 벡터 → 스칼라 | **gradient** | $\mathbb R^N$, $(\partial y/\partial x)_ n=\partial y/\partial x_n$ | $x$의 각 성분이 변하면 $y$는? |
| 벡터 → 벡터 | **Jacobian** | $\mathbb R^{N\times M}$, $(\partial y/\partial x)_ {n,m}=\partial y_m/\partial x_n$ | $x$의 각 성분이 변하면 $y$의 각 성분은? |

### 3.7 벡터 역전파  🟠  [W4M1 p39–40]
- 4차원 입력 $x=(1,-2,3,-1)$, $f(x)=\max(0,x)$ (원소별) → $y=(1,0,3,0)$
- upstream $\partial L/\partial y=(4,-1,5,9)$
- Jacobian $\partial y/\partial x$: 판서처럼 $y_i=\max(0,x_i)$는 $x_i$에만 의존 → 대각행렬 $\text{diag}(1,0,1,0)$ (대각성분 $\partial y_i/\partial x_i$)
- $\partial L/\partial x=[\partial y/\partial x][\partial L/\partial y]=(4,0,5,0)$
- **Jacobian은 희소하다**: 비대각 성분은 항상 0 → **Jacobian을 명시적으로 만들지 말고** 암묵적으로 곱한다:

$$\Big(\frac{\partial L}{\partial x}\Big)_ i=\begin{cases}(\partial L/\partial y)_ i&x_i\gt 0\cr0&\text{otherwise}\end{cases}$$

  판서: $(1,0,1,0)\odot(4,-1,5,9)=(4,0,5,0)$ (원소별 곱)

## 4. Full batch · SGD · Mini-batch  🟠  [W4M2 p2–7]

| 방법 | 목적함수 / 기울기 | 장점 | 단점 |
| --- | --- | --- | --- |
| Full (batch) | $f=\frac1N\sum_{i=1}^N\mathcal L(\hat y_i,y_i)$, $\nabla f=\frac1N\sum_i\nabla f_i$ | **정확한** 기울기 | 데이터가 크면 한 스텝이 매우 느림 |
| SGD | $\tilde f=f_i$, $i\sim\text{Uniform}(\lbrace1,\dots,N\rbrace)$, $\nabla\tilde f=\nabla f_i$ | 한 스텝이 **매우 빠름** | **분산이 큼**, 경로가 불안정 |
| Mini-batch | $\tilde f=\frac{1}{\lvert\mathcal K\rvert}\sum_{k\in\mathcal K}f_k$, $\mathcal K\subset\lbrace1,\dots,N\rbrace$ 랜덤 | full보다 훨씬 빠름, SGD보다 안정(분산 감소) | batch size를 정해야 함 |

- **세 방법 모두 기댓값은 full gradient와 같다**: $\mathbb E[\nabla f_i(x)]=\nabla f(x)$, $\mathbb E[\nabla\tilde f(x)]=\nabla f(x)$
  - (보충) $\mathbb E[\nabla f_i]=\sum_{i=1}^N\frac1N\nabla f_i=\nabla f$
- 차이는 **분산**이다 [p6]: 그림에서 batch GD는 매끈하게, mini-batch는 조금 지그재그로, SGD는 심하게 흔들리며 최소점에 간다.
- 실전에서는 대부분 **mini-batch SGD**를 쓴다. 판서 예: 데이터 1000개를 100개씩 나눔.
- **Mini-batch SGD 루프** [p7]: ① batch 샘플링 ② forward로 loss 계산 ③ backprop으로 기울기 ④ 업데이트
- 9/2 GD의 단점("한 스텝마다 전체 데이터를 훑는다")에 대한 답이다 → [09.02 수업정리](09.02%20수업정리.md) §4

## 5. 활성화 함수 재검토 🟡 [W4M2 p8–15]

| 함수 | $g(z)$ | $g'(z)$ | 장점 | 단점 |
| --- | --- | --- | --- | --- |
| Sigmoid | $\dfrac1{1+e^{-z}}$ | $g(1-g)$ | 값이 $[0,1]$로 제한 | ① **포화된 뉴런에서 기울기 0** ② **zero-centered가 아님** (항상 양수) |
| tanh | $\dfrac{e^z-e^{-z}}{e^z+e^{-z}}$ | $1-g^2$ | $[-1,1]$, **zero-centered** (대칭) | 포화 시 기울기 0 |
| ReLU | $\max(0,z)$ | 1 ($z>0$), 0 (otherwise) | **포화 없음**, 계산 쉬움 | zero-centered 아님, **음수 입력에서 기울기 0** |
| Leaky ReLU | $\max(0.01x,x)$ | | 음수 쪽 기울기 0.01 | |
| ELU | $x$ ($x>0$), $\alpha(e^x-1)$ (otherwise) | | | |

- sigmoid가 zero-centered가 아니면 생기는 문제 [p10]: $\dfrac{\partial\mathcal L}{\partial W}=\dfrac{\partial\mathcal L}{\partial h}\cdot\dfrac{\partial h}{\partial W}=\dfrac{\partial\mathcal L}{\partial h}\cdot z^\top$ — 입력 $z$가 전부 양수면 한 뉴런의 모든 가중치 기울기가 **같은 부호** → 가중치가 전부 양수 또는 전부 음수 방향으로만 움직인다.
- ReLU 판서 [p14]: 음수 쪽 기울기 0에 화살표 (보충: 이 영역에 갇힌 뉴런은 다시 학습되지 않는다 — "dead ReLU").

## 6. 가중치 초기화 [W4M2 p16–27]

실험 설정: 은닉 4096의 6층 신경망, tanh, `x = np.random.randn(16, 4096)`, 층마다 `W = c * np.random.randn(Din, Dout)`

### 6.1 너무 작거나 너무 크면 🟡 [p16–21]

| 초기화 | 층별 활성값 std | 결과 |
| --- | --- | --- |
| $W=0.01\cdot$ randn | 0.49 → 0.29 → 0.18 → 0.11 → 0.07 → 0.05 | 위층 활성값이 거의 0 → $\frac{\partial\mathcal L}{\partial W}=\frac{\partial\mathcal L}{\partial h}\cdot z^\top=0$ → **no learning** |
| $W=0.05\cdot$ randn | 전 층 ≈ 0.85, 값이 ±1에 몰림 | tanh 포화 → $\sigma'(z)=1-\tanh^2(z)\approx0$ → $\frac{\partial\mathcal L}{\partial z}=(\sigma'(\cdot)W^\top)\frac{\partial\mathcal L}{\partial h}=0$ → **no learning** |
| Xavier: randn / $\sqrt{D_{in}}$ | 0.63 → 0.49 → 0.41 → 0.36 → 0.32 → 0.30 | 모든 층에서 적당한 크기 |

### 6.2 Xavier (Glorot) 초기화 유도  🔴  [W4M2 p23 → 노트 p24]

**설정** 한 뉴런의 출력 $y=\sum_{i=1}^{D_{in}}w_ix_i$. $w_i$ i.i.d., $x$와 $w$ 독립, $\mathbb E[w_i]=0$, $\text{Var}(w_i)=\sigma^2$, $\mathbb E[x_i]=0$, $\text{Var}(x_i)=V$
**결론** $\text{Var}(y)=D_{in}\sigma^2V$ → 입력 분산을 유지($\text{Var}(y)=V$)하려면 $\sigma^2=\dfrac1{D_{in}}$, 즉 std $=1/\sqrt{D_{in}}$

**핵심 아이디어** 평균이 0이라 분산 = 제곱의 기댓값. 제곱을 전개하면 교차항은 독립성 때문에 0이 되고 대각항만 남는다.

**증명 (판서 순서)**
1. $\text{Var}(y)=\mathbb E[y^2]-(\mathbb E[y])^2$ [p23]
2. $\mathbb E[y]=\mathbb E[\sum w_ix_i]=\sum\mathbb E[w_i]\mathbb E[x_i]=0$ (∵ 독립, $\mathbb E[w_i]=0$)
3. $\mathbb E[y^2]=\mathbb E[(\sum_iw_ix_i)^2]=\sum_i\mathbb E[w_i^2x_i^2]+\sum_{i\ne k}\mathbb E[w_iw_kx_ix_k]$
4. 독립이므로 $=\sum_i\mathbb E[w_i^2]\mathbb E[x_i^2]+\sum_{i\ne k}\mathbb E[w_iw_k]\thinspace\mathbb E[x_ix_k]$ [p24]
   빨간 판서: $\mathbb E[w_iw_k]=\mathbb E[w_i]\mathbb E[w_k]=0$ ($i\ne k$, i.i.d.) → **교차항 = 0**
5. $\mathbb E[w_i^2]=\sigma^2$, $\mathbb E[x_i^2]=\text{Var}(x_i)=V$ (평균 0) → $\text{Var}(y)=\sum_{i=1}^{D_{in}}\sigma^2V=D_{in}\sigma^2V$
6. $\text{Var}(x_i)=V$는 입력 분산. 원하는 것: $\text{Var}(y)=V$ → $D_{in}\sigma^2V=V$ → $\boxed{\sigma^2=\dfrac1{D_{in}}}$ ∎

- 코드의 `np.random.randn(Din, Dout) / np.sqrt(Din)`이 바로 std $=1/\sqrt{D_{in}}$이다.
- (보충) 2단계와 5단계에서 **$\mathbb E[x_i]=0$을 썼다**. tanh처럼 0 근처에서 대칭인 활성화면 성립하지만 ReLU 출력은 항상 0 이상이라 깨진다 → §6.3

### 6.3 ReLU에서는? → He 초기화 🟡 [p25–27]
- Xavier + ReLU: 층을 지날수록 활성값이 0으로 붕괴 (mean 0.39 → 0.07, std 0.58 → 0.10). **Xavier는 zero-centered 활성화 함수를 가정**하기 때문. "no learning =("
- **He (Kaiming / MSRA) 초기화**: std $=\sqrt{2/D_{in}}$ (`* np.sqrt(2/Din)`) → 모든 층에서 mean ≈ 0.55, std ≈ 0.81–0.83. "Just right" (He et al., ICCV 2015)
