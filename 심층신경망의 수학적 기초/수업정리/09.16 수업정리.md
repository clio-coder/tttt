## 1. 분류와 end-to-end 학습 [p4–8]
- 분류: 입력을 둘 이상의 클래스 중 하나로 보낸다. 결정 규칙은 입력공간을 **decision region**으로 나누고, 그 경계가 **decision boundary**다. $f:\mathcal X\to\mathcal Y$, 예: $\mathcal X=\mathbb R^2$, $\mathcal Y=\lbrace C_1,C_2,C_3\rbrace$
- 전통 방식은 색·텍스처 같은 특징을 사람이 설계했다 (이동·크기·회전·가림에 불변인가?).
- 딥러닝은 **특징과 분류기를 함께 학습**한다 (end-to-end).

## 2. 신경망 = 선형함수 + 비선형 활성화 [p9–15]
- 선형함수들을 이어 붙이고 그 사이를 비선형 함수(활성화 함수, 예: max)로 나눈 것.

| 모델 | 식 |
| --- | --- |
| 선형 | $f(x)=Wx$ |
| 2층 신경망 | $f(x)=W_2\max(0,W_1x)$ |
| 3층 신경망 | $f(x)=W_3\max(0,W_2\max(0,W_1x))$ |

- CIFAR10 예: $x\in\mathbb R^{3072}$, $W_1$: $100\times3072$, $h\in\mathbb R^{100}$, $W_2$: $10\times100$ → 파라미터 $308{,}200$개. "Lots of parameters! Rote learning, overfitting to small data" [p12]
- **활성화 함수를 빼면?** [p14] (보충) $W_3W_2W_1x=(W_3W_2W_1)x$ — 행렬 하나짜리 선형 모델과 같다. 비선형성이 있어야 층을 쌓는 의미가 생긴다.
- 활성화 함수 [p15]:

| 이름 | 식 |
| --- | --- |
| Sigmoid | $\sigma(x)=1/(1+e^{-x})$ |
| tanh | $\tanh(x)$ |
| ReLU | $\max(0,x)$ |
| Leaky ReLU | $\max(0.1x,x)$ |
| Maxout | $\max(w_1^\top x+b_1,\thinspace w_2^\top x+b_2)$ |
| ELU | $x$ ($x\ge0$), $\alpha(e^x-1)$ ($x<0$) |

## 3. 구조와 softmax [p16–19]
- 2층 신경망의 계산 그래프: input layer → hidden layer → output layer, $f(x)=\text{softmax}(W_2\max(0,W_1x))$
- **softmax**는 실수 벡터를 pmf로 바꾼다: $\sigma(\vec z)_ i=\dfrac{e^{z_i}}{\sum_{j=1}^Ke^{z_j}}$ ($K$ = 클래스 수). 예: $[-1,3]$ → $[0.018,\thinspace0.982]$ → 9/14 softmax 회귀와 같은 함수 → [09.14 수업정리](09.14%20수업정리.md) §6
- 깊은 신경망은 층이 많고 파라미터가 수백만 개일 수 있다.

## 4. 선형 모델의 한계와 비선형성 [p20–30]
- 예: 2차원 점을 positive/negative로 분류. $\hat y=f(x;w,b)=w_1x_1+w_2x_2+b$ — **파라미터가 함수를 결정한다** ($[w_1,w_2,b]$에 따라 평면이 달라짐) [p21]
- 새 데이터 $[x_1^\ast,x_2^\ast]$를 모델에 넣어 분류한다 [p25–26]
- Issues [p27–29]: 실제 데이터는 대부분 **선형분리 불가능**하다. 선형 모델은 영역을 제대로 못 나눈다. 복잡한 함수를 표현하려면 **비선형성이 필요**하다.
- 비선형성 주입 [p30]: $\hat y=g(w^\top x+b)$, $g$ = 비선형 활성화 함수 (퍼셉트론)

## 5. 층을 쌓는 이유 [p31–46]
- **은닉층은 입력의 비선형 임베딩**이다. 모델은 데이터를 **선형분리 가능한 공간**으로 임베딩할 수 있다 [p31–33]
  - 예: 원 안(빨강)과 밖(파랑)으로 나뉜 2차원 점 → 3차원으로 올리면 원뿔 모양이 되어 평면 하나로 나뉜다.
  - (보충) 9/9 커널 트릭과 같은 발상이다. 차이는 사상 $\phi$를 사람이 고르지 않고 **학습한다**는 점.
- MNIST: $28\times28$ 흑백 이미지 → 784차원 벡터 (픽셀값 0–1) → forward propagation → 출력 10개 (숫자 0–9) [p34–37]
- **임베딩 관점** [p39–40]: 입력을 쉽게 나뉘는 공간으로 비선형 임베딩. 임베딩된 MNIST의 2차원 시각화.
- **인식 관점** [p41–46]: 사람은 숫자를 추상화된 특징의 조합으로 구분한다. 신경망도 여러 단계의 추상화로 이해한다.

## 6. 요약 [p47]
- **Perceptron**: 간단한 비선형 함수
- **Neural network**: 퍼셉트론을 쌓은 것
- **표현**: 깊은 신경망은 서로 다른 추상화 수준을 담는 **특징의 계층**을 배운다 (예: edges → facial landmarks → global face). 이 개념들을 계층적으로 조합해 과제를 푼다.

## 7. PyTorch로 학습하는 순서 [p48]
1. 데이터 불러오기 → 2. 모델 정의 → 3. 모델 생성, **손실함수** 선택, **optimizer** 선택
4. SGD로 학습: 이전 기울기 지우기 → **forward pass** → **backprop으로 기울기 계산** → SGD 업데이트
5. 평가 → 6. 결과 시각화

→ 4단계의 역전파와 SGD가 9/21 주제다.
