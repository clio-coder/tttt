## 1. Swin Transformer란 [W11M p1 · W10W p19]

**Swin Transformer: Hierarchical Vision Transformer using Shifted Windows** (Liu et al., ICCV 2021)
- **Hierarchical feature representation** — ViT는 모든 층이 같은 해상도(16×)인데, Swin은 4× → 8× → 16× 로 패치를 합쳐 가며 CNN처럼 해상도를 줄인다 (그림 (a) vs (b)). → 분류뿐 아니라 segmentation, detection에도 쓴다.
- **Linear computational complexity with respect to input image size.**

$$\Omega(\mathrm{MSA})=4hwC^2+2(hw)^2C,\qquad\Omega(\mathrm{W\text{-}MSA})=4hwC^2+2M^2hwC$$

- 판서 (파랑): $hw$ 위에 " $N$ " → $\Omega(\mathrm{MSA})=O(NC^2)+O(N^2C)$ .
- 판서 (검정): $X\in\mathbb R^{h\times w\times C}$ , $x_{r,c}\in\mathbb R^C$ (박스) — " $h,w$ : 공간", " $C$ : 특징벡터 차원". 위치 $(r,c)$ 마다 $C$ 차원 벡터가 토큰 하나다.

## 2. 🔴 판서: 계층 구조와 window [W11M p2]

$X\in\mathbb R^{56\times56\times96}$ (공간 56×56, 특징 벡터 96차원)

$$56\times56\times96\ \to\ 28\times28\times192\ \to\ 14\times14\times384\ \to\ 7\times7\times768\qquad(\text{Hierarchical feature representation})$$

- 단계마다 공간은 가로·세로 절반, 채널은 두 배 (§5 Patch Merging).
- $N=hw$ , window 크기 $M\times M$ → **window 하나의 토큰 수 $M^2$** , **window 개수 $=N/M^2$**
- 예: $X\in\mathbb R^{N\times C}$ (토큰을 한 줄로), $h=w=56$, $M=7$ → $N=56^2=3136$ , window 개수 $=3136/49=64$

## 3. 🔴 판서: full attention(MSA)의 비용 [W11M p2–3]

**tip: 행렬곱의 비용** (박스)

$A\in\mathbb R^{m\times k}$, $B\in\mathbb R^{k\times n}$, $Y=AB\in\mathbb R^{m\times n}$, $Y_{ij}=\sum_{l=1}^kA_{il}B_{lj}$

- 원소 하나에 곱셈 $k$ 번, 덧셈 $k-1$ 번 → 원소 $mn$ 개 → **$O(mnk)$** (밑줄)

**projection** $Q=XW_Q$, $K=XW_K$, $V=XW_V$, $W_Q,W_K,W_V\in\mathbb R^{C\times C}$

- 행렬곱 $(N\times C)(C\times C)$ → $NC^2$ (파랑 동그라미). $Q,K,V$ 세 개면 ✏️ $3NC^2$ (판서는 "3NC")

**attention** $\text{softmax}\big(\frac{QK^\top}{\sqrt C}\big)V$

| 곱 | 크기 | 비용 |
| --- | --- | --- |
| $QK^\top$ | $(N\times C)(C\times N)\to N\times N$ | $O(N^2C)$ |
| $\text{softmax}(\cdot)V$ | $(N\times N)(N\times C)$ | $O(N^2C)$ (파랑 동그라미) |

- (보충) 슬라이드 식의 계수: projection은 $Q,K,V$ 와 출력 projection까지 $4$ 번이라 $4NC^2$ , attention의 두 곱이 $2N^2C$ → $\Omega(\mathrm{MSA})=4NC^2+2N^2C$ .

## 4. 🔴 판서: window attention(W-MSA)의 비용 [W11M p4]

**window attention** (밑줄): attention을 window 안에서만 한다.

1. window 하나에 토큰 $M^2$ 개 → 두 attention 행렬곱 비용은 §3의 $N$ 자리에 $M^2$ : $\ 2(M^2)^2C=2M^4C$
2. 전체 window 개수 $N/M^2$ →

$$\frac N{M^2}\times2M^4C=2NM^2C\qquad(\text{큰 동그라미})$$

3. **W-MSA cost** $=4NC^2+2NM^2C$ (projection은 토큰마다 하므로 그대로)

**For fixed $M,C$** (밑줄)

| | 비용 | $N$ 에 대해 |
| --- | --- | --- |
| MSA (full attention) | $4NC^2+2N^2C$ | $O(N^2)$ (이중 밑줄) |
| W-MSA | $4NC^2+2NM^2C$ | $O(N)$ |

**예** $h=w=56$, $M=7$, $N=3136$, window 64개: full attention $\approx3136^2=9{,}834{,}496$ vs window $64\cdot49^2=153{,}664$ (둘 다 $\times2C$ 를 뺀 값). 비율은 $N/M^2=64$ 배.

- (보충) 11/4의 linear attention과 비교: 둘 다 $O(N^2)$ 를 $O(N)$ 으로 줄이지만, linear attention은 **softmax를 kernel로 근사**하고, W-MSA는 **attention하는 범위를 window로 제한**한다 (window 밖 토큰은 같은 층에서 보지 못한다 → §6).

## 5. 🟡 Patch Merging (~pooling) [W11M p5]

제목 "(~pooling)"에 동그라미. 그림 (n = 2): 1) 이웃한 2×2 패치를 한 그룹으로 나눈다 2) 그룹 안의 패치들을 깊이(채널) 방향으로 쌓는다 3) 쌓은 그룹들을 합친다.

- (보충) 2×2를 쌓으면 채널이 $4C$ 가 되고, Swin은 linear layer로 $2C$ 로 줄인다 → 공간 절반, 채널 두 배: §2의 $56^2\times96\to28^2\times192$ . CNN의 pooling(+채널 증가)과 같은 역할.

## 6. 🟡 Non-overlapped Shifted window [W11M p6]

- shifted window: 새 window에서의 self-attention이 **이전 층 window의 경계를 넘는다** (겹치지 않는 window의 한계를 해결).
- 그림: Layer $l$ 은 4×4 패치 window 2×2개 → Layer $l+1$ 은 window를 옮겨 크기가 다른 3×3개 (판서: 각 층의 window 하나에 사각형).
- (보충) window만 쓰면 window 사이에 정보가 오가지 않는다. 층마다 window를 (그림에서 2패치 = $M/2$ ) 옮기면, 앞 층에서 다른 window였던 토큰이 같은 window에 들어가 정보가 섞인다. 계산량은 그대로 $O(N)$ .
- (11/4 요약) 패치로 나누면 인접 패치 경계 정보가 끊기는 ViT의 한계를 보완한다. 세부 구조는 11/9에 이어서 다룬다고 했다.
