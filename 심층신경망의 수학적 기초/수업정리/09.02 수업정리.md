## 1. 선형회귀 모델 [W1W p3–5]

- 데이터 $(\mathbf{x}_ i,y_i)=(x_{i1},\dots,x_{ik},y_i)$, $i=1,\dots,n$, $n>k$.
- 모델: $y_i=\beta_0+\sum_{j=1}^k x_{ij}\beta_j+\epsilon_i$. 목표는 데이터를 잘 설명하는 직선(초평면)을 찾는 것.
- 행렬형: $\mathbf{y}=X\boldsymbol\beta+\boldsymbol\epsilon$. $X$의 $i$행은 $(1,x_{i1},\dots,x_{ik})$ — 절편 $\beta_0$ 때문에 첫 열이 1이다.
- 목적함수: 오차제곱합을 최소화한다.

$$\sum_{i=1}^n\epsilon_i^2=\sum_{i=1}^n\Big(y_i-(\beta_0+\sum_{j=1}^k x_{ij}\beta_j)\Big)^2\iff f(\beta)=\lVert y-X\beta\rVert^2=(y-X\beta)^\top(y-X\beta)$$

## 2. 정규방정식 (Normal Equations, "old friend")  🔴  [W1W p6 → 노트 p7–8]

**가정** $X^\top X$가 가역 (보충: $X$의 열들이 선형독립)
**결론**

$$\hat\beta=(X^\top X)^{-1}X^\top y$$

**핵심 아이디어** $f$를 전개해서 벡터 미분 공식 두 개로 기울기를 구하고 0으로 둔다.

**증명 (판서 순서)**
1. 전개 [p6]:
   $$f(\beta)=(y^\top-\beta^\top X^\top)(y-X\beta)=y^\top y-\beta^\top X^\top y-y^\top X\beta+\beta^\top X^\top X\beta$$
   $y^\top y$는 $\beta$와 무관하므로 미분하면 0 (판서에서 빨간 줄로 지움).
2. 일차항: 공식 ⓐ $\nabla_\beta(\beta^\top m)=m$에 $m=X^\top y$ → $-X^\top y$. $y^\top X\beta$는 스칼라라서 $=(y^\top X\beta)^\top=\beta^\top X^\top y$ → 역시 $-X^\top y$. (보충: 판서는 두 항을 모두 $-X^\top y$로 바로 적음)
3. 이차항: 공식 ⓑ $\nabla_\beta(\beta^\top A\beta)=(A+A^\top)\beta$에 $A=X^\top X$ (대칭) → $2X^\top X\beta$.
4. 합치면 [p6 판서]: $\nabla_\beta f=-X^\top y-X^\top y+X^\top X\beta+X^\top X\beta=0$
5. $X^\top X\beta=X^\top y$ (정규방정식) → $\hat\beta=(X^\top X)^{-1}X^\top y$ ∎

**보조 사실**
- ⓐ $\nabla_\beta(\beta^\top m)=m$ [p7]: $\beta^\top m=\beta_1m_1+\beta_2m_2+\beta_3m_3$이므로 $\partial/\partial\beta_k=m_k$ → 기울기 $=(m_1,m_2,m_3)^\top$.
- ⓑ $\nabla_\beta(\beta^\top A\beta)=(A+A^\top)\beta$ [p7–8]:
  - $\beta^\top A\beta=\sum_{i,j}\beta_iA_{ij}\beta_j$
  - $\partial/\partial\beta_k$를 취하면 $\beta_k$가 들어 있는 항만 남는다.
    - (i) $i=k$인 항 $\beta_kA_{kj}\beta_j$ → $\sum_jA_{kj}\beta_j=(A\beta)_ k$
    - (ii) $j=k$인 항 $\beta_iA_{ik}\beta_k$ → $\sum_iA_{ik}\beta_i=(A^\top\beta)_ k$
  - 따라서 $\nabla_\beta(\beta^\top A\beta)=A\beta+A^\top\beta=(A+A^\top)\beta$
  - (보충) $i=j=k$인 항 $A_{kk}\beta_k^2$의 미분 $2A_{kk}\beta_k$는 (i)과 (ii)에 한 번씩 나뉘어 들어가므로 빠지거나 겹치지 않는다.

**이어지는 곳** 9/9 ridge는 같은 계산에 $\lambda\beta$가 더해져 $\hat\beta=(\lambda I+X^\top X)^{-1}X^\top y$가 된다 → [09.09 수업정리](09.09%20수업정리.md) §5

## 3. ML 관점: 어떤 직선이 "최선"인가 [W1W p9–12]

- 여러 직선 중 가장 잘 맞는 직선을 고르는 기준은 **잔차(residual) 제곱합**(SSE)이다.
- 수평 기준선(benchmark)의 SSE는 24.62이고, 직선을 조금 돌리면 16.5로 줄어든다.
- 회전 각도에 따라 SSE를 그리면 **줄었다가 늘어난다** → SSE의 최소점을 찾는 문제 = 최적화. 판서는 이 곡선을 $f(\beta)$로 표시했다.

## 4. 경사하강법 (Gradient Descent)  🟠  [W1W p13–14]

목적함수 $f(\beta)=\sum_{i=1}^n\big(y_i-(\beta_0+\sum_{j}\beta_jx_{ij})\big)^2$에서 초기 벡터 $\beta$로 시작해 반복한다.

$$\beta_l\leftarrow\beta_l-\alpha\frac{\partial f}{\partial\beta_l},\qquad\frac{\partial f}{\partial\beta_l}=-2\sum_{i=1}^n\Big(y_i-(\beta_0+\sum_{j=1}^k\beta_jx_{ij})\Big)x_{il}\quad(x_{i0}=1)$$

- $\alpha$ = learning rate. 슬라이드의 업데이트식 $\beta_l\leftarrow\beta_l+\alpha\sum_i(\cdots)x_{il}$은 부호를 정리하고 상수 2를 $\alpha$에 흡수한 것이다 (보충).
- $f(\beta)$가 **가장 가파르게 줄어드는 방향**으로 한 걸음씩 가는 자연스러운 알고리즘이다.
- **단점:** 한 걸음을 가기 전에 **training set 전체를 훑어야** 한다 (판서 동그라미). → 9/21에서 SGD·mini-batch로 해결 → [09.21](09.21%20수업정리.md)
- 정규방정식은 해를 한 번에 구하고(역행렬 필요), GD는 반복해서 다가간다. 신경망처럼 닫힌 해가 없으면 GD를 쓸 수밖에 없다 (보충).

## 5. 확률 기초 (Preliminary) [W1W p15–19]

### 5.1 공리와 성질 ⚪ [p16]
- 공리: $0\le P(E)\le1$, $P(\Omega)=1$, 서로소인 $E_i$에 대해 $P(\cup E_i)=\sum P(E_i)$.
- 성질: $P(\emptyset)=0$, $P(E^c)=1-P(E)$, $P(E\cup F)=P(E)+P(F)-P(E\cap F)$, $E\subseteq F\Rightarrow P(E)\le P(F)$, 증가·감소하는 사건열의 연속성.

### 5.2 조건부확률과 전확률 법칙 🟡 [p17]
- $P(F\mid E)=\dfrac{P(E\cap F)}{P(E)}$, $P(E)>0$.
- **전확률 법칙:** $\lbrace E_i\rbrace_{i=1}^N$이 $\Omega$의 분할(합집합이 $\Omega$, 서로소)이면

$$P(F)=\sum_{i=1}^NP(E_i)P(F\mid E_i)$$

  $N$은 유한·무한 모두 가능하고, 보통 $P(E_i)$는 계산하기 쉽다. 판서는 $\Omega$를 $E_1,\dots,E_4$ 조각으로 나눈 그림.

### 5.3 베이즈 공식  🔴  [p18 → 노트 p19]

$$P(E_i\mid F)=\frac{P(E_i\cap F)}{P(F)}=\frac{P(F\mid E_i)P(E_i)}{\sum_{j=1}^NP(F\mid E_j)P(E_j)}$$

| 부분 | 이름 | 뜻 |
| --- | --- | --- |
| $P(E_i)$ | **prior** | 관찰 전 믿음 |
| $P(F\mid E_i)$ | **likelihood** | $E_i$일 때 $F$가 관찰될 확률 |
| 분모 $\sum_jP(F\mid E_j)P(E_j)=P(F)$ | **evidence** | 전확률 법칙으로 계산 |
| $P(E_i\mid F)$ | posterior | 관찰 후 갱신된 확률 |

> 판서: "Assume F is observed, find an updated prob. of $E_i$." — 9/7의 베이즈 모델·MAP가 바로 이 틀이다 → [09.07 수업정리](09.07%20수업정리.md) §5–7

### 5.4 독립 🟡 [p18]
- $P(E\cap F)=P(E)P(F)$이면 독립. 그러면 $P(F\mid E)=P(F)$.
- 예: 공정한 동전 두 개. $E$ = 첫째 앞면, $F$ = 둘째 앞면. $P(E)=P(F)=\tfrac12$, $P(E\cap F)=\tfrac14$ → $P(F\mid E)=\dfrac{1/4}{1/2}=\dfrac12=P(F)$.
