## 학습목표

인쇄와 방송, 인터넷과 소셜 미디어, 인공지능과 대규모 언어모델(LLM)로 이어지는 미디어 기술의 변화가 개인과 사회에 미친 영향을 살펴본다. 매스미디어와 대중사회, 소셜 미디어와 이용자 심리, 인터넷과 미디어 산업, 인공지능과 사회 변화를 폭넓게 다룬다. 미디어 이론 학습, 사회 변화 사례 분석, 디지털 도구 체험을 통해 미디어 기술과 사회의 관계를 이해하고 그 영향과 의미를 비판적으로 분석하는 역량을 기른다.
