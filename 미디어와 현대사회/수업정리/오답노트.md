# 미디어와 현대사회 — 오답노트

> 과외 문제 풀이에서 틀린 문제 모음. **부분 정답(△)도 모두 오답으로 처리**했다(뜻은 맞아도 슬라이드 용어가 아니면 시험에선 감점). 문제 → 내 답 → 정답 → 해설 순.
> 시험 직전에는 맨 아래 **[반복해서 틀린 유형]** 부터 볼 것.

## 6. Week 04\~05(p.30) 고난이도 시험

### ⚠️ 지문 A 2번 — 프라이밍 ≠ 프레이밍
- **문제**: 무역 분쟁 보도가 이어진 뒤, 유권자들이 후보를 "통상 협상 능력"을 **기준으로 평가**하기 시작한 현상은?
- **내 답**: 프레이밍 → **정답: 프라이밍(점화)**
- **해설**: 강조된 이슈가 **평가 기준**이 됨 = 프라이밍. 같은 사건을 다르게 **구성**하는 것((가) 사장의 눈물 vs (나) 산업 구조) = 프레이밍. 교수님이 "오타에 너그럽지만 **이 둘은 예외**"라고 한 쌍 → 시험이면 바로 오답. 답안엔 **"점화 효과"** 로 쓸 것.

- **해설**: 이용과 충족의 **욕구 5개·가정 5개는 정해진 이름**이다. 뜻만 쓰면 감점. 욕구 = 인지적 / 정서·감정적 / 개인 통합 / 사회적 통합 / 도피·완화.

### 키워드 2번
- **문제**: "행동주의적 언어 습득은 불가능하다"며 행동주의를 비판한 학자는?
- **내 답**: Katz → **정답: 촘스키**
- **해설**: 카츠 = 베럴슨에 대한 **반론**("사람들이 미디어로 무엇을 하나"). 촘스키 = 행동주의 비판 → **인지 혁명**. 둘 다 중효과 등장 배경이라 섞였다.

### 키워드 3번
- **문제**: 이용과 충족 이론의 5가지 가정 중 유일하게 연구자에 대한 가정은?
- **내 답**: (빈칸) → **정답: 가치 중립성**

### 키워드 4번
- **문제**: 신뢰성·자신감·안정성·지위를 강화하려는, 인지와 감정이 결합된 욕구는?
- **내 답**: 자기 인정 → **정답: 개인 통합**
- **해설**: 인지 + 감정 → **개인 통합**. 예: 자기계발서, K팝 흥행 뉴스에 뿌듯함.

### 키워드 7번
- **문제**: "대중의 눈에 띈다"는 ( )와 "중요하게 인식한다"는 ( )를 구분한다. (영어)
- **내 답**: salitary, negotiate → **정답: salience, importance**

### 키워드 8번
- **문제**: 점화(priming) 개념은 ( )에서 개발되었다.
- **내 답**: (빈칸) → **정답: 인지심리학**
- **해설**: 인지심리학 → 개인의 지식 = **개념들의 연결망** → 아이옌거 등이 정치·언론 연구로.

### 키워드 9번
- **문제**: 하나의 개념이 활성화되면 의미망을 따라 관련된 여러 개념으로 퍼지는 것은?
- **내 답**: 의미 활성화 → **정답: 활성화 확산 (spreading activation)**
- **해설**: 활성화 **확산** = 네트워크 전체로 **퍼짐** / 의미 **점화** = 앞 개념이 뒤 개념 하나를 **떠올리게** 함. 두 단어를 섞으면 안 된다.

### 키워드 10번 (△ → 오답 처리)
- **문제**: 정치적으로 무지한 사람이 프라이밍에 더 취약한 이유는 ( ) 능력이 부족하기 때문이다.
- **내 답**: 반론 → **정답: 반박 논증 (counterargument)**

### 키워드 11번
- **문제**: 갬슨은 프레임을 "구성적인 ( )"로 개념화했다.
- **내 답**: 의미 틀 → **정답: 줄거리 (organizing story-line)**

### 키워드 12번 (△ → 오답 처리)
- **문제**: 아이옌거에 따르면 프레임에 따라 ( )이 달라진다.
- **내 답**: 누가 책임을 져야 하는지 → **정답: 책임 귀인 (Attribution of Responsibility)**

### 키워드 13번
- **문제**: 노엘레 노이만: "( ) 없이" + "내 스스로의 정체를 알리면서" 말할 수 있는 의견 = 여론
- **내 답**: 주변에 대한 두려움, 압박 → **정답: 고립에 대한 공포**
- **해설**: 답을 두 개 쓴 것도 감점 대상.

### 키워드 15번 (△ → 오답 처리)
- **문제**: 폰 노이만 구조는 다른 말로 ( ) 구조라고 한다.
- **내 답**: 내장형 메모리 → **정답: 프로그램 내장형**
- **해설**: 메모리에 **프로그램**과 자료를 함께 저장 → 물리 재배치 없이 소프트웨어로 변경. ↔ 프로그램 외장형(초기 진공관).

### 키워드 17번
- **문제**: 카스텔에 따르면 전통적인 "장소의 공간"은 "( )"으로 바뀐다.
- **내 답**: 네트워크 공론장 → **정답: 흐름의 공간 (space of flows)**
- **해설**: ⚠️ **네트워크화된 공론장 = 벤클러**. 카스텔 = 네트워크 사회, 흐름의 공간, "흐름의 권력이 권력의 흐름보다 우선한다", Net vs Self.
