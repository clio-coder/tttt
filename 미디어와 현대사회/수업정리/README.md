## 시험 공통 안내 (수업 중 교수님 발언 모음)
- **시험 준비는 Key Points 슬라이드 중심 + 시험 안내 자료** (Week 01 p.4). Key Points는 "외워야 된다, 시험에 나온다" (9.9).
- 형식: **객관식 + 단답형 + (서술형)**. 시험 전에 **기출 샘플·시험 문제 템플릿** 제공 예정 (Week 01 p.6, 9.9).
- 중간고사 **키워드는 40\~50개** 수준 (9.14). 공부 방식: **키워드를 주면 설명, 설명을 주면 키워드** (9.9).
- **OX 15\~20문제**: 약 5개는 단순, 나머지는 생각해야 하는 "꼬인" OX. 학생들은 **OX에서 많이 틀린다** (9.21).
- 키워드 답은 **웬만하면 한국어로**. 과도한 번안(비행기 → 날틀)은 X. 영어 철자는 조금 틀려도 됨. 모르면 비워 두고 사과 메모는 쓰지 말 것 (9.9, 9.21).
- 주관식에서 "A는 긍정론자, B는 부정론자"만 쓰면 **기본 점수만**. 핵심 키워드와 근거가 들어가야 함 (9.21).
- 연도는 중요하지 않다. **누가 어떤 키워드를 말했는지**가 중요 (9.9).
- **중간고사 범위**: Week 05 **p.30**까지 수업, "시험은 여기까지, 쪽수는 공지" (10.14) → eTL 확인. 출제 비중은 **Key Points 80\~90% + 수업 언급 10\~20%** (10.14). 시험 범위는 보통 5\~6주차 사이에서 끊기고, Week 04부터가 "시험에 많이 나오면 좋다"(예시를 들기 쉬워서) (9.30).
- **한·영 혼용 금지**: "황색 저널리즘"(9.23), "여론 리더"(9.30)처럼 섞지 말고 한쪽으로 통일. **프라이밍은 "점화 효과"로 외워 프레이밍과 혼동하지 말 것**(오타에 너그럽지만 이 둘은 예외) (10.7).
- "강효과냐 중효과냐" 같은 분류는 묻지 않는다. **각 이론의 이름과 핵심**을 묻는다 (10.7).
- **형식(시험샘플)**: OX / 키워드 / 지문(기사) 답변 / 서술 A·B 택1(10문장 이내). OX는 **O/X**로, 답은 **하나만** (10.12).
