### 🟠 중요 (Week 05 Key Points p.43\~44)
- **배비지·러브레이스·폰 노이만**이 컴퓨터 발전에 미친 영향(**OX**): 배비지 = 해석 기관(거대한 계산기) / 러브레이스 = 알고리즘(조건문·루프문·서브루틴), **아날로그 현상을 0과 1로 환산할 수 있다는 개념** / 폰 노이만 = **물리적 재배치 없이 소프트웨어적으로 프로그램을 바꿀 수 있는 구조**(CPU·메모리·입출력).
- **IBM과 Apple**이 현대 컴퓨터에 준 영향(**OX**): IBM = 상업용 컴퓨터, **개방형 아키텍처**(호환 부품 → 시장 점유율) / Apple = **완제품·유저 친화적 구조**로 대중화, Macintosh = **GUI·마우스 대중화**.
- 키워드: **GUI, HCI, WYSIWYG, 폰 노이만 구조(장점)**
- 학자 구분(설명 → OX·빈칸): **벨**(포스트산업 사회, 정보사회·정보활동) / **토플러**(좁은 방송, blips, cf. 롱테일) / **카스텔**(네트워크 사회, "흐름의 권력이 권력의 흐름보다 우선한다", 네트와 자아) / **셔키**("the Internet runs on love", 인지 잉여) / **벤클러**(네트워크 정보 경제, 모듈성, 세분성, 네트워크화된 공론장)
- **Web 1.0 vs 2.0**의 차이
- **BBS·유즈넷·초기 커뮤니티**의 특징과 차이, 한계(키워드 — 로컬 커뮤니티(지역 기반), 글로벌 커뮤니티(취미 기반), 중앙집중형, 분산형, 공유·동기화, 트래픽)
- BBS·유즈넷(·The Well)과 현재 인터넷 문화의 연관(**OX**, 키워드 — 게시판 문화, 스팸메일, Flame Wars, 익명·가명, 실명(YOYOW), 구독, 커뮤니티 자율규제)
- 현대 소셜 미디어의 특징(키워드 — **프로필, 유저 연결, 사용자 생성 콘텐츠, 플랫폼**)

### 🟡 수업 중 짚음 (Key Points 밖 — 10\~20% 대비)
- 진공관 컴퓨터 시절에서 나온 용어: 진공관의 열과 빛에 **벌레(bug)** 가 꼬여 고장 → "**버그**". 천공카드 구멍을 잘못 뚫으면 반창고로 막음 → "**패치**".
- **Xerox PARC**(제록스 팔로알토 연구소)가 GUI, **WYSIWYG**("What You See Is What You Get", 보이는 대로 출력 — 예전엔 굵게 하려면 코드를 짜서 출력해야 했다), 마우스 UI를 고안했다. 1983년 **HCI** 분야 확립. 교수님도 HCI 출신. 요즘의 UX·UI 전문가가 이 계열이고, 이걸 "극한으로 깎은" 회사가 애플.
- 웹 브라우저: **Mosaic → 넷스케이프**는 원래 **유료**였는데, 마이크로소프트가 **인터넷 익스플로러를 OS에 기본 탑재**해 반독점 재판까지 갔고, 결국 "브라우저를 돈 주고 살 필요가 있나"가 되며 몰락했다.
- **Web 1.0** = 정적 페이지, 소비 위주(법령·입시 정보 찾아보기) / **Web 2.0** = 사용자 생성 콘텐츠·상호작용(블로그, 위키피디아, 트위터, 페이스북). 영상: 1.0은 읽기 전용, 2.0은 읽기·쓰기(UCC), 그러나 이익과 데이터 소유권은 플랫폼 기업이 가져감.
- **Web 3.0**(블록체인·NFT·탈중앙화, 데이터 소유권이 개인에게): "**썰이 많다**", 지금은 유보적 입장(바이럴이었다, 2.0의 확장판이다 등) → **다루지 않음**.
- 벨: 문명 게임의 "테크 트리"처럼 한 시대의 지배적 노동이 최적화되면 다음 단계가 열린다. 벨 본인은 "정보 사회"라는 말을 직접 쓰지는 않았고 후에 정보사회 개념으로 발전. 다음 단계는 AI일지도.
- 토플러: 대중 매체는 "무난한 맛"을 추구할 수밖에 없지만 이제는 **원하는 콘텐츠**를 전달하는 좁은 방송이 가능 → 개인 맞춤형 콘텐츠. 40년 전 책인데 **쇼츠·피드**를 예견한 셈.
- 롱테일: 예전엔 상위 20%(파레토 법칙)를 노렸지만, 이제는 길게 뻗은 꼬리(희소한 다수)에도 먹을 게 많다(교수님 예: 쿠팡이 물 떨어질 때쯤 재구매를 추천).
- 카스텔: 같은 1천억 매출이라도 식품 회사보다 **정보 메신저 기업**이 대중에게 더 강한 영향력을 가진다. 네트 vs 자아 예: 디지털 노마드 vs 로컬 노동, "인터넷에선 100만 유튜버지만 현실에선…". **코로나** 때 재택이 가능한 화이트칼라는 오히려 복지가 늘고, 블루칼라는 대중교통 축소로 출근 비용이 늘어 양극화(학력별 이동 거리·출근 시간 연구).
- 셔키: 예전엔 맛집을 잡지로 찾았지만 이제 인터넷 사람들이 하루 30분씩 모아 전국 맛집 지도를 만든다(**인지 잉여**). 인터넷 맛집 사전이 공중파로 진출하는 등 **합 이상**의 효과. 시민단체가 예산·납품을 분석해 유착을 찾는 것도 같은 원리(투명한 정부 + 시민 참여).
- 벤클러: 전통적 위계(사원 → 관리자 → …) 대신 **자발적 작업 선택**(예: 나무위키 편집). **모듈성** 예: 큰 배의 **격벽 구조**(한 칸이 침수돼도 다른 칸은 안전), 게임 번역에서 메뉴 번역을 포기해도 스크립트 번역엔 영향 없음. **세분성**: 작업이 너무 크면 부담·위험이 커지니 최대한 잘게. 크라우드 펀딩(와디즈)과 비슷한 원리를 공론장에 적용. 2006년의 기대였지만 요즘은 "언론 말고 유튜브를 믿어"처럼 공론장이 **과도해졌다**.
- 소셜 미디어라고 부르는 이유: 모든 미디어는 원래 사회적이다(신문 보고 친구와 대화, TV 보며 모금·투표). 그런데 TV는 콘텐츠 목적이 분명하지만 소셜 미디어 피드는 **구체적 지시 없이** 참여 틀만 준다("다 올리세요, 선 넘은 것만 쳐낼게요") + **커뮤니티 구축**(유튜브 댓글 커뮤니티).
- **플랫폼**: 학술적으로는 사용자 간 상호작용을 조직하기 위해 **자동화된 프로그래밍 구조**가 있어야 한다(인력만으로 관리가 안 돼 프로그램으로 관리). IT 쪽은 용어를 새로 만들어 "깃발 꽂기"를 좋아해서 소셜 네트워크 서비스·소셜 미디어 플랫폼·플랫폼 기업 등 용어가 난립.
- **소셜 미디어의 양면성**: 틱톡에서 활동하는 음악가는 20분짜리 대작이 아니라 **30초 안의 훅**을 만든다 → 플랫폼을 쓰면서 동시에 **플랫폼이 유도하는 행동**을 하게 된다.
- 인터넷의 역사를 공부하면 옛날 것이 **리메이크·부활**하는 경우가 많다(그래서 배운다). 요즘 다시 "강력한 서버 + 단말기" 시대로 돌아갈 수도 있다는 썰(램 값 폭등).
- BBS: 내 컴퓨터를 서버로 열어 사람들이 **전화선 모뎀**으로 접속해 게시물을 남기는 것(동네 교회 홈페이지 같은 느낌). 전화 요금이 나오고 접속 중엔 전화를 못 받음. 텍스트로 그림을 그리는 문화.
- 유즈넷: 지역 서버에 접속해 글을 쓰면 **주기적으로 동기화**되어 전 세계 게시판에 퍼짐(이메일 CC처럼). 운영은 대학·ISP. 레딧, 한국의 DC인사이드·더쿠처럼 하위 게시판이 엄청 많은 구조. 리눅스·해커 문화는 **코드라는 공통 언어**가 있어 더 빨리 퍼졌다. 그룹마다 규칙이 다름(애완견 게시판은 하루 5개, 해킹 게시판은 무제한).
- 유즈넷에서 나온 것: **상업적 스팸메일**(자동차·애완견·육아 게시판에 무차별 변호사 광고 — Canter & Siegel), **Flame Wars**(키보드 배틀, "플레이밍"), **Godwin's Law**(대화가 길어질수록 나치·히틀러 비유가 나올 확률이 높아진다 — 교수님은 "말이 길어지면 욕이 나온다"는 식으로 설명).
- 한국 **PC통신**: BBS와 유즈넷을 섞은 형태. 웹소설의 원조(『퇴마록』, 『드래곤 라자』, 『마지막 해커』 등), 텍스트 머드 게임 → 통신 기능을 빼고 2D 그래픽을 입힌 **『바람의 나라』** → 스토리·유저 간 대결을 넣은 **『리니지』**.
- BBS·유즈넷의 쇠퇴: 텍스트 기반이라 불편·촌스러움 → **그래픽 웹 포럼·SNS**로. BBS는 개인 컴퓨터라 접속자가 많으면 터지고 지역 밖은 요금 부담, 유즈넷은 동기화 **트래픽** 폭증 + 하위 게시판이 너무 많아 **자동 관리가 안 돼 무법지대**(불법 복제 등). 검색엔진(구글)이 생기며 굳이 접속할 필요가 없어졌다(뉴비 텃세도 한몫).

### p.9 "유저 중심" 디지털 미디어 연구 — HCI 🟠
- 컴퓨터가 대중화되며 **"사람들이 어떻게 컴퓨터를 사용하는지"** 에 대한 연구 필요성 증가.
- **Xerox PARC (Palo Alto Research Center, 1970\~)**: **GUI, WYSIWYG**(What you see is what you get), **마우스 UI** 등 고안.
- **"The Psychology of Human-Computer Interaction" (1983)** — Stuart K. Card, Thomas P. Moran, Alan Newell
  - **HCI(Human-Computer Interaction)** 연구관을 확립한 기초 저서.
  - **심리학 원리와 연구 방법**을 적용 → 인간이 컴퓨터와 상호작용하는 방식을 분석하는 토대.
  - (⚪) 정보 처리 모델, 텍스트 편집 연구, 모델 단순화·검증, 공학적 모델 파트 등으로 구성. **GOMS(Goals, Operators, Methods, Selection rules)** 모델 제시.
  - 다양한 학문적 논의를 인간-컴퓨터 상호작용에 적용하는 예시. 교수님: 인지 지식 + 컴퓨터·공학 지식이 다 필요한 "짬뽕" 학문. 연구 프레임워크를 정의했다는 데 의미.

### p.10\~11 인터넷 미디어의 시작 🟠
- 컴퓨터 대중화와 함께 1980년대(\~90년대) 인터넷 핵심 기술의 **"오픈소스"화 (HTML, URL, HTTP)** → **월드 와이드 웹** 기반 구축 → 인터넷이 상업적·교육적·사회적 공간으로 급격히 확장.
- **Mosaic (1993)**: 최초로 대중적 성공을 거둔 **"웹 브라우저"** (→ **넷스케이프**로 발전).
- 1990년대 미국 정부의 **규제 완화**와 함께 다양한 인터넷 기업이 발전 → 지나친 투자 열기로 **닷컴버블** 형성·시장 붕괴(1990\~2000) → 붕괴 후 새로운 사업 모델.
- **웹 1.0 시대(1990\~2000년대 초반) → 웹 2.0 시대(2000년대 중반\~2010년대 초반)**

| | **Web 1.0** | **Web 2.0** |
|---|---|---|
| 특징 | **정적 페이지** 중심, 대부분의 유저가 콘텐츠를 **소비** | **사용자 생성 콘텐츠**와 **상호작용** 중심 |
| 예 | 전문 정보·기업 웹사이트 (교수님: 법령·입시 정보 찾아보기) | 블로그, 위키피디아, 소셜 미디어(트위터, 페이스북) |

### p.13 다니엘 벨 — 포스트 산업 사회 🟠
- 1970년대 사회학자 **다니엘 벨(Daniel Bell)**, **포스트 산업 사회(post-industrial society)** 개념.
  - (미래 사회는) **정보 처리와 관계를 맺는 것이 일상생활의 중심**에 놓일 것이다.
  - 각 시대에는 **지배적인 일**이 있다 → **특정 시대에 지배적인 작업 형태가 일정 수준으로 합리화되면 다음 형태로 전환**된다!
    - 농업 → **"추출"** (자동화되며 도시로 이동) / 산업 → **"제작"** (공장이 점차 로봇화) / 20세기 후반(포스트 산업) → **"정보활동"** (정보가 대다수 사람들에게 **노동의 소재**가 된다)
  - 통신 기술과 컴퓨터 기술의 강력한 융합 → **정보 전문가(information professionals)** 의 출현(두드러진 범주).
  - **거의 모든 사람이** 일의 중요한 부분으로서 어떤 형태로든 **정보를 다룬다**(예: 은행원, 교사, 개발자).
  - 벨의 포스트 산업 사회 개념은 후에 **정보사회(information society)** 개념으로 변화·발전.

### p.14\~15 앨빈 토플러 — 좁은 방송, 롱테일 🟠
- **앨빈 토플러(Alvin Toffler)**: 정보 대중화에 대한 벨의 의견과 **다른 관점**(『**제3의 물결**』, 1980).
  - 정보는 더 이상 **"대중화"되지 않으며 "좁은 방송(narrowcasting)"** 이 제공될 것이다 = **"가능한 가장 넓은 청중이 아닌, 특정하고 목표 지향적인 청중에게 콘텐츠를 전달하는 것"**.
  - cf. **크리스 앤더슨(Chris Anderson)의 『롱테일(The Long Tail)』(2006)**.
  - 전자 매체를 통해 끊임없고 빠르게, 다양한 정보가 **작은 콘텐츠 조각(blips)** 형태로 제공될 것.
  - 기술·사회 변화의 가속화 속도가 **적응 능력을 앞질러** 방향 감각 상실과 격변을 불러올 것.
  - 그러나 (탈중앙화된) 컴퓨팅 기술이 개인에게 **더 많은 자율성**(정보, 상호작용)을 보장할 수 있다.
  - **분열된 청중의 개별적인 필요와 관심**에 맞춘 전문화되고 **인터랙티브한 미디어**가 요구될 것이다!
- **파레토 법칙과 롱테일 (p.15)**: Pareto Principle vs Long-Tail → 같은 현상에 대한 **다른 해석**. 롱테일은 **"희소한 다수"** 에 중심을 둔다. (cf. **파레토 최적과 다른 개념**)

### p.16 마누엘 카스텔 — 네트워크 사회 🔴
- **마누엘 카스텔(Manuel Castells, 1996)**: **"네트워크 사회"** 개념.
  - 벨과 토플러의 정보 사회는 역사적으로 **단기적인 시각**이며, **"네트워크 사회"** 가 더 적합하다.
  - 현대 사회의 주요 구조와 활동은 **전자적으로 처리된 정보 네트워크**를 중심으로 조직된다.
  - 전통적인 **"장소의 공간(space of places)" → "흐름의 공간(space of flows)"**.
  - 물리적 제약 약화 + 경제 활동과 사회적 상호작용이 **글로벌 차원**에서 운영(**이를 통제하는 것이 권력**).
  - **"흐름의 권력이 권력의 흐름보다 우선한다"**.
  - 네트워크 사회는 **"네트와 자아(Net and Self)"의 양극적 대립**으로 구성(**권력은 네트워크에, 의미와 정체성은 지역적 장소에**).
    - 글로벌 흐름에 통합된 (정보) 기술을 가진 **"네트워커"** vs (자동화로) 불안정한 **로컬 노동**에 갇힌 사람들.
    - 글로벌하고 유동적이며 상호 연결된 **"Net"** vs 지역에 뿌리를 둔 **"Self"**.

### p.17 클레이 셔키 — 인지 잉여 🟠
- **클레이 셔키(Clay Shirky)**: 디지털 미디어의 **집단적 힘** 강조(『Here Comes Everybody』(2008), 『Cognitive Surplus』(2011)).
  - 디지털 기술이 커뮤니케이션 방식, 협력 구조, 사회 참여 방식을 전환했다.
  - 전통적 매스미디어(소수 → 다수) → 인터넷·소셜 미디어(누구나 콘텐츠 제작·배포, 쌍방향 소통).
  - **전통적인 위계 구조 없이** 전례 없는 수준의 그룹 협력과 조직화 지원(예: P2P, 오픈소스 개발).
  - **"the Internet runs on love"** → 사람들이 공유 관심사·목표를 중심으로 모여 강력하게 협력(교수님: 여기서 love는 **열정**에 가깝다).
  - **인지 잉여(cognitive surplus)**: 인터넷은 사람들이 **여가 시간과 재능을 모아** 강력한 인간 표현과 미디어 콘텐츠를 창조하게 한다.
  - **집단 행동은 개별 행동의 합 이상**(시너지 + 온라인 뒤의 인간적 요소).
  - 인터넷의 협력적이고 투명한 특성이 **정부와 민주주의**를 바꿀 수 있다(투명한 정부 + 시민 참여).

### p.18\~19 요하이 벤클러 — 네트워크 정보 경제 🔴
- **요하이 벤클러(Yochai Benkler)** — 『The Wealth of Networks』(2006)
  - **네트워크 정보 경제(networked information economy, NIE)** 라는 새로운 경제·사회 패러다임.
  - **Commons-based peer production**: 누구나 접근하고 재사용할 수 있는 **공동 자원**을 만드는 시스템.
    - 참여자들은 전통적 위계 대신 **자발적으로 작업 선택**(예: 오픈 액세스 + 비영리 개발 환경 / 회사 내 일부 "유연한 조직").
    - **모듈성(Modularity)** 과 **입자/세분성(Granularity)** 이 필요(**분리 가능, 되도록 세밀하게** 나눠져야 함).
  - **네트워크화된 공론장(Networked Public Sphere)**: 인터넷이 **민주주의에 중요한 기회**를 제공한다.
    - 소수 언론사·미디어에 집중된 권력 → 누구나 블로그·SNS·유튜브로 정보를 생산·공유(미디어 소유자의 권력 약화, 적극적 참여 유도, 다수의 행위자 격려).
    - 정보 생산·소통이 **분산화** → 더 많은 사람에게 정치 참여 기회 + 전통적 권력구조 재편.
- 교수님 구분: 셔키는 협력이 **어떤 열정 동인**으로 움직이는지에 집중, 벤클러는 그것이 **경제적으로**, 그리고 **민주주의에** 어떤 영향을 줄지에 집중.
- p.19 영상(참고).

### p.20\~21 소셜 미디어의 등장 🟠
- 웹 1.0 → 2.0의 변화 → 다양한 **"소셜 미디어 플랫폼"** 등장·발전(Blog, Twitter, Facebook, TikTok 등).
  - 사용자 생성 콘텐츠, 바이럴, 밈 등 다양한 인터넷·사회 현상 유도(+ 배경 제공).
- 모든 미디어에는 **"사회적 측면"** 이 있다(미디어 효과 이론, 이용과 충족 이론을 생각해 보자). 사람들은 단순히 정보를 얻으려고만 미디어를 쓰지 않는다(예: 인기 TV쇼를 보는 이유).
- 그러나 소셜 미디어는 기존 미디어와 다른 **"새로운 형태"의 "협력과 참여"** 를 유도(1990년대 용어 등장 + 셔키, 벤클러).
- **소셜 미디어 = 1) (유저 간) 연결을 만들고 2) 콘텐츠를 공유하고 반응하기 위한 → 대규모 인터넷 환경**.
  - 1) 참여를 위한 **틀**을 제공하지만 **"콘텐츠에 대한 구체적 지시사항은 없으며"** 2) **커뮤니티 구축** 기능을 제공.
- 현대 소셜 미디어는 **"플랫폼(Platform)"** 이라는 명칭을 많이 쓴다(App, Service로도 통칭).
  - **플랫폼: 사용자 간의 상호작용을 조직하기 위해 설계된 프로그래밍 가능한 구조** (Dijck, Poell and de Waal, 2018) (⚪ 정의는 애매해서 잘 안 냄)
  - 유저는 **"플랫폼을 사용"** 하지만 동시에 **"플랫폼이 유도"(기술·환경적 제약)** 하는 행동을 한다 → **소셜 미디어의 양면성**.

### p.22\~23 소셜 미디어의 시작 — BBS 🔴
- 현대 소셜 미디어는 과거 (유저) 플랫폼의 **계승·변화·확장** 형태로 발전(기술 발전의 영향).
- 인터넷 초기(1970\~90) **BBS(Bulletin Board System)** 와 **유즈넷(Usenet)** 등장 = 현대 소셜 미디어의 **전신**.
- **BBS**
  - **개별 컴퓨터 서버**에 **전화선 모뎀**으로 접속, **취미 중심**으로 운영되며 **개별 운영자가 관리**.
  - 다양한 유저가 접속해 게시글을 읽고 쓰고 파일을 공유(+ **회선 제한**).
  - **로컬 커뮤니티**와 깊은 관련(장거리 전화 요금, 개인\~소규모 단체 운영 → **지역 소모임**).
  - 개별 서버라 **네트워크 확장에 제약** + 대부분 **"익명"** 시스템(**프로필 기능 없음**).
  - 최초의 BBS: **1978년 시카고 CBBS**(Computerized Bulletin Board System) — **겨울 폭풍**에 고립된 Randy Suess와 Ward Christensen이 개발. 초기엔 **단일 회선**으로 한 번에 한 명만 접속.

### p.24\~25 초기 소셜 미디어의 발전 — 유즈넷 🔴
- **유즈넷(Usenet)**: BBS와 동시대에 존재한 또 다른 플랫폼(동일하지 않음).
  - **1979년 Tom Truscott와 Jim Ellis**가 고안한 **"분산형" 메시지 보드 시스템**(이메일처럼 여러 사람에게 분산 전달).
  - 유저가 계층으로 구분된 **뉴스 그룹**에 접속(+ 구독)해 글을 읽고 쓰면 활동이 뉴스 서버로 전송(+ 다른 뉴스 서버로 전달).
  - BBS가 개별 서버에 **직접** 접속한다면, 유즈넷은 **원하는 서버**(보통 ISP나 대학 서버)에 접속.
  - 정보가 **"여러 서버에 걸쳐 분산된"** 형식 — **서버 간 복제**로 메시지 공유·확산(**동기화**).
  - **전 세계적으로** 메시지를 주고받을 수 있음(서버가 여러 지역에 있음).
  - 지역 단위 토론도 있었지만 **전 세계에 걸친 전문화 + 다양한 주제**가 논의되는 공간(예: 리눅스, 해커 문화).
  - BBS는 운영자에 따라 구조·규칙·환경이 제각각이었지만, 유즈넷은 **비슷한 뉴스그룹 구조**를 썼다(그룹마다 다른 문화).
  - **소셜 미디어 문화에 영향**: **상업적 대량 스팸메일**(Canter & Siegel, 상징적 사례), **Flame Wars + Godwin's Law**(키보드 배틀).

| 비교 (교수님 정리) | **BBS** | **유즈넷** |
|---|---|---|
| 운영 | **개인**(개별 운영자), 개별 서버에 직접 접속 | 대학·ISP 서버, **분산형**(서버 간 복제·동기화) |
| 범위 | **로컬**(지역 기반, 전화 요금) | **글로벌**(취미·전문 주제 기반) |
| 주제 | 지역에 한정된 주제·소모임 | 수많은 주제의 하위 게시판(뉴스그룹) |
| 정체성 | 익명, 프로필 없음 | — |
| 남긴 것 | 게시판 문화 | **스팸메일, Flame Wars, Godwin's Law** |
| 한계 | **접속 제한**, 확장 제약 | **관리·트래픽 문제**(동기화 부담, 통제 불가) |

### p.26\~29 초기 소셜 미디어의 발전 (한국) — PC통신
- 한국에서는 **BBS와 유즈넷 방식이 결합된 PC통신** 플랫폼·문화가 발전(슬라이드는 이미지).
- 교수님: 웹소설의 원조(PC통신 연재 소설), 텍스트 기반 게임 → 『바람의 나라』 → 『리니지』로 이어짐.

### p.30 소셜 미디어의 변화 — BBS·유즈넷의 쇠퇴 🟠
- BBS와 유즈넷 인구는 **1990년대 중반 이후**, 인터넷 보편화와 웹의 등장으로 감소.
  - **WWW와 웹 브라우저**의 발전 → **"그래픽 기반" 인터페이스(+ 사용자 편의성)** 선호 증가.
  - 더 다양한 기능을 주는 **웹 기반 포럼(Forum)** 과 이후의 **SNS** 발전.
  - **기술적 한계**(BBS의 **접속 제한**, 유즈넷의 **관리 및 트래픽 문제**)가 두드러짐.
    - 예: 탈중앙화에 따른 **스팸·저작권·불법 정보의 범람**(통제가 어려움).
    - 예: **"The Well"** 같은 대안 모델의 성공(**실명**으로 가입, You Own Your Own Words → **YOYOW** 정책).
  - 이후 **검색엔진**(예: Google)의 등장·발전으로 다양하고 수준 높은 정보에 대한 접근성 증가.
  - **ISP**를 통해 쉽고 빠르게 인터넷 접속 가능(전화 기반 연결의 쇠퇴).
