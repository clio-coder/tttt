## 0. 시험 안내 (최종)

### 0-1. 문제 형식 (`시험샘플.pdf` + 10.12 안내)
| 유형 | 형식 | 샘플 예 |
|---|---|---|
| **1. OX** | 문장 → O/X | "빌트모어 협정으로 라디오는 TV 뉴스가 등장할 때까지 쇠퇴기를 겪었다" → X / "팀 버너스 리는 선정된 사업자 중심으로 한시적 라이선스 제도를 주장했다" → X |
| **2. 키워드(빈칸)** | 설명 속 빈칸 채우기 | "이니스는 장기간 유지되지만 제한된 청중을 갖는 (**시간**) 편향적 미디어와 대립되는 (**공간**) 편향적 미디어로 분류" — **순서를 정확하게 맞출 것** / "프라이밍 이론에서 하나의 개념이 다른 하나의 개념을 떠오르게 하는 것 = (**의미점화**)" |
| **3. 지문 답변** | 뉴스 지문 + 질문 4\~5개(키워드·OX 섞임) | 청소년 위험 방송 뉴스 → "이 문제의식으로 청소년 콘텐츠 규제를 연구하는 흐름은 (**규범**) 이론" / "선거 기간에 계속 보도되면 유권자가 후보의 청소년 교육관을 중요 평가 기준으로 삼는다(프라이밍)" → O |
| **4. 서술** | **A형·B형 중 하나 선택**, **10문장 이내**(초과해도 가산점 없음) | A형 "**데카르트와 흄이 학문적 모델·이론에 미친 영향을 (강의 슬라이드 기준으로) 설명**" — 우리 범위다! |

- 샘플의 일부 개념(스튜어트 홀, FOMO, 인지부조화, 미디어화, 슈퍼팩, 와츠·스트로가츠)은 **이번 범위가 아니다**(샘플에 "예시 내용은 이번 시험 범위와 무관" 명시). 하지만 빌트모어·MTV·니켈로디언·팀 버너스 리·이니스·의미점화·규범 이론·프라이밍·데카르트·흄은 **우리 범위와 겹친다** → 실제 시험 난이도·문장 스타일이 이와 비슷할 것.

### 0-2. 답안 작성 규칙 (어기면 감점)
- **OX는 O 또는 X로**. T/F로 쓰려면 아주 정확하게. 애매하게 걸친 표기는 **오답 처리** (10.12).
- **답을 두 개 적지 말 것.** 조교가 1차로 보고 고른 답으로 채점한다 (10.12).
- 키워드는 웬만하면 **한국어**로. 영어 철자는 조금 틀려도 된다. 과한 번안 금지(비행기 → "날틀" X) (9.21).
- **한·영 혼용 금지**: "옐로우 저널리즘" 또는 "황색 언론"(**"황색 저널리즘" X**) / "오피니언 리더" 또는 "여론 지도자"(**"여론 리더" X**) (9.23, 9.30).
- **프라이밍 ≠ 프레이밍.** 점화/프라이밍, 틀짓기/프레이밍 다 되지만, 프라이밍은 **"점화 효과"** 로 쓰는 게 안전. 다른 오타엔 너그럽지만 이 둘은 예외 (10.7, 10.12).
- 서술형에서 "A는 긍정론, B는 부정론"만 쓰면 **기본 점수만**. 핵심 키워드와 근거를 넣을 것 (9.21).
- 모르면 비워 두기. 사과 메모 금지.

### 0-3. 출제 성향 (교수님 발언 모음)
- **Key Points 80\~90% + 수업 언급 10\~20%** (10.14).
- **OX 15\~20문제**: 5개쯤은 단순, 나머지는 한 번 꼰 문제. 학생들은 **키워드보다 OX에서 더 많이 틀린다** (9.21).
- 키워드 **40\~50개** 수준. **키워드 → 설명, 설명 → 키워드** 양방향 (9.9, 9.14).
- **한 문장이면 끝나는 내용은 OX로** 나온다(예: Mean World Syndrome) (10.12).
- 연도는 중요하지 않다. **누가 어떤 키워드를 말했는지** (9.9).
- "강효과냐 중효과냐", "이게 최초냐" 같은 분류·최초 따지기는 **안 묻는다**. **이론 이름과 핵심**을 묻는다 (10.7, 10.14).
- Week 04(효과 이론)는 기사 예시를 들기 쉬워 "시험에 많이 나오면 좋다" (9.30).
- "**좋아하는 유형**" = 신문 기사를 주고 밑줄 친 부분이 **어떤 선전 기법·욕구·이론·프레임**인지 묻기 (9.28).

## 1. Week 01 — 미디어와 커뮤니케이션 기초 (9.7·9.9)

### 📌 Key Points 문항 → 답 (p.51)
**① 현대적 맥락에서 "미디어"의 두 가지 의미는? 차이는?** 🟠
| | 뜻 | 예 |
|---|---|---|
| 독립적 의미 | **기관·집단** | 방송국, 신문사 |
| 다른 개념과 연계된 의미 | **과정·환경·구성 요소** | 커뮤니케이션 미디어, 뉴 미디어 |

**② 데카르트와 흄은 (사회과학) 이론·모델에 어떤 영향을 미쳤나?** 🔴 (OX 예고 + 샘플 서술 A형)
| | 데카르트 | 흄 |
|---|---|---|
| 입장 | **합리적 연역** | **경험주의**, 회의 |
| 핵심 | 복잡한 대상을 **최소 요소로 분해**한 뒤 질서 있게 연결해 전체를 이해(**4원칙**: 분해·종합·명증·열거), 『방법서설』 | 과학적 사실에서 나온 법칙·인과는 필연적 진리가 아니라 **반복된 경험에 근거한 개연적 추론**(**귀납의 문제**, 이론의 한계) |
- ⚠️ 예고 OX: "문제를 단순하게 분해하고 단순한 것 → 복잡한 것으로 가는 방법은 흄에게서 유래" → **X**(데카르트).
- 칼 포퍼: **반증 가능성**.

**③ 이론·모델로 연구자는 무엇을 이루나? 왜 새 이론이 나오나?** 🟠
- 특정 현상의 **설명** + 일어나지 않은 현상의 **예측**.
- 사회·기술은 계속 변한다 → 학자들이 시기마다 새 설명을 낸다. "All Models Are Wrong, Some Are Useful"(Box).

**④ 커뮤니케이션 이론의 4가지 구분과 특징** 🔴 (예시 → 이론 이름 / A·B 비교 서술)
| 이론 | 핵심 | 방법 | 수업 예시 |
|---|---|---|---|
| **Communication Science** | 측정 가능한 증거로 **과정·효과** 확인(고전적 효과 논의) | **양적** | 금연 캠페인 긍정 vs 부정 메시지 효과 비교 |
| **해석 이론** | **텍스트**와 행동의 **해석**, 문화·사회적 **맥락** | **질적**(인터뷰) | 주부 20명 인터뷰로 판매 부진 원인, 청소년에게 공포 금연광고가 안 먹히는 이유, 미드소마·데몬 헌터스의 국가별 해석 |
| **비판 이론** | 사회 **개혁**, **불평등·권력** | 마르크시즘 계열, **유럽** 뿌리 | 드라마가 특정 직업·연애를 "정상"으로 강요 |
| **규범 이론** | 사회 운영의 **이상적 기준** 설정 | 정치·법학과 연계 | AI 규제 기사, 언론 자유의 한계, AI 생성물 표시 의무, 수정헌법 1조·사전 검열 |
- 비판 vs 규범: 둘 다 더 나은 사회를 향하지만 **기준을 세우는 쪽 = 규범**, **권력·불평등을 드러내는 쪽 = 비판**.
- 🟥 해석 이론: 정량적 데이터로는 행동의 **특정 측면만** 이해. 사건이 **왜·어떻게** 일어났고 **함의가 무엇인지**. "같은 텍스트, 다른 해석".
- 🟥 비판 이론: 미디어는 **긍정적인 역할만 하지 않는다**(경계해야 한다).
- 연결: **허친스 위원회 → 규범 이론** (9.30), 샘플 지문 "청소년 콘텐츠 규제 연구 → **규범**".

**⑤ 예시를 주면 어떤 맥락(이론)인지 답할 수 있나?** → ④ 표의 예시로 연습.

**⑥ 매스 미디어 모델과 뉴 미디어 모델의 차이 (키워드 — 송신·수신자의 관계)** 🔴 (OX·식별)
| | 대인 | **매스 미디어 모델** | **뉴 미디어 모델** |
|---|---|---|---|
| 관계 | 일대일 | **일대다** | 경계가 흐려짐 |
| 수신자 | 특정 | **불특정 다수** | 수신자도 생산·공유 |
| 상호작용 | 상호작용적 | **제한적**(일방향) | 피드백·참여 쉬움 → **masspersonal** |
- 예고: "수신자가 다수이고 피드백이 어렵다 → 어떤 모델?" → **매스 미디어 모델**.
- 기초 모델: **송신자 → 메시지 → 매체 → 수신자**. 같은 메시지도 매체 기술이 다르면 **다른 커뮤니케이션 경험**.

### 🗣️ Key Points 밖 수업 언급
- 미디어 = **medium의 복수형**, 라틴어 **medius**(중간). 12세기 "두 지점 사이" → 14세기 교환 관계를 **조직**하는 사람·기관 → 19세기 중반 **대중 소통 채널**.
- 지식을 얻는 세 방법: 경험·직관 → 권위(누적된 경험) → **과학적 연구·절차**.
- 19세기 이후 **공간·시간·이웃** 개념 변화. 20세기 미디어의 **제도화·산업화·일상화** → 정부·기업 투자 → 커뮤니케이션 연구 발전.
- 미디어는 커뮤니케이션 모델의 **구성 요소**이자 새 사회 현상을 이끄는 **배경 혹은 주체**.
- 유명인끼리 공개 멘션 주고받기 = **masspersonal** 예. 뉴 미디어 모델까지는 정립됐다.
- **Shaper / Mirror / Representation**: 교수님 합의점은 "대표적인 것만 뽑아 반영(Representation)".
- 시험 준비는 **Key Points + 시험 안내 자료**(p.4), 시험은 객관식·단답형·(서술형)(p.6).
- 🟥 미디어는 **"공기처럼"** 받아들여지고 사람마다 **다른 방식**으로 쓴다 → 미디어 탐구 = 인간·사회 탐구.
- Winner(1980) "Do Artifacts Have Politics?": 기술·인공물은 중립이 아니라 **정치적 성격**을 가질 수 있다(→ Week 02 위너).

### ⚪ 안 나온다고 한 것
- 현대 미디어 모델의 지형(콘텐츠·산업·기술·사용자·사회): "**시험에는 안 나옵니다**."
- 과학철학 세부(데카르트·흄은 키워드만).

## 2. Week 02 — 기술 발전과 미디어 (9.9·9.14·9.16·9.21)

### 📌 Key Points 문항 → 답 (p.55\~56)
**① 새 미디어 기술은 어떻게 받아들여지나? 왜 기존 미디어 역사를 공부하나? (한 문장)** 🔴 빈칸 예고
- 미디어 기술은 **대체되지 않고 축적**된다. 새 미디어는 기존 미디어와 **충돌하고, 기존 관행을 재현·재구성**하며 각자 영역을 찾거나 병합된다 → 그래서 과거를 알아야 현재가 보인다.

**② 기술과 사회 관계를 설명하는 두 접근법의 이름·내용·차이** 🔴 (설명 → 키워드)
| | **기술 결정론** | **사회 구성주의** |
|---|---|---|
| 핵심 | **기술**이 사회 구조·문화의 주요 요인 | 기술은 **사람들이 어떻게 쓰는지**에 따라 결정 |
| 접근 | **환원주의**(부분을 알면 전체를 안다) | **전체론**(전체를 알아야 부분이 이해된다) |
| 변화 | **불가피**, 사회적 맥락·인간 선택의 영향 작음 → "인간 자율성" 비판 | **사회적 합의**의 결과, 언어·담론이 방향을 정함 |
- 둘은 대립이 아니라 **연속된 논의 공간**.
- 예고: "전체론적 접근, 전체를 알아야 부분이 이해된다" → **사회 구성주의**.

**③ 각 접근법의 대표 학자와 이론 (위너 vs 휴즈)** 🔴 (예시 구분 / OX / 빈칸)
| | **랭던 위너** | **토마스 휴즈** |
|---|---|---|
| 이론 | **자율적 기술**(Autonomous Technology) | **기술적 모멘텀**(Technological Momentum) |
| 요지 | 기술 체계가 너무 얽히고 강력해 **인간 통제를 제약**, 의도치 않은 결과 → 순진한 결정론을 넘어 **기술의 정치성**(설계·배치가 정치·사회 질서를 만든다) | 초기엔 유동적 → 투자·습관·기술 기반 문화가 쌓이면 **바꾸기 어려워짐**. 온건·절충, **soft determinism** |
| 시험용 예시 | **낮은 교량**, **LLM 검열 기준**을 누가 정하나, 스마트폰-앱스토어-반도체 공급망 연쇄 | **110V/220V**, USB, TV 프로그램 포맷, 일본 **플로피 디스크**, 코볼, 천공카드 도개교 |
- 한 줄: 위너 = 기술이 **정치적으로** 누른다 / 휴즈 = 초기 선택이 **눈덩이처럼** 굳는다.
- **SCOT**(기술의 사회적 구성 이론, "욕심 있다면 물어볼 수 있다"): 기술의 의미·설계·방향은 **여러 사회집단의 해석과 이해관계** 속에서 결정. 예: penny-farthing(속도) → **safety bicycle**(안전).

**④ Medium Theory 두 관점의 핵심 주장 (예시 구분 / 주관식 서술)** 🔴
- 공통 전제: 매체는 중립적 도구가 아니라 **세상을 보는 틀·현실 인식 감각**에 영향을 준다(이전엔 미디어 = 중립적 도구).
- **맥루한(긍정)**: "**The medium is the message**" — 콘텐츠보다 **매체의 형식·특성이 만드는 사회적 변화**가 중요(아이팟 → 음악 감상 행위 자체가 변함). 미디어 = **감각의 확장**(The Extensions of Man).
- **포스트먼(부정)**: 매체는 서로 다른 사고·행동을 유도한다. **인쇄**(논리·맥락·분석, 긍정) → **전신**(정보의 **탈맥락화**: "내 삶에 중요한가?" → "새롭고 흥미로운가?") → **사진**(맥락이 있는 것처럼 보이게) → **TV**: **오락이 많은 게 아니라 모든 주제가 오락의 형식으로** 제시된다 → 합리적 숙고·논증 중심의 공적 담론 약화. 『죽도록 즐기기』, "**Now… this**", "They entertain each other", 『테크노폴리』의 **지식 독점**.
- ⚠️ 주관식에서 "긍정론자 vs 부정론자"만 쓰면 기본 점수 → **핫·쿨**, **전신·TV가 왜 문제인지**를 써야.

**⑤ 맥루한은 미디어를 어떻게 구분했나? 새 미디어에 대한 태도는?** 🔴
| | **핫 미디어** | **쿨 미디어** |
|---|---|---|
| 해상도·정보량 | **높음** | **낮음** |
| 감각 | **단일** 감각 | **다감각** |
| 참여 | **적게** 요구(수동) | **능동적** 참여(스스로 보완) |
| 예 | 인쇄물, 라디오, 영화 | 전화, 만화, **1960년대 TV** |
- 구분은 **고정되지 않는다**(TV는 지금은 핫 쪽, 로블록스는 쿨?). "라디오는 핫이냐 쿨이냐" 같은 문제는 **안 낸다** → **기준 + 예시 1\~2개로 서술**.
- 태도: **낙관**(쿨 미디어 = 전자매체가 정보 흐름·접근성을 바꿔 사회에 강한 영향) + 단편화·불안정 우려도.

**⑥ 포스트먼 미디어 비판의 핵심 논리** → ④ 참조. 핵심 한 문장: "**모든 주제가 오락의 형식으로 제시된다**."

**⑦ 이니스(시간·공간 편향)와 옹(글쓰기는 인위적 기술)** 🔴 (OX / 괄호 — 샘플: **순서 정확히**)
| 이니스 | **시간 편향** | **공간 편향** |
|---|---|---|
| 성격 | **내구성**, 오래 지속 | **일시적**, 짧게 유지 |
| 청중 | **제한된** 청중 | **장거리**, 빠르게 |
| 예 | 점토, 석판 | 서신 (※ PDF의 TV는 교수님이 덧붙인 예) |
| 사회 | 안정성(PDF "안전성"), 공동체, 전통 → **종교** | 변화, 세속, 물질주의 → **중앙집권적 제국** |
- 이니스, 『The Bias of Communication』(1951): **미디어는 사회·정치·문화 구조를 형성**한다. 사회 번영엔 **두 미디어의 균형**. 맥루한에 영향.
- **옹**, 『Orality and Literacy』(1982): 구술(즉흥, 운율·반복, 집단적, 구체적) vs 문자(축적·보존, 시각적, 개인적, **추상·분석적**). 문자 문화 → **분석적 사고 패턴**, 아는 사람 ≠ 아는 것(지식의 체계화), **과거·현재·미래의 선형적 시간 인식**.
- **"글쓰기는 인위적인 기술"**: 말은 타고나지만 글은 훈련이 필요. 플라톤 『파이드로스』의 비판(기억 파괴, 반응 안 함, 자기 방어 불가)에 대해 옹은 **인위성이 장점**(피아노·바이올린), 글쓰기 = **가장 중요한 기술**, 청각 → 시각으로 사고 확장.
- ⚠️ 예고 OX: "옹은 문자 문화가 구술 문화 **다음의 발전 단계**라고 했다" → **X**(서로 다른 체계).

**⑧ 인쇄 매체는 기존 미디어와 어떻게 결합했고 공론 환경을 어떻게 바꿨나 (타이포그래피, 공적 논의, 루터)** 🔴 (OX 위주)
- 새 미디어는 이전 관행을 **재현·재구성** → 대표 예 **타이포그래피**(필사를 모방하다 인쇄에 맞는 표준 서체·문장부호로). **인쿠나블라**(1450\~1500) = 필사를 모방한 **과도기** 인쇄본.
- **루터**: **자국어(독일어) 성경** → 지식 독점에 도전 → **지식의 대중화**(독학 가능 수준), **인쇄 매체를 통한 공개 논박 = 공적 논의 환경**. 브로드사이드 → 뉴스 형식, 카페·선술집의 공통 화제. 비판: 담론 저속화, 가짜 뉴스.

**⑨ 전신·전화가 가져온 변화 (메시지 전달 속도, 표준 시간·가격대, 언론재벌)** 🟠
- 전신: **"운송" → "전송"**, 메시지가 전달자보다 빨라짐. **표준 시간대, 통일된 가격·정보** → 인식 세계 확장. 자본 집중 → **언론재벌**.
- 전화: 전신과 달리 **가정문화**, **사적 영역**으로. 경쟁 → 통합 → **공공 서비스** 편입.

**⑩ 빌트모어 협정의 배경·진행·결과** 🔴 (서술 "3개 이상" / OX)
- 배경: 1930년대 **Press-Radio War**(신문: "기사를 훔쳐 간다", AP 공급 차단 1933).
- 협정(1933): **신문에 유리**, 라디오 뉴스는 오전·오후 짧게만.
- 결과: 단기 효과, **장기 실패** — ① **독립 라디오 방송국** ② **해설자 고용**(분석·맥락) ③ **라디오 광고 급성장** ④ **자체 뉴스 공급망**.
- 결말: 라디오 = **속보**, 신문 = **탐사보도**로 분화. "협정 자체보다 **금지가 어떻게 우회됐는지**"가 중요.
- ⚠️ 샘플 OX: "빌트모어 협정으로 라디오는 TV 뉴스 등장 때까지 쇠퇴기를 겪었다" → **X**.
- 예고 OX: 네이버 뉴스와 언론사의 공급 갈등은 빌트모어 협정의 재현 → **O**.

**⑪ 방송문화의 발전: 보드빌·라디오·TV는 어떻게 연결되나** 🔴 (OX)
- **보드빌 → 라디오 쇼 → TV 쇼**로 **인력·포맷**이 흡수됨 → "TV 포맷은 보드빌의 영향" **O**.
- 라디오: 기업 방송국, 집에서 문화를 즐김. TV: 전후 가정 필수품, 라디오 방송국(NBC·CBS)이 흡수.
- **I Love Lucy**: **3카메라 기법**, 35mm, 재판매, 스폰서·광고 문화 → **현대 시트콤 체계화**. ⚠️ "보드빌 영향으로 **롱테이크**" → **X**.

**⑫ 인터넷 미디어만의 특징과 그 이유 (개방·분산 구조, 비상업적 공유·공개 문화, 팀 버너스 리)** 🔴
- **ARPANET(1969)**: 냉전기 ARPA에서 **공적 목적**으로 개발(상업 목적인 다른 미디어와 차이). 노드가 끊겨도 다른 경로로 전송 → **개방·분산 구조**(통제·독점이 어려움), 연구실 출신이라 **특허 없이 공유**(오픈소스 문화).
- 특징: **빠른 확산**(페이스북 6년 5억), 개방·분산, 사용자 경험 강조. 자유로운 공론의 기대 vs 지금은 복합적 평가.
- **팀 버너스 리**: WWW, HTML·HTTP·URL을 **무료 공개**. ⚠️ "선택받은 기업·사람에게만 공개/라이선스" → **X**(샘플에도 나옴).

**⑬ 키워드: 패킷, 노드, HTTP, HTML, 하이퍼텍스트, programming priesthood** 🟠
- **패킷** = 작은 블록으로 분할된 메시지 / **라우팅** = 최적 경로 탐색 / **노드** = 네트워크에 연결된 장치
- **HTML** = 문서 공유 형식 / **HTTP** = 전송 규칙 / URL = 주소 형식
- **하이퍼텍스트** = 하이퍼링크로 연결된 **비선형·상호연결** 텍스트(테드 넬슨 제안)
- **programming priesthood** = 테드 넬슨이 비판한 "기술 사제"(기술 독점) ↔ 루터 시대 사제의 지식 독점과 같은 구조

**⑭ 닷컴 버블과 인터넷 미디어에 미친 영향 (소셜 미디어, Web 2.0)** 🔴 (키워드)
- 90년대 후반 투자 과열(수익 모델 부재, 광고 시장 미성숙) → 붕괴 → 살아남은 기업들의 **Web 2.0**("정보 제공" + **"상호 연결"**) → **소셜 미디어**. 키워드 답은 "닷컴 버블"("닷컴 거품" OK).

### 🗣️ Key Points 밖 수업 언급
- 간접적 기술 영향: **물레방아**(마을 단위), **열차**(생활권·여가 확장). 문자 메시지로 진로 상담 → "무례"(상호작용 맥락이 아직 미확정).
- **1952 CBS의 UNIVAC 선거 예측**: 컴퓨터가 아이젠하워 당선을 예측했지만 방송국이 믿지 못함 → 기술 진보와 **수용 속도의 차이**(과학 지식 + 사회문화 배경 + 상징적 사건).
- 미디어 발전 7지점: 생각을 위한 도구 → 문자 → 인쇄 → 전기·유선(**운송 → 전송**) → 이미지·소리의 저장 → 무선 방송 → 컴퓨터·인터넷.
- **extra-somatic memory**(인체 외부 기억) → 토큰 → 문자. 페니키아 문자(자음만, 표음 문자에 영향).
- **키푸**: 관점에 따라 시간·공간 편향 둘 다 가능 → "이건 어느 쪽?" 문제는 **안 낸다**. **그리오**: 서아프리카 구술 문화의 역사가·중재자.
- 영국(**수신료·공영방송**, BBC) vs 미국(**민영·상업방송**) — Raymond Williams(1974), 사회 구성주의·문화연구의 예.
- 목판과 활판은 **같이** 발전. **조용한 독서 → 색인 보편화**(색인이 인쇄로 "처음" 생긴 게 아님 ⚠️).
- **타이타닉**: 속보, 무선 전신 실시간 보도, **오보**의 상징적 사건. 철도 옆에 전신선 → 통신·교통은 "의미적으로만" 분리.
- 영화: **니켈로디언**(도시 노동자·이민자의 **새로운 사회적 접점** — 샘플 OX O), 영화 궁전, 보드빌 쇠퇴(반복 상영), 유성영화(『재즈 싱어』, 연기·표준어 변화).
- 라디오 재원: 미국 사유화 / 유럽 정부후원 / 캐나다 혼합. 집에 모여 듣는 문화.
- TV: **Texaco Star Theater**(버라이어티, 스타 진행자 밀턴 벌 "Mr. Television"), **닐슨 시청률**. 엘비스(시청각 충격). I Love Lucy의 **PPL** 원형(가짜 상품 에피소드).
- 방송 기술: 1960\~70 케이블·위성(HBO 프리미엄, 1970 월드컵 컬러 중계), CG(Babylon 5 에미상), **TiVo·DVR "time-shifting"**, **MTV = 광고와 전문화된 음악 콘텐츠의 결합**(샘플 OX O), Thriller(스토리 있는 뮤직비디오).
- 정치: **닉슨 vs 케네디**(라디오 청취자는 닉슨, TV 시청자는 케네디 → 매체가 결과를 바꿈), **Daisy 광고**(1964, 최초의 네거티브 광고 → 규제 논의).
- 인터넷: NSFNET 백본 **1995** 종료 → 상업 ISP. Gopher·WAIS → WWW·Mosaic. **Webvan**(쿠팡식 모델, 실패) vs **Amazon**(책부터). 모바일 → **24시간 온라인**, 온·오프 경계 흐려짐.

## 3. Week 03 — 고전적 미디어 효과 이론 (9.23·9.28·9.30)

### 📌 Key Points 문항 → 답 (p.49\~50)
**① 기술 발전이 초기 매스 미디어에 미친 영향 (대량생산, 페니 프레스, 독자층·수익 전략)** 🔴 (OX/키워드)
- 인쇄기술(대량생산) + 교통·통신 → **페니 프레스**(1833, 벤자민 데이, 1센트) → **노동자·중산층** 대상, **광고 수익 모델**(구독료·후원금 의존 ↓) → 주제가 정치·경제 분석에서 **범죄·스캔들·속보**로. "같은 정보를 공유하는 대중"의 탄생.

**② 초기 경쟁 환경이 부른 보도 태도 → 옐로우 저널리즘** 🔴 (키워드)
- 판매를 위해 **선정적 헤드라인, 과장·조작, 감정적 호소, 불분명한 정보원, 자기 과장 홍보**를 쓰는 보도. **1890년대 퓰리처(뉴욕 월드) vs 허스트(뉴욕 저널)** 경쟁. ⚠️ 표기: "옐로우 저널리즘" 또는 "황색 언론".

**③ 기술적 연구와 설명적 연구의 차이** 🔴 ("이건 시험에 나온다")
| | **기술적(Descriptive)** | **설명적(Explanatory)** |
|---|---|---|
| 질문 | **무엇이** 일어나나("이게 뭐지?") | **왜·어떻게**("어떻게 돌아가지?") |
| 방법 | 관찰, 체계적 묘사, 가설보다 데이터 수집(탐색적) | **가설 → 검증**, 인과·메커니즘 |
| 예 | 버튜버 시청자 인터뷰 | 실존 인물 vs 가상 캐릭터 건강 메시지 효과 |
- 상호보완적(기술적 → 설명적). 예시 → 차이 서술, 빈칸 → 기술/설명.

**④ 블루머의 연구가 "효과" 연구에서 중요한 이유 (연구방식, 미디어 효과 인식)** 🟠
- 『Movies and Conduct』(1933), **페인 펀드 13개 연구 중 하나**. ① **연구방식**: 초기 **대규모** 실증 연구, 관습적 방법 대신 **탐색적**(에세이·설문·심층 인터뷰) ② **효과 인식**: 영화는 단순 오락이 아니라 사상·인식·현실 해석에 영향을 주는 미디어("진정한 교육 기관", 모방, **극단성을 보통처럼** 제시, 연애 방식).

**⑤ 리프먼의 관점 (스테레오타입, 동의의 제조, 엘리트) / ⑥ 듀이의 입장** 🔴 (OX)
- **리프먼 『여론』(1922)**: 현대 사회는 너무 복잡 → **스테레오타입**으로 단순화(대부분 언론이 형성) → 소수 엘리트에 의한 **동의의 제조**(긍·부정을 떠나 "그렇다") → 평균인은 고도화된 의견을 갖기 어렵다 → **전문가의 여론 형성 불가피**.
- **듀이**: 문제 진단에는 **동의**, 그러나 엘리트주의 비판 — 민주주의는 **대중의 교육과 참여**로 발전해야 한다.
- ⚠️ 예고 OX: "듀이는 민주적 가치를 함양해 대중이 이슈를 이해하는 것에 반대했다" → **X**.

**⑦ (학술적) 패러다임의 의미** 🔴 (OX/키워드, 서술 X)
- **한 시대의 지배적인 세계관·생각의 바탕**(예: 천동설·지동설). 커뮤니케이션학에서는 강효과 시기를 **직접효과 패러다임**이라 부름.

**⑧ 직접효과와 제한효과의 차이** 🟠
- **직접효과**(강효과, 교수님: "주사 이론"): 메시지가 **도달하기만 하면** 효과가 난다. 20세기 중반까지 지배적, 세계대전 배경. 비판: 단순화·선형화(단, 사후적 비판이고 "주류 연구"의 방향).
- **제한효과**: 효과가 **없다는 게 아니라** 생각보다 **약하고 일부에만**, 조건에 따라 다르다. 사회**심리학의 실험**, 사후 분석이 아닌 **예측**. ⚠️ "효과 없음"으로 바꾼 OX 주의.

**⑨ 직접효과의 대표 학자와 이론 / 라스웰 vs 섀넌·위버** 🔴 (누구의 주장인지 OX)
| | **라스웰** (정치학) | **섀넌·위버** (공학) |
|---|---|---|
| 관심 | 엘리트가 대중 사회에서 아이디어의 순환을 **조직**하려고 소통을 어떻게 쓰나, **선전**·사회적 기능 | **지점 간 정보의 효율적 전달**, 정보량·전송 용량·**노이즈**의 수학적 분석 |
| 산물 | 선전 연구(1927), **미디어의 기능**, **SMCRE** | 정보 이론(1949), **노이즈**, **redundancy**, **엔트로피**, 정보 = **불확실성의 감소** |
- 섀넌·위버 핵심 두 가지: ① 정보를 **숫자로 환산**해 계산 ② 전송 중 **노이즈**(손실) → **부가 정보 삽입(redundancy)**.

**⑩ 선전 기술의 종류와 내용 (기사 → 어떤 기법인지 설명)** 🔴 (주관식 가능, "제가 좋아하는 유형")
| 기법 | 내용 | 수업 예 |
|---|---|---|
| **Name calling** | 근거 없이 **나쁜 이름** → 거부·비난 | 정치인 멸칭 |
| **Glittering generality** | 증거를 요구하지 않게 **미덕 있는 단어**와 연결 | "새 희망 기금" 반대 = 새 출발을 막는 것 |
| **Transfer** | 존경받는 **가치·권위**를 옮겨 붙임 | "구글 매니저 출신" |
| **Testimonial** | 존경·혐오받는 **인물의 발언** | 원로 스님의 덕담 |
| **Plain folks** | **평범한 사람** 강조 | 전통시장 튀김, "서민 가정 출신" |
| **Card stacking** | 사실·부정확한 사실을 **선택적**으로 | "재취업률 95%"(곧 퇴사 은폐), 범죄율 5배(경범죄 포함) |
| **Bandwagon** | **다들** 받아들였다 | "지지율 1위" → 여론조사 공표 금지 |
- 출처: IPA(1937)의 『The Fine Art of Propaganda』(1939). ⚠️ **라스웰이 쓴 책 아님**. 이름 철자는 대충 OK, 보기에서 고를 수 있게.

**⑪ 키워드: SMCRE, 미디어의 기능, 엔트로피, 노이즈** 🔴
- **SMCRE**: Sender(누가)–Message(무엇을)–Channel(어떤 채널로)–Receiver(누구에게)–Effect(어떤 효과로). 5개 다 쓰기·글자 바꾸기 문제 X. "라스웰이 제시"만.
- **미디어의 기능**(라스웰, 1948, 미디어 = 사회기관): ① **감시**(사건 감시·전달) ② **상관**(연결·해석) ③ **문화유산 전달**. ⚠️ **오락은 후속 학자가 추가** → 보기 함정.
- **엔트로피**: 정보의 **불확실성·무질서 정도**. 명작 vs 스팸 → 아무렇게 친 글자가 정보량이 더 많다(예측 불가). **콘텐츠는 중요하지 않고 예측 가능성이 핵심**.
- **노이즈**: 메시지를 손상시킬 수 있는 **모든 것**.

**⑫ 제한효과의 대표 학자와 이론 (호블랜드 실험, 수면자 효과, 2-Step Flow)** 🔴
- **호블랜드**(예일, 심리학, 전쟁부 의뢰): 『Why We Fight』 시청 vs 비시청 → **지식**·일부 의견 ↑, **태도** 제한적, **복무 동기** 변화 없음 → **정보 전달 ≠ 설득**, 효과는 개인의 신념·태도·가치관에 따라 다름. 의의: 직접효과 약화 + 현대 **설득 연구**의 기반.
- **수면자 효과**: **즉각적 vs 장기적** 효과의 차이(5일보다 9주 뒤 효과가 큼, 비시청 집단은 변화 없음). 이유: 출처 의식이 흐려짐 / 메시지와 반론의 연결 약화. ⚠️ 녹취의 "수면제 효과"는 오기.
- **라자스펠드**(컬럼비아, 정량 분석) → **2-Step Flow**: 미디어 → **오피니언 리더**(매체로 정보를 받아 **자기 관점으로 해석**) → 추종자. 1940 에리 카운티 패널(600명·7회): 다수가 선거 운동 전 결정, 바꾼 사람은 소수, 선택은 **사회적 맥락**의 영향 → 선거 운동은 **기존 성향 강화·참여 촉진**. 디케이터(여성 800명, 패션·영화·공공 문제·쇼핑): **분야마다 다른** 오피니언 리더, 다양한 계층.
  - 🔴 예고: 현상 → "라자스펠드의 이론은?" **2-Step Flow** / "메시지를 잘 보고 전달하는 A는?" **오피니언 리더**. ⚠️ "여론 리더" X.
- **클래퍼**: 미디어는 기존 태도를 **강화**(강화 이론). 영향은 개인 성향·사회 관계·집단 소속·문화 규범의 **매개** → **현상론적 접근**.

**⑬ 초기 미디어 규범 논의 (언론의 4계급, 허친스 위원회의 결론과 의의)** 🔴
- **제4계급**(18세기 영국, 에드먼드 버크): 입법·사법·행정에 더한 **4부**, **정부의 감시자** → 언론 자유 보장 이유.
- **허친스 위원회**(1947): 언론은 정부 통제를 받지 않지만 **자유로운 사회의 유지·발전에 기여할 책임** → **수정 자유주의**, **사회적 책임 이론**의 시작. 지식인 12명(**언론인 없음**), 출판사·편집자 반발. 영향: 사설, **옴부즈맨**, 편집위원회 외부 참여.
- 🔴 "허친스 위원회와 관련된 이론 분류는?" → **규범 이론**. (PDF 본문 "허친스", Key Points·교수님 발음 "허친슨" — 허친스 권장)

**⑭ 언론의 자유와 통제에 대한 4가지 이론** 🔴 (예시 → 이론)
| 이론 | 구분 포인트 | 예 |
|---|---|---|
| **자유주의** | **무제한적 자유**(실제론 존재 어려움) | 누구나 아무 책이나 |
| **사회적 책임** | 자유 + **필요한 경우** 정부 규제 | 방송 면허·주파수 경매, 영화 등급 |
| **권위주의** | 정부의 **검열·라이선스**(허가) | 『돈키호테』 초판 왕실 허가 문구 |
| **전체주의** | **국가가 미디어 조직(생산 수단) 소유**, 선전 도구 | 방송국 직원이 공무원 (원래 이름: 소비에트 공산주의 이론) |

### 🗣️ Key Points 밖 수업 언급
- **Great Moon Hoax**(1835, 『The Sun』): 가짜 저널·실존 전문가 이름 → 처벌 법이 없어 대박 → 다른 신문도 따라 함 → 옐로우 저널리즘 촉진. **옐로 키드** 만화가 두 신문에 연재.
- 산업화·도시화: 서로 모르는 이질적 사람들의 밀집 → 종교·전통 대신 **미디어가 사람들을 묶는 역할**.
- **〈우주전쟁〉**(1938 할로윈, 오슨 웰스): 캔트릴(프린스턴) 『The Invasion from Mars』 — 600만 청취, 100만 공포. 반론: 청취율 **2%**, 유도 질문 설문, **신문의 라디오 공격**, 신화가 남은 이유 = **이야기의 힘**. 요지: 방송은 관심을 한 점으로 모으고, 새 미디어엔 **작용·반작용**.
- 가짜뉴스 공식: 재미 + 일부 진실 + 공포·거부감. Vox 가짜 레스토랑 실험 → 항상 의심.
- 커뮤니케이션학의 기원 두 입장: 그리스 레토릭부터 vs **1·2차 대전 이후 융합 학문**(교수님은 후자). 라스웰은 원래 **정치학자**. 정체성 논쟁(기자 직업훈련 vs 통계·실험 분석) → 후자가 이김.
- 선전의 정의(라스웰): 이야기·소문·보도·그림 등 **사회적 커뮤니케이션**으로 **opinion을 통제**.
- 섀넌·위버는 공학자에 가깝다. 위버의 세 문제: **기술적**(정확한 전달) / **의미적**(의도한 의미) / **효과**(행동에 영향).
- 『Why We Fight』: 진주만 이후, 프랭크 캐프라, 7편, 적군 선전영화 활용. 실험의 **무작위 배정**.
- 수면자 효과 사례: "MSG 유해"를 어디서 들었는지 기억 못 함, 연예인 탈세 오보 뒤 정정을 기억 못 함.
- 2-Step Flow의 약화·부활: **TV 보급**으로 약화(종전 뉴스는 직접 들은 사람 50% 미만 vs 케네디 암살은 TV로 직접 본 사람 50% 이상) → **소셜 미디어 인플루언서**로 부활, 원하는 뉴스만 골라 봄.
- 클래퍼(1960) 정리 4가지: 직접 영향은 드물다 / 2단계 흐름 / 다른 영향이 거부·수정 / 효과는 적당하고 격리된 수준. → 측정 부정확·요소 제한 반성 → 1960년대 이후 정교화·분화.
- **블루머의 상징적 상호작용론**(영화 연구 블루머와 같은 사람): 개인은 메시지의 **능동적 해설자**, 미디어는 **기호와 서사**를 제공 → 현실의 재구성, **사용자 중심 접근**(HCI)에 영향.
- **아이디어의 시장**(수정헌법 1조, 제퍼슨) vs 허친스. 옴부즈맨은 **제재 권한 없음**(토요일 오전 시청자 의견 프로).
- 『뉴스룸』(이상주의) vs 『네트워크』(냉소: 자극 추구, 사망 장면 직후 광고).
- 효과 이론 분화 도식: 직접 → 제한(1930\~70) → 1970년대 전후 개인 수준(심리학)·사회 수준(사회학)·비판·문화로.

### ⚪ 안 나온다고 한 것
- 인쇄기 속도 수치, rhetorical vs empirical, 포커스 그룹 등 연구 기법 세부, 섀넌·위버 모델 그림 암기, 위버 해설 경위, 엔트로피 응용 연구, 오락 기능을 추가한 학자 이름, SMCRE 5개 쓰기.

### 📌 Key Points 문항 → 답 (p.56\~57)
**① 중효과 이론의 등장 배경 (인지혁명, TV의 등장과 채널 다양성)** 🟠
- **연구 정체**: 베럴슨(1959) "커뮤니케이션 연구는 **쇠퇴·죽어가고** 있다"(새 아이디어 부족) → **카츠의 반론**: "미디어가 사람에게 무엇을 하나"보다 **"사람들이 미디어로 무엇을 하나"**, 청중을 사회·심리 변수로 **분류**하자.
- **TV 확산**(1950\~60): 효과가 제한적이라는데 하루 종일 TV 보는 사람들 → 효과를 잘못 본 것 아닌가.
- **채널 증가**(Big Three → 케이블·위성): **선택권** ↑ → "이제는 보낸다고 다 받지 않는다" → 상호작용하는 이용자.
- 설득 전통(아리스토텔레스 로고스·에토스·파토스, 청중을 동일 집단으로 봄)의 한계. Herzog(1940s) 라디오 연속극 동기 연구는 패러다임 밖이라 외면.
- **인지 혁명**(1960s): **행동주의**(자극 → 조건화 → 행동, 명시적 행동만) → **촘스키**(언어 습득은 자극·반응으로 불가) → 마음의 **정보 처리 모델**.

**② 이용과 충족 이론은 "연구 대상" 관점에서 과거와 어떤 차이? (수용자 중심, 이용 동기, 선택)** 🟠
- 메시지의 효과 → **수용자가 왜·어떻게 미디어를 선택·이용하는지**. 핵심은 "이용하면 충족된다"가 아니라 **충족되는 욕구를 정교하게 구분**한 것. 궁극적으로는 효과를 이해하려는 노력(니즈를 알면 그 니즈를 채우는 콘텐츠를 만든다).

**③ 5개 동기 구분 (예시 → 어떤 동기?)** 🔴
| 욕구 | 내용 | 예 |
|---|---|---|
| **인지적** | 정보·지식·이해 강화 | 신문으로 국제 정세, 대선 후보·어제 사건 |
| **정서·감정적** | 미적·즐거움·감정 경험 | 음악·드라마 감동 |
| **개인 통합**(인지+감정) | 신뢰성·자신감·안정성·지위 | GDP 상승, 오징어게임·K팝 흥행 뉴스(뿌듯함), **자기계발서** — "예제는 노골적으로 이 둘 중" |
| **사회적 통합** | 가족·친구·세상과의 연결 | 가족과 TV, 친구와 드라마 수다 |
| **도피·완화** | 자신·사회적 역할과의 접촉 약화 | 『반지의 제왕』 마라톤 |

**④ 5개 가정 구분 (주장 → OX)** 🔴
1. **능동적 청중** 2. **청중 주도성**(선택·만족의 주도권은 청중) 3. **미디어 간 경쟁**(다른 자원과 경쟁) — 1\~3은 "청중은 능동적"이면 거의 풀림
4. **자기 인식**: 사람들은 미디어 이용 **이유·동기를 충분히 인식**(아니면 조사가 무의미)
5. **가치 중립성**: **연구자**가 문화적 가치 판단을 **보류** — ⚠️ **유일하게 연구자에 대한 가정**, 가장 많이 틀림
- 예고 OX: 연구자 A "건전한 사회라면 권장되기 어려운 현상", "사회에 매우 부정적이라 분석 필요" → **5번 위배**.

**⑤ 의제설정·프레이밍·프라이밍 구분** 🔴
| 이론 | 한 줄 | 설명하는 것 | 지문 단서 |
|---|---|---|---|
| **의제설정** | 많이 다루면 **중요하다고 인식** | **무엇이** 중요한 이슈인가 (찬반 X) | "○○ 보도가 늘자 ○○를 가장 중요한 문제로 꼽은 사람 증가" |
| **점화(프라이밍)** | 강조된 이슈가 **판단 기준**이 됨 | 그 이슈로 **누구를 어떻게 평가**하나 | "선거 중 외교 충돌 보도 → 후보의 외교 능력이 평가 기준" |
| **프레이밍** | **구성 방식**에 따라 해석이 달라짐 | **어떻게 이해·해석**하나, **누구 책임**인가 | 같은 사건 다른 헤드라인, 개인 책임 vs 사회 책임 |

**⑥ 의제설정의 핵심과 한계 (부모·자식 비유)** 🔴
- 배경: 1970년대 제한효과에 의문 → 행동(X) → **의견·태도(인지적 효과)**, 직접(X) → **중·장기·간접**. **코헨(1963)**: "무엇을 생각할지"는 몰라도 **"무엇에 대해 생각할지"** 는 놀랍게 성공. **가장 대표적인 중효과 이론**.
- **의제의 종류**: **미디어 의제 / 공중 의제 / 정책적 의제**, 한정된 시간·공간에서 **경쟁**, 언론 내부 선택 = **게이트키핑**. 질문: 미디어 의제가 공중 의제에 영향을 주나?(salience → importance)
- **McCombs & Shaw(1972)**: 1968 대선, **채플힐**, 미결정 유권자 100명 → 매체 강조 이슈와 유권자 중요 이슈의 **상관이 매우 높음**, 선호 후보와 무관하게 **매체 전체**의 보도를 따름(대안적 설명 = 선택적 소비와 반대).
- 한계: 연구상(부동층, **상관 ≠ 인과**, 선후 관계) → 샬럿 연구로 보강. **근본 한계**: 무엇이 **중요한지**는 설명하지만 **찬성·반대 전개는 예측 불가**.
- **"언론은 여론을 낳은 부모"**(McCombs): 자식의 **존재**까지는 영향, **어떻게 자랄지**는 손 못 씀.
- ⚠️ 예고 OX: "의제설정 이론에 따르면 앞으로의 찬성·반대는 언론 보도에 달려 있다" → **X** ("매력적인 오답").

**⑦ 프레이밍을 통한 기사 설명 (기사 + 이론·학자)** 🔴
- **정의**: 뉴스가 현실을 특정 방식으로 **선택·강조·요약**해 이해·해석 범위에 영향. **구성주의**: 언론은 사회를 정확히 반영(X) → **사회적 동의를 유도해 의미·해석을 만든다**(O). 오리/토끼.
- **엔트먼(1993)**: 정의가 **일관성 없음**("fractured paradigm") 비판. 정의 = 일부 측면을 **선택·강조**하고 연결해 **특정 해석·평가·해결책을 촉진**. 기능 = 문제 정의 → 원인 진단 → 도덕적 판단 → 해결책 제안(목록 암기 X). **공적 논의의 범위를 제한, 권력 강화**(전쟁/제재만 → **협상** 배제).
- **아이옌거(1991)**: 프레임에 따라 **책임 귀인**이 달라짐 — **일화 중심**(개인·사건 → **개인 책임**) vs **주제 중심**(사회·정치·경제 맥락 → **사회·정부 책임**). **TV 뉴스는 일화 중심 경향** → 민주주의에 부정적.
  - 🔴 예고: 인터넷 도박("A씨가 1억 날렸다" = 일화 / "청년 실업·SNS 부자 문화" = 주제), 뒷광고("유튜버 윤리" = 일화 / "법·제도 미비" = 주제).

**⑧ 프라이밍을 통한 기사 설명 (OX·키워드)** 🔴
- 의제설정 이후 **여론의 변화 방향**(Iyengar & Kinder, 1987). 언론의 강조 → 공중이 그 **개념·용어를 계속 사용** → 정치적 판단에 영향. 지식 = **개념들의 연결망**.
- 실험(Iyengar, Peters & Kinder, 1982): 조작한 저녁 뉴스(국방·오염·물가) → 의제설정 + **그 이슈로 대통령 평가**(점화). **도덕성 평가엔 약함**, **정치적으로 무지한 사람이 더 취약**(반박 논증 부족).
- 사례: **1980 대선 이란 인질 사태 → 카터 외교 능력이 기준 → 레이건 승리**, **『The West Wing』**(드라마·가상 정치인도 영향).
- 🔴 예고: "대선 중 외국과 외교 충돌 보도 → 후보 평가" → **프라이밍**. 샘플: "선거 기간 청소년 사고 뉴스 반복 → 후보의 청소년 교육관을 평가 기준" → **O**.

**⑨ 키워드: 의제(의 종류), 점화효과(활성화 확산, 의미 점화), 프레이밍의 공명·반복·내러티브** 🔴 ("OX 나오기 딱 좋다", "키워드 나오기 쉽다")
- **활성화 확산**: 한 개념이 활성화되면 의미망을 따라 **관련된 여러 개념으로 퍼짐**(네트워크 전체가 켜짐)
- **의미 점화**: 선행 개념의 활성화로 관련 **후속 개념의 기억·처리가 촉진**. 샘플: "**하나의 개념이 다른 하나의 개념을 떠오르게 하는 것** = 의미점화"
- **미디어 점화**: 미디어가 이슈를 강조 → 접근 가능성 ↑ → 이후 판단의 **평가 기준**
- **공명**(resonance): 시대·환경적 맥락이 맞으면 큰 반향(반대도 가능) / **반복**: 공명하는 프레임에 반복 노출 → 그 프레임으로 사건 이해 / **내러티브**: 지식 체계와 안 맞아도 **이야기가 그럴듯하면** 해석의 근거
- (+) 프레임 이해엔 이용자의 **지식 체계**가 어느 정도 필요. **갬슨**: 프레임 = **구성적 줄거리**.

**⑩ 침묵의 나선의 작동 (여론, 공표, 다수, 소속 욕구)** 🔴
- **노엘레 노이만**(독일, 1973 "Return to the concept of powerful mass media"): **집단의 동조 압력 + 미디어의 영향**.
- 사람은 **고립에 대한 공포**(소속 욕구) → 자기 의견이 **다수인지** 알고 싶어 함 → 미디어가 지배적 의견을 **공표** → 소수라고 **느낀** 사람은 자기 검열·침묵 → 다수 의견이 더 지배적으로 보임(**나선**). 여론 = 고립의 공포 없이 **정체를 드러내며** 말할 수 있는 의견. ⚠️ 다수·소수는 **인식된** 것(실제와 다를 수 있음).
- 교수님: "**공표** 개념과 **침묵으로 피드백이 강화**된다는 것 정도만."

**⑪ 침묵의 나선의 한계 (재현이 어려운 이유, 측정 한계)** 🔴 (OX)
- 재현 연구의 **결론이 일관되지 않음** → **문화적 차이**(Scheufele & Moy, 2000), **다원주의 사회**(미국)에서는 잘 안 나타남.
- **측정**: "말할 **의도**가 있습니까?"(X) → "말한 **적이** 있습니까?"(O). 교육 수준·주변 관계·이슈 속성과 상호작용.
- 언론 비판: 기존 권력을 강화하나? 단편적 보도?

**⑫ 배양 이론의 연구 배경 (TV의 폭력성) / ⑬ 핵심 가정 / ⑭ Mean World Syndrome / ⑮ 비판** 🔴 ("한 문장짜리 → OX")
- 배경: 1968 **린든 존슨**의 "폭력의 원인과 예방에 대한 국가위원회" → TV 내용 분석 → 약 **30년 문화 지표 프로젝트**(TV 폭력 모니터링 + 시청자 사회 인식 조사), **거브너**.
- 가정: TV는 단순 오락이 아니라 **장기간에 걸쳐** 세계관·사회 인식을 **배양**한다.
- **Mean World Syndrome**: **TV를 많이 보는 사람**(4시간 기준)일수록 범죄 희생 가능성·이웃 불안·사회의 범죄 증가를 **과대평가**.
- 또 다른 발견: TV에는 현실보다 **폭력·사고 빈도가 높다**(18세까지 살인 4만 건 — 부정확).
- 비판: TV 현실이 그렇게 다른가(**드라마만** 연구), **인과**가 있나(**지역 범죄율 통제** 시 실제 위험 지역 사람이 더 느낌) → **"효과는 있으나 강력하다고 보긴 어렵다"** → 그래도 **포기·냉소주의** 우려.
- 🔴 예고 지문: "폭력 게임 회사 과징금, 청소년이 폭력에 너무 노출" → **배양 이론**.

### 🗣️ Key Points 밖 수업 언급
- 베럴슨 비판의 두 의미(교수님): 초석 학자들의 **은퇴**, 10년 넘게 같은 질문 → **확장판**만.
- DuMont = TV 제조사 출신, 네트워크·자본 부족 → 1956년부터 **Big Three**.
- 아리스토텔레스는 **에토스**를 가장 중요하게 봄(당시엔 혈통·외모).
- Herzog: 주부들이 라디오 연속극을 듣는 이유 = **감정적 해방, 희망적 사고, 조언 획득**.
- Katz 외(1973): 이스라엘 1,500명, 35개 질문, **비매체 자원과 비교**. 매체는 개인·대인보다 **사회·정치적 욕구**에 더 유용, 많은 욕구는 **비매체**로 충족, **TV는 다재다능하지만 특화 없음**, **신문은 국가·사회 인지**에 가장 유용, TV와 가장 대체 가능한 매체 = **라디오**, 가장 어려운 매체 = **책**.
- U&G 비판 3가지: **능동성**(TV를 배경음악처럼), **자기 기록**의 객관성(교수님의 "대부 효과"), **라스웰 기능과 뭐가 다르냐**. 이후: 로그·시청률 기기 등 새 측정, **청중 → 사용자**(Ruggiero 2000, Sundar & Limperos 2013). U&G는 아직 현역(클럽하우스는 왜 흥했다 사라졌나).
- 의제설정은 **mass보다 public(공중)** 선호. **salience(눈에 띔) ≠ importance(중요 인식)** — 학계는 중요하게 구분(시험은 OX 정도).
- 프라이밍: 너무 먼 것(대통령 가창력)은 연결 안 됨, 지식이 많으면 새 요소 끼워 넣기 어려움, 이미 너무 중요한 이슈(**경제**)는 효과가 안 커짐(상승 여지 없음). 영상: 간호사 → "주사", **코카콜라는 뉴스 직후 광고 안 함**. "스타" 말고 **애스터리스크**.
- 이슈 관리: 과거(기자 대접) → 현대(**트렌드 유도, ESG**). "갑질" 연결은 끊기 어렵다, 의도적 바이럴은 어렵다. 다다음 주 **스핀 닥터** 예고.
- 프레이밍 3버전 해석: Ver1 국회의원 **개인 비난** / Ver2 행정 신뢰 + **사회운동 부정** / Ver3 **행정**에 대한 비난. 프레임은 "귀에 걸면 귀걸이" → 두세 개만. 강자 vs 약자(언더독) 서사.

**① 배비지·러브레이스·폰 노이만이 컴퓨터 발전에 미친 영향 (OX)** 🔴
- **라이프니츠**(17세기): **이진 시스템**. 디지털 = 라틴어 **digitus**(손가락), 정보를 **이산적인 숫자 값**으로.
- **찰스 배비지**: **"해석 기관"** 개념(거대한 계산기, 당시 미완성).
- **에이다 러브레이스**: 다양한 **알고리즘**(최초의 프로그래머), **루프문·조건문·서브루틴**, **아날로그 현상을 수치화**(0과 1로 환산)한다는 개념.
- **폰 노이만**: **입·출력 + CPU + 메모리** 구조(EDVAC). **프로그램 내장형**: 메모리에 프로그램·자료를 같이 저장, **물리적 재배치 없이 소프트웨어적으로 프로그램 변경** ↔ 초기 진공관의 **프로그램 외장형**(연산마다 배선·스위치를 물리적으로 재배치). "OX 정도"(10.12).
- 배경: 세계대전의 **복잡한 계산**(암호 해독, 탄도 계산) → Colossus(1943), ENIAC(1945) → 전후 과학·상업 용도.

**② IBM과 Apple은 현대 컴퓨터에 어떤 영향? (OX)** 🔴
- **IBM**: 1950년대 **상업적 목적**의 컴퓨터(UNIVAC 등과 함께), IBM PC(1981) **개방형 아키텍처** → **수많은 호환 기기**(조립 PC, 표준화).
- **Apple**: **Apple II**(1977) = **완제품 PC + 유저 친화적 디자인·구조**(확장 슬롯, 소프트웨어) → 대중화. **Macintosh**(1984) = **GUI와 마우스**를 도입한 대중적 컴퓨터(엄밀히는 "처음"이 아니라 **대중화**).
- ⚠️ "이게 최초냐"는 안 묻는다 → "초기 컴퓨터는 대중 친화적이지 않았는데 **애플로 대중화**됐다", "**사용자 친화적 인터페이스**로 애플이 인기" 식.
- Altair 8800(1975): 대중화의 상징이지만 **조립식**.

**③ 키워드: GUI, HCI, WYSIWYG, 폰 노이만 구조(장점)** 🟠
- **GUI**: 그래픽으로 명령하는 사용자 인터페이스(키보드 명령어 입력 대신). Xerox PARC 고안, Mac이 대중화.
- **HCI**(Human-Computer Interaction): 인간과 컴퓨터의 상호작용 연구. 『The Psychology of HCI』(1983, Card·Moran·Newell)가 연구관 확립, **심리학 원리·방법**을 적용. GOMS 모델.
- **WYSIWYG**: What You See Is What You Get — **보이는 대로 출력**(스펠링 대충 OK).
- 폰 노이만 구조의 장점 → ① 참조.

### 🗣️ Key Points 밖 수업 언급

- 벨은 "정보사회"라는 말을 직접 쓰진 않았다(후에 발전). 토플러는 40년 전에 **쇼츠·피드**를 예견. 롱테일 예: 쿠팡 재구매 추천.
- 카스텔: 같은 매출이라도 **정보 기업**이 더 강한 영향력. **코로나** 때 화이트칼라(재택)는 이득, 블루칼라는 출근 비용 ↑ → Net vs Self 양극화. 디지털 노마드 vs 로컬 노동.
- 셔키: 전국 맛집 지도(인지 잉여), 시민단체의 예산·납품 분석.
- 벤클러: 모듈성 = 큰 배의 **격벽 구조**, 게임 번역 분업. 나무위키(자발적 편집), 크라우드 펀딩. 2006년의 기대 → 지금은 공론장이 **과도**해짐("언론 말고 유튜브를 믿어").
- 소셜 미디어라 부르는 이유: 모든 미디어는 사회적이지만, 소셜 미디어는 **구체적 지시 없는 참여 틀 + 커뮤니티 구축**. 플랫폼 용어 난립(IT의 "깃발 꽂기").
- 인터넷 역사는 옛것이 **리메이크·부활**하는 경우가 많다.
- BBS: 내 컴퓨터를 서버로 → 전화선 접속(전화비, 전화 불통), 텍스트로 그림 그리기. 유즈넷: 지역 서버 → 주기적 **동기화**(이메일 CC처럼), 레딧·DC인사이드·더쿠 같은 하위 게시판 구조, 그룹마다 규칙 다름.
- **Godwin's Law**: 대화가 길어질수록 나치 비유가 나올 확률이 높아진다(키배가 길어지면 결국 욕).
- PC통신: 웹소설의 원조(『퇴마록』, 『드래곤 라자』 등), 텍스트 머드 → **『바람의 나라』** → **『리니지』**.
- 쇠퇴 이유 보충: BBS는 접속자가 많으면 터짐, 유즈넷은 동기화 **트래픽** 폭증 + 자동 관리 불가로 **무법지대**(불법 복제), 구글 검색, 뉴비 텃세.

### [5-부록] 수업 미진행 p.31\~42 (공지 범위에 포함되면 볼 것)
- **The Well**: 최초의 인터넷 커뮤니티 중 하나(캘리포니아 히피 문화, Whole Earth Catalog). BBS → 인터넷 포럼. **실명 인증(+가명) + YOYOW(You Own Your Own Words, 자율규제) + 유료 구독**. 운영은 대부분 **유저**. 심도 있는 대화 → **EFF** 설립, 라인골드 『The Virtual Community』(1993).
- **Web 2.0**: 팀 **오라일리**가 대중화, "유저 참여·창작". 새 현상이 아니라 사회적 상호작용의 **인터넷 확장**. **Six Degrees**(1997\~2001): 프로필 + 친구 맺기. 밀그램 Small World 실험(평균 약 6.2번 전달).
- **블로그**: Web + Log, Jorn Barger "Weblog", 2000년대 블로그 플랫폼, **RSS 피드**로 추적·수집 쉬워짐, 링크·댓글로 연결된 **Blogosphere** → 정치·사회 토론장. 국내 싸이월드.
- **SNS**: Friendster·MySpace 쇠퇴, LinkedIn·Facebook·Twitter. **Boyd & Ellison(2007)**: ① 공개·반공개 **프로필** ② 다른 사용자와 **연결** ③ 연결 목록을 보고 탐색.
- 소셜 미디어 정의: Carr & Hayes(2015) 인터넷 기반·비동시적·지속적 **매스퍼스널** 채널, 사용자 생성 콘텐츠에서 가치. 최근: 광고·AI로 "참여"가 사라짐.

## 9. 서술형(A/B 택1, 10문장 이내) 대비 — 문장 뼈대

> 샘플 A형이 "데카르트와 흄"이었다. 아래는 **10문장 이내**로 쓰는 뼈대. 키워드(굵게)를 꼭 넣을 것.

**① 데카르트와 흄이 학문적 모델·이론에 미친 영향** (샘플 A형)
1. 학자들은 복잡한 사회 현상을 분석하려고 **모델·이론**을 만든다.
2. 데카르트는 **합리적 연역**의 입장에서, 절대 무너지지 않는 토대("나는 생각한다")에서 출발해 지식을 쌓았다.
3. 그의 **4원칙**은 복잡한 대상을 **최소 요소로 분해**하고 단순한 것에서 복잡한 것으로 **종합**하는 방법이다.
4. 이는 현상을 단순한 구성 요소로 나눠 모델링하는 방식(예: 송신자-메시지-매체-수신자)의 바탕이 됐다.
5. 흄은 **경험주의** 입장에서 경험에 회의적 관점을 도입했다.
6. 과학적 법칙과 인과는 필연적 진리가 아니라 **반복된 경험에 근거한 개연적 추론**이라는 **귀납의 문제**를 제기했다.
7. 이는 이론에 **한계**가 있고 언제든 수정될 수 있다는 인식으로 이어졌다(cf. 포퍼의 **반증 가능성**).
8. 그래서 연구자는 모델로 현상을 **설명**하고 **예측**하지만, 사회가 변하면 새 모델이 계속 나온다.
9. "All models are wrong, some are useful"이라는 말이 이를 보여 준다.

**② 맥루한 vs 포스트먼** — 공통 전제(매체는 중립적 도구가 아님) → 맥루한(미디어는 메시지, 감각의 확장, 핫·쿨 기준 2개 + 예시, 낙관) → 포스트먼(인쇄 → 전신의 탈맥락화 → 사진 → TV, 모든 주제가 오락의 형식, 공적 담론 약화, Now… this) → 한 줄 대비.

**③ 핫·쿨 미디어** — 기준 ①해상도·정보량 ②참여(+감각) → 핫 예시 1개와 이유 → 쿨 예시 1개와 이유 → 구분은 시대에 따라 변한다(1960년대 TV는 쿨).

**④ 빌트모어 협정이 실패한 이유** — 배경(Press-Radio War, AP 차단) → 협정 내용 → 실패 원인 4개(독립 방송국, 해설자, 광고 수익, 자체 공급망) → 결과(속보 vs 탐사보도 분화) → 네이버 뉴스 재현 사례.

**⑤ 직접효과에서 제한효과로** — 직접효과(라스웰·섀넌·위버, 주사 이론, 세계대전 배경) → 실험 도입(심리학) → 호블랜드(지식 ↑, 태도·동기 제한, 수면자 효과) → 라자스펠드(2-Step Flow, 오피니언 리더) → 클래퍼(강화, 현상론적 접근) → 효과는 없지 않고 조건적.

**⑥ 의제설정의 내용과 한계 + 후속 이론** — 코헨 → 의제 3종·게이트키핑 → McCombs & Shaw 결과 → 한계(찬반 예측 불가, 부모 비유, 상관 ≠ 인과) → 점화(평가 기준)·프레이밍(해석 방식)으로 확장.

**⑦ 이용과 충족이 이전 연구와 다른 점** — 베럴슨·카츠 → TV·채널·인지 혁명 배경 → 수용자 중심(이용 동기·선택) → 5개 욕구 → 5개 가정(가치 중립성) → 비판과 현대화.

**⑧ 침묵의 나선의 작동과 한계** — 노엘레 노이만·동조 압력 → 고립 공포 → 다수 파악 욕구 → 미디어 공표 → 침묵 → 나선 → 인식된 다수 → 한계(문화 차이, 다원주의, 측정: 의도 vs 행동).

**⑨ 벨·토플러·카스텔(·셔키·벤클러) 비교** — 벨(정보활동, 정보사회) → 토플러(대중화 X, 좁은 방송, blips, 롱테일) → 카스텔(정보사회는 단기적, 네트워크 사회, 흐름의 권력, Net vs Self) → (셔키·벤클러: 협력·공론장).

**⑩ BBS vs 유즈넷과 현대 소셜 미디어** — 구조(개별 서버·중앙 vs 분산·동기화) → 범위(로컬 vs 글로벌) → 문화(익명 게시판 vs 스팸·Flame Wars·Godwin's Law) → 한계(접속 제한 vs 트래픽·관리) → 쇠퇴(그래픽 웹·검색엔진) → 현대 소셜 미디어로 계승.
