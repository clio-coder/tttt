# 2026-2 학교 공부 정리

수업 내용을 정리한 마크다운 노트 모음입니다.

## ⚠️ 업로드 규칙 — 반드시 지킬 것

이 레포에는 **학습 내용을 정리한 마크다운(`.md`) 노트만** 올린다. 예외 없이 지킨다. 그 밖의 파일은 절대 올리지 않는다.

**올리는 것**

- 수업 내용을 정리한 노트: 강의·장별 정리, 문법·본문 정리, 시험 대비, 예상 문제·모의고사, 퀴즈 분석, 빈칸 정답
- 목차 역할의 README: 이 파일, 과목 README, 노트 목차

**올리지 않는 것**

- 노트를 만드는 방법을 적은 작업용 문서: `정리 규칙.md`, 자료 출처 확인, 자료 선별 안내 등
- 수업자료 원본: PDF, 슬라이드, 사진, 녹음·스크립트
- 과제·실습 파일: 제출물, 코드(R·Python 등), 데이터, `.Rhistory`
- 그 밖에 `.md`가 아닌 모든 파일

**링크:** README나 노트에 올리지 않은 파일로 가는 링크가 있으면, 레포에 올리는 사본에서 그 링크를 뺀다.

## 수식 작성 규칙 — GitHub에서 깨지지 않게

GitHub은 수식 안에도 마크다운 처리를 먼저 하고, 한 페이지에서 렌더링하는 수식 양에 한도가 있다. 이를 어기면 "Unable to render expression."이 뜨거나 수식이 조용히 틀리게 나온다.

| 쓰지 말 것 | 대신 쓸 것 | 이유 |
| --- | --- | --- |
| 한 파일에 수식이 너무 많음 | 파일을 나눈다 | 수식 개수 + `{` 개수가 약 2,000을 넘으면 그 뒤 수식이 전부 렌더링되지 않는다 |
| `\operatorname{Var}` | `\mathop{\mathrm{Var}}\nolimits` | GitHub이 `\operatorname`을 막는다 |
| `\\` (행렬·aligned 줄바꿈) | `\cr` | `\\`가 `\`로 바뀐다 |
| `\{`, `\}` | `\lbrace`, `\rbrace` | 백슬래시가 사라져 중괄호가 안 보이거나 `\left{` 오류 |
| `\,`, `\!` | `\thinspace`, `\negthinspace` | `,` `!`가 그대로 찍힌다 |
| `\;`, `\:` | `\ ` | 같은 이유 (`\medspace`, `\thickspace`는 GitHub에 없음) |
| `\\|` | `\Vert` | 같은 이유 |
| `\%` | 퍼센트는 수식 밖에 쓴다 | `%`는 주석이라 뒤가 잘린다 |
| `$$` 블록 안의 `<`, `>` | `\lt`, `\gt` | 뒤쪽이 HTML 태그로 읽혀 사라진다 (인라인 `$…$`은 괜찮다) |
| 문장·목록·표 안의 `\begin{pmatrix}` 등 | 빈 줄로 둘러싼 최상위 `$$…$$` 블록 | `\begin`이 든 수식은 그 경우에만 인식된다 |
| `}_{`, `)_{` | `}_ {`, `)_ {` | 밑줄이 기울임꼴 표시로 짝지어져 수식이 통째로 깨진다 |
| `*` | `\ast` | 같은 이유 |
| `Bernoulli$(p)$`, `"$x$"` | 여는 `$` 앞에 공백 | 여는 `$`는 공백·`(` 뒤에서만 인식된다 |
| `$0.1\cdot$randn` | 닫는 `$` 뒤에 공백 | 닫는 `$` 바로 뒤에 영문자가 오면 인식되지 않는다 |
| `…(x)$)` | `…(x){}$)` | `)$)`는 닫는 `$`로 인식되지 않는다 |
