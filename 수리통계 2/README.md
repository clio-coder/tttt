## 학습목표

통계적 추론의 주요 개념과 방법을 학습한다. 수리통계학 1을 간략히 복습한 뒤 자료축소, 점·구간추정, 가설검정, 베이즈 추론, 점근이론을 다룬다. 여유가 있으면 붓스트랩과 인과추론도 다룬다.

이수 후에는 다음을 할 수 있어야 한다.

1. 통계적 추론의 기본 개념과 수학적 원리를 설명한다.
2. 최대우도추정법과 베이즈추정법을 유도하고 비교한다.
3. 가설검정의 기본 원리와 대표 검정법을 설명한다.
4. 점근이론으로 추정량의 근사분포를 유도한다.
5. 통계적 추론과 머신러닝의 관계를 설명한다.
