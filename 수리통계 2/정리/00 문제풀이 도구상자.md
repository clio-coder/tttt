### 1.2 답안 체크리스트

내 hw1 제출 풀이에서 실제로 나온 실수를 바탕으로 만들었다 (자세한 내용은 각 장 노트의 hw1 "내 풀이 점검").

- ☐ **부호:** 지수족의 $-A$, Chernoff의 $-\lambda t$. 다 쓴 식을 원래 식으로 되돌려 검산했나? (hw1 #5(b))
- ☐ **부등호의 엄격성:** $\ge$ vs $>$. 경계값 ($a=0$, $\sigma^2=0$)을 넣어 봤나? (hw1 #1(d), #2(e))
- ☐ **적용 범위:** 꼬리부등식은 $t > 0$, Chernoff는 $\lambda > 0$, 분포수렴은 연속점. (hw1 #2(d))
- ☐ **근거 한 단어:** 어느 줄에서 독립·평균 0·볼록성·CMT를 썼는지 밝혔나? (hw1 #4(c), #7)
- ☐ **스케일:** 합의 편차 $\epsilon$ vs 평균의 편차 $t$ ($\epsilon=nt$), 분모는 $\sum(b_i-a_i)^2$
- ☐ **양측이면 ×2:** 합집합으로 두 꼬리
- ☐ **두 꼬리 모두:** $M_n/c_n\xrightarrow{p}1$은 아래·위 꼬리를 **둘 다** 보여야 한다
- ☐ **지시함수:** support가 모수에 의존하면 결합밀도에 $\prod I(\cdot)$를 쓰고 $\min$· $\max$로 바꿨나?
- ☐ **분해정리:** $h$에 $\theta$가 숨어 있지 않나? $g_\theta$는 $T(x)$를 통해서만 $x$에 의존하나?

## 3. 도구 카드

카드마다 **언제 · 틀 · 나온 곳**. 장 노트의 `[T…]` 표시가 이 번호다.

### T1 Markov
- **언제** 비음 확률변수의 꼬리를 기댓값으로 누를 때. 모든 꼬리부등식의 출발점.
- **틀** $X\ge t\thinspace I(X\ge t)$ → $\Pr(X\ge t)\le\mathbb EX/t$. 일반형: 증가 $\varphi\ge0$이면 $\Pr(X\ge t)\le\mathbb E\varphi(X)/\varphi(t)$.
- **나온 곳** [ch1 2](ch1%20집중부등식.md#2-markov-부등식), Chebyshev, Chernoff, hw1 #4(f)

### T2 Chernoff
- **언제** " $\Pr(\cdots\ge t)\le e^{-\cdots}$" 꼴을 보일 때.
- **틀** $\lambda > 0$: $\Pr(X\ge t)\le e^{-\lambda t}\mathbb Ee^{\lambda X}$. MGF가 $e^{c\lambda^2/2}$ 이하이면 $\lambda^\star=t/c$, bound $e^{-t^2/(2c)}$.
- **나온 곳** [ch1 4.1](ch1%20집중부등식.md#41-chernoff-bound), Hoeffding, 대칭화 (f), Bernstein, ch1 V1·V3

### T3 독립이면 MGF가 곱
- **언제** 합이나 평균의 MGF.
- **틀** $\mathbb Ee^{\lambda\sum X_i}=\prod\mathbb Ee^{\lambda X_i}$ (독립 필수 — 빠지면 반례: 모두 같은 변수).
- **나온 곳** [ch1 5.2](ch1%20집중부등식.md#52-hoeffding의-부등식), hw1 #4(e), ch1 V4

### T4 볼록성
- **언제** 지수함수를 위에서 누를 때, 기댓값과 함수의 순서를 바꿀 때.
- **틀** 현: $x=\theta a+(1-\theta)b$이면 $g(x)\le\theta g(a)+(1-\theta)g(b)$. Jensen: $\varphi(\mathbb EY)\le\mathbb E\varphi(Y)$ (조건부도). Hölder: $\int f^cg^{1-c}\le(\int f)^c(\int g)^{1-c}$.
- **나온 곳** hw1 #1(b), #4(c), [ch2 2.3](ch2%20모수모형과%20지수족.md#23-자연모수공간은-볼록집합), ch1 V5

### T5 Taylor 나머지항
- **언제** $L(0)=L'(0)=0$이고 $L''$를 상수로 누를 수 있을 때.
- **틀** $L(h)=L(0)+L'(0)h+\frac{L''(\xi)}2h^2$, $\xi$는 0과 $h$ 사이 → $L(h)\le\frac{\sup L''}2h^2$.
- **나온 곳** hw1 #1(f)

### T6 u(1−u) ≤ 1/4
- **언제** 로지스틱·베르누이형 2계도함수 ($pe^h/(1-p+pe^h)$ 꼴).
- **틀** $u(1-u)=\frac14-(u-\frac12)^2$.
- **나온 곳** hw1 #1(e), 베르누이 분산 $p(1-p)\le1/4$ (Chebyshev 예제)

### T7 분산은 제곱오차의 최솟값
- **언제** 분산의 상계.
- **틀** $\mathbb E(Z-c)^2=\mathop{\mathrm{Var}}\nolimits Z+(\mathbb EZ-c)^2\ge\mathop{\mathrm{Var}}\nolimits Z$. $Z\in[a,b]$이면 $c=\frac{a+b}2$로 $\mathop{\mathrm{Var}}\nolimits Z\le\frac{(b-a)^2}4$.
- **나온 곳** hw1 #2(b), ch1 V4(d)

### T8 대칭화
- **언제** 평균 0인 변수의 MGF를 Rademacher로 바꿀 때.
- **틀** 독립 복사본 $X'$: $e^{sX}\le\mathbb E[e^{s(X-X')}\mid X]$ (조건부 Jensen) → $X-X'\overset{d}{=}\varepsilon(X-X')$ → $(X,X')$에 조건부로 $\cosh$ bound.
- **나온 곳** [ch1 6.3](ch1%20집중부등식.md#63-대칭화로-hoeffding약한-판-증명), hw1 #4(c)(d)

### T9 급수 비교
- **언제** $\cosh$, 짝수 차수만 남는 급수.
- **틀** $(2k)!\ge2^kk!$ → $\sum\frac{s^{2k}}{(2k)!}\le\sum\frac{(s^2/2)^k}{k!}=e^{s^2/2}$. 비슷한 것: $2\cdot3^{k-2}\le k!$ (유계형 Bernstein).
- **나온 곳** hw1 #4(b), [ch1 7.3](ch1%20집중부등식.md#73-유계형-bernstein)

### T10 합집합
- **언제** 양측 꼬리, 여러 사건 (함수집합, 최댓값의 위 꼬리).
- **틀** $\Pr(\bigcup A_k)\le\sum\Pr(A_k)$. 양측 = 2 × 단측.
- **나온 곳** Thm 1.6 양측, hw1 #4(f), #7 위 꼬리, ch1 V5·V7, First Borel–Cantelli

### T11 지수족 레시피
- **언제** "지수족으로 나타내라".
- **틀** ① $\log f$ 전개 ② 섞인 항 = $\eta^\top T$, $x$만 = $\log h$, 모수만 = $-A$ ③ $A$를 $\eta$로 ④ 자연모수공간 = $\lbrace\eta:\int he^{\eta^\top T} < \infty\rbrace$ 직접 계산. 검산: 원래 밀도로 되돌리기, $A'$ = 평균.
- **나온 곳** [ch2 3.2](ch2%20모수모형과%20지수족.md#32-지수족-꼴로-쓰는-4단계-레시피), hw1 #3, #5

### T12 이차형식
- **언제** 정규분포 (특히 다변량), 제곱합 분해.
- **틀** $(x-\mu)^\top\Sigma^{-1}(x-\mu)=x^\top\Sigma^{-1}x-2\mu^\top\Sigma^{-1}x+\mu^\top\Sigma^{-1}\mu$, $x^\top\Lambda x=\mathop{\mathrm{tr}}\nolimits(\Lambda xx^\top)$, $\sum(x_i-\mu)^2=\sum(x_i-\bar x)^2+n(\bar x-\mu)^2$.
- **나온 곳** hw1 #5, [ch4 3.2](ch4%20자료축약.md#32-ex-43-정규-표본)

### T13 정규화 항등식 미분
- **언제** 지수족의 평균·분산·누율.
- **틀** $e^{\psi(\alpha)}=\int e^{\alpha^\top t}f_0$ 미분 → $\dot\psi=\mathbb Et$, $\ddot\psi=\mathop{\mathrm{Var}}\nolimits t$. MGF: $\mathbb E_\alpha e^{s^\top t}=e^{\psi(\alpha+s)-\psi(\alpha)}$.
- **나온 곳** [ch2 5](ch2%20모수모형과%20지수족.md#5-누적생성함수와-theorem-21), ch2 V2·V3·V5

### T14 Chebyshev로 확률수렴
- **언제** 평균·분산 계산이 쉬운 통계량의 $\xrightarrow{p}$.
- **틀** $\Pr(\lvert X_n-c\rvert > \epsilon)\le\mathbb E(X_n-c)^2/\epsilon^2$.
- **나온 곳** WLLN, Thm 3.2, ch3 V5

### T15 편향–분산 분해
- **언제** " $\xrightarrow{qm}c$를 보여라".
- **틀** $\mathbb E(X_n-c)^2=\mathop{\mathrm{Var}}\nolimits X_n+(\mathbb EX_n-c)^2$ → 평균 → $c$, 분산 → 0.
- **나온 곳** [ch3 3.2](ch3%20확률변수의%20수렴.md#32-보충-편향분산-분해), hw1 #6, ch3 V8

### T16 최댓값·최솟값의 CDF
- **언제** $\max$· $\min$의 확률수렴, 극한분포.
- **틀** $\Pr(\max\le x)=F(x)^n$, $\Pr(\min > x)=(1-F(x))^n$, $\Pr(\max\ge x)\le n(1-F(x))$. $M_n/c_n\xrightarrow{p}1$은 **두 꼬리**.
- **나온 곳** [ch3 7](ch3%20확률변수의%20수렴.md#7-보충-최댓값과-최솟값-다루기), Ex 3.5, hw1 #7

### T17 지수 극한과 부등식
- **언제** $(1-a/n)^n$ 꼴.
- **틀** $(1-x/n)^n\to e^{-x}$, $1-x\le e^{-x}$ → $(1-p)^n\le e^{-np}$.
- **나온 곳** Ex 3.5, hw1 #7, ch3 V1–V3

### T18 CMT와 Slutsky
- **언제** 수렴을 함수·곱·합으로 옮길 때, 모르는 모수를 추정량으로 바꿀 때.
- **틀** $g$ 연속이면 $g(X_n)\to g(X)$ (p, d). $X_n\xrightarrow{d}X$, $Y_n\xrightarrow{p}c$이면 $X_n+Y_n\xrightarrow{d}X+c$, $X_nY_n\xrightarrow{d}cX$. **$Y_n$의 극한은 상수**여야 한다.
- **나온 곳** [ch3 6](ch3%20확률변수의%20수렴.md#6-cmt-slutsky-clt), hw1 #7 마지막 단계, ch3 V3·V4

### T19 Borel–Cantelli
- **언제** a.s. 수렴.
- **틀** 모든 $\epsilon$에서 $\sum_n\Pr(\lvert X_n-X\rvert > \epsilon) < \infty$ ⟹ a.s. (First BC: $\sum\Pr(A_n) < \infty$ ⟹ $\Pr(A_n\text{ i.o.})=0$). 반대 방향 (a.s. 아님): 독립 + $\sum=\infty$ → Second BC.
- **나온 곳** [ch3 8](ch3%20확률변수의%20수렴.md#8-보충-almost-sure-수렴과-borelcantelli), ch1 V9, ch3 V1·V6

### T20 엡실론 샌드위치
- **언제** CDF의 수렴을 보일 때 (p ⟹ d, Slutsky).
- **틀** $F(x-\epsilon)-\Pr(\lvert X_n-X\rvert > \epsilon)\le F_n(x)\le F(x+\epsilon)+\Pr(\cdots)$ → lim inf/lim sup → $\epsilon\downarrow0$ (연속점).
- **나온 곳** [ch3 4.2](ch3%20확률변수의%20수렴.md#42-thm-33-확률수렴이면-분포수렴), Slutsky 보충 증명

### T21 정의로 충분성
- **언제** 이산형이고 "정의로 보여라" 또는 분해가 안 보일 때.
- **틀** $\Pr_\theta(X=x\mid T=t)=\Pr_\theta(X=x)/\Pr_\theta(T=t)$ ($T(x)=t$)를 계산해 $\theta$가 사라지는지.
- **나온 곳** Ex 4.1, 4.2, ch4 V7 (연속형은 결합밀도/주변밀도)

### T22 분해정리 + 지시함수
- **언제** 충분통계량을 보이거나 찾을 때 (거의 항상).
- **틀** $p_\theta(x)=h(x)g_\theta(T(x))$. support가 모수에 의존하면 $\prod I(x_i\ge\theta)=I(\min x_i\ge\theta)$, $\prod I(x_i\le\theta)=I(\max x_i\le\theta)$. 관측마다 모수가 다르면 먼저 공통 조건으로 ($x_i/i$).
- **나온 곳** [ch4 3.3](ch4%20자료축약.md#33-보충-support가-모수에-의존할-때), hw1 #8, #9, #5(e)

### T23 우도비 판정법
- **언제** "최소충분통계량을 구하라".
- **틀** $p_\theta(y)=k(x,y)p_\theta(x)$ ∀θ ⟺ $T(x)=T(y)$. 지수 부분은 $T(y)-T(x)$의 계수가 0, 지시함수 부분은 $\theta$ 구간이 같아야.
- **나온 곳** [ch4 5](ch4%20자료축약.md#5-최소충분통계량), ch4 V2·V3·V8·V10, hw1 #9 보충

### T24 충분하지 않음 보이기
- **언제** "충분하지 않음을 보여라".
- **틀** $T$의 값 하나를 정하고 그 값을 주는 점들을 나열 → 조건부확률 하나가 $\theta$에 의존하면 끝 (반례 하나).
- **나온 곳** Ex 4.2의 $X_1$, ch4 V6

### T25 MLE의 존재와 유일성
- **언제** "MLE가 존재하고 유일함을 보여라", 가능도방정식의 근이 최대인지 확인할 때.
- **틀** 모수공간을 벗어나면 (경계·무한대로 가면) $\ell\to-\infty$ → 존재. 헤시안 음정치 (1차원: $\ell'' < 0$) → 유일, 그리고 $\nabla\ell=0$의 근 = MLE.
- **나온 곳** [ch5 1.3](ch5.3-5.5%20최대가능도추정.md#13-존재와-유일성), 로지스틱 (튜터링2 문제2)

### T26 재매개화로 오목하게
- **언제** 원래 모수로는 로그가능도가 오목이 아닐 때.
- **틀** 율 $\lambda=1/\theta$, 정밀도 $1/\sigma^2$, 자연모수 $\alpha$ 등으로 바꿔 순오목 → MLE → 불변성으로 되돌리기.
- **나온 곳** [ch5 2.3](ch5.3-5.5%20최대가능도추정.md#23-재매개화로-오목하게-만들기), hw2 #3, ch5 V1

### T27 점수의 Taylor 전개
- **언제** MLE·한 단계 추정량의 점근분포를 **증명**할 때.
- **틀** $0=S_n(\hat\theta)=S_n(\theta_0)+(\hat\theta-\theta_0)S_n'(\tilde\theta)$ → $\sqrt n(\hat\theta-\theta_0)=\lbrace-\frac1nS_n'(\tilde\theta)\rbrace^{-1}\frac1{\sqrt n}S_n(\theta_0)$ → 분모 LLN ($I$), 분자 CLT ($N(0,I){}$) → Slutsky.
- **나온 곳** [ch5 6.2](ch5.3-5.5%20최대가능도추정.md#62-thm-82와-증명), 튜터링2 Thm 5

### T28 EM 알고리즘
- **언제** 결측값·잠재변수 때문에 관측자료 가능도가 복잡할 때.
- **틀** 완전자료 MLE를 먼저 구한다 → E-step: 완전자료 로그가능도가 결측값에 대해 1차식이면 결측값을 조건부 기댓값으로 → M-step: 공식에 대입. 단조성 $\ell(\theta^{(t+1)})\ge\ell(\theta^{(t)})$.

## 5. 공식표

### 5.1 부등식

| 이름 | 가정 | 식 |
| --- | --- | --- |
| Markov | $X\ge0$ | $\Pr(X\ge t)\le\mathbb EX/t$ |
| Chebyshev | $\mathop{\mathrm{Var}}\nolimits X < \infty$ | $\Pr(\lvert X-\mu\rvert\ge\epsilon)\le\sigma^2/\epsilon^2$ |
| Chernoff | MGF 유한 | $\Pr(X\ge t)\le\inf_{\lambda > 0}e^{-\lambda t}\mathbb Ee^{\lambda X}$ |
| Mills | $Z\sim N(0,1)$ | $\Pr(\lvert Z\rvert > t)\le\sqrt{2/\pi}\thinspace e^{-t^2/2}/t$ |
| Hoeffding's lemma | $a\le X\le b$, $\mathbb EX=0$ | $\mathbb Ee^{\lambda X}\le e^{\lambda^2(b-a)^2/8}$ |
| Hoeffding | 독립, $a_i\le X_i\le b_i$ | $\Pr\big(\sum(X_i-\mathbb EX_i)\ge\epsilon\big)\le e^{-2\epsilon^2/\sum(b_i-a_i)^2}$ |
| Hoeffding (베르누이) | iid Bernoulli $(p)$ | $\Pr(\lvert\bar X_n-p\rvert\ge\epsilon)\le2e^{-2n\epsilon^2}$ |
| sub-Gaussian 꼬리 | $\mathbb Ee^{s(X-\mu)}\le e^{\sigma^2s^2/2}$ | $\Pr(X-\mu\ge t)\le e^{-t^2/(2\sigma^2)}$ |
| Bernstein (적률) | $\mathbb E\lvert X_i\rvert^k\le\frac{k!}2M^{k-2}v_i$ | $\Pr(\sum X_i\ge\epsilon)\le e^{-\epsilon^2/(2(V+M\epsilon))}$ |
| Bernstein (유계) | $\lvert Y_i\rvert\le M$, 평균 0 | $\Pr(\sum Y_i\ge t)\le e^{-t^2/(2(\sigma^2+Mt/3))}$ |
| 최댓값 (보충) | 각각 $\sigma$-sub-Gaussian | $\mathbb E\max_{i\le n}X_i\le\sigma\sqrt{2\log n}$ |
| 유한 함수집합 (보충) | $0\le L\le1$, $\lvert\mathcal F\rvert=K$ | 확률 $1-\delta$로 $\sup_f\lvert\widehat R-R\rvert\le\sqrt{\log(2K/\delta)/(2n)}$ |

### 5.2 지수족

- 꼴: $f=h(x)e^{\eta^\top T(x)-A(\eta)}$ (강의: $e^{\alpha^\top t(x)-\psi(\alpha)}f_0(x){}$). 분포별 표 → [ch2 3.3](ch2%20모수모형과%20지수족.md#33-자주-나오는-지수족-표)
- $\nabla A=\mathbb ET$, $\nabla^2A=\mathop{\mathrm{Cov}}\nolimits T\succeq0$ ($A$ 볼록), 자연모수공간 볼록
- $T$의 MGF: $e^{A(\eta+s)-A(\eta)}$ · Fisher 정보 $=\nabla^2A$ · MLE: $\nabla A(\hat\eta)=\bar T$
- KL: $D(\eta_1\Vert\eta_2)=A(\eta_2)-A(\eta_1)-(\eta_2-\eta_1)^\top\nabla A(\eta_1)$
- iid 표본: $\sum T(X_i)$가 충분 (자연모수공간이 열린 집합을 포함하면 최소충분)
- 지수족이 아님: support가 모수에 의존

### 5.3 수렴

```
   a.s. ==> p ==> d        qm ==> p ==> d
   a.s. 와 qm 은 무관       d ==> p 는 극한이 상수일 때만
```

| 정리 | 가정 | 결론 |
| --- | --- | --- |
| WLLN | iid, $\mathop{\mathrm{Var}}\nolimits < \infty$ | $\bar Y_n\xrightarrow{p}\mu$ |
| SLLN | iid, $\mathbb E\lvert Y\rvert < \infty$ | $\bar Y_n\xrightarrow{\text{a.s.}}\mu$ |
| CLT | iid, $0 < \sigma^2 < \infty$ | $\sqrt n(\bar Y_n-\mu)/\sigma\xrightarrow{d}N(0,1)$ |
| CMT | $g$ 연속 | $g(X_n)\to g(X)$ (p, d) |
| Slutsky | $X_n\xrightarrow{d}X$, $Y_n\xrightarrow{p}c$ | $X_n+Y_n\xrightarrow{d}X+c$, $X_nY_n\xrightarrow{d}cX$ |
| a.s. 충분조건 | $\sum\Pr(\lvert X_n-X\rvert > \epsilon) < \infty$ ∀ε | $X_n\xrightarrow{\text{a.s.}}X$ |

**표준 극한**

| 상황 | 결과 |
| --- | --- |
| Unif $(0,\theta)$ 최댓값 | $X_{(n)}\xrightarrow{p}\theta$, $\frac n\theta(\theta-X_{(n)})\xrightarrow{d}\text{Exp}(1)$ |
| Exp (rate $\lambda$) 최댓값 | $M_n/\log n\xrightarrow{p}1/\lambda$, $\lambda M_n-\log n\xrightarrow{d}$ Gumbel $e^{-e^{-x}}$ |
| Exp (rate $\lambda$) 최솟값 | $X_{(1)}\sim\text{Exp}(n\lambda)$ 정확히 |
| AR(1) 표본평균 ($-1\le\beta < 1$) | $\bar X_n\xrightarrow{qm}\mu/(1-\beta)$ |
| 드문 큰 값 | $\sqrt nI(U\le1/n)$: p, a.s.이지만 qm 아님 / 독립 Bernoulli $(1/n)$: qm이지만 a.s. 아님 |

### 5.4 충분통계량 빠른 표

| 모형 (iid) | 충분통계량 | 최소충분 |
| --- | --- | --- |
| Poi $(\theta)$, Ber $(\theta)$ | $\sum X_i$ | 같음 |
| $N(\mu,\sigma^2)$ | $(\sum X_i,\sum X_i^2)$ | 같음 ($\sigma^2$ 알면 $\bar X$) |
| Gam $(\nu,\sigma)$ | $(\prod X_i,\sum X_i)$ | 같음 |
| Unif $(0,\theta)$ | $X_{(n)}$ | 같음 |
| Unif $(\theta,\theta+1)$, Unif $(\theta,2\theta)$ | $(X_{(1)},X_{(n)})$ | 같음 (2차원) |
| Unif $(-\theta,\theta)$ | $\max\lvert X_i\rvert$ | 같음 |
| $e^{\theta-x}I(x\ge\theta)$ (hw1 #8), 파레토 $\theta x^{-2}I(x\ge\theta)$ | $X_{(1)}$ | 같음 |
