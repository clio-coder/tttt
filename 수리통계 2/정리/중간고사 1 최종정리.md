## 1. 집중부등식

### 1.1 기본 부등식

| 이름 | 가정과 결론 |
| --- | --- |
| Markov | $X\ge0$이면 $\Pr(X\ge t)\le\mathbb EX/t$ |
| Chebyshev | $\Pr(\lvert X-\mu\rvert\ge t)\le\sigma^2/t^2$ |
| Chernoff | $\Pr(X\ge t)\le\inf_{\lambda > 0}e^{-\lambda t}\mathbb Ee^{\lambda X}$ |
| Hoeffding's lemma | $a\le X\le b$, $\mathbb EX=0$이면 $\mathbb Ee^{\lambda X}\le e^{\lambda^2(b-a)^2/8}$ |
| Hoeffding | 독립이면 $\Pr(\sum_i(X_i-\mathbb EX_i)\ge t)\le\exp\{-2t^2/\sum_i(b_i-a_i)^2\}$ |
| Bernstein | 독립, 평균 0, $\lvert Y_i\rvert\le M$, $\sigma^2=\sum_i\mathop{\mathrm{Var}}\nolimits(Y_i)$이면 $\Pr(\sum_iY_i\ge t)\le\exp\{-t^2/[2(\sigma^2+Mt/3)]\}$ |

합을 평균으로 바꿀 때는 $t$ 대신 $nt$를 넣는다. 양측확률은 두 단측확률에 합집합 부등식을 적용하므로 앞에 2가 붙는다.

### 1.2 Hoeffding's lemma 증명 뼈대

1. $a < b$이고 $\mathbb EX=0$이면 $a\le0\le b$이다.
2. 볼록성으로, $x\in[a,b]$일 때

   $$e^{\lambda x}\le\frac{b-x}{b-a}e^{\lambda a}+\frac{x-a}{b-a}e^{\lambda b}.$$

3. $x=X$를 넣고 기댓값을 취한 뒤 $\mathbb EX=0$을 사용한다.
4. $p=-a/(b-a)$, $h=\lambda(b-a)$로 놓으면 우변은 $e^{L(h)}$이고

   $$L(h)=-ph+\log(1-p+pe^h).$$

5. $L(0)=L'(0)=0$이고

   $$L''(h)=u(1-u)\le\frac14,\qquad u=\frac{pe^h}{1-p+pe^h}.$$

6. Taylor 정리로 $L(h)\le h^2/8$. 마지막에 $h=\lambda(b-a)$를 되돌린다.

**감점 포인트:** 볼록결합의 두 가중치, $\mathbb EX=0$을 사용한 줄, Taylor 나머지항을 명시한다.

### 1.3 Hoeffding 부등식 증명 뼈대

중심화한 합을 $S=\sum_i(X_i-\mathbb EX_i)$라 하면, $\lambda > 0$에서

$$
\Pr(S\ge t)
\le e^{-\lambda t}\mathbb Ee^{\lambda S}
=e^{-\lambda t}\prod_i\mathbb Ee^{\lambda(X_i-\mathbb EX_i)}
\le\exp\left\{-\lambda t+\frac{\lambda^2}{8}\sum_i(b_i-a_i)^2\right\}.
$$

첫 부등식은 Markov, 곱은 독립성, 마지막은 Hoeffding's lemma이다. 이차식을 최소화하는

$$\lambda^\star=\frac{4t}{\sum_i(b_i-a_i)^2}$$

를 대입한다.

### 1.4 Sub-Gaussian과 대칭화

$X$가 평균 $\mu$이고

$$\mathbb Ee^{s(X-\mu)}\le e^{\sigma^2s^2/2}$$

이면 $\sigma$-sub-Gaussian이다. 따라서

$$\Pr(\lvert X-\mu\rvert\ge t)\le2e^{-t^2/(2\sigma^2)}.$$

- $N(\mu,\sigma^2)$는 정확히 등호를 만족한다.
- Rademacher 변수 $\varepsilon$은 $\mathbb Ee^{s\varepsilon}=\cosh s\le e^{s^2/2}$.
- 평균 0이고 $a\le X\le b$이면 독립 복사본 $X'$에 대해

  $$\mathbb Ee^{sX}\le\mathbb Ee^{s(X-X')}=\mathbb Ee^{s\varepsilon(X-X')}\le e^{s^2(b-a)^2/2}.$$

  첫 부등식은 $e^x$에 대한 조건부 Jensen, 분포상 등호는 $X-X'$의 대칭성이다.
- iid 표본평균은 $(b-a)/\sqrt n$-sub-Gaussian이다.

### 1.5 Bernstein과 Hoeffding 비교

$d=b-a$라 하면 $Y_i=X_i-\mathbb EX_i$에 대해 $\lvert Y_i\rvert\le d$이고

$$\sigma^2=\sum_i\mathop{\mathrm{Var}}\nolimits(X_i)\le\frac{nd^2}{4}.$$

최악의 분산 상계를 Bernstein에 넣으면 분모가

$$\frac{nd^2}{2}+\frac{2dt}{3}$$

이 되어 Hoeffding의 분모 $nd^2/2$보다 크다. 따라서 이 경우 Hoeffding이 더 강하다. 실제 분산을 알 때 Bernstein이 더 강한 정확한 조건은

$$\boxed{\sigma^2 < \frac{nd^2}{4}-\frac{dt}{3}}.$$

이 조건이 가능하려면 $t < 3nd/4$이어야 한다.

- $t\ll\sigma^2/d$: Bernstein 지수는 약 $-t^2/(2\sigma^2)$. 분산이 작으면 유리하다.
- $t\gg\sigma^2/d$: Bernstein 지수는 약 $-3t/(2d)$로 선형이다. 충분히 큰 $t$에서는 이차 지수인 Hoeffding이 유리하다.

## 2. 모수모형과 지수족

### 2.1 지수족 레시피

목표 형식은

$$f(x\mid\eta)=h(x)\exp\{\eta^\top T(x)-A(\eta)\}.$$

1. $\log f(x\mid\theta)$를 전개한다.
2. 모수와 자료가 섞인 항을 $\eta^\top T(x)$로 묶는다.
3. 자료에만 의존하는 항은 $\log h(x)$, 나머지 모수항은 $-A(\eta)$로 둔다.
4. 원래 모수와 자연모수의 관계를 역으로 풀고, 적분 가능성과 support를 확인해 자연모수공간을 구한다.

**검산:** $\eta^\top T-A(\eta)+\log h$를 원래 로그밀도로 되돌린다. 특히 부호는 반드시 $-A$이다.

### 2.2 핵심 성질

$$\nabla A(\eta)=\mathbb E_\eta[T(X)],\qquad
\nabla^2A(\eta)=\mathop{\mathrm{Cov}}\nolimits_\eta(T(X))\succeq0.$$

- 증명은 정규화 항등식 $e^{A(\eta)}=\int e^{\eta^\top T(x)}h(x)dx$를 미분한다.
- 헤시안이 공분산이므로 $A$는 볼록하다.
- iid 표본에서는 $\sum_iT(X_i)$가 충분통계량이다.
- 지수족 MLE는 적률을 맞춘다.

  $$\nabla A(\hat\eta)=\frac1n\sum_iT(X_i).$$

- support가 모수에 의존하면 일반적인 정규 지수족의 공통 support 조건이 깨진다.

### 2.3 자주 나오는 표현

| 분포 | 자연모수와 log-partition |
| --- | --- |
| Bernoulli | $\eta=\log[p/(1-p)]$, $A(\eta)=\log(1+e^\eta)$ |
| Binomial $(m,p)$ | 같은 $\eta$, $A(\eta)=m\log(1+e^\eta)$ |
| Poisson | $\eta=\log\lambda$, $A(\eta)=e^\eta$ |
| 정규, 분산 알려짐 | $\eta=\mu/\sigma^2$, $T=x$, $A(\eta)=\sigma^2\eta^2/2$ |
| 정규, 둘 다 미지 | $T=(x,x^2)$, $\eta=(\mu/\sigma^2,-1/(2\sigma^2))$, 두 번째 자연모수는 음수 |

다변량 정규에서는 이차형식을 전개하고

$$x^\top\Lambda x=\mathop{\mathrm{tr}}\nolimits(\Lambda xx^\top)$$

를 사용한다. 자연모수 $\eta=\Sigma^{-1}\mu$, $\Lambda=-\Sigma^{-1}/2$이고 $\Lambda$는 대칭 음의 정부호여야 한다.

## 3. 확률변수의 수렴

### 3.1 관계도

```text
a.s.  ==>  p  ==>  d
qm    ==>  p  ==>  d
```

- a.s.와 qm 사이에는 일반적인 포함관계가 없다.
- $X_n\xrightarrow{d}c$처럼 극한이 상수이면 $X_n\xrightarrow{p}c$이다.
- 확률수렴만으로 기댓값 수렴은 보장되지 않는다.

### 3.2 문제별 첫 수

| 문제 | 첫 수 |
| --- | --- |
| $X_n\xrightarrow{qm}c$ | $\mathbb E(X_n-c)^2=\mathop{\mathrm{Var}}\nolimits(X_n)+(\mathbb EX_n-c)^2$ |
| $X_n\xrightarrow{p}c$ | 평균·분산이 쉬우면 Chebyshev, 아니면 두 꼬리를 직접 계산 |
| 최댓값·최솟값 | $\Pr(M_n\le x)=F(x)^n$, $\Pr(m_n > x)=[1-F(x)]^n$ |
| 극한분포 | 변환한 통계량의 CDF를 직접 구해 점별 극한 |
| 함수의 수렴 | 먼저 안쪽 변수의 수렴을 보이고 CMT |
| 미지 모수를 추정량으로 대체 | CLT 뒤에 Slutsky |
| a.s. 수렴 | $\sum_n\Pr(\lvert X_n-X\rvert > \epsilon) < \infty$와 Borel-Cantelli |

### 3.3 필수 정리

- WLLN: iid, 유한분산이면 $\bar X_n\xrightarrow{p}\mu$.
- CLT: $\sqrt n(\bar X_n-\mu)/\sigma\xrightarrow{d}N(0,1)$.
- CMT: $g$가 극한점에서 연속이면 수렴을 $g$를 통해 옮긴다.
- Slutsky: $X_n\xrightarrow{d}X$, $Y_n\xrightarrow{p}c$이면 합·곱·비의 극한을 상수처럼 처리한다.
- First Borel-Cantelli: $\sum_n\Pr(A_n) < \infty$이면 $\Pr(A_n\text{ i.o.})=0$.

### 3.4 표준 예제

- $X_i\sim\mathrm{Unif}(0,\theta)$이면

  $$X_{(n)}\xrightarrow{p}\theta,\qquad
  \frac n\theta(\theta-X_{(n)})\xrightarrow{d}\mathrm{Exp}(1).$$

- 율 $\lambda$인 지수분포의 최댓값 $M_n$은

  $$\frac{M_n}{\log n}\xrightarrow{p}\frac1\lambda,\qquad
  \lambda M_n-\log n\xrightarrow{d}\text{Gumbel}.$$

- AR(1) $X_n=\beta X_{n-1}+e_n$, $-1\le\beta < 1$에서는 계수를 기하급수 합으로 풀어 평균과 분산을 계산하면

  $$\bar X_n\xrightarrow{qm}\frac{\mu}{1-\beta}.$$

## 4. 자료축약

### 4.1 충분통계량

$T(X)$가 충분하다는 것은 $T$가 주어졌을 때 원자료의 조건부분포가 모수에 의존하지 않는다는 뜻이다.

**Neyman-Fisher 분해정리**

$$f_\theta(x)=h(x)g_\theta(T(x))$$

로 쓸 수 있으면 $T$는 충분통계량이다. $h$에는 모수가 없어야 하고, $g_\theta$는 자료에 오직 $T(x)$를 통해서만 의존해야 한다.

support가 모수에 의존하면 지시함수를 반드시 쓴다.

$$\prod_iI(x_i\ge\theta)=I(X_{(1)}\ge\theta),\qquad
\prod_iI(x_i\le\theta)=I(X_{(n)}\le\theta).$$

### 4.2 최소충분통계량

우도비 판정법의 핵심은

$$\frac{f_\theta(x)}{f_\theta(y)}\text{가 }\theta\text{와 무관}
\quad\Longleftrightarrow\quad T(x)=T(y).$$

양방향을 모두 확인한다. 충분통계량은 여러 개일 수 있지만 최소충분통계량은 생성하는 분할이 가장 거칠다.

### 4.3 빠른 예제

| 모형 | 충분·최소충분통계량 |
| --- | --- |
| Poisson, Bernoulli | $\sum_iX_i$ |
| $N(\mu,\sigma^2)$ 둘 다 미지 | $(\sum_iX_i,\sum_iX_i^2)$ |
| $N(\mu,\sigma^2)$에서 분산 알려짐 | $\bar X$ |
| $\mathrm{Unif}(0,\theta)$ | $X_{(n)}$ |
| $\mathrm{Unif}(\theta,\theta+1)$ | $(X_{(1)},X_{(n)})$ |
| $e^{\theta-x}I(x\ge\theta)$ | $X_{(1)}$ |

## 5. 점추정과 적률이용 추정법

### 5.1 기본 개념

- **추정량:** 표본의 함수인 확률변수 $\hat\theta=w(X_1,\dots,X_n)$.
- **추정값:** 관측된 자료를 넣은 실현값.
- **일치성:** 모든 $\theta$에서 $\hat\theta_n\xrightarrow{p}\theta$.
- **무편향성:** $\mathbb E_\theta\hat\theta=\theta$.
- 일치성과 무편향성은 서로를 보장하지 않는다.

### 5.2 적률법

$k$차원 모수라면 보통 처음 $k$개의 표본 적률과 모집단 적률을 맞춘다.

$$m_j=\frac1n\sum_iX_i^j=\mu_j(\hat\theta),\qquad j=1,\dots,k.$$

**주의점**

- 모멘트 조건의 선택에 따라 추정량이 유일하지 않을 수 있다.
- 해가 모수공간 밖에 나올 수 있다.
- 필요한 모집단 적률이 존재하는지 먼저 확인한다.
- $\theta=g(\mu_1,\dots,\mu_k)$이고 $g$가 연속이면 WLLN과 CMT로 MME의 일치성을 보인다.

정규분포에서

$$\hat\mu=\bar X,\qquad
\hat\sigma^2_{\mathrm{MME}}=\frac1n\sum_i(X_i-\bar X)^2.$$

두 번째 추정량은 일치하지만 편향되어 있다. 무편향 표본분산은 분모가 $n-1$이다.

## 6. 최대가능도추정

### 6.1 MLE 계산의 세 갈래

1. **매끄러운 모형:** 로그가능도를 미분해 score를 0으로 둔다. 헤시안·경계·전역성을 확인한다.
2. **support가 모수에 의존:** 미분하기 전에 지시함수와 가능한 모수 구간을 본다. 가능도가 증가·감소하는 경계가 MLE인 경우가 많다.
3. **이산 모수공간:** 후보들의 가능도를 직접 비교하고 동률도 쓴다.

경계에서만 supremum이 달성되고 경계가 모수공간에 없으면 MLE는 존재하지 않는다.

### 6.2 존재·유일성

- 존재: 모든 콤팩트 집합을 벗어날 때 $\ell(\theta)\to-\infty$이면 최대점을 콤팩트 집합 안에 가둘 수 있다.
- 유일성: 모수공간이 볼록이고 헤시안이 모든 점에서 음의 정부호이면 로그가능도는 순오목하다.
- 순오목인 경우 score 방정식의 해가 존재하면 유일한 전역 MLE이다.
- 원래 모수에서 오목하지 않으면 자연모수·율·정밀도 등으로 재매개화하고 불변성으로 되돌린다.

### 6.3 프로파일 가능도와 불변성

관심 모수 $\eta$, 부수모수 $\xi$일 때

$$L_p(\eta)=\sup_\xi L(\eta,\xi).$$

전체 MLE의 $\eta$ 성분은 $L_p$의 최대점이다. 또한 $\eta=g(\theta)$이면

$$\hat\eta=g(\hat\theta).$$

$g$가 일대일이 아니어도 유도 가능도, 즉 프로파일 가능도로 같은 결론을 얻는다.

### 6.4 지수족의 MLE

$$\ell(\eta)=n\{\eta^\top\bar T-A(\eta)\}+C$$

이므로

$$\nabla\ell=n\{\bar T-\nabla A(\eta)\},\qquad
\nabla^2\ell=-n\mathop{\mathrm{Cov}}\nolimits_\eta(T).$$

공분산행렬이 양의 정부호이면 로그가능도는 순오목하고, $\nabla A(\hat\eta)=\bar T$의 해가 존재할 때 유일한 MLE이다. 단, 표본 적률이 평균모수공간의 경계에 있으면 유한 MLE가 없을 수 있다.

### 6.5 수치 알고리즘과 EM

- Newton-Raphson: $\theta^{(r+1)}=\theta^{(r)}-H(\theta^{(r)})^{-1}U(\theta^{(r)})$.
- Gradient descent: 1차 미분만 사용하며 보폭 선택이 중요하다.
- Coordinate descent: 한 번에 한 좌표씩 최적화한다.
- EM: 잠재·결측 자료를 도입해 완전자료 문제를 반복해서 푼다.

EM에서

$$Q(\theta\mid\theta^{(r)})
=\mathbb E_{Z\mid Y,\theta^{(r)}}[\log f(Y,Z\mid\theta)].$$

- E-step: 현재 모수에서 결측 충분통계량의 조건부 기댓값을 계산한다.
- M-step: 그 기댓값을 완전자료 MLE 공식에 넣는다.
- 관측자료 로그가능도는 매 단계 감소하지 않는다.
- 단조성은 전역 최대 수렴을 뜻하지 않는다. 여러 초기값과 최종 우도를 비교한다.

## 7. MLE의 점근이론

### 7.1 일치성

$$R_n(\theta)=\frac1n\sum_i\log\frac{f_{\theta_0}(X_i)}{f_\theta(X_i)},\qquad
R(\theta)=\mathrm{KL}(f_{\theta_0}\Vert f_\theta).$$

MLE는 $R_n$의 최소점이고, 참모수는 $R$의 최소점이다. 필요한 핵심 조건은 다음과 같다.

1. **강한 식별성:** 모든 $\epsilon > 0$에 대해

   $$\inf_{\lVert\theta-\theta_0\rVert\ge\epsilon}R(\theta)\ge\eta_\epsilon > 0.$$

2. **균등 대수의 법칙:** $\sup_\theta\lvert R_n(\theta)-R(\theta)\rvert\xrightarrow{p}0$.
3. MLE가 존재한다.

증명의 핵심은

$$
R(\hat\theta_n)
\le\sup_\theta\lvert R_n(\theta)-R(\theta)\rvert.
$$

$\hat\theta_n$이 참모수에서 $\epsilon$ 이상 떨어지면 왼쪽은 강한 식별성에 의해 $\eta_\epsilon$ 이상이어야 하므로 그 확률이 0으로 간다.

**구별:** 식별가능성은 각 고정된 다른 모수의 KL이 양수라는 뜻이다. 강한 식별가능성은 참모수에서 일정 거리 이상 떨어진 모든 모수에 대해 공통의 양의 간격이 있다는 더 강한 조건이다.

### 7.2 점근정규성

한 관측치 점수를 $s(\theta;X)=\partial\log f_\theta(X)/\partial\theta$라 하면

$$\mathbb E_{\theta_0}s(\theta_0;X)=0,\qquad
I(\theta_0)=\mathbb E[s^2]=\mathbb E[-\ell''(\theta_0;X)].$$

내부 MLE에서는 $S_n(\hat\theta_n)=0$. 평균값 정리로

$$
\sqrt n(\hat\theta_n-\theta_0)
=\left\{-\frac1nS_n'(\tilde\theta_n)\right\}^{-1}
\frac1{\sqrt n}S_n(\theta_0).
$$

- 분모는 LLN과 일치성으로 $I(\theta_0)$에 확률수렴한다.
- 분자는 CLT로 $N(0,I(\theta_0))$에 분포수렴한다.
- Slutsky로

  $$\boxed{\sqrt n(\hat\theta_n-\theta_0)\xrightarrow{d}N(0,I(\theta_0)^{-1}).}$$

경계, 모수 의존 support, 증가하는 부수모수 차원에서는 이 결론이 깨질 수 있다. $\mathrm{Unif}(0,\theta)$의 MLE는 $\sqrt n$이 아니라 $n$ 속도이고, Neyman-Scott에서는 MLE가 불일치한다.

### 7.3 Cramér-Rao 하한

한 관측치 정보량이 $I_1(\theta)$이고 $T$가 $g(\theta)$의 불편추정량이면 정칙조건 아래

$$\boxed{\mathop{\mathrm{Var}}\nolimits_\theta(T)\ge\frac{[g'(\theta)]^2}{nI_1(\theta)}.}$$

증명 뼈대는

$$\mathop{\mathrm{Cov}}\nolimits(T,S_n)=g'(\theta),\qquad
\mathop{\mathrm{Var}}\nolimits(S_n)=nI_1(\theta)$$

와 Cauchy-Schwarz이다. support가 모수에 의존하면 미분과 적분의 교환이 깨져 하한을 적용할 수 없다.

### 8.2 hw2

| 문제 | 핵심 결과와 첫 수 |
| --- | --- |
| 1 | $f=\theta x^{-2}I(x\ge\theta)$: 충분통계량·MLE는 $X_{(1)}$. $\mathbb EX=\infty$이므로 $\mathbb E(X^{-1})=1/(2\theta)$를 사용 |
| 2 | $\theta\in\{0,1\}$: 두 가능도를 직접 비교. 기하평균이 $1/4$보다 작으면 1, 크면 0, 같으면 둘 다 MLE |
| 3 | 경쟁위험: $k=\sum W_i$, $S=\sum Z_i$이면 $\hat\lambda=S/k$, $\hat\mu=S/(n-k)$. 횟수가 0이면 대응 평균모수의 유한 MLE가 없음 |
| 4 | Satterthwaite: $\nu=(\sum_i a_i\nu_i)^2/(\sum_i a_i^2\nu_i)$. 모든 $a_i$가 같으면 정확 |
| 5 | Poisson 결측: 완전자료 MLE를 먼저 구하고 $x_1$ 자리에 $\mathbb E[X_1\mid\text{관측}]=\tau_1^{(r)}$를 대입 |
| 6 | 식별가능하지만 강한 식별가능성은 아닌 예. 아래 계산을 기억 |

hw2 6에서 $p_0=1/2$, $p_k=1/2+1/(k+2)$이다. 서로 다른 $k$는 서로 다른 성공확률을 주므로 식별가능하다. 그러나 $\delta_k=1/(k+2)$라 두면

$$
\mathrm{KL}\left(\mathrm{Ber}(1/2)\Vert\mathrm{Ber}(1/2+\delta_k)\right)
=-\frac12\log(1-4\delta_k^2)
=2\delta_k^2+o(\delta_k^2)\to0.
$$

따라서 $\epsilon=1$에서 참모수와 거리 1 이상인 모수들의 KL infimum이 0이므로 강한 식별성이 성립하지 않는다. 각 고정된 $k$의 KL은 양수이므로 참모수는 여전히 유일한 최소점이다. 양의 간격이 없으면

$$R(\hat\theta_n)\le\sup_\theta\lvert R_n-R\rvert$$

에서 작은 위험을 작은 모수 거리로 바꾸는 단계가 막힌다. 이것만으로 MLE의 불일치가 증명되는 것은 아니다. 강한 식별성은 제시된 일치성 정리의 충분조건이다.

**확인 필요:** hw2 7·8은 교재 연습문제 6.14·6.15를 참조하지만 문제 본문이 폴더에 없다. 교재에서 문제를 따로 확인해야 한다.

## 9. 자주 하는 실수

- 지수족에서 $+A$가 아니라 $-A$이다.
- MLE에서 score가 0이라는 것은 내부점에서만 성립한다.
- support가 모수에 의존하면 미분보다 지시함수와 경계를 먼저 본다.
- MLE가 존재하는지, 유일한지, 경계에서만 supremum을 갖는지 구분한다.
- 적률법은 필요한 적률이 존재하는지 먼저 확인한다.
- 확률수렴은 최댓값 문제에서 아래·위 꼬리를 모두 보여야 한다.
- 분포수렴은 CDF의 연속점에서 확인한다.
- 양측 꼬리에는 합집합 부등식으로 2가 붙는다.
- 최소충분성의 우도비 판정은 양방향이다.
- 점별 LLN만으로 자료에 따라 선택된 MLE의 일치성을 결론 내릴 수 없다. 균등 LLN이 필요하다.
- EM의 우도 단조 증가가 전역 최대 수렴을 뜻하지 않는다.
- Cramér-Rao는 공통 support와 미분-적분 교환 같은 정칙조건을 확인한 뒤 사용한다.
