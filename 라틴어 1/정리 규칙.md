### 1.2 규칙에 반영한 특징

1. **복습 슬라이드가 많이 반복된다.** 명사 변화표는 L03→L04→L05, 형용사는 L04→L05→L06, 동사 활용표는 L06→L07→L08에 다시 나온다. 강의별로 정리하면 같은 내용이 여러 번 들어가므로 **문법은 주제별로 누적해서** 정리한다.
2. **분홍색은 그 강의의 문법 포인트다.** 지문에서 분홍 밑줄이 친 단어는 Stage 2–3에서는 대격, Stage 4에서는 동사 인칭을 가리킨다. 본문을 분석할 때 이런 단어는 ★로 표시한다.
3. **핵심 내용 대부분이 이미지다.** 텍스트 추출만으로는 정리할 수 없으므로 페이지를 직접 보고 옮긴다.
4. **과제는 교재 지문 독해다.** 수업 중에 무작위로 지명해서 한 문장씩 번역시키고, 이 참여로 출석 20%를 확인한다. 과제 지문 해석은 출석과 시험에 모두 걸린다.
5. **시험 방식은 "어형 변화와 해석"이다.** 과거 기출(Oxford 교재를 쓰던 때)의 유형은 ① 원형 복원 ② 어형 변화와 뜻 ③ 문장 번역 ④ 단어 뜻이었다. 번역 문제는 주어를 빠뜨리거나 단수·복수를 틀리면 감점됐다.

## 3. 공통 규칙

| 항목 | 규칙 |
| --- | --- |
| 출처 태그 | `[L04 p27]` = 제4강 PDF 27쪽. 모든 표·예문·지문에 붙인다. 슬라이드 밖 자료는 `[Explorer]`, `[지문 이름]`처럼 출처를 밝힌다. |
| 중복 | 여러 강의에 반복된 슬라이드는 **처음 나온 곳 기준으로 한 번만** 적고, 반복된 강의는 `반복: L04·L05`로 표시한다. |
| 중요도 | ★★★ 3개 이상 강의에서 반복되었거나 퀴즈에 나온 것 · ★★ 2개 강의 · ★ 1개 강의. "퀴즈"는 수업 중 퀴즈, 슬라이드에 링크된 온라인 퀴즈, 예고된 퀴즈를 말한다. 산정표는 [강의 인덱스 4절](정리/00%20강의%20인덱스.md)에 있다. |
| 장음 | 장음(macron) `ā ē ī ō ū`로 통일한다. 슬라이드 텍스트에 장음이 빠져 있으면 교재 이미지를 기준으로 보충한다. |
| 오타 | 슬라이드 오타는 교재 표기로 바로잡아 적는다. 예: `trinclinio`→`triclīniō`, `tricilinium`→`triclīnium` |
| 격 용어 | 주격(nom.) · 속격(gen.) · 여격(dat.) · 대격(acc.) · 탈격(abl.) · 호격(voc.). 과거 기출의 "목적격"은 대격, "소유격"은 속격과 같다. |
| 범위 | 수업에서 다룬 것만 적는다. 기존 Oxford 자료로 보충한 내용은 `[Oxford]`로 표시한다. |
| 불확실 | 판독이 어렵거나 확신이 없으면 `[확인 필요]`로 표시한다. |
| 어미 강조 | 변하는 부분을 굵게 쓴다. 예: `amīc**um**`, `laud**ant**` |

### 단어 표기 (사전형)

시험의 "원형"은 명사는 단수 주격, 동사는 **직설법 현재 능동태 1인칭 단수**, 형용사는 남성 단수 주격이다. 이에 맞춰 모든 단어를 사전형으로 적는다.

| 품사 | 형식 | 예 |
| --- | --- | --- |
| 명사 | 주격, 속격 어미, 성 + 뜻 | `amīcus, -ī, m. 친구` · `rēx, rēgis, m. 왕` · `canis, -is, c. 개` |
| 형용사 | 남·여·중 주격 + 뜻 | `laetus, -a, -um 기쁜` |
| 동사 | 1인칭 단수, 부정사, (활용 번호) + 뜻 | `salūtō, salūtāre (1) 인사하다` · `capiō, capere (3-io) 잡다` |
| 불규칙 동사 | 표시를 붙인다 | `sum, esse (불규칙) ~이다, 있다` |
| 전치사 | 뒤에 오는 격 | `ad (+acc.) ~로, ~를 향해` |

## 4. 문법 정리 규칙 (1순위)

각 문법 항목은 아래 틀을 따른다.

```markdown
## 1변화 명사  ★★★  [L03 p8–9] · 반복: L04·L05·L08

> **핵심:** 단수 주격 -a → 대격 -am. 대부분 여성.

| 격 | 단수 | 복수 |
| --- | --- | --- |
| 주격 | port**a** | port**ae** |
| 대격 | port**am** | port**ās** |
| … | … | … |

※ 수업에서 집중한 칸(현재: 주격·대격 단수, 주격 복수)은 굵은 테두리나 ★로 표시

**수업 예문**
- Metella culīn**am** intrat. — 메텔라가 부엌으로 들어간다. [L02 p27]

**헷갈림 주의**
- -ae는 단수 속격·단수 여격·복수 주격이 모두 같다 → 문맥으로 구분

**드릴** (시험 4유형)
1. 원형 복원: villam → ?
2. 어형 변화: pecūnia 단수 대격 → ? (뜻도)
3. 번역: Metella cēnam gustat.
<details><summary>정답</summary> … </details>
```

- **핵심은 한 줄로** 적는다. 변화표 → 수업 예문 → 헷갈림 주의 → 드릴 순서로 쓴다.
- 수업에서 6격 전체 표를 보여준 경우(1·2·3변화)에는 전체 표를 싣는다. 다만 현재 Stage에서 집중한 칸을 따로 표시한다.
- **판별법을 꼭 넣는다.** 예: 3변화는 주격만 봐서는 어간을 알 수 없으므로 대격 `-em`을 보고 어간을 찾는다(`mercātor`→`mercātōr-em`). 2활용(`sedēs`)과 3활용(`curris`)은 2인칭 모음으로 구분한다.
- 드릴에는 **Cambridge 수업 어휘만** 쓰고, 정답은 `<details>`로 접어 둔다.

## 5. 본문 해석 정리 규칙 (2순위)

Stage 파일 하나는 아래 순서로 구성한다.

1. **개요:** 이 Stage의 문법 포인트(→ 문법 파일 링크), 다룬 강의
2. **어휘:** Vocabulary checklist와 슬라이드에 나온 단어
   `| 사전형 | 품사·변화 | 뜻 | 본문 속 형태 |`
3. **대표 예문:** 모델 문장 중 문법 포인트를 보여주는 것만 골라 싣는다 (전부 옮기지 않는다).
4. **지문별 분석:** 과제 지문을 먼저 한다.

```markdown
### in forō  [L04 p22] · 교재 ○쪽 · 과제 ✅

**새 단어** (본문 등장 순)
| 본문 형태 | 원형 | 분석 | 뜻 |
| --- | --- | --- | --- |
| ★negōtium | negōtium, -ī, n. | 2변화 중성 · 단수 대격 | 사업, 일 |

**문장별 해석**
| # | 시작 단어 | 핵심 분석 | 해석 (직역) |
| --- | --- | --- | --- |
| 1 | Caecilius nōn est… | in + 탈격 = 장소 | 카이킬리우스는 집에 있지 않다. |

**이 지문의 문법 포인트:** 분홍 밑줄 = 대격 → [01 명사 격변화](../문법/01%20명사%20격변화.md)
```

### 해석 규칙

- **직역을 우선한다.** 주어를 빠뜨리지 않고, 단수·복수를 살린다(`āctōrēs` → "배우**들이**"). 대격은 "~을/를"로 옮긴다. 기출의 감점 기준에 맞춘 것이다.
- `est`는 보어와 함께 오면 "~이다", `in` + 장소와 함께 오면 "~에 있다"로 옮긴다. [L02 p6]
- 현재형은 "~한다"와 "~하고 있다"를 모두 인정한다. [L01 p31]
- 인명은 처음 나올 때 라틴어를 함께 적는다. 예: 카이킬리우스(Caecilius), 그루미오(Grumiō)
- 문장 번호는 지문의 마침표·물음표·느낌표를 기준으로 1부터 매기고, 인용문 안의 문장에도 각각 번호를 붙인다. 단, 인용문과 그 뒤의 `inquit`·`clāmat`·`respondet`는 한 문장으로 묶는다. 대화극(in basilicā, Poppaea)은 대사 단위로 번호를 붙인다.
- **교재 지문 전문은 노트에 옮겨 적지 않는다.** 원문은 PDF 쪽수로 연결하고, 노트에는 단어 분석과 문장별 해석만 적는다. 교재 저작권 때문이기도 하고, 원문을 보면서 스스로 해석한 뒤 노트로 확인하는 편이 연습에도 낫다.
- 슬라이드에 없는 과제 지문은 PDF 속 링크(읽기 자료 페이지 → Explorer)에서 원문과 단어 분석을 찾아 정리한다. 링크에도 없으면 `[교재 필요]`로 표시한다.
