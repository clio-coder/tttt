## 1. 중간고사 공지 [L10 p43 · L11 p16]

| 항목 | 내용 |
| --- | --- |
| 범위 | **Stage 1–6 문법 사항 + vocabulary checklist** |
| 유형 | **객관식 및 주관식 총 40문제** |
| 결과 | 당일 오후 개별 이메일 안내 예정 |
| 10/14(수) | Stage 1–6 문법 총정리: "**명사와 동사의 어형 변화에 초점**을 맞춰 지금까지 배운 문법 사항 복습" + **복습 quiz** |

**공지에서 읽을 수 있는 것**
- 범위가 "문법 사항"과 "vocabulary checklist" 두 가지다. **교재 지문은 범위에 따로 적혀 있지 않다.** 지문은 문법과 어휘가 실제 문장에서 어떻게 쓰이는지 익히는 용도로 본다.
- 총정리의 초점이 **명사와 동사의 어형 변화**다. 명사는 수업에서 집중한 **주격 단수·대격 단수·주격 복수**, 동사는 **현재·미완료·완료**가 중심이다. 속격·여격·호격은 표로만 보여 줬으므로 비중을 낮춘다(10/14 판단).
- 어휘는 **교수님 목록 110단어**로 한정된다. 문제에서 단어가 사전형(동사는 현재·부정사·완료, 명사는 주격·속격·성)으로 주어진다고 했으므로, 완료형을 통째로 외우기보다 **사전형을 읽어 내는 법**(4.1절)에 집중한다. 뜻은 외운다.
- 40문제가 객관식과 주관식으로 나뉜다. 유형별 문항 수는 공지에 없다.

**10/14 총정리 강의와 복습 퀴즈로 확정된 것** [L12 · 10/14 강의 스크립트 · 퀴즈 분석 ★절]
- **동사는 네 가지 인칭·수만 배웠다:** "1인칭 단수, 2인칭 단수, 3인칭 단수, 그리고 3인칭 복수 이 네 가지 형태를 배웠었는데요." [10/14 21:28] 총정리 표도 이 네 줄만 보여 줬다 [L12 p21]. Stage 6은 **3인칭** 미완료·완료뿐이다 [L12 p25–30]. → 외울 동사 형태는 **8칸**이다 ([02 동사 §0](문법/02%20동사%20활용.md)).
- sum도 **sum, es, est, sunt**와 미완료 **erat, erant**만 나왔다 [L12 p23, p28]. "sum 동사의 미완료 시제는 두 가지 유형밖에 배우지 않았죠. 이것만 기억하시면 돼요." [10/14 40:29]
- **1·2변화는 직접 변화시킬 수 있어야 하고, 3변화 형용사는 나오면 해석할 정도로만** 파악한다. [10/14 06:12 · 10/12 강의]
- **3변화 명사는 사전형(속격)을 봐야 어간을 안다.** "그때그때 이 형태를 암기해 줘야 되는 거죠." [10/14 05:26] 시험에서도 3변화 명사는 사전형을 힌트로 줄 가능성이 높다 (퀴즈: `leo, leonis, m.`).
- **완료 어간은 외워야 한다.** -vit / -vērunt로 끝나면 1활용일 확률이 높다. [10/14 44:22] 퀴즈에서는 필요한 완료형을 사전형 힌트로 줬다 (`festīnō, festīnāre, festīnāvī`).
- 교수님이 말한 공부법: **"사전형으로 단어가 제시됐을 때 변화를 시켜 보실 수 있는 것을 목표로"** — 예: `portō, portāre, portāvī`를 주고 3인칭 복수 완료를 쓰라고 하면 portāvērunt. [10/14 48:10]
- **장단음은 특별히 강조하지 않는다**고 했고 [10/12 강의], 두 퀴즈 모두 장음 표시 없이 출제됐다. 장음 없는 문장을 읽는 연습을 해 둔다.
- 퀴즈에 **한국어 → 라틴어 작문**이 나왔다. 필수 어휘를 라틴어로 떠올리는 연습이 필요하다.

교수님이 퀴즈 두 개와 "유사하게(혹은 더 어렵게)" 출제한다고 했다. 두 퀴즈 42문항의 유형 분포는 아래와 같다. → 문항 원문과 정답은 [퀴즈 분석 ★절](퀴즈%20분석.md)

| 유형 | 퀴즈 문항 수 | 예 (퀴즈 원문) | 연습 |
| --- | ---: | --- | --- |
| **동사 형태 고르기** — 한국어 + 시제 → 알맞은 형태 | 17 | `coquus culinam ___.` 요리사가 부엌으로 들어가고 있었다. (미완료) → intrabat | 모의고사 1–10번 |
| **주어 고르기** — 동사 어미 → 주어 | 6 | `___ ad forum venio.` → ego | 모의고사 11–16번 |
| **형용사·명사 일치 고르기** | 4 | `ancilla erat ___.` → irata | 모의고사 17–22번 |
| **형태 직접 쓰기** (단답) | 11 | `puer ad villam ___.` (미완료) * festīnō … → festinabat | 모의고사 23–32번 |
| **해석** | 2 | `puer et puella ad forum ambulabant.` | 모의고사 33–36번 |
| **작문** (한국어 → 라틴어) | 2 | 하녀는 외침을 들었다. (완료) → ancilla clamorem audivit | 모의고사 37–40번 |

- 퀴즈에 **없었던** 유형: 원형 복원, 단어 뜻 쓰기, 변화 종류 이름 대기. 과거 Oxford 기출에는 있었으므로 "더 어렵게" 낼 때 섞일 수 있다. → [모의고사 2회](모의고사/모의고사%202회.md) 11–16번, 23–34번
- 과거 기출의 번역 감점 기준: **주어를 빠뜨리면 감점, 단·복수를 틀리면 단어마다 감점.** 올해는 여기에 **시제**가 더해진다.
- 과거 기출의 "목적격" = **대격**이다.

## 4. 체크리스트

### 명사 · 형용사
- [ ] 주격 = 주어·est 뒤 보어, 대격 = 목적어 (대격 단수는 항상 -m)
- [ ] porta · amīcus · puer · dōnum · rēx의 주격 단수, 대격 단수, 주격 복수
- [ ] 3변화 사전형에서 어간 찾기 (mercātor, mercātōris → mercātōrem)
- [ ] 1변화 남성 (agricola), 5변화 rēs (rem)
- [ ] magnus, -a, -um 주격·대격·복수 주격, 명사 + 형용사 일치 (magnum canem, agricolam fortem)
- [ ] 필수 명사 34개의 변화 종류와 성

### 동사
- [ ] **동사 8칸** — 현재 1·2·3인칭 단수 + 3인칭 복수, 미완료 3인칭 단·복수, 완료 3인칭 단·복수 ([02 §0](문법/02%20동사%20활용.md))
- [ ] 현재 인칭어미 -ō -s -t -nt (1·2인칭 복수 -mus -tis는 표에만 나왔다 → 참고)
- [ ] 1·2·3·3-io·4활용 현재 4칸 + 부정사 (3인칭 복수 -ant / -ent / -unt / -iunt)
- [ ] 미완료 -bat / -bant, 활용별 연결 모음 (-ābat / -ēbat / -ēbat / -iēbat)
- [ ] 완료 -it / -ērunt (완료 어간은 사전형 세 번째 형태에서)
- [ ] sum: sum, es, est, sunt / 미완료 erat, erant
- [ ] 기본어 네 형태의 이름과 쓰임
- [ ] 현재·미완료·완료 구분 (portat / portābat / portāvit)
- [ ] 사전형 읽기: 부정사로 활용 종류, 세 번째 형태로 완료 어간 (scrīpsī → scrīpsit). 자주 보는 불규칙 완료(stetī, cucurrī, ēgī, vīdī, vēnī, ēmī)는 눈에 익혀 둔다
- [ ] 미완료와 완료의 뜻 차이 (동영상 / 스틸 사진)

### 그 밖
- [ ] 전치사 + 격: in·ē/ex + 탈격, ad·per + 대격
- [ ] est: "\~이다" / "\~에 있다"
- [ ] 의문사 cūr, quis, quid, ubi · ego / tū
- [ ] 접속사 postquam, quod, et, sed
- [ ] 필수 어휘 110단어 뜻

### 4.1 사전형 읽는 법

문제에 단어가 사전형으로 주어지면 아래 순서로 읽는다.

| 품사 | 사전형 | 읽는 법 |
| --- | --- | --- |
| 명사 | `mercātor, mercātōris, m.` | 두 번째 형태 끝으로 변화 종류: **-ae** 1변화 · **-ī** 2변화 · **-is** 3변화. 3변화는 **-is를 떼면 어간** → mercātōr**em**, mercātōr**ēs** |
| 동사 | `scrībō, scrībere, scrīpsī` | **부정사**로 활용 종류: -āre 1 · -ēre 2 · -ere 3 · -īre 4. 부정사에서 -re를 떼면 현재 어간 → scrībē**bat**. **세 번째 형태에서 -ī를 떼면 완료 어간** → scrīps**it**, scrīps**ērunt** |
| 형용사 | `magnus, magna, magnum` · `fortis, forte` | 남성·여성·중성 주격. 둘뿐이면 3변화 형용사 |

## 6. 단기 학습법 (10/14 → 10/19)

시험은 **읽고 알아보는 능력보다 직접 만들어 내는 능력**을 묻는다 (퀴즈 42문항 중 형태 쓰기·작문·고르기가 대부분). 교수님도 "사전형을 보고 스스로 변화시켜 보는 연습"을 공부법으로 제시했다. 그래서 눈으로 다시 읽기보다 **빈 종이에 직접 써 보고 맞춰 보는 방식**이 가장 효율적이다.

### 6.1 매일 하는 세 가지

### 6.3 시험장에서

- **동사 빈칸:** ① 시제 표시(현재/미완료/완료) 확인 → ② 주어가 ego / tū / 단수 / 복수 중 무엇인지 → ③ 어미 결정 (-ō / -s / -t / -nt · -bat / -bant · -it / -ērunt)
- **주어 고르기:** 동사 어미에서 거꾸로 간다. -nt면 복수 주격, -ō면 ego, -s면 tū
- **형용사 빈칸:** 꾸미는 명사(또는 est의 주어)의 **성·수·격**을 먼저 적고 고른다. 명사의 변화 종류가 아니라 성을 본다 (agricola → īrātus, ancilla → īrāta)
- **해석:** 주어를 빠뜨리지 말고, 단·복수와 시제("\~하고 있었다" / "\~했다")를 살린다
- **작문:** 주어(주격) → 목적어(대격) → 동사 순서로 쓰고, 마지막에 동사 어미와 시제를 한 번 더 확인한다
- 장음 표시는 없어도 된다. 대신 장음 없이 같은 모양이 되는 형태(venit / vēnit)는 **시제 정보**로 판단한다
