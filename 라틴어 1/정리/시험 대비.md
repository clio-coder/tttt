## 2. 예상 출제 유형 (과거 기출 기준)

과거 기출은 Oxford 교재를 쓰던 시기의 것이라 **형식만 참고**한다. [과거 Oxford 자료/시험 형식 참고]

| 유형 | 과거 기출 예 (2022 중간) | 배점 | 요령 |
| --- | --- | --- | --- |
| ① 문장 번역 | `casam intrant.` → | 1문항 3점 | **주어 빠뜨리면 −1**, **단·복수 틀리면 단어마다 −1**, 한 단어 틀릴 때마다 −1 |
| ② 원형 복원 | `clamamus` → clamo, `terris` → terra | 1문항 1점 | 명사 = 단수 주격 / 동사 = **직설법 현재 능동태 1인칭 단수** / 형용사 = 남성 단수 주격 |
| ③ 어형 변화 + 뜻 | `rogo 3인칭 복수` → rogant / 뜻 | 형태 1점 + 뜻 1점 | 기출의 "목적격" = **대격**, "소유격" = **속격** |
| ④ 단어 뜻 | `iterum` → | 1문항 1점 | Vocabulary checklist 중심 |

- 기출 번역 문제는 대부분 **주어가 생략된 짧은 문장**이었다 (`saepe rogatis.` 너희는 자주 묻는다). **동사 어미로 주어를 채워 넣는 연습**이 핵심이다.

## 3. 체크리스트

### 문법 (1순위)
- [ ] 6격 이름과 용법 — [01 명사 1절](문법/01%20명사%20격변화.md)
- [ ] 주격 ↔ 대격 구분 (대격 단수 -m) ★★★
- [ ] 1변화 porta 표 · 1변화 남성 명사 (poēta, agricola, nauta)
- [ ] 2변화 amīcus 표 · puer 형 · 중성 dōnum 표 (주격 = 대격)
- [ ] 3변화 rēx 표 · 대격 -em으로 어간 찾기 (31개 목록)
- [ ] 복수 주격 -ae / -ī / -ēs ★★★
- [ ] 인칭어미 -ō -s -t -mus -tis -nt ★★★
- [ ] 1·2·3·3-io·4활용 현재 6칸 ★★★
- [ ] sum 6칸 (+ adsum, absum)
- [ ] 활용 종류 판별 (2인칭 모음, 3인칭 복수)
- [ ] 동사 원형 목록 (1인칭 단수) — [02 동사 9절](문법/02%20동사%20활용.md)
- [ ] 형용사 성·수·격 일치 (magnum canem 함정) ★★★
- [ ] 전치사 in / ad / ē (+ prope, per, dē) 뒤의 격
- [ ] est: "~이다" vs "~에 있다"
- [ ] 의문사 cūr, quis, quid, ubi · ego / tū / mē / tē
