### 5변화 (속격 -eī) — 1개

| 사전형 | 뜻 | 대격 단수 | 주격 복수 | Stage |
| --- | --- | --- | --- | :---: |
| rēs, reī, f. | 것, 사물, 일 | rem | rēs | 6 |

- **agricola**는 1변화지만 **남성**이다.
- **canis, iuvenis, senex**는 남성·여성 모두로 쓰인다 (m./f.). 슬라이드에서는 c.(공성)로 적기도 했다. [L08 · L10 p20]
- **rēs**는 5변화라 변화표를 배우지 않았다. 사전형 `rēs, reī, f.`와 대격 `rem`만 알아 둔다 (`rem probat`, `tōtam rem nārrāvit`).
- 3변화는 속격에서 `-is`를 떼어 어간을 찾는다: pater → patr-, mercātor → mercātōr-, senex → sen-, clāmor → clāmōr-.
- 중성(vīnum, forum)은 주격과 대격이 같고 복수는 `-a`다.

## 6. 헷갈리기 쉬운 것

| 함정 | 설명 |
| --- | --- |
| **현재와 완료가 같은 모양** | `bibit`(마신다 / 마셨다), `contendit`(서두른다 / 서둘렀다)는 3인칭 단수에서 현재와 완료가 같다. 문맥으로 판단한다. |
| **장음 하나 차이** | `venit` 온다 ↔ `vēnit` 왔다 · `emit` 산다 ↔ `ēmit` 샀다 |
| **2활용 완료 -it** | `respondet` 대답한다 ↔ `respondit` 대답했다 · `sedet` ↔ `sēdit` · `videt` ↔ `vīdit` |
| **stō는 1활용인데 완료가 stetī** | -āvī가 아니다. `stat` 서 있다 → `stetit` 섰다 |
| **currō → cucurrī** | 첫 음절이 중복된다. `currit` → `cucurrit` |
| **reddō, vēndō → -didī** | `reddidit`, `vēndidit` |
| **agō → ēgī** | 어간 모음이 바뀐다. `agit` → `ēgit` |
| **sum 계열** | sum → fuī, adsum → adfuī, absum → āfuī. 미완료는 erat, aderat, aberat |
| **inquit** | 결여 동사라 이 형태로만 쓴다. "말한다"와 "말했다" 모두 된다. |
| **뜻이 비슷한 동사** | contendō 서두르다, 향하다 ↔ festīnō 서두르다 · spectō 바라보다, 구경하다 ↔ videō 보다 · petō 향하다, 공격하다, 구하다 ↔ quaerō 찾다, 구하다, 묻다 |
| **뜻이 비슷한 명사** | servus 노예 ↔ lībertus 해방 노예 · ancilla 여자 노예 ↔ fēmina 여자 ↔ puella 소녀 · clāmor 소음, 외침 ↔ clāmō 소리치다 |
| **quod / quoque / quis** | quod \~때문에 · quoque 또한 · quis 누구 |
| **tum / tū / tuus** | tum 그때 · tū 너 · tuus 너의 |
