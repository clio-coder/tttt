# 04 문장 구조 · 전치사 · 의문사

> 범위: Stage 1–5 · 문장을 해석할 때 필요한 뼈대를 모았다.

---

## 1. est의 두 가지 쓰임 ★★★ [L01 p25, p28 · L02 p3–6] · 반복: L03

### 1.1 계사 — "~이다" (주격 보어)

`Metella est māter.` — 메텔라는 어머니다.

| 성분 | 역할 | 격 |
| --- | --- | --- |
| Metella | 주어 (subject) | 주격 |
| est | **계사** (copula): 주어와 보어를 연결 | – |
| māter | **주격 보어** (subject complement) | **주격** |

- 보어도 **주격**이다. `est` 뒤의 명사를 대격으로 착각하지 않는다.
- 계사 문장은 앞뒤를 바꿔도 뜻이 같다: `ancilla est Melissa.` = `Melissa est ancilla.` [L05 p9]

### 1.2 존재 — "(~에) 있다" (장소)

`canis est in viā.` — 개가 거리에 있다.

| 성분 | 역할 |
| --- | --- |
| canis | 주어 |
| est | 주어와 술어적 표현을 연결한다는 점은 같지만, **"있다"로 번역** |
| in viā | 장소·위치를 나타내는 **전치사구** |

- `Grumiō nōn est in culīnā.` — 그루미오는 부엌에 없다.

## 2. 어순과 문장 성분 ★★★

- 기본 어순은 **주어 – (목적어) – 동사**다. 한국어처럼 동사가 끝에 오는 경우가 많다.
  - `Caecilius pecūniam numerat.` 카이킬리우스는 돈을 센다.
- 하지만 **격어미가 역할을 정하므로** 어순이 바뀌어도 뜻은 같다.
  - `Metellam amīcus salūtat.` = `amīcus Metellam salūtat.` 친구가 메텔라에게 인사한다.
- **해석 순서:** ① 동사를 찾는다 → ② 주격(주어)을 찾는다 → ③ 대격(목적어)을 찾는다 → ④ 전치사구·부사를 붙인다
- 인용문에서는 동사가 주어 앞에 오기도 한다: `"salvē!" respondet Pantagathus.`

### 자주 나오는 작은 단어

| 단어 | 뜻 | 위치·용법 |
| --- | --- | --- |
| nōn ✔ | ~않다 | 동사(또는 est) **바로 앞**: `Caecilius nōn est laetus.` |
| et ✔ | 그리고 | 두 문장·단어 연결: `Clāra Quīntum salūtat et vīllam intrat.` |
| sed ✔ | 그러나 | 문장 맨 앞: `sed tōnsor nōn rīdet.` |
| quoque ✔ | ~도, 또한 | **꾸미는 단어 바로 뒤**: `Barbillus quoque intrat.` 바르빌루스**도** 들어간다 |
| tamen ✔ | 그러나, 그럼에도 | 보통 **두 번째 자리**: `urbs tamen nōn est quiēta.` |
| ecce! ✔ | 봐라! | 감탄 |
| subitō | 갑자기 | 문장 앞 |
| hodiē ✔ | 오늘 | |
| mox | 곧 | |
| semper | 항상 | |
| cotīdiē | 매일 | |
| tandem | 마침내 | |
| intentē | 주의 깊게 | |
| ferōciter | 사납게 | |
| suāviter | 감미롭게 | |
| magnificē | 호화롭게, 훌륭하게 | |
| satis ✔ | 충분히; (감탄) 그만! | `satis! satis!` |

## 3. 전치사 ★★★ [L04 p32–34] · 반복: L05·L06 · 퀴즈: stage 3 quiz

> **핵심:** 전치사마다 뒤에 오는 **격이 정해져 있다.** `ad`는 대격, `in`·`ē`는 탈격.

| 전치사 | 뒤에 오는 격 | 뜻 | 수업 예문 |
| --- | --- | --- | --- |
| **in** | + 탈격 | ~안에, ~위에 | servus est in hort**ō**. / Metella est in culīn**ā**. / Clāra in triclīni**ō** labōrat. / magnus leō est in pictūr**ā**. / Herculēs quoque est in pictūr**ā**. |
| **ad** | + 대격 | ~로, ~쪽으로 | artifex ad vīll**am** ambulat. / Quīntus ad iānu**am** venit. / Metella artificem ad triclīni**um** dūcit. / Caecilius ad vīll**am** revenit. / fīlia ad triclīni**um** venit. |
| **ē** | + 탈격 | ~에서 (밖으로) | Caecilius surgit et ē tabern**ā** exit. |

### ad와 in의 차이 [L04 p33]

- `artifex ad vīllam ambulat.` 예술가가 **집으로** 걸어간다. (방향 → 대격)
- cf. `artifex in forō ambulat.` 예술가가 **포룸 안에서** 걷는다. (장소 → 탈격)

### 지문·어휘에 나온 전치사 (수업 슬라이드 밖)

| 전치사 | 격 | 뜻 | 예 |
| --- | --- | --- | --- |
| prope | + 대격 | ~근처에 | Melissa prope nāv**em** stat. [ōrnātrīx] |
| per | + 대격 | ~을 통과하여, ~을 따라 | turba per port**am** ruit. [āctōrēs] / puerī per vi**am** currunt. [Poppaea] |
| dē | + 탈격 | ~에서 아래로; ~에 관하여 | pāstōrēs dē mont**e** veniunt. [āctōrēs] |

- `in`은 **대격**과 쓰이면 "~안으로"라는 뜻이 된다 (Cambridge 어휘: in, on; into, onto). Stage 1–5 지문에서는 모두 탈격으로만 나온다. [참고]
- `ē`는 모음 앞에서 `ex`가 된다. [참고]

## 4. 의문문 ★★★ [L06 p27–28] · 반복: L07 · 퀴즈: stage 4 quiz

### 의문사

| 의문사 | 뜻 | 수업 예문 | 해석 |
| --- | --- | --- | --- |
| **cūr** | 왜 | cūr tū coquis? | 너는 왜 요리하니? |
| **quis** | 누가 (사람, 주격) | quis es tū? | 너는 누구니? |
| **quid** | 무엇을 / 무엇이 | quid tū habēs? | 너는 무엇을 가지고 있니? |
| **ubi** | 어디에 | ubi est mercātor? | 상인은 어디에 있니? |

- `quis`는 사람, `quid`는 사물에 쓴다. `quid`는 목적어(대격)로 자주 쓰인다: `quid tū dīcis?` 너 무슨 말을 하는 거니?
- `ubi`는 **"어디에"**다. "어디로"가 아니다.

### 의문사 없는 의문문

- 물음표(?)와 억양으로만 묻는다: `tū ānulum habēs?` 너는 반지를 가지고 있니? [Hermogenēs] / `tū es Pompēiānus?` 당신은 폼페이 사람이오? [in basilicā]

## 5. 호격 — 부르는 말 ★ [L02 p39]

- 호격은 대개 **주격과 형태가 같다**: `salvē, tōnsor!` 안녕하시오, 이발사! / `Lucriō! Lucriō!` / `Hermogenēs, quid tū in urbe agis?`
- 2변화 `-us`만 `-e`로 바뀐다: `amīcus` → `amīce` [L03 p11 표]
- 욕설·감탄: `pestis! furcifer!` 이 망할 놈! 악당! (둘 다 호격) [Cerberus]
- 인사: `salvē!` 안녕! (한 사람에게) · 수업 끝인사 `Valēte, discipulī et discipulae!` 잘 있어요, 학생 여러분! (여러 명에게)

## 부록: 발음과 음절 ★ [L01 p6–18]

> 시험 범위("어형 변화와 해석") 밖으로 보이지만, 본문 소리 내어 읽기(출석 참여)에 필요해서 짧게 적는다.

### 알파벳 [L01 p6–7]
- 라틴 알파벳은 21자(+ 그리스어 차용 Y, Z = 23자)다. 영어의 **J, U, W가 없다** (I가 j, V가 u·w 역할).

### 자음 [L01 p8–10]
| 글자 | 발음 | 예 |
| --- | --- | --- |
| c | 항상 [k] | cum, cīvis, facilis |
| g | 항상 [g] / gn = [ŋn] | glōria, magnus (mang-nus) |
| h | 항상 소리 냄 | hic, haec |
| i (자음) | [j] | iūstus(yustus), cuius(cui-yus), iam(yam) |
| qu | [kw] | quid, quoque |
| r | 굴려서 | Rōma |
| s | 항상 무성 [s] | sed |
| v | [w] | vīvō, vīnum (위눔), vīdī (weedee) |
| bs/bt | [ps]/[pt] | urbs, optiō |
| t | 항상 [t] | nātiōnem |
| ch, ph, th | 그리스어 차용 (χ, φ, θ) | chorus, philosophia, theātrum |

### 모음 [L01 p11–13]
- 장모음(ā ē ī ō ū)은 단모음보다 **약 두 배 길이**로 발음했다. 장음 표시는 뜻 구분에도 쓰인다 (`via` 주격 ↔ `viā` 탈격).

### 이중모음 [L01 p14–15]
| 이중모음 | 발음 | 예 |
| --- | --- | --- |
| ae | high의 [ai] | cārae, saepe |
| au | how의 [au] | aut, laudō |
| ei | eight의 [ei] | deinde |
| eu | e-u 각각 | seu |
| oe | boy의 [oi] | coepit, proelium |
| ui | u-i 각각 | huius, cui |
- 이중모음은 **장음절**로 취급한다. 이중모음이 아니면 두 음절로 나눈다: fu-it, frūctu-ī

### 음절 나누기 [L01 p16–17]
1. 붙어 있는 두 모음 사이에서 나눈다: de-a, de-ae
2. 모음 사이의 자음 하나는 뒤 음절로 간다: a-mī-cus
3. 모음 사이의 자음 둘 이상은 첫 자음 뒤에서 나눈다: mit-tō, ser-vā-re, cōn-sūmp-tus
4. 예외
   - 폐쇄음(p, b, t, d, c, g) + 유음(l, r)은 떼지 않는다: pa-trem, cas-tra
   - qu, ch, ph, th는 한 자음으로 친다: ar-chi-tec-tus, lo-quā-cem
   - 전치사 합성어는 전치사 뒤에서 나눈다: ab-est
