# 퀴즈 분석

> 수업 퀴즈를 네 종류로 나눠 정리했다. 확인 가능한 퀴즈는 문제와 정답을 모두 옮겼다.
> - **★ 교수님 출제 퀴즈 (Google Forms)** — stage 5 quiz(9/30)와 stage 1-6 복습 quiz(10/14)는 문항을 확인했다. **"시험이 이와 유사하게(혹은 더 어렵게) 출제된다"**고 했으므로 가장 중요한 자료다. → ★절
> - **수업 중 퀴즈** (stage 1–2, 3, 4, 6) — 문제를 확인할 수 없다. 범위만 추정한다. → 1절
> - **슬라이드에 링크된 온라인 퀴즈** (Cambridge MyCLC) — 전부 확인했다. → 2절
> - **읽기 자료 페이지에 딸린 추가 퀴즈** (Stage 3–6) — 슬라이드에서 직접 링크하지는 않았다. → 0절, 3–4절

### ★.3 두 퀴즈에서 읽히는 출제 방식

| 유형 | 문항 수 (두 퀴즈 합계 42) | 핵심 기술 |
| --- | ---: | --- |
| 동사 형태 고르기 (한국어 + 시제 → 인칭·수·시제) | 17 | 주어(ego / tū / 단수 / 복수)와 시제 표시를 보고 어미 결정 |
| 주어 고르기 (동사 어미 → 주어의 인칭·수·격) | 6 | -ō → ego, -s → tū, -t → 단수 명사, -nt → 복수 주격 |
| 형용사·명사 일치 고르기 | 4 | 꾸미는 명사의 성·수·격 (ancilla → īrāta, cēnam → optimam) |
| 형태 직접 쓰기 (단답) | 11 | 현재 3인칭 단·복수, 미완료·완료 3인칭, 형용사 일치. **힌트 없이** 써야 하는 필수 어휘가 많다 (labōrat, sedet, īrātus, multī, amīcī, dormiunt) |
| 해석 | 2 | 시제(미완료 "\~하고 있었다")와 단·복수, 형용사 일치 |
| **작문** | 2 | 필수 어휘로 짧은 문장 만들기. intrō + 대격, 대격 목적어, 완료형 |

- 동사는 **현재 1·2·3인칭 단수와 3인칭 복수, 미완료·완료 3인칭 단·복수**만 나왔다. 10/14 강의에서 "이 수업에서 배운 인칭은 1인칭 단수, 2인칭 단수, 3인칭 단수, 3인칭 복수 네 가지"라고 한 것과 같다. [10/14 강의 21:28]
- 명사는 **주격 단수 · 대격 단수 · 주격 복수**만 나왔다.
- 3변화 명사나 불규칙 완료형처럼 규칙으로 만들 수 없는 형태는 **사전형을 힌트로 줬다** (leo, leonis, m. · festīnō, festīnāre, festīnāvī). 반면 1·2변화 명사·형용사와 현재형은 힌트 없이 물었다.
- 교수님이 "시험은 이와 유사하게(혹은 더 어렵게)"라고 했으므로, 이 형식으로 만든 연습 세트를 [모의고사](모의고사/모의고사%201회.md)에 두었다.

## 4. Stage 6 퀴즈 — 시제 (읽기 자료 페이지 [stage-6](https://myclc.co.uk/book-1/stage-6), 슬라이드 직접 링크 없음)

### 4.1 시제 분류 — Which tense? · [링크](https://files.cambridgescp.com/MyCLC/SortingWords/UK5sw.html?file=uk5_sw06_whichtense)

| 미완료 Imperfect | 완료 Perfect |
| --- | --- |
| portābat, postulābat, lacrimābat, sedēbat | festīnāvit, agitāvit, nārrāvit, rogāvit |
| dormiēbat, bibēbat, **erat**, habēbat | audīvit, portāvit, pulsāvit, festīnāvit |
| dormiēbant, **erant**, portābant, sedēbant | intrāvērunt, audīvērunt, superāvērunt, laudāvērunt |

마지막 문제는 세 시제를 나눈다.

| 현재 | 미완료 | 완료 |
| --- | --- | --- |
| portat, dormit, sedent | erant, ambulābant, recitābat | intrāvit, pulsāvit, audīvērunt |

- **출제 포인트:** `-ba-`가 있으면 미완료, `-v-` + `-it` / `-ērunt`면 완료다. **erat / erant는 미완료**다.

### 4.2 단수 · 복수 분류 (과거 시제) — Singular or Plural? · [링크](https://files.cambridgescp.com/MyCLC/SortingWords/UK5sw.html?file=uk5_sw06_sorp)

| 단수 | 복수 |
| --- | --- |
| audīvit, portāvit, erat, salūtābat | ambulābant, salūtāvērunt, erant, dormiēbant |
| intrāvit, clāmāvit, scrībēbat, dormiēbat | vēndēbant, incitābant, laudāvērunt, festīnāvērunt |

- **출제 포인트:** 미완료는 `-bat` / `-bant`, 완료는 `-it` / `-ērunt`.

### 4.3 명사 · 동사 분류 — Nouns or verbs? (Stage 6) · [링크](https://files.cambridgescp.com/MyCLC/SortingWords/UK5sw.html?file=uk5_sw06_nounsorverbs)

| 명사 | 동사 |
| --- | --- |
| iānua, mercātor, coquus, pugna | aberat, parāvit, habeō, vēndēbat |
| lībertus, amīcus, fūr, soror | erant, festīnāvit, salūtāvērunt, quaesīvit |

### 4.4 어미 고르기 — Word Endings: Verbs (Stage 6) · [링크](https://files.cambridgescp.com/MyCLC/WordEndings/UK5we.html?fn=uk5_we06_verbs)

미완료(끝나지 않은 과거 동작: \~하고 있었다)와 완료(끝난 과거 동작: \~했다) 가운데 고른다.

| # | 문제 | 보기 |
| ---: | --- | --- |
| 1 | 상인이 포룸에서 걷고 있었다. | mercātor in forō ambulā(bat / vit). |
| 2 | 딸이 집으로 서둘러 가고 있었다. | fīlia ad vīllam festīnā(bat / vit). |
| 3 | 아버지가 서재에서 일하고 있었다. | pater in tablīnō labōrā(bat / vit). |
| 4 | 아들이 음식을 준비하고 있었다. | fīlius cibum parā(bat / vit). |
| 5 | 은행가가 포룸에서 예술가에게 인사했다. | argentārius in forō artificem salūtā(vit / bat). |
| 6 | 소년들이 침실에서 자고 있었다. | puerī in cubiculō dorm(iēbant / īvērunt). |
| 7 | 갑자기 해방 노예들이 함성을 들었다. | subitō lībertī clāmōrem aud(īvērunt / iēbant). |
| 8 | 여자들이 울고 있었다. | fēminae lacrimā(bant / vērunt). |
| 9 | 도둑들이 돈을 요구했다. | fūrēs pecūniam postulā(vērunt / bant). |
| 10 | 상인들이 포도주를 나르고 있었다. | mercātōrēs vīnum portā(bant / vērunt). |

<details><summary>정답</summary>

1. ambulābat 2. festīnābat 3. labōrābat 4. parābat 5. salūtāvit 6. dormiēbant 7. audīvērunt 8. lacrimābant 9. postulāvērunt 10. portābant
— 한국어가 "\~하고 있었다"이면 미완료, "\~했다"이면 완료를 고른다. 7번처럼 `subitō`(갑자기)가 있으면 대개 완료다.

</details>
