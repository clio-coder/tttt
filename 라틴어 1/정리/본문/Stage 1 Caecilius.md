## 2. 대표 예문 — 모델 문장 [L01 p22–30]

모델 문장은 세 단계로 짜여 있다. 패턴별로 대표 예문을 골랐다.

| 패턴 | 예문 | 해석 |
| --- | --- | --- |
| ① A est B (계사) | Caecilius est pater. / Metella est māter. / Grumiō est coquus. | 카이킬리우스는 아버지다. / 메텔라는 어머니다. / 그루미오는 요리사다. |
| ② A est in 장소 (존재) | Caecilius est in tablīnō. / Metella est in ātriō. / Cerberus est in viā. | 카이킬리우스는 서재에 있다. / 메텔라는 아트리움에 있다. / 케르베루스는 거리에 있다. |
| ③ A in 장소 + 동사 | pater in tablīnō scrībit. / māter in ātriō sedet. / fīlius in triclīniō bibit. / fīlia in hortō legit. / servus in cubiculō labōrat. / canis in viā dormit. | 아버지는 서재에서 글을 쓴다. / 어머니는 아트리움에 앉아 있다. / 아들은 식당에서 마신다. / 딸은 정원에서 읽는다. / 노예는 침실에서 일한다. / 개는 거리에서 잔다. |

- 현재형은 두 가지로 번역한다: `canis in viā dormit.` 개가 거리에서 잔다 / 자고 있다. [L01 p31]

## 3. 교재 연습 — Complete and translate [L02 p11]

상자 안의 단어를 한 번씩 써서 문장을 완성하고 번역하는 문제다.
상자: `scrībit` · `in culīnā` · `fīlius` · `amīcus` · `legit` · `in viā`
예: `canis ... stat.` → `canis in viā stat.` 개가 거리에 서 있다.

| | 문제 |
| --- | --- |
| a | Grumiō ... cantat. |
| b | ... in hortō sedet. |
| c | mercātor in tablīnō ... |
| d | Cerberus ... dormit. |
| e | Metella in ātriō ... |
| f | ... in triclīniō cēnat. |

<details><summary>정답 예시</summary>

- a. Grumiō **in culīnā** cantat. 그루미오는 부엌에서 노래한다.
- b. **fīlius** in hortō sedet. 아들은 정원에 앉아 있다.
- c. mercātor in tablīnō **scrībit**. 상인은 서재에서 글을 쓴다.
- d. Cerberus **in viā** dormit. 케르베루스는 거리에서 잔다.
- e. Metella in ātriō **legit**. 메텔라는 아트리움에서 읽는다.
- f. **amīcus** in triclīniō cēnat. 친구는 식당에서 저녁을 먹는다.
- b와 f의 fīlius / amīcus, c와 e의 scrībit / legit은 서로 바꿔 넣어도 문법상 맞다.

</details>

## 4. 지문

### Cerberus — 교재 6쪽 · 과제 ✅ 9/7 · [L01 p18 · L02 p8] · [Explorer](https://files.cambridgescp.com/MyCLC/Explorers/UK5nexus.html?file=w5U01EX001)

**줄거리:** 가족들이 각자 방에 있는 동안 개 케르베루스가 부엌에 들어와 식탁 위에 뛰어오르고, 자던 요리사 그루미오가 깨어나 화를 낸다.

**문법 포인트:** `est in + 장소`(있다) vs `in + 장소 + 동사`, 모든 동사가 3인칭 단수 `-t`, 호격 `pestis! furcifer!`

**새 단어** (본문 등장 순, 1.1–1.2에 없는 것만)

| 본문 형태 | 원형 | 분석 | 뜻 |
| --- | --- | --- | --- |
| hortō | hortus | 2변화 단수 탈격 (in + 탈격) | 정원에서 |
| ātriō | ātrium | 2변화 중성 단수 탈격 | 아트리움에서 |
| tablīnō | tablīnum | 2변화 중성 단수 탈격 | 서재에서 |
| viā | via | 1변화 단수 탈격 | 거리에 |
| culīnā | culīna | 1변화 단수 탈격 | 부엌에 |
| mēnsā | mēnsa | 1변화 단수 탈격 | 식탁 위에 |
| pestis! furcifer! | pestis, furcifer | 호격 | 이 망할 놈! 악당 녀석! |

**문장별 해석**

| # | 시작 단어 | 핵심 분석 | 해석 |
| ---: | --- | --- | --- |
| 1 | Caecilius est… | est + in 장소 = 있다 | 카이킬리우스는 정원에 있다. |
| 2 | Caecilius in hortō… | in + 탈격 + sedet | 카이킬리우스는 정원에 앉아 있다. |
| 3 | Lūcia est… | | 루키아는 정원에 있다. |
| 4 | Lūcia in hortō… | scrībit 3활용 | 루키아는 정원에서 글을 쓰고 있다. |
| 5 | Metella est… | in ātriō | 메텔라는 아트리움에 있다. |
| 6 | Metella in ātriō… | legit 3활용 | 메텔라는 아트리움에서 (책을) 읽고 있다. |
| 7 | Quīntus est… | in tablīnō | 퀸투스는 서재에 있다. |
| 8 | Quīntus in tablīnō… | | 퀸투스는 서재에서 글을 쓰고 있다. |
| 9 | Cerberus est… | in viā | 케르베루스는 거리에 있다. |
| 10 | coquus est… | in culīnā | 요리사는 부엌에 있다. |
| 11 | coquus in culīnā… | dormit 4활용 | 요리사는 부엌에서 자고 있다. |
| 12 | Cerberus intrat. | 목적어 없이 "들어온다" | 케르베루스가 들어온다. |
| 13 | Cerberus circumspectat. | | 케르베루스가 둘러본다. |
| 14 | cibus est… | in mēnsā = 식탁 위에 | 음식이 식탁 위에 있다. |
| 15 | canis salit. | | 개가 뛰어오른다. |
| 16 | canis in mēnsā… | stat 1활용 | 개가 식탁 위에 서 있다. |
| 17 | Grumiō stertit. | | 그루미오는 코를 골고 있다. |
| 18 | canis lātrat. | | 개가 짖는다. |
| 19 | Grumiō surgit. | | 그루미오가 일어난다. |
| 20 | coquus est… | īrātus 주격 보어 (슬라이드 밑줄) | 요리사는 화가 났다. |
| 21 | "pestis! furcifer!"… | 호격 + clāmat | "이 망할 놈! 악당 녀석!" 요리사가 외친다. |
| 22 | Cerberus exit. | exit 불규칙 | 케르베루스가 나간다. |

> `in`은 "\~안에"뿐 아니라 "\~위에"도 된다: `in mēnsā` 식탁 **위에**.
