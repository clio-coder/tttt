## 2. 대표 예문 — 모델 문장 [L02 p13–35]

주격(인사받기 전)과 대격(인사받는 대상)을 짝지어 보여 준다.

| 주격 문장 | 대격 문장 | 변화 |
| --- | --- | --- |
| Caecilius est in ātriō. | amīcus **Caecilium** salūtat. | -us → -um |
| Metella est in ātriō. | amīcus **Metellam** salūtat. | -a → -am |
| fīlius est in ātriō. | amīcus **fīlium** salūtat. | -us → -um |
| fīlia est in ātriō. | amīcus **fīliam** salūtat. | -a → -am |
| canis est in ātriō. | amīcus **canem** salūtat. | -is → -em |
| coquus est in culīnā. | Metella **culīnam** intrat. | -a → -am |
| Grumiō labōrat. | Metella **Grumiōnem** spectat. | -ō → -ōnem |
| cibus est pāvō. | Metella **cibum** gustat. | -us → -um |
| amīcus est in hortō. | Metella **amīcum** vocat. | -us → -um |

- 해석: 친구가 카이킬리우스(메텔라, 아들, 딸, 개)에게 인사한다. / 메텔라가 부엌으로 들어간다. / 메텔라가 그루미오를 바라본다. / 음식은 공작새다 → 메텔라가 음식을 맛본다. / 메텔라가 친구를 부른다.
- 이 밖의 모델 문장: `Grumiō est anxius.` 그루미오는 걱정한다. / `Metella Grumiōnem laudat.` 메텔라가 그루미오를 칭찬한다.

## 3. 지문

> 분홍 밑줄은 **대격**을 표시한다 (L03 슬라이드 기준). 아래 분석에서 ★로 표시했다.

### 3.1 mercātor — 교재 24쪽 · 과제 ✅ 9/9 · [L03 p5–6] · [Explorer](https://files.cambridgescp.com/MyCLC/Explorers/UK5nexus.html?file=w5U02EX001)

**줄거리:** 상인 바르빌루스가 카이킬리우스를 찾아온다. 둘은 식당에 기대어 누워 저녁을 기다리고, 그루미오는 부엌에서 노래하며 공작새를 요리한다.

**새 단어**

| 본문 형태 | 원형 | 분석 | 뜻 |
| --- | --- | --- | --- |
| ★Caecilium | Caecilius | 2변화 단수 대격 | 카이킬리우스를 |
| ★vīllam | vīlla | 1변화 단수 대격 | 집으로 (intrat의 목적어) |
| ★mercātōrem | mercātor | 3변화 단수 대격 | 상인을 |
| ★pecūniam | pecūnia | 1변화 단수 대격 | 돈을 |
| ★tablīnum | tablīnum | 2변화 중성 단수 대격 (주격과 같은 형태) | 서재로 |
| ★triclīnium | triclīnium | 2변화 중성 단수 대격 | 식당으로 |
| lectō | lectus | 2변화 단수 탈격 (in + 탈격) | 긴 의자에 |
| ★pāvōnem | pāvō | 3변화 단수 대격 | 공작새를 |
| ★coquum | coquus | 2변화 단수 대격 | 요리사를 |
| ★cēnam | cēna | 1변화 단수 대격 | 저녁 식사를 |
| ★Grumiōnem | Grumiō | 3변화 단수 대격 | 그루미오를 |

**문장별 해석**

| # | 시작 단어 | 핵심 분석 | 해석 |
| ---: | --- | --- | --- |
| 1 | amīcus Caecilium… | Caecilium 대격 | 친구가 카이킬리우스를 방문한다. |
| 2 | amīcus est… | 계사 | 그 친구는 바르빌루스다. |
| 3 | Barbillus est… | mercātor 주격 보어 | 바르빌루스는 상인이다. |
| 4 | mercātor vīllam… | intrat + 대격 | 상인이 집으로 들어온다. |
| 5 | Clēmēns est… | in ātriō | 클레멘스는 아트리움에 있다. |
| 6 | Clēmēns mercātōrem… | 3변화 대격 | 클레멘스가 상인을 맞이한다. |
| 7 | Caecilius est… | in tablīnō | 카이킬리우스는 서재에 있다. |
| 8 | Caecilius pecūniam… | pecūniam numerat 돈을 세다 | 카이킬리우스는 돈을 세고 있다. |
| 9 | Caecilius est… | argentārius 주격 보어 | 카이킬리우스는 은행가다. |
| 10 | amīcus tablīnum… | 중성 대격 | 친구가 서재로 들어온다. |
| 11 | Caecilius surgit. | | 카이킬리우스가 일어난다. |
| 12 | "salvē!" Caecilius… | | "어서 오시오!" 카이킬리우스가 상인에게 인사한다. |
| 13 | "salvē!" mercātor… | mercātor 주격 | "안녕하시오!" 상인이 대답한다. |
| 14 | Caecilius triclīnium… | | 카이킬리우스가 식당으로 들어간다. |
| 15 | Barbillus quoque… | quoque = ~도 | 바르빌루스도 들어간다. |
| 16 | amīcus in lectō… | in lectō recumbit | 친구는 긴 의자에 기대어 눕는다. |
| 17 | argentārius in lectō… | | 은행가도 긴 의자에 기대어 눕는다. |
| 18 | Grumiō in culīnā… | | 그루미오는 부엌에서 노래한다. |
| 19 | Grumiō pāvōnem… | 3변화 대격 | 그루미오는 공작새를 요리하고 있다. |
| 20 | coquus est… | laetus 주격 보어 | 요리사는 기분이 좋다. |
| 21 | Caecilius coquum… | audit + 대격 = ~의 소리를 듣다 | 카이킬리우스는 요리사(의 노랫소리)를 듣는다. |
| 22 | Caecilius nōn est… | nōn은 동사 앞 | 카이킬리우스는 기분이 좋지 않다. |
| 23 | Caecilius cēnam… | exspectat + 대격 = ~을 기다리다 | 카이킬리우스는 저녁 식사를 기다린다. |
| 24 | amīcus cēnam… | | 친구도 저녁 식사를 기다린다. |
| 25 | Caecilius Grumiōnem… | 3변화 대격 | 카이킬리우스는 그루미오를 부른다. |

- 17·24번은 원문에 "~도"(quoque)가 없지만, 앞 문장과 이어서 자연스럽게 옮겼다. 직역하면 "은행가는 … 눕는다", "친구는 … 기다린다"이다.

### 3.2 in triclīniō — 교재 24쪽 · 과제 ✅ 9/9 · [L03 p15–16] · [Explorer](https://files.cambridgescp.com/MyCLC/Explorers/UK5nexus.html?file=w5U02EX002)

**줄거리:** 공작새 요리를 대접받은 주인과 손님이 포도주를 마시다 잠든다. 그 틈에 그루미오가 남은 음식을 먹고, 포파이아가 그루미오를 칭찬한다.

**새 단어**

| 본문 형태 | 원형 | 분석 | 뜻 |
| --- | --- | --- | --- |
| ★vīnum | vīnum | 2변화 중성 단수 대격 | 포도주를 |
| pāvō | pāvō | 3변화 단수 **주격** | 공작새(요리)가 |
| optimus | optimus | 형용사 남성 단수 주격 (최상급) | 최고의 |
| cēna | cēna | 1변화 단수 **주격** (주어!) | 저녁 식사가 |
| ★Barbillum | Barbillus | 2변화 단수 대격 | 바르빌루스를 |
| ★Poppaeam | Poppaea | 1변화 단수 대격 | 포파이아를 |
| ★cibum | cibus | 2변화 단수 대격 | 음식을 |
| ★ancillam | ancilla | 1변화 단수 대격 | 여자 노예를 |
| laetissimus | laetus | 형용사 최상급 남성 단수 주격 | 매우 기쁜 |

**문장별 해석**

| # | 시작 단어 | 핵심 분석 | 해석 |
| ---: | --- | --- | --- |
| 1 | Grumiō triclīnium… | 중성 대격 | 그루미오가 식당으로 들어온다. |
| 2 | Grumiō pāvōnem… | | 그루미오는 공작새를 나른다. |
| 3 | Clēmēns triclīnium… | | 클레멘스가 식당으로 들어온다. |
| 4 | Clēmēns vīnum… | 중성 대격 | 클레멘스는 포도주를 나른다. |

| 9 | dominus coquum… | | 주인이 요리사를 칭찬한다. |

| 14 | dominus Poppaeam… | 두 동사를 et로 연결 | 주인은 포파이아(의 노래)를 듣고 포도주를 마신다. |
| 15 | mox dominus… | | 곧 주인은 잠이 든다. |
| 16 | amīcus quoque… | | 친구도 잠이 든다. |
| 17 | Grumiō triclīnium… | intrat et circumspectat | 그루미오가 식당에 들어와 둘러본다. |

### 3.3 in culīnā — 교재 26쪽 (Practising the Language) · [L02 p40–44] · [Explorer](https://files.cambridgescp.com/MyCLC/Explorers/UK5nexus.html?file=w5U02EX003)
