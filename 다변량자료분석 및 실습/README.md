## 학습목표

다변량 자료 분석의 이론적 기초와 주요 분석 방법을 학습한다. 다변량 정규분포와 관련 분포 이론, 평균벡터와 공분산구조 추론, 차원축소 이론을 다루며, 주성분분석·인자분석·분류·판별분석·정준상관분석·군집분석·그래피컬 모델 등 다양한 방법을 실제 자료 분석에 적용하는 능력을 기른다.
